# research-33 — 미니멀 고객의 실행 문제 기반 시장 카테고리 재검토

상태: 내부 전략·비공개 검증 설계 / 2026-08-24

## 결론

첫 검증 카테고리는 **기내수하물 중심 장기여행 준비·이동 운영**으로 권고한다.

> 적은 짐으로 오래 이동할 때, 다시 싸고 다시 찾고 다시 사는 일을 줄이는 여행 운영.

이는 시장이 이미 검증됐다는 뜻이 아니다. 현재 자료에는 실제 첫 10명의 행동·가격·유료 전환 데이터가 없으므로, 별도 승인 후 비공개 실험에서 검증할 1순위 가설이다. `신혼·장기여행 준비`는 지불 맥락과 문제 비용이 커지는 진입 장면으로 활용하되, 일회성 허니문만을 독립 카테고리로 확정하지 않는다.

### 반증 가능한 검증 가설

`7~30일 기내수하물 중심 여행자`에게 수동 운영표와 7일 체크리스트를 제공하면, 10명 중 최소 4명이 출발 후 동일 유형의 준비 누락·재구매를 줄였다고 확인하고, 3명 이상이 같은 결과물을 재사용·재요청한다. 이 조건이 충족되지 않으면 카테고리 또는 제공 방식을 Continue로 승격하지 않는다.

### 카테고리명 후보 3개

1. **기내수하물 장기여행 운영** — 추천. 장면·제약·결과가 가장 구체적이다.
2. **장기여행 준비·이동 운영** — 신혼·장기체류까지 넓힐 때의 확장명.
3. **의도적 소비 판단 기록** — 구매 의사결정 후보의 좁은 이름. `미니멀 라이프 도구`보다 검증 가능하다.

## 역할별 판단과 synthesis

### Planner

취향 집단을 검증 대상에서 제외하고 `반복 실행 문제 → 관찰 행동 → 지불 주체`를 평가축으로 고정했다. 문제 비용·빈도, 4주 관찰성, 접근성, 지불 주체, 위험, 차별화를 함께 봐야 한다.

### Developer

앱·자동화 없이 여행 1건당 폼 1개, 개인별 `버릴 것·대체할 것·반드시 챙길 것` 목록, 출발 전 7일 체크리스트, 1회 중간 확인, 종료 회고만으로 첫 가치가 관찰된다. 최소 입력은 여행 기간의 범주, 기내수하물 여부, 여행자 수의 범주, 주요 준비 문제다.

### Marketer

`미니멀한 사람을 위한 앱` 대신 `이번 여행에 필요한 것만 결정하고 다시 싸는 일을 줄인다`를 사용한다. 좋은 신호는 호감·조회가 아니라 실제 항목 제공, 결과물 재사용, 자기 말로 가치 설명, 기존 무료 대체재보다 계속 쓰겠다는 선택, 구체적인 가격 조건이다. 가격·경쟁 사업자 데이터가 없는 부분은 가설로 남긴다.

### Operator

이번 Intent 권한으로 실제 모집·발송·결제·지불 의향 검증을 실행할 수 없다. 따라서 현재 결론은 시장성보다 **운영 준비도와 다음 승인 조건**에 한정한다. 정확한 위치·숙소·항공권·여권·계정·건강·소득·가족 정보는 받지 않는다. 예약·구매·비자·수하물 규정을 확정적으로 보증하지 않으며, 공식 원문이 필요한 내용은 링크와 확인 시각을 붙인다.

### 종합 결정

네 역할의 충돌은 `반복성·확장성`(Planner/Developer)과 `지불 맥락`(Marketer) 사이에 있다. 이를 합쳐 **기내수하물 중심 장기여행 운영**을 첫 카테고리로 택한다. 신혼·장기여행은 고비용 장면으로 포함하되, 일회성 특수성 때문에 별도 시장으로 확정하지 않는다. 소상공인 운영은 동일 평가축의 대조군으로 남긴다. 의도적 소비와 공공정보는 후속 후보이며, 이번 4주 실험의 병렬 실행 대상으로 늘리지 않는다.

## 별도 승인 후 4주 비공개 검증안

### 범위

- 7~30일 여행, 기내수하물 중심, 출발 전 준비 문제 1개
- 1차 5명 → 체크리스트 구조만 수정 → 5명 추가
- 기존 관계망의 비공개 참여자만. 공개 게시·광고·외부 발송은 별도 승인 전 금지
- 코드·앱·API·결제·예약 대행 없음

### 주차별 실행

1. **1주차**: 최근 여행에서 누락·재구매·초과수하물·준비 지연의 실제 기준선을 기록하고 대표 지표를 고정한다.
2. **2주차**: 수동 체크리스트와 짐 축소·이동 운영표를 제공하고 운영자 처리시간과 참여자 선택을 기록한다.
3. **3주차**: 동일 흐름의 재사용·재요청을 관찰한다. 변경 축은 체크리스트 구조 또는 전달 방식 중 하나만 바꾼다.
4. **4주차**: 출발 후 누락·재구매·불필요품과 다음 여행 재사용 의향을 확인하고, 실제 결제 없이 가격 조건을 인터뷰한다.

### 대표 지표와 판정

대표 지표는 **실행 개선률** = 유효 참여자 중 최소 한 가지 준비 문제를 해결하고 출발 후 같은 유형의 누락·재구매가 줄었다고 확인된 비율이다. 열람·좋다는 말·제작자가 유도한 클릭은 제외한다.

수동 비용 판정은 `case 처리시간 ≤ 15분`, `주간 총 운영시간 ≤ 2시간`을 상한으로 둔다. 두 상한을 넘고도 유효 참여자 2명당 최소 1건의 실제 문제 개선이 확인되지 않으면 `Hold`다. 가격 질문·가상의 금액·예약 의향은 지불 증거가 아니며, 실제 결제는 별도 승인 범위다.

- **Continue**: 10명 중 4명 이상이 실제 문제를 해결하고, 3명 이상이 재사용·재요청하며, 신뢰·개인정보·안전 오류 0건, 수동 제공 시간이 가치보다 작음.
- **Change**: 실행은 있으나 특정 여행 유형에만 유효하거나 운영 시간이 과다함. 변경 축 1개만 바꿔 2주 재검증.
- **Hold**: 실제 출발·행동 증거가 5명 미만이거나 콘텐츠 호감만 남음, 반복 문제보다 취향이 주된 이유, 또는 승인된 참가자 데이터가 없음.
- **Crash**: 위치·PII 노출, 잘못된 이동 지시, 최신성 충돌을 확인하지 않은 사용, 승인 범위 초과, 수동 복구 불가.
