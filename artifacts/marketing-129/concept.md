# Instagram first-slide concept — `적게 들고, 오래 남기기`

## Deliverable

- `world-travel-instagram-first-slide.png` — 1080×1350, RGB PNG, 4:5.
- `travel-record-base.png` — 텍스트 없는 생성 베이스 보존본.

## Design decision

상단의 넓은 warm-ivory 여백과 먹색 두 줄 훅으로 모바일 첫 1–3초의 읽힘을 우선했다. 열차 창가의 노트·카메라·태그는 여행을 인증하는 소품이 아니라 기록의 재료로만 두었고, 장소명·날짜·로고·관광지 콜라주를 배제했다. 하단의 작은 `여행에서 남기는 기록`은 메인 훅보다 한 단계 낮은 위계다.

## Boundary

이 이미지는 내부 산출물이다. Instagram 게시, 계정 연결, 예약, API 호출, 캡션·해시태그 작성은 수행하지 않았다.
