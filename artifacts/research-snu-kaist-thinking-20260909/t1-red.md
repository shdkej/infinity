# T1.2 Red 검증 — 비교 틀의 편견·인과 과장

- **판정:** PASS
- **검증 시각:** 2026-09-09T23:50:00Z
- **검증자:** Red 역할 에이전트

## 요청 일치성

이 조사는 서울대·KAIST 출신의 타고난 집단 특성이나 우열을 판정하지 않는다. 비교 가능한 범위는 제도적 affordance와 조건부 경험 패턴이며, 학교 라벨은 인과 원인으로 사용하지 않는다.

## 통과한 검증

1. **고정관념·프레스티지:** ‘서울대형/KAIST형 사고’, IQ·성격·계급·우열 서사를 제외했다.
2. **인과:** 선발·자기선택, 교육 경험, 졸업 후 환경을 분리하고, 반사실 또는 준실험 없이는 인과를 주장하지 않는다.
3. **출처 범위:** 공식 학사 페이지는 제도 구조만, 일반 고등교육 연구는 통제 필요성만 뒷받침한다.
4. **의존성:** T1.1 증거를 검토했으며, 이 PASS 기록 뒤에만 T1.3을 활성화할 수 있다.

## 유지할 한계

- 공식 교육과정 페이지는 개별 학생의 실제 노출이나 사고 결과를 증명하지 않는다.
- 일반·해외 고등교육 연구는 서울대–KAIST 효과의 크기나 방향을 추정하지 않는다.
- 설문·인터뷰는 가설 생성 또는 조건부 기술이며, 응답·회상 편향을 가진다.
- 졸업 후 직무·지역·네트워크는 질문에 따라 매개변수일 수 있으므로 총효과 분석에서 무심코 통제하지 않는다.
- 직접 비교 자료가 없는 현재의 기본 결론은 **학교별 사고 차이 확인 불가**다.
