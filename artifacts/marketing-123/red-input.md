# Red input — marketing-123

- 요청 일치성: Waiting이던 `marketing-123`을 실제 진행시키되, 여행 대시보드/Notion에 있는 실제 구매물 기준으로 첫 상품 3개 후보·초안·게시 단위를 보정했는가
- 실제 구매 근거가 없는 기존 후보를 추천 후보로 남기지 않고, 찾지 못했다고 명확히 말했는가
- 세 후보가 여행 대시보드/Notion-synced expense 근거를 갖고 있으며 실제 사용 후기·성과·가격 안정성을 발명하지 않는가
- 경제적 이해관계 고지가 공식 링크보다 앞선가
- 사용자 승인·회원 화면 self-check·Red pass 전 공개 행동이 차단되는가
- `첫 상품 3개`와 `7일 21개 게시물`의 관계가 명확히 결정됐는가
- 다음 액션이 계정 화면 self-check와 승인 요청으로 이어지는가

예상 판정: 공개 발행은 여전히 승인 대기지만, 무발행 준비 패키지는 `PASS` 가능해야 한다. Red는 "방향이 맞나? -> 다음 액션이 있나? -> 선택이 맞나? -> 요청과 맞나?" 기준으로 가장 큰 위험만 지적한다.
