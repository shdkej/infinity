# marketing-123 approval request

공개 행동은 아직 하지 않는다. 이 문서는 사용자 승인 전에 필요한 선택지를 고정한다.

## Ready package

- C01: 여행용 파우치와 칫솔
- C02: 여행용 멀티플러그와 종이세제
- C03: 손톱깎이, 수건, 빨랫줄

기존 후보였던 `여행용 압축파우치`와 `접지형 65W GaN 3포트 충전기`는 여행 대시보드/Notion 지출에서 실제 구매 근거를 찾지 못해 제외했다.

## User account self-check

토스쇼핑 Sharelink 회원 화면에서 아래만 확인한다.

- 위 3개 후보 또는 유사 대체 상품이 각각 공식 Sharelink로 발급 가능한가
- 발급 링크가 상품 상세 단위인지 검색/카테고리 단위인지
- 화면에 표시되는 수수료, 정산, 고지, 금지 조건이 기존 가이드와 충돌하지 않는가
- 가격, 옵션, 재고, 배송, 환불 조건이 공개 초안과 충돌하지 않는가

## Approval boundary

승인 문장 예:

```text
marketing-123: 실제 여행 준비 구매물 3개 기준으로 공식 Sharelink 발급 후 Threads 초안 3개 공개 게시 승인
```

승인 전 금지:

- Threads 공개 게시
- 공식 링크 공유
- 댓글/DM/메일/업로드/광고 집행
- 계정 설정 또는 공개 범위 변경
- 구매, 결제, 정산 정보 저장
