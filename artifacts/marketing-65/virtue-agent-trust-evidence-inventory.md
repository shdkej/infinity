## 신뢰 구조 전제 (공통)

Virtue는 **외부 자율 행동 없음** AI 판정 제품이다.
- AI는 판정/관점만 보여주고, 모든 최종 선택은 사용자에게 있다.
- 저장 비강제 / 무시 비용 0 / 외부 효과 0
- 위험의 본체: 행동적 해가 아니라 **자기인식 오보정** (AI 판정을 사실/결론으로 읽는 것)
- 동사 프레임 기준: `채점`/`판정` (판결) vs `본`/`읽은`/`보여주기` (관점) — 관점 프레임 우선 (marketing-45)
- 에이전트가 자율 외부 행동을 하지 않으므로 agentic guardrail/monitoring/accountability 플레이북은 적용 안 함 (marketing-38)

| **개인정보/저장 경계** | 로컬 저장, 외부 전송 없음, 저장 전 데이터 영구 보관 없음 | 로컬 누적 저장, 외부 공유 없음, 집계는 로컬 | 처리 후 미저장 시 영구 보관 없음, 판정 데이터 외부 전송 없음 | 명시 저장 선택 후 영구 보관, 삭제 옵션 존재 |
| **비추천 상황** | 법적/의료/도덕 판단 대체, 타인 평가, 사실 확인 도구 | 단기 표본으로 성격/능력 결론 도출, 외부 기준 비교 | 전문가 판단 대체, AI 판정을 공개 자료/사실로 사용 | 민감 정보 영구 저장, 타인 관련 주석, 공개/공유 자료 활용 |

## 잡별 신뢰 보정 역할 요약 (marketing-24 기반)

| 잡 | 신뢰 보정 역할 | 특이점 |
|----|--------------|--------|
| **J1** | 통과점 — 저장 전 판정은 중간 신호 | 저장 = 통과 완료 |

| **J3** | 본체 (신뢰 진폭 최대) — 판정 자체가 first value | 저장 없이 종료 = 정상 성공, 불신·과신 모두 가장 민감 |
| **J4** | 영구 주석 — 저장 전 신중한 선택이 신뢰의 핵심 | 되돌리기 가능(수정/삭제) |
