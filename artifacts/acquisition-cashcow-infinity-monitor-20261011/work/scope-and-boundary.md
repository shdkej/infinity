# T1.1 기존 후보·예산 기준과 Infinity 실행 범위

## 확인 기준

- 기존 Archive `acquisition-cashcow-research-20261010`은 공개 후보 10개를 비교했지만 직접 상세·owner hours·transfer scope 부족으로 4점 이상 후보를 확정하지 않았다.
- 이번 후속 범위는 이전 결과를 중복 확정하지 않고, Fello·Listing·Sellernet·Flippa·Empire Flippers·Quiet Light·Acquire의 공개 목록을 페이지 단위로 재순회해 새 후보와 기존 후보의 변경을 식별한다.
- 예산 상한은 표시 가격 기준 3천만원 이하이며, 원화 환산이 없거나 통화가 불명확하면 `capital_risk`와 `budget_status: unknown`으로 둔다. 환율 추정으로 통과시키지 않는다.

## 증거 계약

후보별 `source_url`, 확인 시각 UTC, 사이트·페이지/커서, 표시 가격·통화, 매출·이익·기간/정의, owner hours/운영 부담, 기술·플랫폼 의존, fit 상태, 중복 키, 접근 제한/실패 사유를 기록한다. 판매자 주장과 독립 확인을 분리하고 직접 원문이 없으면 보류한다.

## 보호 경계

허용: 로그인 없이 접근 가능한 공개 페이지 읽기, 기존 승인된 Notion DB의 스키마·행 존재 확인, 로컬 실행 경로·중복 방지·실패 기록 검증.

금지: 판매자 연락, 구매·계약·결제, 비공개 자료 요청, 로그인·시크릿 변경, 새 스케줄 등록, 공개 발송, 승인되지 않은 Notion schema/권한 변경.

## 완료 기준

T1.2는 페이지 종료/접근 제한을 포함한 순회 인벤토리를 만들고, T1.3은 실제 Notion 행·필드 반영을 확인한다. T2.1은 재실행 명령과 중복/실패 기록을 확인하며, T2.2는 Red PASS와 원격 SHA를 남긴다.
