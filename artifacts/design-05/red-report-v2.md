# Red 시각 검증 — design-05 v2

PASS. v2는 v1의 HTML 카드/패널 느낌에서 벗어나, YouTube 영상 위에 얹는 물성 있는 종이 소품으로 읽힌다.

## 네 질문

- 방향이 맞나? → 맞다. `FIELD RECEIPT`를 깨끗한 정보 패널이 아니라 여행 현장 메모지/영수증형 에페메라로 재정의했다.
- 다음 액션이 있나? → 있다. 실제 영상 컷 위에서 330-430px 폭으로 올려 한 번 더 확인한다.
- 선택이 맞나? → 맞다. 찢긴 종이, 낮은 정보 밀도, 좌상단 보조 배치, 투명 PNG가 영상 오버레이 목적에 맞다.
- 요청과 맞나? → 맞다. HTML틱함을 줄이고 영상용 디자인 객체로 바꾸라는 요구를 반영했다.

## 시각 확인

- HTML틱함 감소: PASS. 불규칙한 찢김, 종이 질감, 세로 접힘, 흐린 인쇄감으로 웹 UI 패널 느낌이 크게 줄었다.
- 투명 영역: PASS. 원본 PNG는 RGBA이며 오브젝트 바깥 알파가 살아 있다.
- 그림자: PASS. 그림자는 종이 주변에만 붙고 전체 화면 사각형처럼 보이지 않는다.
- 텍스트 가독성: PASS with caution. 핵심 텍스트는 1080p 프리뷰에서 읽히지만, 하단 `keep the dust. keep the scale.`은 모바일 시청에서는 장식 수준일 수 있다.
- 스탬프 충돌: PASS. 스탬프가 핵심 본문을 덮지 않는다. 점선과는 조금 가까우나 치명적 충돌은 아니다.

## 판정

최종 판정: PASS. v2는 YouTube 영상 오버레이로 사용 가능한 수준이다.
