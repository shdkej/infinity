# T2.2 Red 검증 — 반복 유료 행동 여행 도구 가설

- Red session: `/root/red_travel_research`
- 판정: **PASS — 가설·근거 해석·L0 경계에 한함**

## 통과 항목

1. 요청 적합성: 제품 출시 판단이 아니라 반복 유료 행동의 최소 반증 가설 선택으로 제한했다.
2. 직접 WTP: Day One·TripIt·Polarsteps·TravelJournal 가격은 인접 범주 신호이며, 여행 회수 카드의 직접 지불 의사로 추론하지 않았다.
3. L0: 모집·외부 발송·결제·사전결제·배포를 수행하지 않았고, 7일 검증은 별도 동의·권한 승인 후에만 가능하다.
4. 개인정보: 계정, 정확 위치·EXIF, 원본 사진, 예약·확인번호, 동행인 정보, 검색·이동 이력, 외부 API를 제외했다.
5. 판정 충돌: Stop 조건 하나라도 성립하면 Continue보다 우선하며 상충 응답은 Stop/Discard로 기록한다.

## 한계

- 현재 증거는 역할별 수렴과 공개 인접 가격뿐이다. 여행 회수 카드의 직접 지불 의사·반복 사용·가격 수용성은 입증하지 않았다.
- 7일 계획은 실행되지 않았고, 참여자 동의·모집 승인도 없다.
- Continue 임계값을 충족하더라도 Stop 조건 부재를 함께 기록해야 하며, 이를 출시·결제 실험 승인으로 해석하지 않는다.
