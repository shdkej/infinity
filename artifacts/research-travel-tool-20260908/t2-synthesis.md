# T2.1 근거 통합 — 상위 후보와 7일 반증 계획

## 결정

**상위 후보: 여행 회수 카드**

여행 중 또는 직후의 한 장면을 짧게 남기고, 다음 유사 상황에서 다시 쓸 **선택 기준 한 개**로 복원하는 로컬 우선 도구다. 여행 플래너·장소 저장소·사진 백업이 아니라, `장면 → 판단 → 다음 선택 기준`의 재사용만 다룬다.

### 채택 근거

- Planner·Developer·Marketer·Operator 네 역할이 “적은 입력으로 다음 선택을 다시 고민하지 않게 하는 카드”에 수렴했다. 상세 session evidence와 링크는 [`t1-role-evidence.md`](t1-role-evidence.md)에 있다.
- 사용자 맥락의 여행 전 시나리오 보존·여행 후 감각 회수, 적은 입력점·맥락 복원·다음 행동 원칙에 맞는다.
- [Day One](https://dayoneapp.com/plans/), [TripIt](https://www.tripit.com/web/pro/pricing), [Polarsteps](https://www.polarsteps.com/fr/plus), [TravelJournal](https://www.traveljournal.me/en/pricing)은 기록·운영·회고에 반복 결제가 존재함을 보이는 **인접 신호**다. 이 카드의 직접 지불 의사 증거는 아니다.

## 후보 비교와 제외

| 후보 | 판단 | 이유 |
| --- | --- | --- |
| 여행 회수 카드 | 채택 | 장소·기록량 대신 다음 선택 기준의 재사용만 검증할 수 있다. |
| 한 장소·한 기준 리스트 | 보류 | [Wanderlog](https://wanderlog.com/blog/2024/11/26/wanderlog-vs-tripit/)·지도 목록 기능과 겹친다. 회수 카드의 재사용이 관찰된 뒤에만 맥락을 추가한다. |
| 예약 뒤 다음 행동 한 칸 | 보류 | [TripIt Pro](https://www.tripit.com/web/pro/pricing)의 이메일 통합·실시간 알림 경쟁과 인접한다. 메일·캘린더 권한 없이 효용이 확인될 때만 재검토한다. |
| 일정·지도·실시간 알림·자동 여행기 | 제외 | 데이터 신뢰, 위치 추적, 권한, 운영·지원 책임이 L0 연구 범위를 넘는다. |

## 최소 제품·개인정보 경계

- 입력: 짧은 장면 또는 문장 하나, `유지/피함` 판단 하나, 다음번 기준 한 줄.
- 출력: 사용자가 직접 열 때만 보이는 한 장의 기준 카드.
- 제외: 계정, 지도, 추천, AI 요약, 자동 위치, EXIF, 원본 사진 업로드, 예약/확인번호, 동행인 정보, 검색·이동 이력, 외부 API·결제·배포.

## 7일 반증 계획 — 승인 후에만 실행

이 계획은 조사 산출물이며, 현재 참여자 모집·외부 발송·결제·사전결제는 수행하지 않는다. 실제 실행은 별도 동의·권한 승인 뒤에만 가능하다.

| 구간 | 검증 행동 | 기록할 최소 신호 |
| --- | --- | --- |
| Day 1–2 | 최근 실제 선택 1건을 3필드 카드로 기록 | 완결 여부, 입력 시간, 추가 설명 필요 여부 |
| Day 3–5 | 같은 카드를 다시 열고 다음 선택 기준으로 쓸 수 있는지 확인 | 재열람 여부, 기준 재사용 응답 |
| Day 6–7 | 기존 노트·사진으로 충분한지와 반복 사용 의도를 분리 질문 | 대체 가능성, 재사용 의도 |

### 사전 고정 판정

- **Continue:** 5명 중 3명 이상이 3분 안에 실제 선택을 카드화하고, 2명 이상이 재열람 뒤 구체적 다음 행동을 바꾸거나 확정하며, 2명 이상이 사진 저장이 아닌 판단 재사용을 위해 보관하겠다고 답한다.
- **Stop/Discard:** 기록이 여행 일기·사진 보관으로만 해석되거나, 다음 행동보다 장소·후기·체크리스트를 원하거나, 여행 사이 재열람 사례가 없다.
- **충돌 해소:** Stop 조건이 하나라도 성립하면 Continue보다 우선한다. 상충 응답은 Stop/Discard로 기록한다.

## 결론의 한계

인접 서비스의 공개 가격은 범주 수요의 신호이지 직접 WTP가 아니다. 이번 결정은 결제 검증이나 제품 출시 결론이 아니라, **가장 작은 반증 가능한 가설**을 고른 것이다.
