# 반복 유료 행동 여행·기록·취향 마이크로도구 리서치

## 결론

**우선 가설: 여행 회수 카드.** 여행 중 또는 직후의 한 장면을 `유지/피함` 판단과 다음번 선택 기준 한 줄로 압축하고, 사용자가 유사 상황에서 직접 열어 보는 로컬 우선 카드다. 여행 플래너, 장소 목록, 사진 백업, 실시간 여행 운영 도구는 아니다.

이 결론은 **제품 출시나 결제 판단이 아니다.** 현재 근거는 네 역할의 독립 조사와 인접 제품의 공개 가격이다. 후보의 직접 지불 의사, 반복 사용, 가격 수용성은 아직 입증되지 않았다.

## 후보 결정

1. **채택 — 여행 회수 카드:** 적은 입력으로 다음 선택 기준의 재사용을 관찰할 수 있다.
2. **보류 — 한 장소·한 기준 리스트:** 장소·지도 목록 기능과 겹칠 위험이 있어 카드 재사용이 관찰된 뒤에만 검토한다.
3. **보류 — 예약 뒤 다음 행동 한 칸:** 메일·캘린더 권한 없이 효용을 보일 수 있을 때만 다시 검토한다.
4. **제외 — 일정·지도·실시간 알림·자동 여행기:** 외부 데이터 신뢰, 위치·권한, 운영·지원 책임이 L0 범위를 넘는다.

## 최소 경계

- 입력: 짧은 장면/문장 하나, `유지/피함` 판단 하나, 다음번 기준 한 줄.
- 출력: 사용자가 직접 열 때만 보이는 한 장의 기준 카드.
- 제외: 계정, 정확 위치·EXIF, 원본 사진 업로드, 예약·확인번호, 동행인 정보, 검색·이동 이력, 지도·추천·AI 요약, 외부 API, 결제, 배포.

## 7일 반증 계획 — 별도 승인 후에만

| 구간 | 최소 확인 |
| --- | --- |
| Day 1–2 | 실제 선택 1건의 3필드 카드화, 완결 여부·입력 시간·추가 설명 필요 여부 |
| Day 3–5 | 카드 재열람과 기준 재사용 응답 |
| Day 6–7 | 기존 노트·사진으로 충분한지와 반복 사용 의도를 분리 확인 |

**Continue:** 5명 중 3명 이상이 3분 이내에 실제 선택을 카드화하고, 2명 이상이 재열람 뒤 다음 행동을 바꾸거나 확정하며, 2명 이상이 사진 저장이 아닌 판단 재사용을 위해 보관하겠다고 답한다.

**Stop/Discard:** 기록이 일기·사진 보관으로만 해석되거나, 다음 행동보다 장소·후기·체크리스트를 원하거나, 여행 사이 재열람 사례가 없다.

**충돌 해소:** Stop 조건 하나라도 성립하면 Continue보다 우선한다. 상충 응답은 Stop/Discard로 기록한다. Continue여도 출시·결제 실험 권한은 생기지 않는다.

## Red 및 운영 상태

T2.2 Red는 요청 적합성, 인접 가격의 과장 금지, L0 경계, 개인정보 제외, Stop 우선 규칙에 대해 PASS를 판정했다. 실제 7일 실험, 참여자 동의·모집, 결제, 배포, 외부 발송은 수행하지 않았다.

## 인계

별도 승인된 후속 intent가 있을 때만 동의·모집 경계와 로컬 프로토타입 범위를 다시 검토한다. 그 전에는 이 문서를 반복 유료 행동의 **반증 가능한 가설**로만 사용한다.
