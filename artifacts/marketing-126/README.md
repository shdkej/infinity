## Card Copy

1. 여행은 실험실이 됩니다  
   불편을 발견하면 작게 만들고 직접 써봅니다.

2. 가설 → 실행 → 증거 이 순서로 돕니다  
   좋아 보이는 말보다 실제로 쓴 장면을 남깁니다.

3. 기록에서 골라 다음 선택을 고칩니다  
   한 번의 결론보다 다음 반복에서 달라진 것을 봅니다.
