# 국내 미니멀 큐레이션·리뷰 가이드 — 내부 템플릿

**범위:** 이 문서는 실제 후보, 촬영, 게시물, 구매 추천을 만들지 않습니다. C1에서 제한적으로 확인한 UNHIDE·HPIX의 카드 구조만 사용해, 새 소재를 `draftable` 또는 `hold`로 가르는 내부 리뷰와 30–60초 대본 틀을 제공합니다.

**핵심:** 미니멀은 화면을 비우는 일이 아니라, `사용 장면 → 제약/불편 → 조건부 판단`만 남기는 일입니다. 대상 이름·브랜드·미감·가격은 그 판단을 바꾸는 근거가 있을 때만 보조적으로 기록합니다.

## 1. 카드 하나, 판단 하나

한 카드는 한 대상과 한 선택 압력만 다룹니다.

```yaml
card_id: KR-YYYY-NN
axis: person | space | object
scene: "어떤 장면에서 쓰이거나 문제가 생기는가"
constraint: "시간·공간·동선·관리 중 무엇이 불편한가"
decision: draftable | hold | exclude
decision_reason: "이 조건이면 채택 / 이 조건이면 보류"
viewer_condition: "시청자가 적용하려면 확인할 작은 조건 하나"
evidence:
  - claim_id: KR-...-F1
    url: https://...
    publisher: "발행 주체"
    opened_at: "ISO-8601"
    access_status: open | restricted | dead
    locator: "제목·본문 절·캡션"
    tag: fact | inference
relationship_status: confirmed | none_declared | unknown
rights_status: pass | unknown | fail
privacy_status: pass | unknown | fail
public_access_status: pass | unknown | not_applicable
safety_route_status: pass | unknown | not_applicable
asset_status: self_made | licensed | unknown
reuse_limit: "권리·관계·안전·접근 상태의 구체 제한"
reviewed_at: "ISO-8601"
```

### 축별 추가 게이트

| 축 | `draftable` 전 필수 조건 |
|---|---|
| 사람 | 식별 가능성·공개 동의 확인. 미성년자, 사적 대화/화면, 주소 단서는 제외 |
| 공간 | `public_access_status=pass` **및** `safety_route_status=pass`. 정확 위치·실시간 방문 정보는 별도 판단 |
| 물건 | 기능 주장별 공식 근거와 기준일. 미확인 기능·성능은 해당 문장에서 삭제 |

## 2. 판정기

1. 모든 `evidence`에 열린 원문, locator, 사실/추론 태그가 있는지 확인합니다.
2. 권리·관계·프라이버시와 해당 축의 추가 게이트가 모두 `pass`인지 확인합니다.
3. 모두 통과하면 `draftable`입니다. 하나라도 `unknown`, `restricted`, `dead`, `fail`이면 `hold`입니다. 명백히 범위 밖이거나 위험하면 `exclude`입니다.
4. `draftable`은 **내부 대본 초안 가능** 상태일 뿐, 촬영·자산 사용·외부 연락·공개 게시의 승인 상태가 아닙니다.

## 3. 대본 공통 구조

`선택 장면 → 제약/트레이드오프 → 조건부 판단 → 시청자 적용 조건 → 사실·출처·관계 고지`

- 한 편에는 한 대상·한 판단만 둡니다.
- ‘최고’, ‘필수’, ‘가성비’, 순위, 포괄적 라이프스타일 일반화는 쓰지 않습니다.
- 적용 조건과 출처·관계 고지를 줄이기 위해 생략하지 않습니다. 자리가 부족하면 장면 설명을 덜어냅니다.

### 30초

| 시간 | 역할 | 빈칸 |
|---|---|---|
| 0–5초 | 사용 장면 | `[언제/어디서]` |
| 5–12초 | 제약 또는 불편 | `[무엇이 걸리는가]` |
| 12–20초 | 조건부 판단 | `[이 조건이면 채택, 아니면 HOLD]` |
| 20–26초 | 시청자 적용 조건 | `[따라 하기 전 확인할 한 가지]` |
| 26–30초 | 사실·출처·관계 고지 | `[claim_id/출처/관계/상태]` |

### 45초

| 시간 | 역할 |
|---|---|
| 0–6초 | 사용 장면 |
| 6–17초 | 제약·트레이드오프 |
| 17–30초 | 조건부 판단의 근거 |
| 30–39초 | 시청자 적용 조건 |
| 39–45초 | 사실·출처·관계 고지 |

### 60초

| 시간 | 역할 |
|---|---|
| 0–8초 | 사용 장면 |
| 8–22초 | 제약·트레이드오프 |
| 22–40초 | 조건부 판단과 제외 이유 |
| 40–52초 | 시청자 적용 조건 |
| 52–60초 | 사실·출처·관계 고지 |

## 4. 사례 참고의 좁은 적용

| 근거 | 내부적으로 참고하는 구조 | 절대 가져오지 않는 것 |
|---|---|---|
| UNHIDE (KR-S1) | 공간의 사용 장면, 공개 접근, 안전·동선을 분리하는 카드 | 장소 추천, 정확 위치, 대여 전환, 사진/UI/브랜드 톤 재사용 |
| HPIX (KR-O1) | 물건을 공간의 불편·용도·배치 조건과 연결하는 카드 | 상담·판매 전환, 가격·재고·혜택, 성능 우위, 이미지/UI 재사용 |

P1(B tv 404), P2(KOCCA 본문 locator 미확인), S2/O2(29CM 403)는 `hold`이며, 콘텐츠·형식·기능 주장과 템플릿 예시의 근거로 사용하지 않습니다.

## 5. 대본 전 사전 점검

| 점검 | 결과 | 실패 시 |
|---|---|---|
| 원문·locator·사실/추론 태그가 모두 있는가 | `pass / hold / exclude` | `hold` |
| 관계·권리·프라이버시 상태가 확인됐는가 | `pass / hold / exclude` | `hold` |
| 축별 게이트(동의·공개 접근/안전·공식 기능 기준일)를 통과했는가 | `pass / hold / exclude` | `hold` |
| 30/45/60초판 모두 적용 조건과 고지 슬롯이 있는가 | `pass / hold` | 대본 수정 |
| 가격·혜택·CTA·순위·제3자 자산·정확 위치가 빠졌는가 | `pass / hold` | 대본 수정 또는 `hold` |

`hold_reason`과 `reopen_condition`을 카드에 남깁니다. 출처를 적었다는 이유만으로 진행하지 않습니다.

## 6. 승인 경계

다음은 이 가이드의 범위 밖이며 별도 사용자 승인이 필요합니다: 실제 후보 확정, 촬영, 제3자 이미지·영상·PDF 캡처·음원 사용, 식별 가능한 인물 또는 사적 공간 공개, 정확 위치·방문 시점·동선 공개, 외부 연락, 구매·유료 상담, 공개 게시·발송.

## 역할 수렴

- **Planner (`/root/planner_t21`)**: 한 판단·한 카드와 30초에도 적용 조건·고지 슬롯을 유지하도록 확인했습니다.
- **Developer (`/root/developer_t21`)**: 재현 가능한 evidence 레코드와 축별 gate, `hold_reason`/`reopen_condition`을 고정하도록 확인했습니다.
- **Marketer (`/root/marketer_t21`)**: 선택 이유를 중심에 두고 미니멀을 ‘덜어낸 판단’으로, 상업·브랜드 모방을 배제하도록 확인했습니다.
- **Operator (`/root/operator_t21`)**: 권리·관계·안전은 대본 진입 전 차단 게이트이며 실제 외부 실행은 승인 전 금지임을 확인했습니다.
