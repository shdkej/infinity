# T1.2 Red — 국내 사례 근거 지도 검증

**판정: FAIL — 재현 가능한 근거를 보완한 뒤에만 C1으로 진행합니다.**

## 확인한 사실

- 2026-09-12T00:22Z에 원문 URL을 재조회했습니다. SK브로드밴드 B tv 링크는 HTTP 404였고, 29CM의 두 콘텐츠 URL은 비대화형 조회에서 HTTP 403이었습니다.
- KOCCA PDF, UNHIDE, HPIX URL은 HTTP 200을 반환했습니다. 다만 KOCCA는 채널 운영 주체의 원문이 아닌 기관의 2018년 인터뷰 기록입니다.
- 6건은 국내 미니멀 큐레이션의 대표 표본이 아니라, 국내 공식 운영 표면에서 확인을 시도한 **제한적 형식 참고 표본**입니다. 사람 사례는 미디어/인물, 공간·물건 사례는 상업·플랫폼 표면에 치우쳐 있습니다.

## Red 실패 사유

1. **B tv 사실성:** 404 URL은 ‘한 작품을 세 논점으로 심층 리뷰’했다는 주장을 재현하지 못합니다. 채널 존재와 해당 형식 주장을 분리하거나, 현재 열리는 SK/B tv 1차 원문으로 교체해야 합니다.
2. **증거 레코드 부족:** 카드마다 claim ID, 발행 주체, 발행일 또는 `null`, 열람 시각, 근거 위치/짧은 요약이 없습니다. 29CM 403은 접근 제한을 기록하고, 열어 본 대체 공식 근거가 없으면 형식 주장에 쓰지 않습니다.
3. **대표성·관계 상태:** 6건 균형은 대상군 수의 균형일 뿐 대표성 증거가 아닙니다. 모든 판매·예약·상담 카드에 `형식 참고 / 독립 추천 불가 / 권리·관계·안전 미확인 시 hold`와 상품·유료 서비스 연결 상태를 일관되게 표시해야 합니다.
4. **세부 사실의 과장 위험:** UNHIDE의 ‘크기/가격’, HPIX의 ‘목재 디테일·3D 사전 계획·기능 역할’은 카드별 근거 위치가 없는 한 더 좁은 직접 관찰로 축소해야 합니다.

## 최소 보완과 재검증 기준

- T1.1R에서 404 B tv 근거를 현재 열리는 공식 출처로 교체하거나 해당 카드의 형식 주장을 제거하고, 인물 축의 대체 공식 사례를 추가합니다.
- 6개 카드에 claim 레코드(발행 주체·열람 시각·근거 위치·사실/추론·접근 제한)를 추가합니다.
- 제목·결론·카드 상태를 제한적 형식 참고 표본으로 정규화하고, 상업 CTA·가격·이미지·정확 위치의 재사용 금지를 같은 강도로 고정합니다.
- T1.2R은 위 변경 뒤 URL 접근성과 카드 레코드를 다시 판정합니다. 그 전에는 T1.3을 시작하지 않습니다.
