# C1 — 국내 사례에서 가져올 운영 원리

**결론:** 국내 사례의 ‘스타일’이나 판매 문법을 가져오지 않습니다. 2026-09-12에 재현 가능했던 UNHIDE와 HPIX의 공식 표면에서, **사용 장면·조건·판정 상태를 분리하는 내부 카드 구조**만 제한적으로 참고합니다. 이는 두 사례가 국내 큐레이션 전체를 대표한다는 뜻도, 실제 후보·촬영·게시를 승인한다는 뜻도 아닙니다.

## 적용 원리 — 추론

1. **공간은 이름보다 사용 장면과 검증 상태로 기록합니다.** UNHIDE가 로케이션·스튜디오·팝업·갤러리 탐색을 표시한다는 사실([KR-S1-F1](korean-case-map.md#claim-레코드))에서, 내부 공간 카드는 `사용 장면`, `공개 접근`, `안전·동선`을 별도 필드로 둡니다. 장소 추천이나 정확 위치 공개로 확장하지 않습니다.
2. **물건은 미감보다 공간의 불편·용도·배치 조건을 먼저 기록합니다.** HPIX가 상담 후 3D 렌더링·배치·가상 인테리어 시뮬레이션을 제공한다고 표시한다는 사실([KR-O1-F1](korean-case-map.md#claim-레코드))에서, 내부 물건 카드는 해결하려는 불편과 사용 조건을 먼저 적습니다. 실제 기능은 별도 공식 자료와 기준일이 있을 때만 말합니다.
3. **한 카드에는 하나의 조건부 판단만 둡니다.** 장면 → 제약/조건 → `채택 또는 HOLD`를 한 단위로 닫습니다. ‘베스트’, ‘필수’, 순위, 포괄적 미니멀 라이프스타일 주장으로 일반화하지 않습니다.
4. **고지는 장식이 아니라 차단 게이트입니다.** 권리·관계·안전이 하나라도 미확인이면 하단 고지로 덮지 않고 카드 전체를 `hold`로 둡니다. `usable_as_format_reference`도 독립 추천 상태가 아닙니다.

## 카드 최소 필드 — 내부용

| 필드 | 목적 | 미충족 시 |
|---|---|---|
| `evidence_status` | `usable_as_format_reference` 또는 `hold`를 고정 | `hold` |
| `claim_id`, URL, 발행 주체, 열람 시각, 접근 상태, locator | 사실/추론 재현 | `hold` |
| 사용 장면 또는 공간 불편·용도 | 이름·미감만으로 선택하지 않음 | 제외 |
| 관계·권리·안전 상태 | 공개·자산·인물/위치 위험 판정 | `hold` |
| 공개 접근·안전/동선 (공간) | 민감/사적/위험 공간 차단 | `hold` |
| 공식 기능 근거·기준일 (물건) | 성능·기능 과장 차단 | 해당 주장 삭제 |

## 명시적 비적용

- UNHIDE의 대여/플랫폼 및 HPIX의 유료 상담·판매 표면에서 가격·재고·할인·혜택·상담 전환·구매 CTA·성능 우위를 가져오지 않습니다.
- 제3자 사진·영상·PDF 캡처, 서비스 화면, 브랜드 톤을 재사용하지 않습니다.
- 정확 위치·실시간 동선·사적 또는 민감 장소를 공개하지 않습니다.
- P1(B tv 404), P2(KOCCA 본문 locator 미확인), S2/O2(29CM 403)의 콘텐츠·형식·기능 주장을 복원하지 않습니다.
- 6개 제한 표본을 국내 큐레이션의 대표성, 시장 성과, 성공 공식으로 주장하지 않습니다.

## 역할 수렴

- **Planner (`/root/planner_t13`)**: 두 표면은 내부 카드의 사용 장면·검증 상태 구조로만 참고해야 하며, hold 4건을 일반화 근거로 쓰지 말아야 한다고 확인했습니다.
- **Developer (`/root/developer_t13`)**: claim 재현 필드와 `reuse_limit`을 카드의 필수 게이트로 두고, hold에서 형식 규칙을 도출하지 말아야 한다고 확인했습니다.
- **Marketer (`/root/marketer_t13`)**: 브랜드 미학 대신 조건부 선택 이유를 전달하고, 판매·혜택·구매 설득 문법을 배제해야 한다고 확인했습니다.
- **Operator (`/root/operator_t13`)**: 권리·관계·공개 접근·안전/동선 미확인 시 hold, 실제 후보 확정·촬영·자산 사용·공개·외부 연락은 별도 승인이라고 확인했습니다.

## 다음 단계 경계

T2.1은 이 원리를 가이드와 30–60초 템플릿으로 옮길 수 있습니다. 단, 실제 국내 후보 선정, 촬영, 제3자 자산 사용, 공개 게시, 외부 연락은 이 리서치의 범위 밖이며 별도 승인 없이는 실행하지 않습니다.
