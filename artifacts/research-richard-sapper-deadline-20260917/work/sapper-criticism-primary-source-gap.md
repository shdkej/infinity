# Sapper 비평 자료의 원문 접근성·카탈로그·2차 해설 경계

## 결론

접근 가능한 **직접 비평 원문**은 Mark Wilson의 [Fast Company 2015 글](https://www.fastcompany.com/3043093/the-thinkpad-is-a-lasting-but-overrated-design)이다. 제목·저자·발행일과 TrackPoint/현대 입력 방식에 대한 평가 문장을 직접 확인했다. 이 글은 특정 제품 계열과 당시 기술 환경을 대상으로 한 저널리즘적 비평이다.

반면 Domus의 2013년 Sapper 인터뷰 에세이는 검색 결과로 존재를 확인했지만 이번 재열람에서는 403으로 원문을 가져오지 못했다. MoMA의 *Workspheres* 카탈로그 PDF도 URL과 기관 출처는 확인했지만 파일 크기 제한으로 직접 열람하지 못했다. 두 자료는 제목·검색 스니펫 이상의 주장 근거로 사용하지 않는다.

| 자료 층위 | 접근 상태 | 허용 범위 | 금지 범위 |
| --- | --- | --- | --- |
| [Fast Company, Mark Wilson, 2015](https://www.fastcompany.com/3043093/the-thinkpad-is-a-lasting-but-overrated-design) | 전문 직접 열람 | 저자·날짜·특정 ThinkPad/TrackPoint 비평의 존재와 글 안의 논지 | 전 세계 사용자·전문가 합의, 사퍼 전 경력의 최종 평결 |
| [Domus, “The black box syndrome”, 2013](https://www.domusweb.it/en/design/2013/02/18/the-black-box-syndrome.html) | 검색 결과 확인, 직접 재열람 403 실패 | 서지 단서와 이전에 확인된 인터뷰 에세이의 존재 | 정확한 문장 인용·세부 해석·Sapper 발화의 확정적 재전달 |
| [MoMA *Workspheres* 카탈로그 PDF](https://www.moma.org/documents/moma_catalogue_168_300133807.pdf) | 기관 PDF URL 확인, 파일 크기 제한으로 본문 미열람 | 기관 카탈로그 자료가 존재한다는 사실 | Sapper/ThinkPad에 관한 카탈로그의 개별 주장·페이지·비평적 결론 |
| 기관 소장/전시 페이지 | 공개 메타데이터 직접 열람 가능 | 작품·전시·소장 사실 | 독립 비평 합의나 장기 사용성 평가 |

## 인용 규칙

1. 전문을 직접 열람하지 못한 자료는 긴 인용·세부 주장을 만들지 않고, 접근 불가·서지 확인 상태로만 표시한다.
2. 전시 카탈로그·박물관 소장 페이지는 제도적 맥락 자료다. 독립 비평, 사용자 연구, 시장 성과를 대신하지 않는다.
3. 한 저널리즘 글의 평가를 복수 전문가의 합의로 일반화하지 않는다.
4. 저작권 보호 원문은 필요한 짧은 범위 외 장문 전재하지 않는다.

## 재개 조건

- Domus의 합법적 원문 접근 또는 인쇄/도서관 소장본 확인
- MoMA 카탈로그의 특정 페이지·저자·문맥을 직접 열람할 수 있는 경로
- 독립 학술 데이터베이스에서 사퍼 제품의 사용성·비평을 추적할 수 있는 서지
