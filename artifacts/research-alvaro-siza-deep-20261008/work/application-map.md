# 사용자 관심사와 알바로 시자 연결 지도

| 사용자 관심사 | 관찰 가능한 연결 | 제한 |
|---|---|---|
| 상대성이론 | 관찰자·동선·빛·시간에 따라 달라지는 경험 | 물리학의 상대성이론과 동일시 금지 |
| WWW | 국제 작업에서 장소의 언어가 이동·번역되는 문제 | 세계화는 지역성의 성공만이 아니라 손실도 동반 |
| 돌로미티 | 바위·지형·기후를 읽고 개입을 최소화하는 비교 렌즈 | 실제 영향·작업은 별도 확인 전 추정 금지 |
| 정성 들인 마감 | 벽 두께, 틈, 손잡이, 빛, 동선 같은 가까운 디테일의 누적 | 비용·노동·현장 관리 조건을 숨길 수 있음 |
| 미니멀모음 | 결과물보다 선택 기준·맥락·제외·재방문을 큐레이션 | 시자의 권위나 스타일이 아니라 관찰 절차를 배워야 함 |
