# 미군 TTP 학습 루프: 현장 학습이 조직 자산이 되는 방식

**결론:** 미군의 공개 학습 체계에서 AAR은 현장 성과를 즉시 교정하는 장치이고, Army Lessons Learned Program(ALLP)은 반복·전군 영향이 있는 관찰을 검증·해결·전파·평가하는 장치입니다. Infinity에는 이 둘을 합치지 말고, `작업 직후 회고 → 재현 가능한 관찰 등록 → 책임자 검증 → 변경 실행 → 효과 재확인`의 작은 폐루프로 옮기는 것이 맞습니다.

**신뢰도:** 중간. AAR과 ALLP의 공식 문서·공식 기관 설명은 일치하지만, JLLIS의 세부 워크플로와 현장별 처리시간은 공개 접근이 제한돼 있어 일반화하지 않았습니다.

## 메커니즘 맵

| 단계 | 실제 역할·산출물 | 다음 단계로 가는 기준 | Infinity의 최소 대응 |
|---|---|---|---|
| 1. 현장 포착 | AAR 참가자·관찰자가 목표, 실제 발생, 강점·약점을 대조한다. | 특정 과업·표준·증거가 연결된 관찰인가 | 작업 종료 직후 `observation`: 의도·실제·증거 링크 |
| 2. 즉시 교정 | 리더와 참가자가 다음 수행 방법·담당자를 정하고 재훈련을 계획한다. | 한 팀이 바로 바꿀 수 있는가 | 다음 leaf 또는 후속 intent에 책임자·재검증 시점 기록 |
| 3. 조직 검증 | ALLP/COE 네트워크가 관찰을 분석하고, 추세·근본 원인·영향 범위를 판별한다. | 반복성·영향·근거가 충분한가 | 동일 관찰 2건 이상 또는 명시 위험이면 `lesson` 검토 |
| 4. 해결·표준화 | 교리·훈련·교육·리더 개발·운영의 수정 후보를 소유자에게 연결한다. | 변경 소유자와 변경 대상이 명확한가 | 규칙·템플릿·스킬·운영 문서 중 정확한 변경 대상을 하나 지정 |
| 5. 전파 | TLLM-Army/CALL 제품과 JLLIS가 정보를 배포·보관한다. | 적용 대상이 식별됐는가 | Archive/Agent Wiki에는 검증된 원칙만 승격, 실행 로그는 Infinity에 보존 |
| 6. 효과 평가 | 수정이 문제를 실제로 완화했는지 다시 확인한다. | 다음 실행의 증거가 이전 관찰을 반증/지지하는가 | 후속 실행에서 지표·반례를 확인하고 유지·수정·폐기 결정 |

## 핵심 발견

### 1) AAR은 ‘회의록’이 아니라 표준 대비 공동 분석과 다음 수행 약속입니다

**근거:** FM 7-0 Appendix K는 AAR을 훈련 중·직후 수행하는 guided analysis로 정의하고, 계획된 일·실제 발생·옳고 그름·다음 표준 수행을 순서로 둡니다. 공식 교육 지침은 후속 조치로 재훈련, SOP 수정, lessons learned 통합·공유를 명시합니다.

**해석:** 개인 회고를 지식 자산으로 바꾸려면 감상이나 ‘배운 점’만 남겨서는 부족합니다. 의도한 표준, 실제 증거, 바꿀 행동, 책임자를 같은 레코드에 둬야 합니다.

**한계/반증:** AAR만으로 전군 표준이 바뀌지는 않습니다. 팀 내부에서 해결 가능한 문제와 조직 차원의 lesson을 구분하지 않으면 저장소만 늘어납니다.

### 2) ALLP의 핵심은 수집량이 아니라 검증된 변경의 폐루프입니다

**근거:** 미 육군 Combined Arms Command는 관찰을 지속 수집하고, 발견된 lesson/best practice를 검증한 뒤 교리·훈련·교육·리더 개발·운영에 corrective action으로 통합하며 그 효과도 확인한다고 설명합니다. Joint Lessons Learned Program은 discovery, validation, resolution, evaluation, dissemination의 5단계를 공식적으로 분리합니다.

**해석:** ‘lesson’은 단순 인사이트의 동의어가 아니라, 해결 대상으로 충분히 검증되어 실제 변경과 효과 확인까지 연결된 항목입니다. Infinity도 observation과 reusable principle을 같은 상태로 취급하지 않아야 합니다.

**한계/반증:** Army의 제도는 지휘 체계·전담 조직·보안 시스템을 전제로 합니다. 개인 시스템에 중앙 승인 단계를 그대로 복제하면 속도만 잃습니다.

### 3) 전파는 문서 발행만이 아니라 다음 훈련·실행에 반영될 때 완료됩니다

**근거:** TLLM-Army는 연간 계획을 통해 tactical부터 strategic 수준의 lesson을 수집·분석·전파·통합·보관하며, 추세·근본 원인 분석과 제품 개발을 수행한다고 밝힙니다. 2025년 TC 7-0.1 안내도 AAR 후속 조치에 기록, SOP 수정, lesson 공유를 포함합니다.

**해석:** Infinity에서 Archive는 ‘배포 완료’가 아니라 결과 보존입니다. 반복 가능한 원칙은 다음 intent의 작업 기준·템플릿·검증 조건에 재사용된 증거가 생겨야 살아 있는 자산입니다.

**한계/반증:** 빠른 전파(Quick-Fire류)가 필요한 상황도 있지만, 공개 자료만으로 각 항목의 검증 기준·처리 SLA를 확정할 수 없습니다. 안전 또는 정책 영향이 큰 변경은 별도 승인이 필요합니다.

## Infinity에 적용할 최소 루프

1. **Observation (즉시):** intent 종료마다 `예상 / 실제 / 증거 / 영향 / 다음 행동` 다섯 필드를 기록합니다.
2. **Triage (주기):** 동일 원인 반복, 안전·품질 영향, 여러 intent 영향 중 하나가 있을 때만 lesson 후보로 승격합니다.
3. **Owner validation:** 변경 가능한 정확한 문서·템플릿·코드 소유자와 반증 조건을 지정합니다. 근거가 부족하면 `hypothesis`로 남깁니다.
4. **Change + reuse:** 변경을 실행하고, 다음 실제 intent에서 그 규칙이 사용됐는지와 결과가 좋아졌는지를 기록합니다.
5. **Decision:** 유지·수정·폐기 중 하나를 선택합니다. 후보 목록만 보관하지 않습니다.

## 옮기지 말아야 할 것

- **군사 전술·보안 정보:** 공개 1차 자료의 학습 구조만 다루며 전술 내용·비공개 운영 절차는 전용하지 않습니다.
- **지휘체계 복제:** 개인/소규모 팀은 OLM 같은 상설 임명·대규모 승인 체계 대신, 변경 소유자 한 명과 재검증 일자로 충분합니다.
- **‘모든 회고의 중앙 등록’:** AAR 수준의 즉시 교정과 조직 lesson을 구분하지 않으면 운영 부담이 이익을 압도합니다.

## 다음 판단 하나

다음 Infinity intent 하나에서 위 다섯 필드 Observation 템플릿을 실제로 사용하고, **재사용된 규칙이 다음 실행의 결정 또는 검증을 바꿨는가**만 판정하십시오. 바꾸지 못했다면 템플릿을 더 늘리지 말고 폐기 또는 축소하는 편이 맞습니다.
