## 로컬 실행 단계

> 이 단계는 **로컬 브라우저 + 1688 계정** 필요. 로컬 Claude Code 또는 사용자가 직접 수행.

1. 1688.com 접속
2. `手机防丢绳 手腕` 검색
3. 필터: 가격 CNY 7 이하, 공급사 평점 4.8 이상, 거래량 100건 이상
4. 상위 3–5개 공급사 상세 페이지 확인
5. 각 공급사에 샘플 2–3개 요청 (블랙·네이비 색상)
6. 결제·배송 정보 입력 (로컬 Alipay/위챗페이 또는 소싱 에이전트 경유)
7. 샘플 수령 → QA 체크리스트 확인
8. 합격 공급사 → 50개 정식 주문
9. 스마트스토어 상품 등록 준비 (별도 L1/L2 단계)
