# 소싱-퍼스트 스크린 라운드 2 — 경쟁/소싱 채널 웹 조사

- date: 2026-06-13
- intent: naver-shopping-01
- scope: cloud-only web research (Naver DataLab/Shopping 직접 접근 없음)
- prior_screen: sourcing-first-screen-round1 (5개 후보 중 포켓앨범·다꾸스티커 DataLab 1순위)

## 조사 목적

라운드1에서 DataLab 1순위로 분류된 2개 후보(포켓앨범, 다꾸스티커)에 대해 웹 기반 경쟁·소싱 채널 정보를 수집하여 DataLab 로컬 실행 전 우선순위를 재조정한다.

---

## 후보 1: 포켓앨범 / 여행 사진 앨범

### 경쟁 현황 (공개 웹 기준)

| 항목 | 내용 |
|------|------|
| 주요 플랫폼 | 쿠팡, SSG.com (대규모 경쟁) |
| 키워드 노이즈 | `포카앨범` (K-pop 포토카드 앨범)이 포토앨범 전체 키워드를 잠식 |
| 브랜드 앵커 | 후지필름 Instax 브랜드가 인스탁스 앨범 수요 대부분 흡수 |
| 중고 시장 | 번개장터 K-pop 포카앨범 중심 — 일반 여행 앨범 중고 수요 미약 |

### 소싱 경로

- 타오바오/1688: 접근 가능, 배대지(쉬퍼맨, 이우존 등) 이용
- 국내 도매 경로: **미확인** (문구 도매몰 직접 확인 필요)
- 최소 MOQ: 미확인

### 포지셔닝 과제

- `포켓 앨범` / `포카앨범` 검색 결과를 K-pop 시장에서 **분리 필수**
- `여행 사진 앨범`, `여행 앨범`, `인스탁스 앨범` 등 여행 특화 키워드 전략 필요

### 평가

| 항목 | 결과 |
|------|------|
| 국내 도매 채널 명확도 | ★★ (타오바오 소싱 가능, 국내 도매 미확인) |
| 커뮤니티 수요 증거 | ★★ (K-pop 노이즈로 여행 앨범 수요 분리 어려움) |
| 키워드 차별화 난이도 | 중간~높음 |
| DataLab 우선순위 | **2순위** (라운드1 대비 하향) |

## 후보 2: 투명 스티커 세트 / 다꾸 스티커

### 경쟁 현황 (공개 웹 기준)

| 항목 | 내용 |
|------|------|
| 주요 플랫폼 | GS Shop, SSG, 번개장터(중고 활성), 네이버 스마트스토어 다수 |
| 전문 리테일러 | indigostory.co.kr, sosorowa.com, daggu.co.kr (다꾸 특화 스토어) |
| 2026 트렌드 | 레트로, 홀로그램, 투명 스티커 (publog.co.kr 2026 가이드 확인) |
| 커뮤니티 신호 | 번개장터 다꾸스티커 중고 거래 활성 = 실구매·팬덤 증거 |

### 소싱 경로 (핵심 발견)

| 소싱 유형 | 플랫폼/방법 | 특징 |
|---------|-----------|------|
| 국내 도매 | kids-time.co.kr (문구/완구/팬시 도매몰) | 다꾸스티커 카테고리 별도 운영 |
| 국내 도매 | todanmall.co.kr (토단몰) | 다이어리+다꾸스티커 세트 단품 |
| 국내 도매 | rainmall.co.kr | 다꾸 선물세트 카테고리 |
| 소량 커스텀 | publog.co.kr (굿즈 플래닛) | 1장부터, 다꾸 특화 용지 9종 (레트로/홀로그램/투명) |

### 테마 차별화 가능성

- 일반 다꾸 스티커: 캐릭터/귀여운 일러스트 주도
- **나래 차별화 포인트**: 여행·아날로그 기록·일상 시스템 테마 특화
- `여행 테마 다꾸 스티커` = 검색 키워드 내 니치 포지션 확보 가능
- 소량 커스텀 프린트(publog) → 샘플 리스크 없이 테마 검증 가능

### 평가

| 항목 | 결과 |
|------|------|
| 국내 도매 채널 명확도 | ★★★ (kids-time, todanmall, rainmall 확인됨) |
| 커뮤니티 수요 증거 | ★★★ (번개장터 중고 활성, 전문 스토어 다수) |
| 키워드 차별화 난이도 | 낮음~중간 (여행 테마로 분리 가능) |
| DataLab 우선순위 | **1순위** (라운드1 확인·강화) |

## DataLab 키워드 테스트 계획 (나래 로컬 실행)

### 1순위 실행 — 다꾸 스티커

```
카테고리: 문구/사무용품 > 다이어리/플래너 또는 문구/사무용품 > 스티커
기간: 최근 12개월 (월별)
키워드:
  - 다꾸 스티커     (기본 수요)
  - 투명 스티커     (핵심 트렌드)
  - 씰 스티커       (제품 유형)
  - 다이어리 스티커  (구매 상황)
  - 스티커팩        (세트 형태)
대조군:
  - 홀로그램 스티커  (트렌드 확인)
  - 레트로 스티커    (트렌드 확인)
수집 지표: 클릭 트렌드(월별), 클릭 비중(모바일/PC), 성별·연령, 쇼핑 연관 키워드
```

### 2순위 실행 — 포켓앨범

```
카테고리: 생활용품 > 앨범/액자 또는 사진/카메라 > 액세서리
기간: 최근 12개월 (월별)
키워드:
  - 포켓 앨범       (기본 수요)
  - 여행 앨범       (여행 특화)
  - 인스탁스 앨범    (브랜드 연계)
대조군:
  - 포카 앨범        (K-pop 노이즈 규모 측정)
  - 포토카드 앨범    (노이즈 규모 측정)
```
