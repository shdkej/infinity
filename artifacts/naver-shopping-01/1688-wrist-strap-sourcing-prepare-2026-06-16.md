## 1. 1688 검색어 세트

| 우선순위 | 검색어 | 설명 |
|----------|--------|------|
| 1순위 | `手机防丢绳 手腕` | 손목형 핸드폰 분실방지줄 (핵심 키워드) |
| 2순위 | `手机手腕绳` | 핸드폰 손목줄 (더 일반적) |
| 3순위 | `手机挂绳 手腕` | 핸드폰 걸기줄 손목형 |
| 4순위 | `手腕 手机绳` | 손목 폰줄 |
| 보조 | `防摔防丢手机绳` | 낙하·분실방지 핸드폰줄 |

## 2. 공급사 필터 조건

- **가격**: 단가 0.5–3 CNY/개 (약 100–600 KRW) 범위 타겟
- **MOQ**: 50개 이하 우선. 샘플 단계에서 10–30개 주문 가능한 공급사 선호
- **공급사 등급**: 实力商家 또는 年付 표시 우선 (안정적 공급 보장)
- **출하 방법**: 小包·EMS·순풍(SF Express) 소형 패키지 가능 여부 확인

## 3. 상품 스펙 체크리스트

### 필수 확인 항목
- [ ] **소재**: 나일론/폴리에스터 우선 (가성비); 가죽/PU는 2차 검토
- [ ] **너비**: 5–15mm (너무 얇으면 내구성 문제)
- [ ] **길이**: 손목 조절 가능 15–25cm 또는 고리형 고정 루프
- [ ] **연결 방식**: 유니버설 O링 + 슬라이딩 클립이 가장 범용적
- [ ] **금속 부품**: 금속 클립/카라비너 선호 (플라스틱은 내구성 우려)
- [ ] **색상 확인**: 블랙, 네이비 반드시 포함

### 선택 확인 항목
- [ ] 로고 없는(공백) 버전 존재 여부 (개인 브랜드 레이블 부착 가능성)
- [ ] 소매 포장(OPP 袋) 단품 포장 여부
- [ ] 파단 강도 테스트 결과 또는 스펙 시트 존재 여부

## 4. 주문 수량 계획 (샘플 단계)

| 색상 | 수량 | 비고 |
|------|------|------|
| 블랙 | 10개 | QA 기본 검사 + 개인 사용 테스트 |
| 네이비 | 10개 | 색상 발색 확인 |
| 베이지 또는 화이트 | 5개 | 선택 (여행 감성 색상) |
| **합계** | **25개** | 첫 샘플 배치 |

예상 비용: 25개 × 3 CNY = 75 CNY + 배송비 30–60 CNY = 총 100–135 CNY (약 18,000–24,000 KRW)

## 5. 한국 수입/통관 조건

- **개인 통관 한도**: 150 USD (목록통관) → 샘플 25개는 한도 내 처리 가능
- **통관 방식**: 목록통관 (간이 신고) — 상업 수입 불필요, 개인 구매로 처리
- **배송 방법 추천**:
  - EMS (국제 우편): 7–10일, 소형 패키지 경제적
  - SF Express(순풍): 3–5일, 더 빠름 (배송비 높음)
- **주의**: 배송지는 개인 주소로, 상업용 라벨 없이 발송 요청

## 6. QA 수령 후 체크리스트

샘플 수령 시 직접 확인할 항목:
1. 후크/클립 20회 이상 개폐 내구성 테스트
2. 손목에 착용 시 길이·편의성 확인
3. 스마트폰 낙하 테스트 (30cm 높이에서 줄 잡고 낙하)
4. 세탁 가능 여부 (물에 담근 후 색빠짐·변형 확인)
5. 금속 고리 뻑뻑함/매끄러움 확인

## 7. 판매 포지셔닝 재확인 (리프레임 기준)

소싱 마찰 스크린에서 확정된 포지셔닝:
- **"도난방지"** → **"여행 중 스마트폰 분실·낙하 방지 보조 연결줄"**
- 타겟: 해외여행 준비하는 20-40대; 유럽/일본 배낭여행; 놀이공원·페스티벌 방문자
- 핵심 메시지: "손목에 연결해두면 놓쳐도 안 떨어져요"
- 커버 키워드: `핸드폰손목줄`, `스마트폰스트랩손목`, `여행폰스트랩`
