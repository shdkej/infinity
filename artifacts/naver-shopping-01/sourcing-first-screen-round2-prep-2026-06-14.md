## 후보 A: 포토 포켓 앨범 / 여행 사진 앨범

### 구매 상황 (m50 기준)
"여행 다녀온 후 사진 정리" — 귀국 1-2주 내 구매 타이밍 명확. 아이돌 포토카드 앨범과 시장이 겹치므로 세그먼트 분리 키워드가 핵심.

### DataLab 쿼리 플랜

| 우선순위 | 키워드 | 카테고리 힌트 | 주의 |
|---------|-------|------------|------|
| 1 | `포켓 앨범` | 생활/문구 | 아이돌 시장과 혼재 가능 |
| 1 | `포토 앨범` | 생활/문구 | 범용 — 노이즈 클 수 있음 |
| 2 | `인스탁스 앨범` | 생활/문구 | 브랜드 잠금 있으나 폴라로이드 앨범 수요 신호 |
| 2 | `폴라로이드 앨범` | 생활/문구 | 인스탁스 대체 브랜드 |
| 2 | `여행 앨범` | 여행용품 or 생활 | travel-specific — 볼륨 작을 수 있음 |
| 3 | `미니 포토북` | 생활/문구 | 제작형 수요 포함 가능성 |
| 3 | `포토카드 앨범` | ⚠️ 아이돌 노이즈 | shopping 카테고리 필터 없으면 의미 없음 |

**DataLab API 파라미터 가이드:**
```json
{
  "startDate": "2025-06-01",
  "endDate": "2026-06-01",
  "timeUnit": "month",
  "keyword": ["포켓 앨범", "포토 앨범", "인스탁스 앨범", "폴라로이드 앨범", "여행 앨범"]
}
```
→ Shopping Insight API + Click Trend API 둘 다 테스트

### 타오바오 소싱 쿼리

| 한국어 | 타오바오 검색어 | 예상 가격대 |
|--------|--------------|----------|
| 포켓 앨범 | `口袋相册`, `mini photo album` | 500-1,500원/개 |
| 인스탁스 앨범 | `拍立得相册`, `富士相册收纳` | 800-2,500원/개 |
| 폴라로이드 포켓 | `宝丽来相册`, `照片收纳册` | 600-2,000원/개 |
| 여행 사진 앨범 | `旅行相册`, `旅游照片册` | 700-2,000원/개 |

**소싱 주목 포인트:**
- 색상/재질 옵션 단순화 가능 여부 (화이트/블랙 2색이면 이상적)
- MOQ 50-100개 이하인 공급처 필터
- 포켓 크기: L판(3"×4") vs. 인스탁스(2"×3") 중 수요 더 큰 쪽 DataLab 확인 필요

### Naver Shopping 경쟁도 체크 (접근 가능할 때)
- `포켓 앨범` 검색 결과 수 → 3,000건 미만이면 진입 가능성 높음
- 상위 20개 중 가격 3,000원~12,000원 구간 비율 확인
- 리뷰 100개 이상 셀러 비율 확인 (레드오션 신호)

## 후보 B: 투명 스티커 세트 / 다꾸 스티커

### 구매 상황 (m50 기준)
"다이어리 꾸미기" — 플래너·불릿저널·여행 다이어리 사용자. 디자인 테마 차별화(여행/자연/아날로그 감성)로 범용 스티커와 분리 가능.

### DataLab 쿼리 플랜

| 우선순위 | 키워드 | 주의 |
|---------|-------|------|
| 1 | `투명 스티커` | 가장 직접적인 수요 키워드 |
| 1 | `다꾸 스티커` | 다이어리 꾸미기 세그먼트 직결 |
| 2 | `다이어리 스티커` | 범용 — 경쟁 과밀 가능성 |
| 2 | `씰 스티커` | 봉투씰 vs. 다꾸 씰 혼재 주의 |
| 2 | `포인트 스티커` | 플래너 사용자 타깃 |
| 3 | `여행 스티커` | 볼륨 작을 수 있으나 user-fit 최고 |
| 3 | `플랜 스티커` | 플래너 특화 |

**DataLab API 파라미터 가이드:**
```json
{
  "startDate": "2025-06-01",
  "endDate": "2026-06-01",
  "timeUnit": "month",
  "keyword": ["투명 스티커", "다꾸 스티커", "다이어리 스티커", "씰 스티커", "포인트 스티커"]
}
```

### 타오바오 소싱 쿼리

| 한국어 | 타오바오 검색어 | 예상 가격대 |
|--------|--------------|----------|
| 투명 스티커 세트 | `透明贴纸套装`, `PVC透明贴纸` | 200-600원/팩 |
| 다꾸 스티커 | `手帐贴纸套装`, `手账装饰贴` | 300-800원/팩 |
| 여행 테마 스티커 | `旅行主题贴纸`, `旅游贴纸` | 300-700원/팩 |
| 자연/식물 테마 | `植物贴纸`, `花卉装饰贴` | 200-600원/팩 |

**소싱 주목 포인트:**
- 테마 다양성: 여행/자연/레트로 테마 1-3가지로 한정 → SKU 단순화
- 시트 단위 소싱 → 한국식 `스티커팩`으로 리패키징 가능 여부
- MOQ: 일반적으로 낮음(100개~). 컷팅 완성도·잉크 번짐 샘플 QA 필수

### Naver Shopping 경쟁도 체크 (접근 가능할 때)
- `투명 스티커` 검색 결과 수 → 10,000건 이상이면 레드오션 신호
- 상위 20개 중 가격 1,500원~5,000원 구간 비율 확인
- 여행 테마 특화 셀러 수 확인 (니치 공간 탐색)

## 스코어링 루브릭 (로컬 팀용)

DataLab + Shopping 결과 나오면 아래 기준으로 최종 1순위 선택:

| 기준 | 배점 | 측정 방법 |
|------|-----|----------|
| DataLab 트렌드 | +2 안정/성장, -1 하락 | 12개월 시리즈 |
| 월 검색량 | +2 30k+, +1 10-30k, 0 <10k | SearchAd PC+mobile |
| Shopping 경쟁 수 | +2 <3k, +1 3-10k, 0 10k+ | 쇼핑 검색 결과 수 |
| 소싱 단가 여유 | +2 소싱<30%, 0 소싱>50% | 타오바오 vs. 예상 판가 |
| 사용자 fit | +2 ★★★, +1 ★★ | intents/active 기준 |
| **합계** | 6+ 진행, 3-5 검토, <3 홀드 | |
