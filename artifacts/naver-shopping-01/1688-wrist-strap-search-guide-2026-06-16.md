## 목적

손목 스트랩 (손목 연결 보조 줄, 분실·낙하 방지) GREEN 판정 이후 **1688/타오바오에서 샘플을 조회하는 단계**가 남아 있다. 이 문서는 로컬 실행 시 바로 사용할 수 있는 검색어·필터·평가 기준을 정리한다.

---

## 1688 검색 세션 가이드

### 1단계: 접속
- URL: https://www.1688.com
- 로그인: 알리바바/타오바오 계정
- 언어 설정: 중국어 (한국어 설정 시 결과 제한)

### 2단계: 검색어

우선 순위 순서로 검색:

| 순서 | 검색어 (중국어) | 한국어 의미 |
|------|----------------|-------------|
| 1 | `手机防丢绳 手腕` | 스마트폰 분실방지 줄 손목 |
| 2 | `手机挂绳 手腕` | 스마트폰 스트랩 손목 |
| 3 | `防摔绳 手腕` | 낙하방지줄 손목 |
| 4 | `手机腕绳` | 스마트폰 손목줄 |
| 5 | `手机防丢手绳` | 스마트폰 분실방지 손줄 |

### 3단계: 필터 기준

```
가격: 단가 5위안 이하 (~1,000 KRW)
MOQ: 50개 이하
배송: 인천/서울 직배송 가능 또는 포워더 사용 가능 확인
공급사 등급: 실적 있는 공급사 우선 (금색/은색 메달)
```

### 4단계: 리스팅 평가 체크리스트

각 공급사 리스팅에서 확인할 항목:

- [ ] **소재**: 나일론 편직(耐磨) > 면 > PVC (내구성 순)
- [ ] **후크 타입**: 스프링 클립 or 카라비너 스냅 (신뢰도 높음)
- [ ] **길이 조절**: 조절 클립(调节扣) 포함 여부
- [ ] **폰 연결 방식**: 범용 고리(手机孔挂钩) or 케이스 부착형
  - 범용 고리(이어폰 잭 구멍 or 케이스 구멍) = 호환성 넓음
  - 케이스 부착형 = 반품 리스크 높음 → 제외
- [ ] **색상 옵션**: 최소 블랙·네이비 가능 여부
- [ ] **샘플 가능 여부**: 리스팅 내 "可以打样" 문구 or 소량 주문 가능
- [ ] **사진 품질**: 실물 착용 사진 포함 여부

## 가격 계산 기준

| 항목 | 목표 수치 |
|------|----------|
| 소싱가 (1688 단가) | ≤ 5위안 = ≤ 약 950 KRW |
| 포워더 비용 포함 | 단가 기준 +300~500 KRW 예상 |
| 총 원가 목표 | ≤ 1,500 KRW |
| 네이버 판매가 목표 | 7,900 ~ 12,900 KRW |
| 마진 | 6,000 ~ 11,000 KRW = 마진율 75%+ |

## 주의사항 (재프레임 포인트)

**1688 리스팅 문구에서 주의:** `防盗` (도난 방지), `防抢` (강탈 방지) 포함 제품
- 네이버 스마트스토어에서 이 포지셔닝은 안전 클레임으로 연결될 수 있음
- **대신 사용할 설명:** "여행 중 스마트폰 분실·낙하를 줄이는 손목 연결 보조 줄"
- 상품명 권장: `스마트폰 손목 연결 보조줄 여행용` or `핸드폰 낙하방지 손목 스트랩`

## 샘플 주문 전략

```
1차 샘플: 2~3개 업체, 각 5~10개씩
우선 색상: 블랙, 네이비 (각 업체 1색씩 우선)
예산: 5만원 이내 (샘플 + 배송)
목표: 소재 품질, 후크 내구성, 사진 촬영 적합성 확인
```

### QA 체크포인트 (샘플 수령 후)

- [ ] 후크/스냅 10회 이상 개폐 테스트
- [ ] 500g 이상 하중 2분 걸기 (스마트폰 중량 ~180g × 안전계수)
- [ ] 길이 조절 클립 조작 편의성
- [ ] 손목 착용 시 불편함 여부
- [ ] 사진 촬영 시 시각적 품질 (제품 사진 배경 흰색에서 잘 보이는지)

## 타오바오 병행 검색 (선택)

1688보다 MOQ가 낮고 샘플 주문이 쉬운 경우:

- 검색어: `手机防摔绳 手腕 可以挂手机`

- 리뷰 100개 이상 공급사 우선

## 다음 단계 (샘플 조회 후)

1. 후보 공급사 2~3곳 선정 → 가격·MOQ·배송 협의
2. 샘플 주문 (소량)
3. 수령 후 QA → 합격 시 스마트스토어 입점 신청 타이밍 검토
4. 크로스바디 스트랩 2차 후보 재검토는 손목 스트랩 샘플 성공 후
