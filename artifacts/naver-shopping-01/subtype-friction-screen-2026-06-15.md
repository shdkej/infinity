## 1. 핸드폰 도난방지 스트랩 서브타입 (4종)

### 1-A. 코일형/스프링 분실방지 스트랩 (Universal Coil Safety Tether)

**형태**: 수축·확장 가능한 코일 스프링 코드 (~15cm→90cm). 한쪽 끝 클립(케이스 고리/가방 고리 연결), 반대쪽 손목 루프.

| 항목 | 내용 |
|---|---|
| 옵션 복잡도 | **낮음** — 색상 3-5종(블랙/투명/로즈/화이트/블루), 사이즈 없음 |
| 호환성 | **범용** — 케이스 고리 또는 가방 D링에 클립, 기종 무관 |
| 소싱 마찰 | **낮음** — AliExpress/Alibaba MOQ 1-20pc, 소싱 단가 1,000-3,000 KRW |
| 리테일 가격대 | 9,900-12,900 KRW (3x-10x 마진 가능) |
| 클레임 리스크 | **낮음** — 단순 기계식 제품, 육안으로 확인 가능 |
| 마케팅 주의 | "도난방지 보장"이 아닌 "분실·낙하 방지 보조 스트랩"으로 프레이밍 필수 |
| **판정** | ✅ **PROCEED** — 소싱 샘플 리스트로 진행 |

**이 서브타입이 최적인 이유**: 기종별 재고 분리 없음, 클레임 구조가 단순, 여행 맥락(소매치기 방지/낙하방지)과 자연스럽게 연결.

### 1-B. 크로스보디/목 스트랩 + 범용 어댑터 (Crossbody/Neck Strap with Universal Adapter)

**형태**: 60-160cm 긴 스트랩(넥/숄더), 범용 클립 또는 어댑터로 케이스 루그에 연결.

| 항목 | 내용 |
|---|---|
| 옵션 복잡도 | **중간** — 색상, 소재(나일론/가죽룩), 스트랩 폭 |
| 호환성 | 범용 클립 버전이면 OK, 어댑터 세트 별도 필요할 수 있음 |
| 소싱 마찰 | **중간** — 패션 컴포넌트로 사진/색상 불일치 클레임 가능 |
| 리테일 가격대 | 15,000-25,000 KRW |
| 클레임 리스크 | **중간** — "색상 다름", "소재 거칠음" 류 |
| **판정** | ⚠️ WATCH — 첫 SKU보다 두 번째 번들/add-on 후보 |

### 1-C. 태그홀더 패치 + 탈착 스트랩 (Adhesive Patch + Detachable Strap)

**형태**: 폰 뒷면에 붙이는 접착 실리콘/PU 루프 패치 + 탈착 스트랩.

| 항목 | 내용 |
|---|---|
| 호환성 | 범용 설계지만 매트/텍스처 폰 뒷면에서 접착 불량 가능 |
| 클레임 리스크 | **높음** — "접착력 없음", "폰 뒷면 손상" 클레임 구조적 |
| **판정** | ❌ HOLD — 클레임 리스크가 공급사 수준에서 해결 불가 |

### 1-D. 일체형 케이스 (Phone Case with Integrated Strap Attachment)

**형태**: D링/스트랩홀 내장 케이스. 기종마다 별도 SKU.

| 항목 | 내용 |
|---|---|
| 옵션 복잡도 | **매우 높음** — 아이폰 14/15/15 Pro + 갤럭시 S23/S24/S25 등 모델별 |
| 클레임 리스크 | **높음** — "기종 맞지 않음" |
| **판정** | 🚫 REJECT — 소규모 시작 포지션과 불일치 |

## 2. 압축 파우치 서브타입 (3종)

### 2-A. 롤압축 파우치 2-3종 세트 (Roll-Compression Packing Set)

**형태**: 롤링+클립으로 압축하는 파우치 세트 (S/M 또는 S/M/L).

| 항목 | 내용 |
|---|---|
| 옵션 복잡도 | **중간** — 색상 + 2pc vs 3pc 세트 구성 |
| 클레임 리스크 | **중간-높음** — "생각보다 압축 안 됨", 지퍼 파손 클레임 |
| 기대값 불일치 | 롤 압축과 진공 압축의 차이를 구매자가 혼동 → 실망률 높음 |
| 소싱 마찰 | **중간** — 지퍼 품질 편차가 공급사마다 큼 |
| **판정** | ⚠️ WATCH (메시지 리스크 주의) — 첫 SKU로는 비추 |

### 2-B. 세탁물/습식 파우치 (Wet/Dirty Laundry Pouch)

**형태**: 방수 지퍼 파우치, 젖은 수영복·세탁물 분리용.

| 항목 | 내용 |
|---|---|
| 클레임 리스크 | **낮음** — 단순 방수 파우치, 기대값 명확 |
| 수요 신호 | **매우 약함** — `세탁물파우치` SearchAd <10 PC + 20 mobile/mo |
| **판정** | ❌ HOLD — 수요 신호가 너무 약해 단독 리드 불가 |

### 2-C. 납작 압축팩 2종 (S+L) 세트

**형태**: 평면 지퍼형 의류 압축팩, S와 L 2개 세트.

| 항목 | 내용 |
|---|---|
| 옵션 복잡도 | **중간** — S+L 고정 세트, 2색 이하 |
| 클레임 리스크 | **중간** — 지퍼 품질, 소재 질감 |
| 수요 신호 | `압축파우치` 키워드 우산 하에 포함 (1,230 PC + 7,020 mobile/mo) |
| **판정** | ⚠️ WATCH — 지퍼 품질 커레이션 필수; 단독 리드보다 add-on |

## 4. 다음 액션

**즉시 진행 가능:**
- 코일형 분실방지 스트랩 소싱 샘플 리스트 작성 (AliExpress/Alibaba 3-5 공급사)
  - 목표 스펙: 코일 확장 80-100cm, 클립 내구성 확인, 색상 3-4종, MOQ 5-20pc, 소싱 단가 목표 <3,000 KRW

**보류 (나중에 add-on으로 재검토):**

- 롤압축 파우치: 코일 스트랩 안착 후 add-on 검토, 단독 리드는 보류
