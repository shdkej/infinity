## 신규 소싱 우선 후보 (우선순위 순)

### #1 다이어리/여행 스티커 ★★★

**사용자 핏**: 여행 기록 + 메모리 메이킹 + 다이어리 문화 ✓  
**소싱 용이성**: 극히 낮은 MOQ, 가볍고 보관 쉬움, 반품 리스크 거의 없음 ✓  
**옵션 복잡도**: 낮음 (디자인 세트 단위로 단순화 가능)  
**예상 리스크**: 경쟁 심하지만 디자인/테마 차별화 가능. 여행 테마 특화면 노이즈 적음

**조회 쿼리**:
- OpenAPI top-10: `다이어리 스티커`, `여행 스티커`, `여행 다이어리 스티커`, `버킷리스트 스티커`
- SearchAd 정확 조회: `다이어리 스티커`, `여행 스티커`

**결정 기준**: 월 검색량 3,000+ + 모바일 CTR 2%+ + 상위 10개가 단순 generic sticker shop이 아닌 테마 제품이면 진행

---

### #2 케이블/이어폰 정리 파우치 ★★★

**사용자 핏**: AI/creator 워크플로우 + 여행 기술 정리 ✓  
**소싱 용이성**: 원단 파우치 대량 생산, 도매 쉬움, 가벼움 ✓  
**옵션 복잡도**: 낮음 (색상 2~3가지면 충분)  
**예상 리스크**: 시장 진입 쉬운 만큼 경쟁 있음. 특색 있는 라벨/디자인으로 차별화 필요

**조회 쿼리**:
- OpenAPI top-10: `케이블 정리 파우치`, `이어폰 파우치`, `케이블 파우치`, `여행 케이블 파우치`
- SearchAd 정확 조회: `케이블 파우치`, `이어폰 정리 파우치`

**결정 기준**: 월 검색량 2,000+ + 모바일 CTR 3%+ + 상위가 파우치 전문 상품이면 진행

---

### #3 폴라로이드 앨범 / 포토카드 슬리브 ★★

**사용자 핏**: 여행 메모리 메이킹, 사진 보관 ✓  
**소싱 용이성**: 기성품 대량 공급 가능 ✓  
**옵션 복잡도**: 중간 (사이즈, 용량별 옵션 있으나 1~2 SKU 먼저 테스트 가능)
**예상 리스크**: 아이돌 포토카드 시장이 섞일 수 있음 → "여행" 프레임으로 카테고리 분리 필요

**조회 쿼리**:
- OpenAPI top-10: `폴라로이드 앨범`, `여행 포토앨범`, `포토카드 수납 앨범`, `즉석 사진 앨범`
- SearchAd 정확 조회: `폴라로이드 앨범`, `여행 포토앨범`

**결정 기준**: 아이돌 노이즈 비율 < 40% + 여행/사진 특화 판매자 상위 3개 이상이면 진입 고려

---

### #4 여행 세탁망 ★★

**사용자 핏**: 여행 실용, 극소 마찰 소싱 ✓  
**소싱 용이성**: 가장 단순한 기성품, MOQ 없음, 극히 낮은 반품률 ✓  
**옵션 복잡도**: 매우 낮음 (대/중/소 또는 색상만)  
**예상 리스크**: 가격 경쟁 심할 수 있음. 브랜드 스토리가 없어 콘텐츠 생산 어려울 수도

**조회 쿼리**:
- OpenAPI top-10: `여행 세탁망`, `여행용 세탁 파우치`, `이너백 세탁망`, `여행 빨래망`
- SearchAd 정확 조회: `여행 세탁망`

**결정 기준**: 월 검색량 1,500+ + 상위 판매자가 특정 브랜드 위주가 아니면 진입 가능

---

### #5 슈즈백 / 신발 파우치 ★★

**사용자 핏**: 여행 정리, 기능적 ✓ (창의/기록 각도는 약함)  
**소싱 용이성**: 기성품 도매 쉬움, 부피 가벼움 ✓  
**옵션 복잡도**: 낮음 (사이즈 S/L 정도)  
**예상 리스크**: 스포츠 슈즈백과 겹칠 수 있음

**조회 쿼리**:
- OpenAPI top-10: `여행 슈즈백`, `신발 파우치`, `여행용 신발 주머니`, `구두 파우치`
- SearchAd 정확 조회: `여행 슈즈백`, `신발 파우치`

**결정 기준**: 여행 맥락 제품이 상위 5개 이상 + CTR 2%+ 이면 진입 고려

### #6 라벨 스티커 / 인덱스 탭 ★★

**사용자 핏**: 문서화 + 일상 시스템 + 다이어리 정리 ✓  
**소싱 용이성**: 단가 낮고 가벼움, 세트 구성 쉬움 ✓  
**옵션 복잡도**: 낮음  
**예상 리스크**: 사무용품 시장과 겹칠 수 있음. "여행/여행자" 맥락 분리 중요

**조회 쿼리**:
- OpenAPI top-10: `라벨 스티커`, `인덱스 탭`, `분류 스티커`, `다이어리 인덱스 탭`
- SearchAd 정확 조회: `인덱스 탭`, `다이어리 라벨 스티커`

**결정 기준**: 사무용품 노이즈 비율 < 50% + 다이어리/플래너 맥락 제품 상위 존재 시 진입

**조회 쿼리**:
