## 목적

소싱 마찰 스크린에서 GREEN 판정을 받은 **손목 스트랩(손목 연결 보조 줄)** 의 1688/타오바오 샘플 조회를 위한 실행 가이드. 로컬 에이전트 또는 사용자가 직접 이 가이드를 따라 샘플을 조회하고 주문할 수 있다.

## 검색어 (중문 키워드)

| 우선순위 | 중문 키워드 | 설명 |
|----------|-------------|------|
| 1순위 | `手机防丢绳 手腕` | 폰 분실방지 줄 + 손목 |
| 1순위 | `手机挂绳 手腕` | 폰 스트랩 + 손목 |
| 2순위 | `手腕绳 手机` | 손목 줄 + 폰 |
| 2순위 | `手机腕绳` | 폰 손목 줄 (축약) |
| 보조 | `防丢手腕绳` | 분실방지 손목 줄 |
| 보조 | `手机背带 手腕 旅行` | 폰 스트랩 손목 여행 |

## 필터 조건

### 필수 필터
- **단가**: ≤1,000 KRW (약 5 CNY 이하)
- **MOQ**: ≤50개 (소량 샘플 가능한 공급사)
- **소재**: 나일론 또는 폴리에스터 우선 (가죽은 단가 높고 QA 복잡)

### 권장 필터 (1688 기준)
- `实力商家` (실력 상인) 또는 `诚信通` (성신통) 인증 공급사 우선
- 月销量 (월 판매량) ≥100개 이상 공급사
- 주문 후 7일 내 발송 가능한 공급사

## 제품 스펙 체크리스트

### 핵심 스펙 확인
- [ ] 길이 조절 가능 여부 (슬라이더 클립 포함 여부)
- [ ] 폰 연결 방식: 케이스 구멍 통과 vs. 범용 어댑터 vs. 클립
- [ ] 소재: 나일론 브레이드 / 파라코드 / 실리콘
- [ ] 색상 최소 2가지 (블랙, 네이비) 가능 여부
- [ ] 후크/연결부 소재 (아연 합금 > 플라스틱)

### 샘플 QA 포인트
- [ ] 클립/후크 내구성 (100회 이상 탈착 테스트)
- [ ] 줄 길이 15-25cm (손목 착용 시 폰이 손바닥에 자연스럽게)
- [ ] 봉제선/마감 상태
- [ ] 클립 잠금 방식 (스냅 vs. 비틀림)

## 가격 분석

### 소싱 목표 가격
| 항목 | 목표 |
|------|------|
| 소싱가 | ≤1,000 KRW (≤5 CNY) |
| 한국 배송비 (500개 기준) | 개당 500 KRW 이하 |
| 총 원가 (제품+배송) | ≤1,500 KRW |
| 네이버 판매가 | 6,900–9,900 KRW |
| 예상 마진율 | 70–80% |
| 판매 수수료 (네이버 약 3%) | ~200–300 KRW |
| 순마진 | ~5,000–7,000 KRW/개 |

### 가격 비교 방법
1. 1688에서 상위 10개 공급사 단가 비교
2. 동일 제품 타오바오 가격과 비교 (보통 1688이 30-50% 저렴)
3. 배송비 포함 총 원가 기준으로 평가

## 샘플 주문 방법 (1688 기준)

### 1688 샘플 주문 프로세스
1. 로그인 후 `手机防丢绳 手腕` 검색
2. 좌측 필터: `支持样品` (샘플 지원) 체크
3. 가격 오름차순 정렬 → 5 CNY 이하 필터
4. 상품 상세에서 `联系客服` (고객서비스 문의)로 샘플 가능 수량·단가 확인
5. 샘플 2-3개 (블랙, 네이비 우선) 주문

### 배송 방법 (한국)
- **공급사 직배**: 일부 공급사는 한국 직배 가능 (EMS/e-PACK)
- **포워딩 서비스**: 中韩快递 또는 배대지 활용 권장
  - 예상 배송비: 500g 이하 약 10,000-15,000 KRW
  - 배송 소요: 7-14일

## 공급사 평가 기준

### GREEN 공급사 신호
- 월 판매량 500+ (또는 累计评价 200+)
- 응답률 90% 이상
- 사진 퀄리티 좋음 (실사 포함)
- 한국 수출 경험 (한국어 구매자 리뷰 또는 `韩国` 언급)
- 샘플 소량 1-5개 가능

### RED FLAG
- 최소 주문 수량 1,000개 이상 고집
- 가격이 너무 낮음 (1 CNY 미만): 품질 의심
- 사진이 복사/도용된 것처럼 보임
- 응답 없거나 24시간 이상 지연

## 네이버 스마트스토어 입점 타이밍

샘플 수령 후 다음 단계:
1. 샘플 QA 통과 시 → 스마트스토어 입점 신청 진행
2. 입점 전 필요: Commerce ID 로그인 확인 (Waiting 카드 참조)
3. 상품명 안: "여행 스마트폰 손목 고리 분실낙하방지 보조줄" (한국어 포지셔닝)
