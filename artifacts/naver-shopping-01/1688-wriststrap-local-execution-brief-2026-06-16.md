## 1. 목표 상품 재확인

**제품**: 손목 연결 보조 줄 (Wrist Phone Strap / Wrist Lanyard)

- 포지셔닝: "여행 중 스마트폰 분실·낙하를 줄이는 손목 연결 보조 줄"
- **"도난방지" 주장 X → "분실·낙하 방지 보조 연결줄" O**
- 목표 소싱가: ≤¥5 CNY/piece (≈1,000 KRW)
- 목표 MOQ: ≤50개 (샘플 단계는 5–10개)
- 우선 색상: 블랙, 네이비

- 가격 범위: ¥0.3 ~ ¥5 (개당 도매가)
- 지역 우선: 광동성(廣東), 절강성(浙江) — 부자재·액세서리 제조 클러스터
- 결제: 알리페이 지원 판매자 우선
- 실적: 누적 거래 내역 확인 가능한 판매자

## 3. 제품 스펙 확인 포인트

### 소재/제작
- [ ] 스트랩 소재: 나일론(nylon) 또는 브레이드 나일론 권장
- [ ] 후크/클립 소재: 아연합금(zinc alloy) 권장, 플라스틱은 약해 탈락 기준
- [ ] 핸드폰 연결부: 범용 스마트폰 케이스 홀 적합 여부
- [ ] 길이 조절: 슬라이더 방식 or 고정 길이 여부 확인
- [ ] 색상 일관성: 로트별 색 편차 위험 확인

### 포장
- [ ] 개별 포장 방식 (비닐봉지 vs 택 라벨)
- [ ] OEM 로고 인쇄 가능 여부 (지금은 불필요, 추후 참고)

### 상품 설명 핵심 포인트
1. **여행 시나리오**: 유럽 여행, 지하철, 혼잡한 장소에서 스마트폰 분실·낙하 방지
2. **자연스러운 보호**: 손목에 연결하면 자연스럽게 낙하·분실 감소 (도난방지 주장 대신)
3. **착용 사진 필수**: 손목에 착용한 실제 사진 → 사용법 명확하게
4. **단순한 선택지**: 블랙, 네이비 2종

## 6. QA 체크리스트 (샘플 수령 후)

- [ ] 스트랩 소재 실제 확인 (나일론 질감, 색 균일성)
- [ ] 클립/후크 잠금 강도 확인 (핸드폰 연결 후 흔들어보기)
- [ ] 길이 조절 기능 작동 여부
- [ ] 세탁/마찰 후 색 바램 여부 (간이 테스트)
- [ ] 포장 상태 사진 촬영 (상품 등록용 원본)
- [ ] 착용 사진 촬영 (모델/자가 촬영)

## 7. 1688 가격대별 판단 기준

| 소싱가 | 품질 | 판단 |
|--------|------|------|
| ≤¥5 (~1,000 KRW) | OK | → 50개 본주문 진행 |
| ¥5–10, | OK | → 재협상 또는 판매가 재검토 |
| ¥10+ | 보통 | → 다른 공급사 탐색 |
| 후크 품질 불량 | 무관 | → **무조건 탈락** (핵심 QA) |

1688 가격은 알리바바 대비 20–45% 저렴하며, MOQ도 1–2개부터 가능한 공급사 다수. 초기 샘플 5–10개는 대부분 수용.
