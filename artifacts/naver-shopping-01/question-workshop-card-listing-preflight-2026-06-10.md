## §1. 사용 맥락 확정 (Use-Case Lock)

**선정된 리드 프레임**: AI/creator workshop facilitation cards

다음 중 **하나의 1차 사용 맥락**을 확정해야 한다 (전부를 표방하면 포지셔닝이 흐려짐):

- [ ] AI 제품 브레인스토밍 워크숍 (AI product brainstorm)
- [ ] 크리에이터 스프린트 회고 (creator sprint review)
- [ ] 창업자/팀 회고 카드 (founder/team retrospective)
- [ ] 제품 관찰/피드백 세션 (product-observation / founder reflection)
- [ ] 여행 인사이트→콘텐츠 전환 세션 (travel insight-to-content)

> **추천**: AI 제품 브레인스토밍 + 크리에이터 스프린트 회고를 묶은 "AI×창작 워크숍 촉진 카드"  
> 이유: 두 맥락은 서로 겹치는 구매 상황이며, 33,000원 프리미엄 선례(코칭 인사이트 질문카드)와 같은 교육/워크숍 채널을 공유한다.

## §2. 상품 스펙 잠금 (Card Format / Spec)

등록 전에 아래 사항을 확정해야 한다:

- [ ] 카드 수량 (예: 40장, 60장, 80장)
- [ ] 카드 크기 (예: A6, 명함, 정사각형 90mm)
- [ ] 소재/코팅 (아트지 + UV 코팅, 무광코팅 등)
- [ ] 가이드북/활용법 포함 여부
- [ ] 패키지 형태 (케이스, 박스, 봉투)

> 스펙이 카피에 앞서야 한다 — "몇 장 들어 있는 카드인지"가 제목 바로 다음 관심사.

## §3. 제목/키워드 포지셔닝 (Title / Keyword, DRAFT)

### 핵심 규칙
- **금지**: 제목을 `AI 워크샵 카드` 또는 `크리에이터 워크샵 카드`로 시작하지 않는다 → 야유회/팀빌딩/타로 게임 풀로 흡수됨
- **검색 브릿지**: `워크샵 질문 카드` (23,997) → 개념이 가장 명확한 단어지만 기업 레크리에이션/아이스브레이킹 성향
- **보조 브릿지**: `질문 카드` (18,840), `대화 카드` (18,233) → 폭넓은 수요지만 generic 풀

### 제목 후보 (DRAFT, 사용자 승인 전 비공개)

| 번호 | 후보 제목 | 전략 |
|------|-----------|------|
| T1 | [브랜드] AI·크리에이터 워크숍 질문 카드 — 60장 | 브릿지 `워크샵 질문 카드` + 카드 수량 |
| T2 | 창작자를 위한 워크숍 촉진 카드 [수량]장 | AI 명시 없음; 카피로만 크리에이터 맥락 |
| T3 | [브랜드] 기획 · 회고 · 피드백 질문 카드 | 사용 맥락 3종 나열 (검색 노출 보조) |

> **T1 추천**: 키워드 브릿지 + 스펙 명시 + copy lead 여지. 단, `AI`가 제목에 포함될 경우 야유회 풀 희석 위험 실측 필요 (visual-rank 블록 해제 후 확인).

### 키워드 그룹 (보조)
- 1군: `워크샵 질문 카드`, `질문 카드`, `대화 카드`
- 2군: `아이스브레이킹카드`, `인사이트카드` (고CTR 소량)
- 3군 (카피 내 노출): AI 워크숍, 크리에이터 회고, 팀 회고, 제품 피드백, 기획 세션

## §5. 등록 마찰 / 규정 준수

- 카드 상품은 통상 별도 카테고리 허가가 없음 (복권·도박류 게임은 제외)
- **주의**: 워크숍/교육 카드로 포지셔닝할 경우 "게임 카드" 카테고리 등록 → 교육 카드 등록 시 카테고리 변경 불이익(노출 지연) 가능
- 인지도가 없는 브랜드 신제품 → 초기 리뷰 확보 전략 필요 (체험단 / 쿠폰 이벤트)
- 브랜드·호환·규격 표기 없음 (여기서는 해당 없음)
