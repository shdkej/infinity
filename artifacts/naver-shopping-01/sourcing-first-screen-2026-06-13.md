# 나래 소싱 후보 광역 스크리닝 — 2026-06-13

**배경**: 러기지택/캐리어네임택이 사용자 선호 낮음으로 하향됨 (2026-06-11). 소싱 중심으로 재초점, 제작보다 기성품/위탁 소싱 가능한 상품 후보를 넓게 스크린.

**스크리닝 기준**:
- 샘플 마찰(Sample Friction): 소량 샘플 구매 용이성 (LOW = 국내 인쇄소/도매꾹 소량 가능)
- 옵션 복잡도(Option Complexity): SKU 옵션 수 (LOW = 1-3가지)
- QA/반품 위험: 불량/반품 가능성 (LOW = 종이류, 기능 없음)
- 사용자 취향 부합: 여행·기록·일상 시스템·AI/크리에이터 워크플로우

| 항목 | 평가 |
|------|------|
| 사용자 취향 | ★★★★★ — 여행 기록 + 다이어리꾸미기, 탑승권/티켓 비주얼 |
| 샘플 마찰 | LOW — 국내 스티커 인쇄소(1-5장 소량 주문 가능) |
| 옵션 복잡도 | LOW — 디자인 1-3종, 크기 1-2종 |

| 네이버 수요 신호 | `여행 스티커`, `다이어리 스티커` — 다이어리꾸미기 카테고리 꾸준한 수요 |

| 다음 검증 | 네이버 키워드 수요(SearchAd) + 경쟁사 1-2개 분석 |

## 요약 및 다음 단계

**결론**: Tier 1 후보 3개 모두 소싱 마찰 낮고 종이류 상품정보고시 부담 없음. 사용자 취향 최부합은 **여행 티켓 스티커 세트**.

**다음 액션 (우선순위 순)**:
1. Tier 1 후보 중 1개 최종 선택 (사용자 확인 또는 Narae 자율 판단)
2. 선정 후보 네이버 SearchAd 키워드 수요 검증 (`여행 스티커`, `다이어리 스티커` 등)
3. 경쟁사 1-2개 상세 분석 (리뷰 수, 가격대, 콘텐츠 앵글)
4. 소싱처 1개 컨택 / 샘플 요청 (가격·리드타임 확인)
5. 통과 시 → 소싱·등록 승인 요청 (Infinity Waiting)

**승인 경계**: 
- 소싱처 컨택, 샘플 주문 비용 발생 → Infinity Waiting 등록 + 사용자 확인
- 네이버 키워드 수요 검증(DataLab/SearchAd) → L0, 자율 실행 가능
