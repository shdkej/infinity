## 1. 케이블/충전기 파우치

### 구매 상황
- "여행 짐 쌀 때 케이블이 엉켜서" / "여행가방 속 충전기·케이블 정리"
- 여행 전날 짐 싸기, 출장 준비, 가방 속 케이블 정리가 필요할 때

### 사용자 fit
- 여행-adjacent ★★★
- 디지털 노마드/크리에이터 + 여행 조합 ★★★
- 일상 시스템 정리 fit ★★
- 사용자 content angle: "해외여행 짐 싸기" / "여행 파킹 루틴" 자연스러움

### 소싱 평가
- 1688/Taobao 직구: 쉬움 (MOQ 낮음, 색상/소재/크기 옵션 단순)
- QA 난이도: 낮음 (지퍼 내구성 정도)
- 반품 위험: 낮음
- 묶음 가능: 충전기 파우치 + 케이블타이 세트 등 소단위 번들

### 경쟁 예상
- 중간 경쟁: generic 케이블 파우치는 많지만 용량·구조·소재 차별화 여지 있음
- "여행 케이블 정리"라는 구매 상황 framing이 generic 오브젝트명보다 강할 수 있음
- 큰 셀러들은 주로 사무용/멀티포켓 방향 → 여행-specific이 빈 공간일 수 있음

### DataLab 검증 키워드 (로컬 실행용)
1. `케이블 파우치` (primary)
2. `충전기 파우치` (primary)
3. `여행 케이블 정리` (purchase-situation framing)
4. `충전기 정리 파우치` (compound)
5. `여행 충전기 파우치` (travel-specific)

### 판정
**DataLab 1순위** — fit 높음, 소싱 쉬움, 차별화 여지 있음, 사용자 content 연결 자연스러움

## 2. 휴대폰 도난방지 스트랩/테더

### 구매 상황
- "해외여행 전 소매치기 걱정" / "붐비는 관광지·지하철에서 스마트폰 보호"
- 여행 안전 준비 단계 (짐 싸기 전 보안 체크)

### 사용자 fit
- 여행-safety ★★★
- 기억/기록 도구(스마트폰)를 지키는 맥락으로 자연스러움
- 사용자 content angle: "해외여행 안전 준비" / "도난방지 루틴" 연결 가능

### 소싱 평가
- 1688 기본 available, 와이어/클립 타입 다양
- 소재 종류: 나일론/스테인리스 와이어/에나멜 코팅 등 → 옵션 복잡도 중간
- QA: 금속 클립 내구성, 와이어 두께 확인 필요
- 묶음 가능: 여행 보안 세트 (자물쇠 + 스트랩 등)

### 경쟁 예상
- **낮은 편** — 나이스 키워드가 명확하지 않아 검색 볼륨이 불확실
- "핸드폰 스트랩"은 패션 neck strap과 혼재 가능 → 여행 컨텍스트 명시 필요
- 경쟁이 낮으면 margin 좋지만 수요 볼륨도 낮을 수 있음

### DataLab 검증 키워드 (로컬 실행용)
1. `스마트폰 도난방지` (primary intent)
2. `핸드폰 테더` (product type)
3. `여행 핸드폰 스트랩` (travel-specific)
4. `도난방지 폰 스트랩` (compound)
5. `여행 핸드폰 도난방지` (purchase-situation)

### 판정
**DataLab 1순위 (수요 볼륨 확인 필요)** — fit 높고 경쟁 낮을 수 있지만 수요 불확실. DataLab 확인 후 판단.

## 3. 압축/세탁물 분리 파우치

### 구매 상황
- "장기 여행 짐 정리" / "여행가방 속 세탁물 분리 + 용량 절약"
- 1주일 이상 여행 준비 단계

### 사용자 fit
- travel packing system ★★
- 여행 시스템 정리 fit은 있지만 commodity 위험
- 사용자 content angle: "장기 여행 짐 최소화" / "여행 짐 정리 시스템"

### 소싱 평가
- 단순 commodity: 1688 쉬움, MOQ 낮음
- 경쟁 높음 — 대형 셀러, 가격 경쟁 심함
- QA: 소재 내구성, 지퍼, 압축 기능 확인
- 묶음 가능: 압축 파우치 세트 (크기별 3~5개)

### 경쟁 예상
- **높은 경쟁** — generic 상품이 많고 가격 압박 심함
- 여행-specific framing으로 차별화 가능하지만 한계 있음
- margin: 낮은 편

### DataLab 검증 키워드 (로컬 실행용)
1. `압축 파우치` (primary)
2. `여행 압축 백` (travel-specific)
3. `세탁물 파우치` (laundry separation)
4. `여행 세탁물 분리` (purchase-situation)
5. `압축 여행 파우치` (compound)

### 판정
**DataLab 2순위** — commodity 위험 높음. DataLab 수요 확인 후 경쟁 수준과 margin 재평가.
