## 후보 상세

### 1. 케이블/충전기 파우치 ← DataLab 1순위 ✓

**핵심 구매 상황:** "여행 전 짐 싸는 중 케이블이 엉켜서" / "가방 속 충전기 매번 찾기 힘들어서"

구매 타이밍 명확: 여행 예약 → 짐 준비 → 케이블 정리 문제 인지 → 구매

**Naver 키워드 후보:**
- 1순위: `케이블 파우치`, `전자기기 파우치`
- 2순위: `여행 케이블 파우치`, `케이블 정리 파우치`
- 제외: `여행 파우치` (범용 경쟁 과밀)

**소싱 경로:**
- 타오바오: 매우 용이 (수백 SKU, 샘플 빠른 조달 가능)
- 국내 도매: 중국산 OEM 다수 취급
- 예상 소싱가: 1,500–3,000원

**옵션 구성:** 사이즈 2종 (S·M) + 색상 3종 → 최대 6 SKU
**예상 판매가:** 8,000–15,000원
**예상 마진율:** ~60% (물류비 이전 기준)

**QA 체크포인트:**
- 지퍼 내구성 (나일론 더블 슬라이더 권장)
- 내부 그리드/포켓 유지력
- 방수 코팅 (여행용 필수)

**차별화 포지셔닝:** "크리에이터 케이블 정리 시스템" — 기능성 + 미니멀 스타일
**콘텐츠 앵글:** "해외여행 짐 정리 루틴 / 케이블 엉킴 해결법" (사용자 여행·크리에이터 채널 자연 연계)

---

### 2. 압축/세탁물 분리 파우치 ← DataLab 2순위 (경쟁 주의)

**핵심 구매 상황:** "긴 여행 중 세탁한 옷 분리" / "짐 최소화하며 장기 여행"

**Naver 키워드 후보:**
- 1순위: `세탁물 분리 파우치`, `여행 속옷 파우치`, `여행 세탁 파우치`
- 2순위: `여행 압축팩` (경쟁 있으나 구체적)
- 제외: `압축팩` 단독 (대형 홈쇼핑 셀러 지배 → 진입 불가)

**소싱 경로:**
- 타오바오: 용이 (압축백·세탁물 분리백 다수)
- 예상 소싱가: 1,000–2,500원

**옵션 구성:** 사이즈 세트 (S/M/L) 또는 용도 분리형 (상의/하의/속옷)
**예상 판매가:** 7,000–15,000원 (세트 시 높음)
**예상 마진율:** ~60%

**경쟁 주의:** `압축 팩` 시장은 대형 셀러 지배. `세탁물 분리`로 구체화 필수.
**콘텐츠 앵글:** "미니멀 여행 짐 정리 시스템 / 4박 5일 짐 줄이기"

---

### 3. 휴대폰 도난방지 스트랩/테더 ← 수요 확인 후 판단

**핵심 구매 상황:** "유럽 여행 소매치기 불안" / "스마트폰으로 사진 찍다 떨어뜨릴까봐"

**Naver 키워드 후보 (불확실):**
- `폰 스트랩 여행`, `스마트폰 분실방지`, `핸드폰 도난방지 스트랩`
- `스마트폰 테더` (인지도 낮을 가능성)

**소싱 경로:**
- 타오바오: 용이 (손목 스트랩, 가방 클립 연결형 다수)
- 예상 소싱가: 500–1,500원

**옵션 구성:** 색상 3-5종, 연결 방식 (루프형/클립형)
**예상 판매가:** 5,000–12,000원
**예상 마진율:** ~65% (단가 낮아 절대 마진 작음)

**불확실 요소:**
- Naver 키워드 볼륨 불명확 → DataLab 검증 필수
- 도난방지 제품은 신뢰 필요 → 후기 축적이 중요
- 패션 폰 스트랩 시장과 겹칠 수 있음

**판단:** DataLab 수요 확인 후 진입 여부 결정. 케이블 파우치/세탁 파우치보다 후순위.
