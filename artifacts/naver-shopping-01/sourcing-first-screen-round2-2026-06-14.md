## 후보 상세

### R2-1. 케이블/충전기 파우치 (Round 1 #3 → 재평가)

**핵심 구매 상황:** "여행 전 짐 정리" — 케이블·충전기 엉킴 방지, 이어폰/보조배터리 함께 정리

**Naver 키워드 분석:**
- `케이블 파우치` — 전자기기 액세서리 전문 키워드, 크리에이터/직장인/여행자 타겟
- `충전기 파우치` — 직접 구매 의도
- `여행 케이블 파우치` — 여행 맥락 강조 롱테일
- **주의**: `여행 파우치`는 경쟁 과밀 → `케이블 파우치`로 구체화 필수
- 경쟁 구도: IT액세서리 전문몰, 문구/디자인 브랜드

**소싱 경로:** 타오바오 "旅行数据线收纳包" — 즉시 소싱, 가격대 3,000-15,000원

**옵션 구성:** 사이즈(S/M), 색상 2-3가지 → 낮은 복잡도

**QA 리스크:** 지퍼 내구성 확인 필요 → 중간

**콘텐츠 각도:** "여행 짐 정리 꿀팁", 케이블 정리 before/after

**포지셔닝 기회:** "여행 전용 케이블 정리 파우치" — 일반 케이블 오거나이저 대비 여행 특화 포지셔닝

**결론:** DataLab `케이블 파우치` 검색량 확인 후 타오바오 샘플 발주 검토. R1보다 핏은 낮지만 실용 니즈 명확.

### R2-2. 휴대폰 도난방지 스트랩/테더 (NEW)

**핵심 구매 상황:** "해외여행 소매치기 방지", "관광 중 핸드폰 분실 예방"

**Naver 키워드 분석:**
- `핸드폰 스트랩` / `스마트폰 스트랩` — **패션 스트랩 시장 지배** (케이스 부착형 장식 스트랩이 주)
- `핸드폰 목걸이줄` — 목걸이 케이스/폰 홀더와 경쟁
- `도난방지 폰 홀더` / `스마트폰 도난방지` — 매우 니치, 시장 규모 불확실
- **핵심 문제**: "도난방지" 기능성과 "패션 스트랩" 시장이 혼재; 구매자가 검색하는 키워드가 "안전"보다 "스타일/패션"에 가까울 가능성 높음

**대안 키워드:** `여행 폰 스트랩`, `핸드폰 목걸이줄 여행`, `스마트폰 홀더 여행`

**소싱 경로:** 타오바오 "防盗手机绳/防盗手机链" — 기능성 제품 소싱 가능

**옵션 구성:** 색상/소재 → 낮은 복잡도

**QA 리스크:** 클립/연결부(핸드폰 케이스 부착 포인트) 내구성 → 중간

**콘텐츠 각도:** "여행 안전 팁", "소매치기 방지 여행 준비물" — 자연스러운 연결

**우려 사항:**
1. 패션 스트랩 시장 포화; 기능성 포지셔닝이 차별화되지만 수요 규모 불확실
2. "도난방지"라는 키워드 자체의 네이버 쇼핑 검색량 약할 가능성
3. 사용자 fit이 기억보존/기록 핵심과 연결 약함

**결론:** HOLD. DataLab에서 `여행 폰 스트랩`, `핸드폰 목걸이줄` 검색량 확인 후 재평가 필요.

### R2-3. 압축/세탁물 분리 파우치 (NEW)

**핵심 구매 상황:** "장기여행 짐 줄이기", "세탁물·깨끗한 옷 분리 보관"

**Naver 키워드 분석:**
- `압축팩` — 가정용 이불/옷 보관 대형 브랜드 도미넌트 → 여행 목적과 혼재, 경쟁 과밀
- `여행 압축팩` — 여행 맥락, but 여전히 경쟁 있음
- `세탁물 파우치` / `더티백` — 명확한 구매 목적, 낮은 경쟁 가능성
- `여행 세탁물 정리` — 롱테일 키워드

**대안 포지셔닝:** `세탁물 파우치 여행`, `여행용 더티백`, `여행 세탁물 분리` — 니치하지만 의도 명확

**소싱 경로:** 타오바오 "旅行脏衣收纳袋" — 저가 대량 소싱 가능

**옵션 구성:** 사이즈(L/M/S 세트 또는 단품) → 낮은 복잡도

**QA 리스크:** 방수 코팅 내구성 → 낮음-중간

**콘텐츠 각도:** "여행 짐 정리 꿀팁", "파우치 세트 여행 짐 총정리"

**우려 사항:**
1. `압축팩` 키워드 경쟁 과밀 (가정용 대형 브랜드)
2. 가격대 낮고(3,000-8,000원대) 상품화 차별화 어려움, 마진 압박
3. `세탁물 파우치`로 니치화하면 경쟁 낮지만 수요 규모도 낮을 수 있음

**결론:** HOLD. DataLab에서 `세탁물 파우치`, `더티백 여행`, `여행 압축팩` 검색량 확인 후 판단. 단독 상품보다 여행 짐 정리 파우치 세트(케이블+세탁물+압축) 번들로 구성 가치 검토.
