## 후보 A: 포켓앨범 / 여행 사진 앨범

### 핵심 구매 상황
- **"여행 다녀온 후 사진 정리"** — 인스탁스·폴라로이드 즉석사진, 현상한 필름 사진 보관
- 귀국 후 1~2주 내 구매 타이밍 명확
- 사용자 fit: 여행·기억보존 테마와 직결

### 시장 수요 신호 (공개 정보)
- 인스탁스(후지필름) 공식 쇼핑몰 한국 서비스 활성화 → 즉석사진 시장 건재
- 아이돌 포카앨범 시장과 물리적 겹침 → 포지셔닝 분리 필수 (`포토카드앨범` 키워드 제외)
- `포켓앨범` / `여행앨범` / `인스탁스앨범` 키워드는 아이돌 노이즈 낮음
- 인스탁스 미니필름(100매) 가격비교 페이지 존재 → 소모품 시장과 동반 수요 예상

### 소싱 추정
| 항목 | 추정값 | 비고 |
|------|--------|------|
| 타오바오 도매가 | 500~2,000원/개 | 사이즈·매수에 따라 |
| 1688 대량 구매가 | 300~1,200원/개 | 50개 이상 주문시 |
| 국내 소매가 | 3,000~10,000원 | 사이즈·매수·디자인 |
| 마진율 추정 | 50~70% | 배송비 제외 |
| 옵션 수 | 1~3 (색상 또는 사이즈) | 복잡도 낮음 |
| 샘플 구매 최소 | 1~5개 | 타오바오 소량 가능 |

### 차별화 포인트
- 여행 사진 정리 전용 컨셉 (아이돌 포카앨범과 분리)
- 인스탁스 mini 사이즈 호환 포켓 설계 명시
- 여행 테마 컬러/패턴 (범용 클리어 앨범과 분리)

| 1 | `인스탁스앨범` | 카메라/즉석카메라 | 인스탁스 연동 수요 |

## 후보 B: 투명 스티커 세트 / 다꾸 스티커

### 핵심 구매 상황
- **"다이어리 꾸미기"** → 불릿저널·플래너·여행 기록 꾸미기
- 반복 구매(소모품 성격) → LTV 높음
- 사용자 fit: 기록·일상시스템·다꾸 문화와 직결

### 시장 수요 신호 (공개 정보)
- 🔑 **스티커가 문구류 주문 1위 (61% 차지)** — 국내 디지털 문구 플랫폼 조사
- 다꾸 시장 규모 약 100억원 (MZ세대 중심, 2020 기준 → 현재 더 성장 추정)
- 키즈타임·샐러드마켓 등 국내 도매몰에서 다꾸스티커 카테고리 운영 활성화
- SSG(신세계몰)에서도 다꾸스티커 카테고리 존재 → mainstream 진입
- 번개장터에서 타오바오 다이어리·스티커 개인 소싱 활발 → 수요 검증됨

### 소싱 추정
| 항목 | 추정값 | 비고 |
|------|--------|------|
| 타오바오 도매가 | 300~1,500원/팩 | 디자인·장수에 따라 |
| 1688 대량 구매가 | 150~900원/팩 | 100팩 이상 주문시 |
| 국내 소매가 | 2,000~6,000원/팩 | 테마·장수에 따라 |
| 마진율 추정 | 40~65% | 배송비 제외 |
| 옵션 수 | 디자인별 단품 팩 | 색상 옵션 불필요 |
| 샘플 구매 최소 | 1팩 (타오바오) | 즉시 소량 가능 |
| 국내 도매 최소 | 소량 (키즈타임 등) | 국내 소싱도 가능 |

### 차별화 포인트
- **여행/아날로그 기록 테마 특화** (범용 캐릭터 스티커와 분리)
- 투명 씰 스티커 → 노트/앨범/포스트카드 활용 가능
- 사용자가 자연스럽게 생산할 수 있는 콘텐츠 각도: 여행 다이어리 꾸미기 영상/사진

## DataLab 로컬 실행 플랜

나래(로컬 Claude)를 위한 DataLab 실행 순서:

```
실행 목표: 포켓앨범 vs 다꾸스티커 — 어느 쪽이 DataLab 수요가 더 강한가?

1단계: 쇼핑인사이트 키워드 클릭 트렌드 (최근 12개월)
   - 포켓앨범, 인스탁스앨범, 여행앨범 (카테고리: 아트/취미용품)
   - 다꾸스티커, 투명스티커, 다이어리스티커 (카테고리: 문구/사무용품)
   - 확인: 12개월 중 몇 개월 데이터 존재? 계절성 패턴?

2단계: SearchAd API (키워드 광고 데이터)
   - 월간 PC + 모바일 검색량
   - 경쟁 정도 (낮음/중간/높음)
   - 클릭 단가 추정

3단계: 쇼핑 결과 수 확인 (Naver Shopping 접근 가능 시)
   - `포켓앨범` 검색 결과 수 (경쟁 밀도)
   - `다꾸스티커` 검색 결과 수
   - 상위 10개 판매자 가격대 확인

판정 기준:
- 12개월 중 8개월 이상 데이터 존재 → 안정 수요
- SearchAd 월 모바일 검색량 1,000 이상 → 진입 검토
- 경쟁 결과 수 50,000 이하 → 진입 가능
```
