## 실행 목적

## 우선순위 실행 순서

### 1순위 (즉시 실행)

#### A. 포토 포켓 앨범 / 여행 사진 앨범

**DataLab 키워드 (`getKeywordClickTrend`, 12개월):**
1. `포켓 앨범`
2. `여행 사진 앨범`
3. `인스탁스 앨범`
4. `폴라로이드 앨범`
5. `미니 포토북`

**SearchAd 조회 (월간 검색량):**
- `포켓 앨범` — PC + mobile 합산
- `여행 앨범` — PC + mobile 합산
- `포토카드 앨범` (아이돌 시장 노이즈 감별용, 별도 확인)

**통과 기준:**
- DataLab: 최소 6/12개월 이상 존재 (0 없음)
- Mobile SearchAd: 합산 2,000회/월 이상
- Naver Shopping 상위 20개 중 아이돌 카드 홀더가 80% 미만 (진입 키워드 존재 확인)

**실패 신호:**
- DataLab 0/12 또는 완전 하락 추세
- Mobile <500/월 또는 아이돌 카드 홀더 노이즈 90% 이상

---

#### B. 투명 스티커 세트 / 다꾸 스티커

**DataLab 키워드 (`getKeywordClickTrend`, 12개월):**
1. `투명 스티커`
2. `다꾸 스티커`
3. `다이어리 스티커`
4. `포인트 스티커`
5. `씰 스티커`

**SearchAd 조회:**
- `투명 스티커` — PC + mobile 합산
- `다꾸 스티커` — PC + mobile 합산
- `다이어리 스티커` — PC + mobile 합산

**통과 기준:**
- DataLab: 12/12개월 상시 존재 (스테디셀러 확인)
- Mobile SearchAd: 합산 3,000회/월 이상
- 여행·기록 테마 틈새 확인 가능 (범용 스티커 이외 공간 존재)

**실패 신호:**
- Mobile <1,000/월
- 상위 20개 셀러 평균 리뷰 10,000+ (진입 장벽 과도)

## 로컬 실행 지시 (나래 에이전트)

```
Mode: execute_local
Goal: DataLab Round 2 키워드 수요 검증 (위 우선순위 순서대로)
Tools: Naver DataLab API (getKeywordClickTrend) + SearchAd 키워드 도구 + Naver Shopping 브라우저

실행 순서:
1. 1순위 A (포켓 앨범) — DataLab 키워드 5개 실행
2. 1순위 B (다꾸 스티커) — DataLab 키워드 5개 실행
3. SearchAd 검색량 조회 (A, B 각각)
4. Naver Shopping 경쟁 확인 (HTTP 418 해소 여부 먼저 확인)
5. 결과를 pass/fail 기준에 대조 → Go/No-Go 결정

Report: reports/naver-shopping-01/{timestamp}-local.html (HTML 필수)
Allowed: DataLab API 읽기, 브라우저 read-only
Forbidden: 상품 등록, 가격/재고/광고 변경, 계정 설정 변경
```

```
    NO  → A 단독 진행 (B는 다음 사이클)
  NO  → B 다꾸 스티커 단독 확인
    YES → B 단독 진행
    NO  → C 케이블 파우치로 전환 (2순위 실행)
```
