## 휴대폰 스트랩/테더 서브타입 스크린

출발 신호: `핸드폰도난방지스트랩` 280 PC + 1,500 mobile/mo, mobile CTR 4.26%

### 서브타입 A — 손목 스트랩 (Wrist Lanyard) ✅ GREEN

| 항목 | 평가 |
|------|------|
| 소싱 마찰 | **LOW** — 단순 섬유/코드 제품; 1688 수량 공급 가능 |
| 옵션 복잡도 | **LOW-MEDIUM** — 색상, 소재(나일론/가죽), 길이 조절 클립 |
| QA 리스크 | **LOW** — 후크·스냅 내구성 확인 필요, 그 외 단순 |
| 클레임 리스크 | **LOW** — "도난방지" → "분실·낙하 방지 보조 줄"로 재프레임 시 안전 |
| 반품 리스크 | **LOW** — 단순 기능, 명확한 사용법 |
| 예상 소싱가 | 500–2,000 KRW (1688/타오바오 기준) |
| 예상 판매가 | 6,900–12,000 KRW |
| 마진 | **GOOD** — 원가 1,500 이하면 5,000+ 마진 가능 |
| 사용자 fit | **MEDIUM-HIGH** — 여행 중 스마트폰 분실/낙하 방지 스토리에 맞음 |
| 다음 액션 | 1688/타오바오 `手机防丢绳 手腕` 샘플 조회; 단가 ≤1,000 KRW, MOQ ≤50개 필터 |

**핵심 재프레임**: "도난방지" 주장 X → "여행 중 스마트폰 분실·낙하를 줄이는 손목 연결 보조 줄" O

## 압축 파우치 서브타입 스크린

출발 신호: `압축파우치` 1,230 PC + 7,020 mobile/mo, but OpenAPI 175,568 total listings

### 서브타입 A — 여행 압축 파우치 2-3개 세트 ❌ RED

| 항목 | 평가 |
|------|------|
| 소싱 마찰 | HIGH — 실제 압축비 검증 필요; 지퍼 품질 편차 |

| 클레임 리스크 | HIGH — "압축" 기능 클레임이 핵심; 품질 보장 어려움 |
| 경쟁 포화 | EXTREME — OpenAPI 175,568 total listings; 대형 브랜드·중국직구 공존 |
| 마진 압박 | HIGH — 여행용 압축 파우치 median 14,490 KRW; 소싱가 7,000+ 이면 마진 거의 없음 |
| 판단 | **HOLD** — 초기 SKU 부적합; 경험 후 재검토 |
