## 상세 분석

### 손목 스트랩 (Phone Wrist Strap) — PROCEED

**형태**: 케이스/폰 본체에 연결되는 얇은 루프/밴드. 푸시핀 러그 커넥터 또는 접착식 앵커.

| 항목 | 내용 |
|------|------|
| 소싱 경로 | 1688/알리익스프레스 "phone wrist strap", "手机挂绳 手腕" |
| 도매 단가 추정 | 500–1,500원 (나일론/신축); 실리콘 고급형 1,500–3,000원 |
| 옵션 구성 | 색상 3–5가지; 사이즈 원사이즈 (모델 무관 케이스 연결) |
| 클레임 위험 | "도난방지" 보장성 표현 금지. 안전 프레임: "여행 분실방지 스트랩", "낙하 방지", "travel companion strap" |
| 반품 위험 | 낮음. 주요 불만: 핀 분리. 고품질 연결부로 해결 가능 |
| 판매가 목표 | 9,900–12,900원 |
| 마진 예시 | COGS 1,000–2,500원 → 75–90% 총마진 (물류 전) |
| 경쟁 밀도 | 중간. 패션 위주 판매 다수. 여행+안전 포지셔닝은 차별화 가능 |

**SearchAd 근거**: `핸드폰도난방지스트랩` 280 PC + 1,500 mobile/mo, mobile CTR 4.26%; `도난방지스트랩` 280 + 1,260/mo, mobile CTR 3.28%

**→ PROCEED**: 소싱 마찰 최저, SearchAd 신호 가장 강함. 다음 단계는 샘플 소싱 (사용자 세션 필요).
