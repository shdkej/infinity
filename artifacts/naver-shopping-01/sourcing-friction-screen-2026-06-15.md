## 1. 핸드폰 분실방지 손목 스트랩 / 테더

### 서브타입 A — 손목 스트랩 (`핸드폰 손목 스트랩`)

| 항목 | 평가 |
|---|---|
| 소싱 경로 | 국내 동대문/남대문 도매 or 1688 직수입 |
| 소싱 단가 | ¥5–15 (1688), 국내 도매 KRW 3,000–8,000 |
| 최소 발주량 | 50–100개/색상 (국내 도매 기준) |
| 옵션 복잡도 | 낮음 — 색상 3–5가지, 소재(나일론·캔버스), 연결 방식(링 인서트 or 범용 클립) |
| 클레임 리스크 | **중간** — `도난방지` 키워드는 "뺏어 가는 걸 막는다"는 기대를 생성. 실제로는 스트랩이 끊어지거나 링 인서트가 빠지면 민원 발생. 프레이밍을 `분실방지`로 교체하면 리스크 완화 가능 |
| 호환성 리스크 | 두꺼운 케이스·범퍼 케이스와 링 인서트 방식 충돌 가능. "범용 클립" 방식이 더 안전 |
| 반품 리스크 | **낮음–중간** — 스트랩 파손/링 탈락이 주 반품 원인. 색상/소재 차이 불만은 낮음 |
| 예상 소매가 | KRW 9,900–14,900 |
| 예상 순마진 | SmartStore 수수료 10–15% + 반품 충당 5–10% 차감 후 **25–40%** |
| **판정** | **✅ WATCH LEAD** — 3색 한정 런칭, `분실방지` 프레이밍, 범용 클립 연결 방식 우선 |

### 서브타입 B — 와이어/케이블 테더 (`도난방지 케이블 줄`)

| 항목 | 평가 |
|---|---|
| 소싱 경로 | 보안 용품 도매, 1688 |
| 소싱 단가 | ¥3–8 (1688) |
| 옵션 복잡도 | 매우 낮음 — 길이, 클립 타입(카라비너/스프링 클립) 정도 |
| 클레임 리스크 | 낮음 — 와이어 자체가 물리적 억지력이므로 `도난방지` 주장이 합리적 |
| 반품 리스크 | **낮음** — 기능 명확, 기대치 관리 쉬움 |
| 판정 | **🔵 WATCH (번들 보완재)** — 단독 리드보다는 손목 스트랩과 `여행 보안 2종 세트` 구성에 적합 |

### 서브타입 C — 크로스바디/넥 스트랩 포함 폰 파우치

| 항목 | 평가 |
|---|---|
| 옵션 복잡도 | 높음 (가방 형태 변형 多) |
| 클레임 리스크 | 높음 (가방 내구성, 도난 방지 효과 과대 광고 우려) |
| 반품 리스크 | 높음 (외관/핏 불만) |
| 판정 | **❌ SKIP** — 첫 SKU로 부적합 |

## 2. 압축 파우치

### 서브타입 A — 범용 압축 파우치 (`압축파우치`, `여행용압축파우치`)

| 항목 | 평가 |
|---|---|
| 경쟁 강도 | **극심** — OpenAPI 175,568건, 상위 판매자 수천 건 리뷰 |
| 클레임 리스크 | **높음** — "50% 부피 절감" 등의 압축률 주장은 의류 소재·접는 방식에 따라 달라져 민원 多 |
| 반품 리스크 | **높음** — 기대 압축률 불만, 밸브 파손 등 |
| 마진 | 얇음 (가격 경쟁 극심) |
| **판정** | **🔴 HOLD → DOWNGRADE** — 첫 SKU 불가. 번들 보완 목적으로도 불필요 |

### 서브타입 B — 방수 세탁물/젖은 옷 파우치 (`방수 세탁물 파우치`, `여행 젖은 옷 파우치`)

| 항목 | 평가 |
|---|---|
| 경쟁 강도 | **낮음** — OpenAPI `세탁물파우치` ~3,879건; 상위 경쟁 얕음 |
| 소싱 경로 | TPU/EVA 방수 파우치; 1688 or 국내 도매 |
| 소싱 단가 | ¥3–10 (1688) |
| 옵션 복잡도 | 낮음 — 크기 2종(S/M), 색상 2–3가지 |
| 클레임 리스크 | **낮음** — `방수`는 검증 가능한 기능 주장. 과장 없이 "세탁물·젖은 수영복 수납" 포지셔닝 |
| 반품 리스크 | **낮음** — 기능 명확, 기대치 관리 쉬움 |
| 사용자 적합성 | 여행 기억·일상 시스템 유저 fit ★★★ — 해외여행 중 젖은 수영복/속옷 분리 수납 니즈 명확 |
| 번들 각도 | **`핸드폰 분실방지 스트랩 + 방수 파우치 여행 필수 2종 세트`** 구성 가능 |
| SearchAd 신호 | `세탁물파우치` under 10 PC + 20 mobile/mo (약함) — 단독 키워드보다 번들/세트 검색어 전략 필요 |
| **판정** | **✅ WATCH NEW** — 낮은 경쟁, 관리 가능한 클레임, 번들 구성 가능. 손목 스트랩 LEAD와 페어링 추천 |
