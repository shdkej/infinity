## 1. 1688 검색 쿼리 (우선순위 순)

| 순위 | 쿼리 (중국어) | 의미 | 비고 |
|------|--------------|------|------|
| 1 | `手机防丢绳 手腕` | 핸드폰 분실방지줄 손목 | 네이버 SearchAd 키워드와 직결 |
| 2 | `手机腕带 防摔` | 핸드폰 손목밴드 낙하방지 | 기능 직접 표현 |
| 3 | `手腕挂绳 手机 可调节` | 손목 걸이줄 핸드폰 조절가능 | 조절기능 필터 포함 |
| 4 | `防摔手机绳 腕带` | 낙하방지 핸드폰줄 손목밴드 | 대안 표현 |
| 5 | `手机挂绳 腕绳` | 핸드폰 걸이줄 손목줄 | 광범위 탐색용 |

> **우선 쿼리 1, 2로 시작**. 결과가 부족하면 3, 4, 5 순서로 확장.

## 2. 공급사 필터 조건

### 필수 조건

| 조건 | 기준 |
|------|------|
| 단가 | CNY 1.5–7 / 개 (≈ 280–1,300 KRW) — 이 범위 밖은 제외 |
| MOQ | 50개 이하 (또는 협상 가능 여부 확인) |
| 공급사 등급 | 牛마크(신뢰도 뱃지) 또는 연간 거래 50건 이상 |
| 제품 사진 | 실제 촬영 사진 포함 (렌더링만 있으면 제외) |

### 우선 선택 기준

- 스트랩 소재: **나일론** 또는 **편직 폴리에스터** 우선 (내구성)
- 후크/클립 소재: **아연합금** 또는 **스테인리스 스틸** 우선 (플라스틱 스냅 제외)
- 길이 조절: **슬라이딩 버클** 내장 우선
- 색상: 블랙·네이비·회색 우선 (국내 수요 안전 색상)
- 연간 실제 주문 건수 확인 가능하면 100건 이상 우선

## 3. 레드플래그 (즉시 제외 기준)

| 레드플래그 | 이유 |
|-----------|------|
| 단가 CNY 0.5 미만 | 소재·마감 품질 심각 의심 |
| 실제 제품 사진 없음 (렌더링만) | 재고 없이 드롭십 의심, 실물과 괴리 가능 |
| MOQ 500개 이상 (협상 불가) | 초기 샘플링 단계에 부적합 |
| 폰 케이스 호환성 필요 제품 (태그홀더 패치 포함 세트) | 이미 RED 판정 — 서브타입 C |
| "소매치기 방지" "도난방지 보장" 문구 강조 | 한국 광고법·플랫폼 정책 리스크 |
| 2개 이상 부품 조립 필요 (접착+스트랩 분리) | 옵션 복잡도 증가 |

## 5. 샘플 주문 전략

1. **1차 탐색**: 쿼리 1–2로 검색, 조건 맞는 공급사 3–5개 리스트업
2. **사진/리뷰 확인**: 실제 착용 사진·클립 클로즈업 사진 있는 공급사 우선
3. **견적 문의 (쪽지)**: MOQ·단가·샘플 단위 구매 가능 여부 확인
4. **샘플 주문**: 2–3개 공급사에서 각 5–10개 (색상: 블랙·네이비 우선)
5. **QA 체크포인트**:
   - 후크/클립 50회 개폐 내구성
   - 슬라이딩 버클 조절 부드러움
   - 스트랩 인장 테스트 (500g 이상 하중 견딤)
   - 스티칭/마감 육안 확인
