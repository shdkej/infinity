## 배경

소싱 마찰 스크린(06-15)에서 손목 스트랩이 GREEN 판정됨:
- 저마찰·저클레임·낮은 옵션 복잡도·안정적 마진 예상
- 다음 단계: 1688/타오바오에서 실제 샘플 조회

이 문서는 로컬 1688 세션을 위한 검색 브리프다.

## 단가 벤치마크

Alibaba/Made-in-China 공개 도매 데이터:
- 도매 최저: $0.30/unit (~400 KRW) — 대량 주문 기준
- 도매 평균: $0.80–$1.34/unit (~1,100–1,800 KRW) — 소량 주문
- 1688 목표: ≤500–1,000 KRW (Alibaba보다 30–50% 저렴 예상)
- MOQ: 일부 공급사 50개 미만; No-MOQ 옵션도 있음(프리미엄 가격)

## 마진 시뮬레이션

| 항목 | 금액 |
|------|------|
| 소싱 목표가 | ≤800 KRW |
| 스마트스토어 판매가 | 8,900 KRW |
| Naver 수수료 (~6%) | –534 KRW |
| 배송비 (판매자 부담 시) | –2,500 KRW |
| 예상 순마진/unit | ≥5,000 KRW (~56%) |

## 1688 검색 키워드

우선순위 순:
1. `手机防丢绳 手腕` — 폰 분실방지줄, 손목형 (가장 정확)
2. `手腕手机挂绳` — 손목 폰 걸이줄
3. `手机腕带挂绳` — 폰 손목 밴드형 걸이줄
4. `防手滑手机绳` — 미끄럼방지 폰줄 (낙하 방지 각도)

## 샘플 조건

- 단가: ≤10 CNY (협상 목표 ≤5 CNY)
- MOQ: ≤100개; 샘플 2–5개 가능한 공급사 우선
- 색상: 블랙·네이비·포레스트그린 우선
- 소재: 나일론 또는 폴리에스터 (내구성 > 가죽 초기 SKU)
- 체결 방식: 클립+조절버클 타입 (케이스 구멍 불필요)
- 길이: 조절 가능 (보조 연결줄 15–25 cm 손목부)

## 품질 확인 항목

샘플 수령 후 로컬 테스트:
- 후크/버클 강도 — 200회 반복 개폐
- 스마트폰 무게(200g) 기준 낙하 시뮬레이션
- 봉제 마감 — 실밥·마감 처리
- 색상 안정성 — 물 접촉 후 번짐 여부

## 공급사 선별 기준

- 평점: 4.8+ (1688 기준)
- 运费险(배송 보험) 제공 여부
- 月销量(월 판매량) 100+ 확인
- 샘플 판매 가능 여부 명시

## 로컬 실행 체크리스트

1. 1688.com 로그인
2. 위 키워드로 검색 → 가격 ≤10 CNY 필터
3. 月销量 정렬 (월 판매량 높은 순)
4. 평점 4.8+ 공급사 필터
5. 2–3개 공급사 선정 → 샘플 각 3개 주문 (총 6–9개)
6. 수령 후 품질 확인 항목 체크
7. 통과 시 → 스마트스토어 입점 신청 타이밍 검토

## 국내 마케팅 각도 확인

경쟁 인텔리전스:

- 콘텐츠 각도: 유럽 여행 / 스마트폰 낙하 사고 예방 / 가방 속 폰 꺼내기 번거로움 해결
