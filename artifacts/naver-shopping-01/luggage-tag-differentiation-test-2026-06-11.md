## 개인정보·QA 리스크 분석

### 개인정보 노출 경로 (기존 방식)
- 이름·전화번호·주소를 육안으로 읽을 수 있는 인쇄
- 위험: 가방 탈취, 스토킹, 해외 공항 불필요한 정보 노출

### 리스크 해소 경로

| 방식 | 개인정보 노출 | 도착일 식별 | 스토리 적합도 |
|------|--------------|------------|----------------|
| QR 코드 태그 | 스캔 전 불가 ✓ | 분실 시 연락 가능 ✓ | 여행 시스템 사용자 fit ✓ |
| 이니셜+아이콘 | PII 없음 ✓ | 시각적 식별 ✓ | 미적 감각 fit ✓ |
| 고유 디자인 | 정보 없음 ✓ | 디자인으로 구분 ✓ | 기억 만들기 fit ✓ |
| 코드워드/심볼 | PII 없음 ✓ | 개인 시스템 식별 ✓ | 문서화 취향 fit ✓ |

### QA 리스크
- 인쇄 내구성: 장기 여행 중 색 바램/긁힘 → 소재 선택이 중요 (아크릴/금속 > 종이)
- QR 코드 오인식: 태그 손상 시 스캔 불가 → 이니셜 보조 병기 권장

## 차별화 가설

**핵심 포지셔닝**: "내 짐을 한눈에, 내 정보는 안전하게"
— 여행 시스템 미적 감각 + 개인정보 보호 이중 해소

- 기존 커스터마이즈 네임택: "이름만 예쁘게" — 차별화 약함
- 제안: QR 코드 + 여행 시스템 aesthetic 디자인 네임택
  - 스캔하면 비상 연락처 / 여행 준비 체크리스트로 연결
  - 시각적으로는 브랜드/이니셜/아이콘만 노출
- 사용자 fit: 여행 시스템 문서화, 기억 만들기 ✓
- 콘텐츠 각도: "나의 여행 준비 시스템" 콘텐츠에서 자연 등장 ✓

## 소싱 마찰 예비 확인

| 항목 | 상태 |
|------|------|
| 소재 옵션 | 아크릴, 가죽, 실리콘, 패브릭 — 소량 주문 가능 |
| 예상 MOQ | 50~100개 (커스텀 인쇄 기준) |

| 카테고리 | 여행용품 > 여행소품, 등록 마찰 낮을 가능성 높음 |
