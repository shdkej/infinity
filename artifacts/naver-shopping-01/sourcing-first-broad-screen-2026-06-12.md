## Top 3 검증 우선 후보 — 상세

### 1순위: 여행용 소분용기 세트

**소싱 근거**
- 실리콘/플라스틱 표준 품목, 알리바바 MOQ 100개 이하 가능
- 색/용량 2-3종 정도로 SKU 단순
- 항공 액체류 규정(100mL 이하)과 직접 연결 → 반복 구매 유도 가능

**Naver 검증 항목**
- 키워드: `여행 소분용기`, `실리콘 소분 용기`, `여행 화장품 소분`, `소분 용기 세트`
- 목표: 월 검색량 1,000 이상, 모바일 CTR 1% 이상, 상위 가격대 확인
- DataLab: 12개월 시계열 (여름/연말 여행 시즌 패턴 확인)

**리스크**
- 상위 자리 이미 commodity화 가능성 → 세트 구성/디자인 차별화 필요
- 가격 경쟁 심할 경우 margin floor 확인 필수

### 2순위: 여행 압축팩

**소싱 근거**
- EVA/나일론 압축팩은 표준 소재, 알리바바 저마찰
- 사이즈별 2-3종 세트 구성 가능
- 짐 공간 절약 = 여행자의 핵심 페인포인트 직접 해결

**Naver 검증 항목**
- 키워드: `여행 압축팩`, `압축 파우치`, `옷 압축팩`, `의류 압축팩`
- 목표: 월 검색량 2,000 이상, 모바일 CTR, 상위 가격대 2,000~8,000원대 확인
- DataLab: 시즌성 (여름 성수기 스파이크 여부)

**리스크**
- 이미 commodity 가능성 → HOLD 루브릭 주의
- 용량/소재 옵션이 많아질 경우 복잡도 증가

### 3순위: 케이블/이어폰 정리 파우치

**소싱 근거**
- 여행 + 일상 겸용 → 구매 트리거 다양
- EVA/패브릭 케이스 표준 품목
- 이어폰·충전기·USB 정리 = 디지털 노마드/여행자 직접 연결

**Naver 검증 항목**
- 키워드: `케이블 파우치`, `이어폰 파우치`, `케이블 정리 케이스`, `멀티 케이블 파우치`
- 목표: 월 검색량 500 이상, CTR 1% 이상
- 전자기기 액세서리 카테고리 진입 장벽 확인 (스마트스토어 카테고리 권한)

**리스크**
- 여행 전용 수요 아님 → 여행 시즌성 미약할 수 있음
- 경쟁 전자기기 액세서리 시장 (IT 기기 전문 셀러 존재)

## 로컬 검증 실행 계획

다음 로컬 실행에서 아래 순서로 수행:

```
1. SearchAd KeywordTool API:
   - 각 후보 Top 키워드: PC/모바일 검색량, CTR, 경쟁지수
   - 대상 키워드: 소분용기(4개), 압축팩(4개), 케이블파우치(4개)

2. Naver Shopping OpenAPI:
   - 각 후보 Top 키워드, sort=sim, top-20
   - 가격대 분포, 경쟁 밀도, 브랜드 점유율

3. DataLab Click Trend:
   - 12개월 시계열 (카테고리 cid + 키워드)
   - 시즌성 패턴 확인

4. 루브릭 판정:
   - PROMOTE: 검색량 충분 + CTR 높음 + 경쟁 적당 + 소싱 가능
   - PIVOT: 수요 있지만 진입 방식 조정 필요
   - HOLD: 검색량 낮거나 commodity 포화
   - DROP: 소싱 불가 또는 사용자 선호 미적합
```
