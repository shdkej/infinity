## Tier 1 후보 (로컬 OpenAPI/SearchAd 스크린 대상)

### 1. 여행 일기장 / 트래블 저널 ⭐

- **user-fit**: 기록 습관 + 기억 만들기 ✅✅
- **소싱 경로**: 무지/여행 테마 노트, 중국 도매 소량 가능, MOQ 낮음 ✅
- **옵션 복잡도**: 낮음 (크기 1~2종, 디자인) ✅
- **QA 위험**: 매우 낮음 ✅
- **키워드 후보**: `여행 일기`, `트래블 저널`, `여행 다이어리`, `여행 기록장`, `여행 노트`
- **콘텐츠 각도**: 사용자가 직접 여행 기록하는 모습 → 자연스러운 리뷰/콘텐츠 생산 가능
- **측정**: SearchAd 정확 검색량 + 상위 판매자 리뷰 수·가격대

### 2. 스탬프 여권 / 여행 도장 수집북 ⭐

- **user-fit**: 여행 + 기억 만들기 + 문서화 습관 ✅✅✅
- **소싱 경로**: 소량 제작 가능한 단순 공책 형태 ✅
- **옵션 복잡도**: 매우 낮음 ✅
- **QA 위험**: 매우 낮음 ✅
- **키워드 후보**: `스탬프 여권`, `여행 스탬프북`, `도장 수집 노트`, `트래블 스탬프`, `여행 도장`
- **콘텐츠 각도**: 여행 도장 모으는 감성 콘텐츠 → 자연스러운 리뷰
- **가설**: 니치하지만 바이어 의도 높을 것 (목적구매). 검색량 확인 필요.

### 3. 케이블 / 전자기기 정리 파우치

- **user-fit**: AI/크리에이터 워크플로우 + 일상 시스템 ✅
- **소싱 경로**: 매우 용이, 다수 도매상, 소량 구매 ✅
- **옵션 복잡도**: 낮음 ✅
- **QA 위험**: 낮음 ✅
- **키워드 후보**: `케이블 정리 파우치`, `전자기기 파우치`, `멀티 케이블 백`, `충전기 정리 파우치`
- **주의**: 경쟁 심함. 여행 use-case 특화 or 고용량 차별화 필요.
- **측정**: SearchAd 경쟁강도 + 상위 판매자 리뷰 패턴

- **주의**: 디지털 출력 서비스와 경쟁하는 세그먼트 주의
