## 공급사 필터 기준

### 필수 조건
- **MOQ**: 50개 이하 (이상적으로는 10-30개)
- **단가**: ≤ 5 CNY / 개 (약 900 KRW). 이상적 목표 ≤ 3 CNY (540 KRW)
- **공급사 등급**: 2성(二星) 이상 또는 거래 건수 500+
- **배송**: 한국 직배송 가능 또는 포워더 사용 가능

### 우선 선택 기준
- 리뷰 4.7점 이상
- 재주문율 확인 가능 시 30%+
- 공급사 운영 기간 2년+
- 실제 상품 사진 (렌더링만 있는 경우 패스)

## 샘플 스펙 (우선 주문 대상)

### 재질 우선순위
1. **나일론 웨빙** (Nylon) — 내구성 강, 세척 용이, 저렴
2. **면/캔버스** — 친환경 포지셔닝 가능, 빈티지 감성
3. **PU 가죽** — 프리미엄 포지셔닝, 판매가 상향 가능

### 색상 (첫 샘플 우선순위)
1. 블랙 (검정) — 범용
2. 네이비 (남색) — 여행 코디 중립
3. 베이지/크림 — 감성 여행 포지셔닝

### 치수 기준
- **스트랩 폭**: 7-12mm (너무 얇으면 끊어짐 리스크, 너무 두꺼우면 불편)
- **기본 길이**: 조절 가능 15-25cm
- **연결 고리 직경**: 최소 6mm 이상 (대부분 폰 카드 링 홀 호환)
- **연결 방식**: 범용 루프형 또는 스프링 클립 (호환성 우선)

## QA 체크포인트 (샘플 수령 시 확인)

1. **금속 후크/클립 내구성** — 50회 이상 착탈 테스트; 변형·이탈 없어야 함
2. **조절 클립(어드저스터) 작동** — 미끄러짐 없이 고정되어야 함
3. **스트랩 봉제 상태** — 끝마무리 실밥, 박음질 균일성
4. **폰 연결 루프 강도** — 100g 이상 하중 10초 유지
5. **재질 냄새** — 비닐/화학 냄새 없어야 함
6. **색상 이탈** — 물에 30초 담근 후 색 번짐 없어야 함
7. **조절 후 스트랩 고정** — 착용 중 자연 이완 없어야 함
8. **사용감** — 손목 착용 시 불편함·날카로운 엣지 없어야 함

## 마진 분석

### 보수적 시나리오 (소싱가 높음)

| 항목 | 금액 |
|------|------|
| 소싱가 (5 CNY) | 약 900 KRW |
| 국제 배송비 (50개 기준 배분) | 약 700 KRW/개 |
| 포장비 (개별 OPP백 + 스티커) | 약 200 KRW |
| **원가 합계** | **1,800 KRW** |
| 판매가 | 8,900 KRW |
| 스마트스토어 수수료 (4.5%) | -401 KRW |
| 정산액 | 8,499 KRW |
| **마진** | **~6,699 KRW (75.3%)** |

### 이상적 시나리오 (소싱가 낮음)

| 항목 | 금액 |
|------|------|
| 소싱가 (2.5 CNY) | 약 450 KRW |
| 국제 배송비 | 약 500 KRW/개 |
| 포장비 | 약 150 KRW |
| **원가 합계** | **1,100 KRW** |
| 판매가 | 8,900 KRW |
| 수수료 | -401 KRW |
| **마진** | **~7,399 KRW (83.1%)** |

**결론: 원가 1,100–1,800 KRW 범위에서 마진율 74–84% 예상. 손목 스트랩은 마진 구조 우수.**

## 네이버 쇼핑 포지셔닝 준비

### 추천 제품명 키워드 (검색 최적화)
- `스마트폰 손목 보조줄 분실방지`
- `핸드폰 손목 연결줄 여행용`
- `스마트폰 낙하방지 손목 스트랩`

### 핵심 포지셔닝 메시지
> "여행 중 스마트폰 분실·낙하를 줄이는 손목 연결 보조 줄"
- "도난방지" 주장 X → 오해·기대 불일치 리뷰 리스크
- "분실·낙하 방지 보조줄" O → 정확한 기능 명시, 클레임 최소화

### 타겟 시나리오 (상세 페이지 활용)
1. 유럽/동남아 여행 중 붐비는 관광지
2. 에스컬레이터·지하철 승하차 시
3. 사진 찍다가 손에서 미끄러지는 상황
4. 가방 바깥 주머니에 폰 보관 시 추가 고정

### 썸네일 각도
- 손목에 착용한 모습 + 폰 연결 클로즈업 (착용 방법 즉시 인지)
- 여행 배경 (공항/거리) vs 화이트 스튜디오 컷 2가지

## 로컬 실행 프롬프트 (1688 샘플 조회)

```
목표: 1688.com에서 손목 폰 스트랩 샘플 2-3개 주문

1. 1688.com 접속 → 검색어: 手机防丢绳 手腕
2. 필터:
   - 起订量 (MOQ): ≤ 50개
   - 价格 (단가): ≤ 5 CNY
   - 供应商 (공급사): 2성+ 또는 거래량 기준 상위
3. 상품 선택 기준:
   - 실제 상품 사진 (렌더링 제외)
   - 리뷰 4.7점+
   - 나일론 소재 / 조절 클립 포함
4. 샘플 주문:
   - 블랙 + 네이비 각 5개 (총 10개 또는 최소 MOQ)
   - 공급사 2-3곳 비교 후 1곳 주문
5. 배송: 포워더(이하이배 등) 또는 직배송 선택
6. 주문 완료 후 트래킹 정보 infinity에 기록

허용: L0/L1 (읽기, 주문) | 금지: 스마트스토어 등록·광고·공개발행
```
