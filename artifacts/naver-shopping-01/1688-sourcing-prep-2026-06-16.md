## 1688 검색 쿼리 (우선순위 순)

| 순위 | 검색어 | 설명 |
|------|--------|------|
| 1 | `手机防丢绳 手腕` | 핸드폰 분실방지줄 + 손목 |
| 2 | `手腕绳 手机` | 손목줄 + 핸드폰 |
| 3 | `手机腕绳` | 핸드폰 손목 줄 (복합어) |
| 4 | `防丢绳 手机` | 분실방지줄 + 핸드폰 |
| 5 | `手机挂绳 手腕` | 핸드폰 걸이줄 + 손목 |

> 쿼리 1로 시작하고 결과가 부족하면 2, 3 순서로 시도한다.

---

## 공급사 필터 기준

### 가격 필터
- **목표가**: ≤5 RMB/개 (≈900 KRW, 1,000 KRW 목표 이하)
- **이상적**: 2–3 RMB/개 (고마진 확보)
- **MOQ**: ≤50개 (가능하면 ≤30개로 샘플 단계 진행)

### 공급사 신뢰도
- 별점: 3+ (가능하면 4+)
- 선호 유형: 工厂(공장) > 贸易商(무역상)
- 거래 실적: 최근 90일 내 주문 있음 확인

---

## 제품 스펙 기준

| 항목 | 기준 |
|------|------|
| 소재 | 나일론 편직(尼龙编织) 또는 폴리에스터(涤纶) 우선; 얇은 플라스틱 제외 |
| 너비 | 1–1.5cm |
| 길이 | 15–30cm (손목 스트랩 범위) |
| 연결부 | 범용 클립(通用夹扣) 또는 루프(圆环) |
| 색상 1차 | 블랙(黑色), 네이비(藏青) |
| 색상 2차 | 베이지/크림(米色), 카키(卡其) |

---

## QA 확인 포인트 (제품 사진에서 확인)

1. **연결부 봉제**: 폰과 연결되는 끝부분의 스티치가 이중으로 겹쳐 있는지 (단일 스티치 X)
2. **클립/후크**: 금속 또는 강화 플라스틱 사용 여부 (투명 플라스틱 단독 사용 X)
3. **끝단 마감**: 줄 끝부분이 열 융착 또는 금속 크림프로 마감되어 있는지
4. **폭 균일성**: 전체 길이에서 너비가 일정한지 (접사 사진 확인)

---

## 샘플 주문 전략

- **공급사 수**: 3개 선택
- **수량**: 공급사당 2–5개
- **총 샘플**: ~10–15개
- **색상**: 공급사당 블랙 1 + 다른 색상 1

### 예상 비용 (참고)
| 항목 | 예상 |
|------|------|
| 제품 소싱가 (5 RMB × 15개) | ~75 RMB |
| 중국 내 배송비 (공급사→배송대행지) | ~30 RMB |
| 배송대행비 (중국→한국, EMS/ePacket 기준) | ~15,000–20,000 KRW |
| 합계 | ~30,000 KRW 이하 예상 |

**금지 문구**: "도난방지", "소매치기 방지" (과장 광고 리스크)  
**권장 문구**: "여행 중 스마트폰 분실·낙하를 줄이는 손목 연결 보조 줄"

**타겟**: 해외여행 준비 중인 2030세대  
**스토리**: 카페·관광지에서 스마트폰을 내려놓거나 이동할 때 손목에 연결해두는 생활 습관
