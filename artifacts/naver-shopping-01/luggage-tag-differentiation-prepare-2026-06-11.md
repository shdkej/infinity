## 배경

2026-06-10T20:07Z 하트비트에서 paper/card-led arrival-day insert 키워드 테스트 결과 **HOLD**. 도착날 실패방지 아이디어는 콘텐츠 축으로 유지하되, 캐리어네임택/러기지택이 리드 SKU 후보로서 가능한지를 이번 패스에서 클라우드 리서치로 사전 조사.

## 시장 4계층 분석

| 계층 | 대표 플레이어 | 가격대 | 차별화 요소 | 진입 판단 |
|------|-------------|--------|-------------|----------|
| 1. 범용 PVC | 브랜디·온채널·SSG | 3–8,000원 | 없음 (OEM 도매) | 출혈경쟁 — 회피 |
| 2. 캐릭터 IP | 카카오프렌즈, SSG·GS Shop | 8–20,000원 | IP 라이선스 | IP 의존 — 불가 |
| 3. 아티산 커스텀 | 아이디어스, 커스텀전문샵, 인터마켓 | 15–35,000원 | 가죽+각인+소량 | 공백 인접 — 참조 |
| 4. 전문직 | 힙트릿 크루텍 | 20,000원+ | 항공 승무원 언어 | 니치 — 무관 |

**공백 구간**: 계층 1(범용)과 3(아티산) 사이 — **기능성 스토리 + 경량 개인화** 포지션이 비어 있다.
- 계층 1: "내 이름 적힌 태그" — 스토리 없음
- 계층 3: "장인이 만든 가죽 이름표" — 선물/수집 감성
- **공백**: "해외여행 첫날 분실을 막기 위한 설정 이름표" — 실용적이고 스토리 있으나 아티산 가격 불필요

## 도착날 스토리 연결 가능성

### 긍정적 신호
- 네임택은 여행 전 준비물 리스트에서 빠지지 않는 실물 오브젝트
- "출발 전 마지막 확인" 서사(캐리어에 내 정보 붙이기)와 자연스럽게 연결
- 연락처 + 한영 반납 요청문 포맷("Please return if found") → 실용성 명확
- 인사동/쌈지길 DIY 커스텀 루거지택 체험이 SNS에서 인기: 감성 + 실용의 교차점 이미 증명됨
- 아이디어스에서 가죽 각인 네임택이 활발히 판매 중 → 수요는 존재

### 리스크
- `캐리어이름표 분실방지`가 실제 네이버 키워드로 수요가 있는지 미확인
- 개인정보 노출 우려(주소/전화 인쇄) → "이름+전화번호만" 또는 QR 코드 방식 고려
- 아이디어스와 포지션 겹침 가능 → 네이버 메인 쇼핑 최적화 여부로 차별화
