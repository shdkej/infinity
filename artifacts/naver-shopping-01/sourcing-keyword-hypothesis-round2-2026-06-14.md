## 1. 포토 포켓 앨범 / 여행 사진 앨범

### 소싱 분석 (cloud 추정)

| 항목 | 추정값 |
|------|--------|
| 소싱처 | 타오바오/1688 (透明口袋相册, 旅行相册) |
| 도매 단가 | 1,200–2,500 KRW (L판 80포켓 기준) |
| 국내 소비자가 | 12,000–28,000 KRW |
| MOQ | 50–200개 (소량 가능) |
| 옵션 수 | 1–3 (색상 또는 크기) |
| 배송·QA 리스크 | 낮음 (소품, 기능 단순, 반품 사유 제한) |

**마진 시뮬레이션 (1개당, 판매가 18,000 KRW 기준):**
- 소싱: 2,000 KRW
- 배송: 3,000 KRW
- 플랫폼 수수료(5%): 900 KRW
- 예상 영업이익: ~12,100 KRW (67%)
- 광고비 포함 시 실질 마진 40–50% 예상

### 키워드 가설 (DataLab 검증 대상)

| 키워드 | 예상 수요 레벨 | 노이즈 리스크 | 우선순위 | 목표 DataLab 기준 |
|--------|--------------|------------|---------|------------------|
| `포켓앨범` | 중–높음 | 아이돌 카드 보관 노이즈 | ★★★ | 8/12개월 이상 |
| `여행앨범` | 중 | 낮음 | ★★★ | 6/12 이상, 여름/연말 피크 확인 |
| `인스탁스앨범` | 중 | 낮음 (브랜드 고정) | ★★ | 일관된 수요 확인 |
| `폴라로이드앨범` | 중 | 낮음 | ★★ | 일관된 수요 확인 |
| `미니포토북` | 낮–중 | 낮음 | ★★ | 트렌드 존재 여부만 확인 |
| `포토카드앨범` | 높음 | 아이돌 시장 과밀 | **제외** | 진입 배제 |

**go 조건:** `포켓앨범` 또는 `여행앨범` 중 하나라도 DataLab 8/12개월 이상 + SearchAd 월 1,000 이상  
**no-go 조건:** 두 키워드 모두 DataLab 5/12개월 미만 또는 전체 노이즈 비율 70% 이상

### 차별화 포지션

- **포지션:** 여행 사진 정리 전용 포켓 앨범 (아이돌 포토카드 시장과 명시적 분리)
- **구매 상황 카피:** "여행 다녀온 날, 사진 꺼내 넣는 시간" → 감성 중심
- **콘텐츠 앵글:** 귀국 후 사진 정리 루틴 (30초 릴스/쇼츠)
- **리스팅 키워드 우선:** `여행앨범`, `포켓앨범`, `여행사진앨범`

## 2. 투명 스티커 세트 / 다꾸 스티커

### 소싱 분석 (cloud 추정)

| 항목 | 추정값 |
|------|--------|
| 소싱처 | 타오바오 (透明贴纸, 手账贴纸, 旅行贴纸) |
| 도매 단가 | 300–700 KRW (A6 1시트), 세트(5–10매) 1,500–3,000 KRW |
| 국내 소비자가 | 세트 12,000–20,000 KRW |
| MOQ | 50–100 팩 (매우 낮음) |
| 옵션 수 | 테마별 단품 (여행/자연/기록 테마) |
| 배송·QA 리스크 | 매우 낮음 (종이/필름, 반품 사유 거의 없음) |

**마진 시뮬레이션 (세트 1개당, 판매가 12,000 KRW 기준):**
- 소싱: 2,500 KRW
- 배송: 2,500 KRW
- 플랫폼 수수료(5%): 600 KRW
- 예상 영업이익: ~6,400 KRW (53%)
- AOV 높이기 위해 번들링 필수 (3–5종 묶음 세트 → 판매가 15,000–18,000 목표)

### 키워드 가설 (DataLab 검증 대상)

| 키워드 | 예상 수요 레벨 | 노이즈 리스크 | 우선순위 | 목표 DataLab 기준 |
|--------|--------------|------------|---------|------------------|
| `다꾸스티커` | 높음 | 낮음 (다꾸 시장 특화) | ★★★ | 9/12개월 이상 |
| `투명스티커` | 중–높음 | 중간 (산업용·레이블 노이즈) | ★★★ | 8/12 이상, 카테고리 필터 필요 |
| `다이어리꾸미기` | 높음 | 낮음 | ★★★ | 상위 카테고리 검증용 |
| `여행스티커` | 중 | 중간 (짐 스티커/캐리어 노이즈) | ★★ | 6/12 이상 |
| `꾸미기스티커` | 높음 | 낮음 | ★★ | 보조 확인 |

**go 조건:** `다꾸스티커` DataLab 9/12개월 이상 + SearchAd 월 2,000 이상  
**no-go 조건:** `다꾸스티커` 5/12 미만 또는 시장 급격 포화 징후 (상위 20개 전원 브랜드 셀러)

### 차별화 포지션

- **포지션:** 여행 기록 + 일상 시스템 특화 스티커 (범용 꾸미기와 분리)
- **구매 상황 카피:** "여행 다이어리에 붙이면 완성되는 스티커" → 기록 중심
- **콘텐츠 앵글:** 스티커로 여행 일기 꾸미는 비포/애프터
- **번들 전략:** 3–5종 "여행 기록 다꾸 스타터 팩" → AOV 15,000+ 목표
- **리스팅 키워드 우선:** `다꾸스티커`, `여행스티커`, `투명스티커다꾸`

## DataLab 검증 순서 (나래 로컬 실행)

```
1. DataLab > 쇼핑인사이트 > `포켓앨범` 키워드, 다이어리/플래너 카테고리 12개월
2. DataLab > 쇼핑인사이트 > `여행앨범` 키워드 12개월
3. DataLab > 쇼핑인사이트 > `다꾸스티커` 키워드, 문구류 카테고리 12개월
4. DataLab > 쇼핑인사이트 > `투명스티커` 키워드 12개월
→ go/no-go 기준과 비교 후 1개 후보 확정
→ go 후보 확정 시: 타오바오 샘플 가격 재확인 + 네이버쇼핑 경쟁 현황(접근 가능 시)
```

## 탈락 후보 (라운드 1 유지)

| 항목 | 탈락 이유 |
|------|----------|
| 러기지택 / 캐리어네임택 | 사용자 선호도 낮음, 커스텀 제작 중심 |
| 종이 카드 인서트 (체크리스트) | mobile CTR 0.05%, 제네릭 경쟁 과밀 |
| 트래블러스노트 속지 | 브랜드 잠금 수요 (독립 소싱 불가) |
| 워크샵/질문 카드 | MOQ 높음, 소싱 마찰 큼 |
