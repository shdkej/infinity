## 목적

기존 후보 경로들(트래블러스노트 삽지 → PIVOT/directional, 러기지택 → downgraded, 워크샵 카드 → WITHDRAWN, 아이디어 카드 insert → HOLD, 도난방지 → WATCH)을 거친 뒤, 사용자 선호(소싱 우선·러기지택 선호 낮음)를 반영한 **새 후보 범주 3개**를 도출했다. 로컬 Naver OpenAPI/SearchAd 검증 전 사전 필터링(소싱 마찰·옵션 복잡도·사용자 적합도) 결과다.

## 소싱 우선 스크린 기준

| 기준 | 설명 |
|------|------|
| 소싱 경로 | 국내 도매 또는 중국 수입(1688/타오바오) 완제품, 샘플 없이 소량 주문 가능 |
| 옵션 복잡도 | 변형이 최대 2-3개(색/사이즈), 복잡한 규격이나 커스텀 사양 없음 |
| 사용자 적합도 | 여행·메모리메이킹·AI/창작 워크플로우·일상 시스템 중 하나 이상 해당 |
| QA/반품 리스크 | 의류·전자기기 수준의 사이즈 클레임·결함 클레임 없음 |
| 네이버 등록 마찰 | 인증·허가·특수 상품정보 고지가 필요하지 않은 카테고리 |

## 후보 분석

### A순위: 인스탁스/폴라로이드 액세서리

- **사용자 적합도**: ★★★★★ (여행 사진 + 메모리메이킹 직결)
- **소싱 경로**: 국내 도매/중국 완제품 다수. 인스탁스 미니 규격 표준화 → 호환성 단순
- **옵션 복잡도**: LOW. 미니/와이드 두 규격만 존재. 앨범·프레임·스티커 시트 등 단품 소싱 가능
- **QA/반품 리스크**: LOW. 종이/PVC 소재, 파손 가능성 낮음
- **네이버 카테고리**: 카메라/사진 > 액세서리 (인증 불필요)
- **검증 키워드 (로컬 실행 필요)**:
  - `인스탁스 앨범`, `인스탁스 프레임`, `인스탁스 속지`
  - `폴라로이드 앨범`, `폴라로이드 프레임`
  - `포토 앨범 미니`
- **주의**: 인스탁스 브랜드(후지필름)와 직접 충돌하지 않는 서드파티 호환 포맷인지 확인 필요
- **판정**: 로컬 키워드/경쟁 검증 우선 순위 1순위

### B순위: 씰 스티커 / 포일 스티커 (다꾸)

- **사용자 적합도**: ★★★★☆ (문서화 리듬·일상 시스템·메모리메이킹, 다꾸 문화)
- **소싱 경로**: 중국 1688 (封口贴·装饰贴纸) — 극소 MOQ, 경량, 배송 간단
- **옵션 복잡도**: VERY LOW. 시트 단위 판매, 사이즈 이슈 없음
- **QA/반품 리스크**: VERY LOW. 종이/포일 소재
- **네이버 카테고리**: 문구/완구 > 스티커 (인증 불필요)
- **검증 키워드**:
  - `포일 스티커`, `씰 스티커`, `포인트 스티커`
  - `다꾸 스티커`, `다이어리 꾸미기 스티커`
  - `반투명 스티커`
- **주의**: 시장이 매우 세분화되어 있어 niche 테마(여행·필름카메라·지도 등) 포지셔닝이 중요
- **판정**: 로컬 검증 2순위 (수요가 확인되면 소싱 마찰 최저 선택지)

### C순위: 아코디언 미니 포토 앨범

- **사용자 적합도**: ★★★★☆ (여행 사진 정리·메모리메이킹)
- **소싱 경로**: 국내 도매/중국 완제품 다수. 표준 3×4인치 인스탁스 규격 또는 일반 4R 규격
- **옵션 복잡도**: LOW-MEDIUM. 사이즈(미니/4R) × 색상 2-3가지
- **QA/반품 리스크**: LOW. 커버 인쇄 품질 차이 있지만 기능적 결함 낮음
- **네이버 카테고리**: 앨범/사진첩 또는 문구/완구 (인증 불필요)
- **검증 키워드**:
  - `아코디언 앨범`, `접이식 앨범`, `미니 포토 앨범`
  - `폴라로이드 사진 앨범`, `포토카드 앨범`
- **주의**: A순위(인스탁스 액세서리)와 카테고리 겹침 → 동시에 검증 가능
- **판정**: A순위 검증 시 함께 체크

## 제외 이유 (이번 스크린에서 내림)

| 범주 | 제외 이유 |
|------|----------|
| 여행용 소분 용기 | commodity 포화 시장, 메모리메이킹 적합도 낮음 |
| 케이블 정리/무선 충전기 | 전자기기 반품 리스크, 여행 테마 약함 |
| 미니 데스크 오거나이저 | 여행/메모리메이킹 fit 낮음, 시장 포화 |
| 독서 노트 카드 | 완제품 소싱 불가 → 제작 필요 → sourcing-first 제외 |
| 목베개/슬립마스크 세트 | 소재·소독·반품 리스크 있음, 디자인 차별화 어려움 |

## 다음 로컬 실행 지시

로컬 Naver Shopping Agent가 수행할 작업:

```
1. OpenAPI 검색량 체크:
   후보 A: 인스탁스 앨범, 인스탁스 프레임, 인스탁스 속지, 폴라로이드 앨범
   후보 B: 포일 스티커, 씰 스티커, 다꾸 스티커, 포인트 스티커
   후보 AC: 아코디언 앨범, 미니 포토 앨범, 포토카드 앨범

2. SearchAd 광고 의도 체크:
   각 키워드의 PC/모바일 검색량, 광고 depth, CTR

3. 판정 rubric 적용:
   PROMOTE: 검색량 500+/mo, 광고 CTR 1%+, 경쟁 밀도 thin-moderate
   PIVOT: 수요는 있지만 포화 → 세부 포지셔닝 필요
   HOLD: 수요 약하거나 informational demand
   DROP: 노이즈/규제/비선호

4. 이 스크린 문서 업데이트 후 HTML report 작성
```

## 소싱 리드 (검증 후 진행)

검증에서 PROMOTE/PIVOT이 나오면:
- **국내**: 쿠팡 로켓배송 도매 / 부산 국제시장 포토 코너 / Gelatin/인쇄소 제휴
- **중국**: 1688 — `富士拍立得相册`, `立拍得贴纸`, `封口贴` 검색어로 샘플 없이 소량 선주문 가능
- 샘플 없이 최소 수량 10-20개로 시장 반응 먼저 확인하는 것 권장
