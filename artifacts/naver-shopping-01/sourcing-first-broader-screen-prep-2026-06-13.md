## 사용자 적합 프레임 (이 필터를 통과해야 검증 대상)

- ✅ 여행 준비/경험 기록
- ✅ 메모리 메이킹 (사진, 수집, 스탬프)
- ✅ AI/크리에이터 워크플로우 보조
- ✅ 일상 시스템/문서화 리듬
- ❌ 너무 일반적인 commodity 형태 (다이소 대체품 수준이면 제외)
- ❌ 제작 의존 상품 (커스텀 인쇄 없이는 차별화 불가한 것)
- ❌ 전자제품/의류/식품 (QA·반품 리스크 높음)

## 소싱 우선 스크리닝 기준 (4점 체계)

각 카테고리를 아래 4개 기준으로 0–3점 평가. **합계 10점 이상 → 로컬 OpenAPI/SearchAd 검증 대상. 9점 이하 → HOLD.**

| 기준 | 3점 | 0점 |
|------|-----|-----|
| 샘플마찰 | 국내/중국 소싱 명확, MOQ<100, 샘플비 낮음 | 공급처 불명, MOQ 높음, 긴 리드타임 |
| 옵션복잡도 | 컬러/디자인만, 사이즈·호환 없음 | 사이즈/호환/스펙 분기 많음 |
| QA·반품리스크 | 파손·안전·반품 이슈 거의 없음 | 전자제품·의류·식품 또는 접착/호환 리스크 |
| 사용자적합도 | 핵심 취향(여행·메모리·AI크리에이터·시스템)과 직접 연결 | 취향 미스 또는 generic |

## 신규 후보 카테고리 7개

### C1. 인스탁스 호환 미니 앨범 / 폴라로이드 사진 앨범

- **사용자적합**: 여행 메모리 메이킹, 사진 기록 ✅
- **소싱**: 중국 공장 다수, MOQ 50–100개, 샘플비 낮음
- **옵션복잡도**: 중간 — 인스탁스 미니/와이드 사이즈 분기, 페이지 수 선택
- **QA·반품리스크**: 낮음 — 종이/플라스틱, 사진 직접 손상 없음
- **점수**: 샘플3 / 옵션2 / QA3 / 적합3 = **11점** ✅ 검증 대상
- **Naver 검증 키워드**: `인스탁스 앨범`, `폴라로이드 앨범`, `미니 사진 앨범`, `포토 앨범`
- **주의**: 브랜드명(인스탁스/후지필름) 사용 시 "호환" 표기 필요. 기존 brand refill ecosystem처럼 브랜드 앵커 종속 여부 확인

### C2. 여행 스탬프 세트 / 스탬핑 여행 기록 키트

- **사용자적합**: 여행 메모리, 문서화 리듬, 기억 기록 ✅
- **소싱**: 고무도장·스탬프 세트 소싱 쉬움, 패키지 단위 구성 가능
- **옵션복잡도**: 낮음 — 디자인 세트 선택만
- **QA·반품리스크**: 매우 낮음 — 인쇄 오류 정도
- **점수**: 샘플3 / 옵션3 / QA3 / 적합2 = **11점** ✅ 검증 대상
- **Naver 검증 키워드**: `여행 스탬프`, `스탬프 세트`, `도장 스탬프 키트`, `다이어리 스탬프`
- **주의**: 다이소 수준 commodity 리스크 확인 필요. 가격대·경쟁자 수가 핵심 판단 변수

### C3. 데코 스티커 팩 / 여행 씰 스티커 세트

- **사용자적합**: 여행 기록 꾸미기, 창작 리듬 ✅
- **소싱**: 매우 쉬움 — 디자인 있으면 인쇄 소싱 가능, MOQ 낮음
- **옵션복잡도**: 매우 낮음 — 디자인/테마만
- **QA·반품리스크**: 매우 낮음
- **점수**: 샘플3 / 옵션3 / QA3 / 적합2 = **11점** ✅ 검증 대상
- **Naver 검증 키워드**: `여행 스티커`, `데코 스티커`, `씰 스티커`, `다이어리 스티커`
- **주의**: 경쟁자 수 많고 가격대 낮을 수 있음. 디자인 차별화 없으면 HOLD

### C4. 슬림 카드 지갑 / 경량 목걸이 카드 홀더

- **사용자적합**: 여행 문서 정리, 경량화 ✅ (but anti-theft WATCH와 겹침)
- **소싱**: 쉬움
- **옵션복잡도**: 낮음
- **QA·반품리스크**: 낮음–중간
- **점수**: 샘플3 / 옵션2 / QA2 / 적합2 = **9점** → **HOLD**
- **이유**: 이미 anti-theft 스캔에서 RFID차단지갑·여행지갑 확인 완료. 재검증 불필요. 기존 WATCH 브랜치에서 처리.

### C5. 여행 케이블/이어폰 정리 파우치 (테크 액세서리 정리)

- **사용자적합**: AI/크리에이터 워크플로우, 여행 중 테크 캐리, 시스템 정리 ✅
- **소싱**: 쉬움, 다양한 사이즈·소재
- **옵션복잡도**: 낮음 — 사이즈/컬러
- **QA·반품리스크**: 낮음 — 기능 실망 정도
- **점수**: 샘플3 / 옵션3 / QA3 / 적합2 = **11점** ✅ 검증 대상
- **Naver 검증 키워드**: `케이블 파우치`, `여행 케이블 정리`, `이어폰 케이스`, `테크 파우치`
- **주의**: 기존 `여행파우치` 스캔에서 generic 포화 확인됨. "케이블/테크 정리" 앵글이 독립 shelf로 존재하는지 확인 핵심

### C6. 독서 기록 노트 / 리딩 로그 / AI 학습 노트

- **사용자적합**: 문서화 리듬, AI/크리에이터 워크플로우, 지식 정리 ✅
- **소싱**: 소량 인쇄 제작 필요 가능성 있음 (기성 노트 vs 자체 인쇄 분기 확인 필요)
- **옵션복잡도**: 낮음 — 크기·표지 정도
- **QA·반품리스크**: 매우 낮음
- **점수**: 샘플2 / 옵션3 / QA3 / 적합3 = **11점** ✅ 검증 대상
- **Naver 검증 키워드**: `독서 노트`, `리딩 로그`, `독서 기록 노트`, `북 저널`
- **주의**: "기성 소싱 가능한 노트"냐 "자체 제작"이냐가 핵심 분기. 소싱 우선 원칙 상 기성 제품이 있는지 먼저 확인

### C7. 핸드폰 스트랩 / 폰 목줄 (경량 여행 안전 액세서리)

- **사용자적합**: 여행 중 분실 방지, 경량 액세서리 ✅ (but 호환 이슈)
- **소싱**: 쉬움
- **옵션복잡도**: 낮음–중간 — 소재·컬러
- **QA·반품리스크**: 중간 — 폰 케이스 두께·호환 이슈, 접착 불량 리스크
- **점수**: 샘플3 / 옵션2 / QA2 / 적합2 = **9점** → **조건부 HOLD**
- **이유**: anti-theft 스캔에서 이미 `소매치기 방지` 계열 언급됨. 호환/접착 반품 리스크 해결 방안 없으면 HOLD 유지
