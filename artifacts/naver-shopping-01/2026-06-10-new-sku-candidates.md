# naver-shopping-01: 1차 SKU 거절 후 신규 후보 탐색 (2026-06-10)

> 사용자가 트래블러스노트 travel-prep insert 방향을 "너무 일반적"으로 판단해 보류.
> 다음 후보 기준: 일반 체크리스트·플래너·속지 형식 회피, 구매 이유가 선명한 것.
> 탐색 기준: 실제 여행 실패/동선 리스크/현지 질문 수집/필드 인사이트 재사용/워크숍 대화 도구
> 이 문서는 research/prepare 모드 초안. 네이버 API 호출 없음. 시장 수요 미검증.

## 탐색 기준 재정의

**통과 조건 (모두 충족):**
- 구매 이유가 "여행 준비를 위해" 수준보다 선명할 것
- 제품이 해결하는 문제가 구체적인 여행 마찰(실패, 리스크, 소통 어려움)에 연결될 것
- 기존 트래블러스노트/체크리스트/다이어리 형식과 직접 경쟁하지 않을 것

**차단 조건 (하나라도 해당 시 제외):**
- 일반 체크리스트, 위클리 플래너, 다이어리 형태
- "여행 준비"가 주요 가치인 제품
- 브랜드 없이 범용적으로 경쟁하는 삽입지 형태

## 신규 후보 5개

### 후보 A: 현지 대화 카드 (Local Question Cards)

**제품 개념:** 여행지별로 현지인에게 물어볼 준비된 질문 카드. 카테고리: 음식 추천 / 교통 팁 / 숨겨진 장소 / 언어·문화 주의사항.

**구매 이유 명확도:** ★★★★★
- "구글로는 못 찾는 로컬 정보" = 선명한 문제
- "현지인에게 물어볼 말을 모른다" = 실제 여행 실패 원인

**사용자 fit:** 필드 인사이트 재사용 기준 충족 (카드를 다음 여행에도 씀)

**시장 관측:** 미검증 — 네이버 DataLab/Shopping 확인 필요

**등록 리스크:** 낮음 (종이 카드 상품)

---

### 후보 B: 여행 오류 복기 노트 (Travel Post-Mortem Notebook)

**제품 개념:** 여행에서 실패한 것, 다음에 다르게 할 것, 예상치 못한 발견을 구조화된 폼으로 기록하는 노트. 반복 여행자용.

**구매 이유 명확도:** ★★★★
- "매번 같은 실수를 한다" = 반복 여행자의 진짜 고통
- "다음 여행 전에 이전 여행에서 뭘 배웠는지 잊는다" = 명확한 문제

**차별점:** 체크리스트가 아닌 "사후 분석" 용도 → 기존 플래너와 차별화

**사용자 fit:** 여행 노트·기록 습관 있는 사용자, "필드 인사이트 재사용" 기준 직접 충족

**등록 리스크:** 낮음

---

### 후보 C: 동선 위험 메모 카드 (Route Risk Memo Cards)

**제품 개념:** 여행 중 다음 구간의 위험 요소를 빠르게 메모하는 구조화된 카드. 날씨 창/교통 대안/비상 연락처 템플릿.

**구매 이유 명확도:** ★★★
- 장거리 트레킹, 오지 여행자에게 선명
- 일반 여행자에게는 필요성 낮을 수 있음
- 앱으로 대체 가능한 영역에 걸침

**등록 리스크:** 낮음, 시장 수요 미검증

---

### 후보 D: 여행 워크숍 퍼실리테이션 카드 (Group Trip Workshop Cards)

**제품 개념:** 2인 이상 함께 여행 계획을 세울 때 쓰는 토론/합의 카드. "우리가 이 여행에서 뭘 원하나", "누가 뭘 담당할까" 질문 카드.

**구매 이유 명확도:** ★★★★★
- "그룹 여행 계획은 항상 싸운다" = 매우 선명한 문제
- "혼자 결정하면 불만이 생긴다" = 실제 여행 실패 원인

**사용자 fit:** 커플/친구/가족 여행이 주 패턴이라면 강함

**시장 관측:** 경쟁 희소 가능성 (생소한 카테고리), 검증 필요

**등록 리스크:** 중간 (새 카테고리 → 카테고리 배정 어려울 수 있음)

---

### 후보 E: 도착지 첫인상 메모 카드 (Landing Impression Cards)

**제품 개념:** 여행지 도착 첫 날 빠르게 쓰는 관찰 카드. 냄새, 소리, 사람, 첫 번째 놀라운 것, 기대와 다른 점을 5-7개 고정 슬롯으로 포착.

**구매 이유 명확도:** ★★★
- 여행 블로거/사진가/작가에게 선명한 구매 이유
- 일반 여행자에게는 구매 이유 약함

**사용자 fit:** "컨텐츠 생산자" 또는 "기억 채굴자" 유형에 강함
