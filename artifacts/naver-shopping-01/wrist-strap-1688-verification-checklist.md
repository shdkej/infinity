## 공급사 1: Shenzhen Huanhuan (宇亨 / 环环互扣) — **1순위**

공개 정보: 나일론/우븐 손목 스트랩+패치, USD 0.19-0.30, MOQ 10

### 1688 검색
- 검색: `环环互扣 手腕绳` 또는 `宇亨 防丢绳`
- 가격대 USD 0.19-0.30 기준으로 찾기

### 확인 항목
- [ ] **최근 거래(最新成交记录)**: 1개월 이내 거래 있는지
- [ ] **리뷰(评价)**: 4점 이상, 사진 리뷰 있는지
- [ ] **색상**: 블랙(黑色), 네이비(深蓝色/藏蓝色) 옵션 있는지
- [ ] **패치/라벨**: 손목 스트랩에 패치 포함 여부 / 개인 브랜드 라벨 가능 여부
- [ ] **커넥터 타입**: 폰 링/루프 방식인지 (클립형 vs 걸이형 구분)
- [ ] **MOQ**: 10개 주문 실제 가능한지 재확인
- [ ] **단가**: USD 0.19-0.30 범위 맞는지, 100개 이상 할인폭
- [ ] **배송**: 한국 배송 가능 여부, 예상 기간·방법

### 판단
위 항목 중 색상 + 최근거래 + 리뷰 3개 OK → **샘플 주문 후보 1순위 확정**

- [ ] **최근 거래 + 리뷰**: 신뢰도 확인

## 샘플 주문 요청서 초안 (승인 후 사용)

```

포장: 개별 비닐 포장 (폴리백) 요청
배송: 한국 주소, EMS 또는 UPS/DHL 견적 요청
결제: 알리페이 또는 카드
```
