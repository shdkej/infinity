## 2. 공급사 선별 기준 (1688 필터)

### 가격 필터
- 단가: CNY 2~8 (≈ KRW 400~1,500)
- MOQ: 50개 이하 (가급적 10~30개 샘플 가능한 공급사)

### 공급사 신뢰도 기준
- 거래 횟수: 30회 이상
- 평점: 4.8 이상 (満意度/好评率)
- 사업자 인증: 실명 인증된 업체 우선 (认证供应商)
- 제품 사진: 실물 화보 + 디테일 클로즈업 포함

### 제품 페이지 체크포인트
- [ ] 후크/스냅 재질 명시 (아연합금/스테인리스 등)
- [ ] 끈 재질 명시 (나일론/폴리에스터/가죽)
- [ ] 길이 명시 (18~25cm 범위)
- [ ] 사이즈 조절 클립 유무
- [ ] 패키징 방식 명시 (OPP 봉투 단독 vs 박스)

## 3. 샘플 주문 스펙

### 주문할 제품 스펙
| 항목 | 스펙 |
|------|------|
| 색상 | 블랙, 네이비 우선 (각 1~2개) |
| 재질 | 나일론 또는 폴리에스터 브레이드 |
| 끈 길이 | 18~22cm (고정 또는 조절 가능) |
| 후크 타입 | 카라비너 클립 또는 스냅훅 |
| 연결 방식 | 스마트폰 케이스 루프 끼움 또는 팝소켓 호환 |
| 수량 | 공급사당 10~30개 샘플 |
| 예산 | 공급사당 샘플 비용 CNY 100~300 범위 내 |

### 주문 전 공급사에게 확인할 사항 (채팅/문의)
1. 개인 구매자에게도 샘플 판매 가능한지 확인
2. 실제 사용 사진 추가 요청
3. 배송 방법: EMS/SF Express (한국 직배송 가능 여부)
4. 통관 및 세금 포함 여부 확인

## 4. QA 체크리스트 (샘플 수령 후)

### 외관 검사
- [ ] 끈 표면 마감 균일 (올풀림, 찍힘 없음)
- [ ] 색상 표기와 실제 색 일치
- [ ] 후크/스냅 도금 균일 (긁힘·기포 없음)
- [ ] 봉제 부위 마감 (연결 부위 풀림 없음)

### 기능 검사
- [ ] 후크 개폐 5회 반복 — 걸리거나 헐거움 없음
- [ ] 조절 클립 작동 (있는 경우) — 고정 후 미끄러짐 없음
- [ ] 케이스 루프 통과 여부 — 일반 범용 케이스 루프에 장착 가능
- [ ] 인장 테스트: 500g 중량 1분 — 후크·봉제 이상 없음

### 클레임 리스크 사전 확인
- [ ] 리스팅에 "도난방지" 문구 미사용 확인 ("분실·낙하 방지 보조 줄"로 대체)
- [ ] 재질/성분 표기 가능 여부 (한국 통관/소비자보호법 대응)
