# Principle → product → digital interpretation

Vitsœ pairs the principles with Braun/Vitsœ objects (for example TP 1, MPZ 21, T 1000, Cylindric T 2, 620, 606 and L 2). Those examples are historical evidence of the company’s presentation, not proof that one UI style follows from Rams.

1. **Innovative** — technology should improve use, not become novelty. UI test: does the new interaction reduce a verified user cost?
2. **Useful** — remove a feature only when the core task remains easier.
3. **Aesthetic** — polish supports everyday use; it is not a decoration pass.
4. **Understandable** — make structure and action legible before relying on onboarding.
5. **Unobtrusive** — reserve visual dominance for user-critical states, not brand performance.
6. **Honest** — state price, consent, limitations, and irreversible effects plainly.
7. **Long-lasting** — favour stable information architecture and adaptable components over fashion.
8. **Thorough** — test empty, loading, error, keyboard, mobile, and recovery states.
9. **Environmentally friendly** — in digital work, treat this as a lifecycle question (device/network cost, maintenance, needless refresh), not an aesthetic claim.
10. **As little as possible** — remove nonessential *burden*, never required meaning, affordance, or accessibility support.
