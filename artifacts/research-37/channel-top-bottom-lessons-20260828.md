# research-37 — 채널별 상위 10 / 하위 10 제목 학습

- source: `four-channel-api-evidence.csv` + `four-channel-api-exclusions.csv`
- 기준: YouTube Data API `search.list(order=viewCount, channelId) -> videos.list(snippet,statistics)`
- 수집 시각: `2026-08-28T21:06:41Z`
- 비교 범위: 각 채널별 API 수집 표본 안에서 공개 조회수 상위 10개와 하위 10개
- 주의: 조회수는 채널 규모, 업로드 시점, 주제, 썸네일 영향을 함께 받는다. 아래는 제목과 소재 선택에서 배울 점만 뽑은 것이다.

## 한 줄 결론

잘 나온 제목은 `장소명`이 아니라 `장소에서 생긴 선택 압력`을 판다. 덜 나온 제목은 장면은 있는데, 왜 봐야 하는지의 긴장·비용·변화·관계가 약하다.

## 플팽부부

### 상위 10에서 보이는 것

- 집, 전세돈, 유럽살이, 파이어족처럼 여행을 `인생 선택`으로 끌어올린 제목이 강하다.
- 헝가리/부다페스트가 단순 목적지가 아니라 `정착`, `집 구매`, `살기 힘든 이유`, `관광객 감소` 같은 판단의 배경으로 쓰인다.
- 상위권은 "어디 갔다"보다 "그래서 삶이 어떻게 바뀌나"를 묻는다.

### 하위 10에서 보이는 것

- 베를린 위험한 날, 부다페스트 카페 맛집, 불가리아 매력처럼 소재는 괜찮지만 문제의 크기가 작거나 일반 여행 정보처럼 보인다.
- `찐 카페 맛집`, `여행 전 필수영상` 같은 표현은 흔해서 채널 고유의 관찰이 약해진다.
- 좋은 현장이어도 제목이 생활비/정착/관계 같은 큰 의사결정과 연결되지 않으면 힘이 줄어든다.

### 배울 점

- 플팽부부형 제목은 `여행지 + 내 삶의 결정`으로 써야 한다.
- 마스터님 적용: `부다페스트 좋았다`가 아니라 `여기서 살아도 되나를 처음 계산해본 도시`처럼 써야 한다.
- 피할 것: 맛집/팁/필수영상처럼 일반 여행 블로그 문법으로 낮추기.

## 시칠리안 SICILIAN

### 상위 10에서 보이는 것

- `직접 살아본`, `모든 것`, `현실`, `현재 상황`, `충격적인 하루 경비`처럼 판단 단어가 강하다.
- 숙소, 물가, 변화, 비용, 초성수기, 크루즈처럼 여행자가 바로 판단해야 하는 조건이 앞에 있다.
- 일상 브이로그도 `불경기에 현실감 없이 여행하며 사는 부부`처럼 시대감과 모순을 붙이면 강해진다.

### 하위 10에서 보이는 것

- 로컬 탐방기, 입국기, 쇼핑리스트처럼 형식 자체는 가능하지만 상위권보다 긴장이 약하다.
- `왜 살고 있는 이유`, `해변은 쓰레기 천국일까`처럼 질문은 있지만, 기대와 결과의 충돌이 덜 날카로운 제목은 낮게 잡혔다.
- 너무 로컬 탐방/개인 사연/시작 기록에 머물면 시청자가 얻을 판단값이 흐려진다.

### 배울 점

- 시칠리안형 제목은 `장소 + 지금 상태 + 비용/위험/생활 조건`이 핵심이다.
- 마스터님 적용: `다합 바다 좋았다`보다 `다합에서 오래 머물면 좋은 점보다 먼저 보이는 생활 비용`처럼 써야 한다.
- 피할 것: 그냥 예쁜 곳, 그냥 로컬 탐방, 그냥 개인 사연.

## 한달살러 신디와쏭

### 상위 10에서 보이는 것

- 압도적 상위는 여행보다 `파이어족`, `이자 2배`, `안전 수익`, `일하지 않아도 비용 마련`처럼 돈/자유 구조가 강하다.
- 여행 제목도 `우연히 그곳을 발견`, `한국과 닮은 나라`, `한국말이 더 많이 들림`, `성희롱`, `벼락거지`처럼 개인 감정과 사건이 뚜렷하다.
- 시리즈 번호가 있어도 제목 안에 독립적인 갈등이나 보상이 있어야 본다.

### 하위 10에서 보이는 것

- 4K 산책, 라이브 스트리밍, 안방 구경, 요리, 집들이처럼 맥락을 아는 사람에게만 의미 있는 제목은 약하다.
- `조지아 입국하기`, `베트남 역사와 사회`처럼 정보는 있지만, 현재 나에게 왜 중요한지의 보상이 약하다.
- 귀여운 일상/동물/집밥은 채널 친밀도에는 좋지만 신규 유입 제목으로는 약하다.

### 배울 점

- 신디와쏭형 제목은 `여행 + 돈/자유/관계 사건`이 붙을 때 강하다.
- 마스터님 적용: `세계여행 중 한 달 생활비가 생각보다 바뀐 순간`, `여행하면서 돈 버는 구조가 실제로 가능한지 계산해본 날` 같은 제목이 맞다.
- 피할 것: 영상 품질 표기, 무편집 산책, 라이브 기록을 제목의 중심에 두기.

## 하루다씀 HARUDASSEUM

### 상위 10에서 보이는 것

- 최고 조회는 여행이 아니라 `3년이 지나 드디어 우리집이 생겼다`다. 즉 이 채널에서는 여행보다 삶의 큰 사건이 더 잘 먹혔다.
- 여행 상위권은 `유럽 ep`, `비엔나`, `할슈타트`, `프라하`, `두브로브니크 숙소`처럼 구체 목적지가 있다.
- 다만 조회수 규모가 낮아서 10만+ 경쟁 채널과 같은 공식으로 보기 어렵다.

### 하위 10에서 보이는 것

- 혼인신고, 봄나들이, 샐러드, 전복요리, 집들이처럼 일상 기록은 제목만 보면 외부 유입 이유가 약하다.
- `기습질문`, `SNS 핫플`, `맛있게 만들기` 같은 소재는 흔하고, 채널만의 큰 관찰로 보이기 어렵다.
- 여행 제목도 `마지막`, `아시아지구`, `유람선`, `까르푸`처럼 나열형이면 선택 압력이 약해진다.

### 배울 점

- 하루다씀형 표본은 "일상 브이로그가 왜 안 퍼지는가"를 보여준다.
- 마스터님 적용: 장소를 나열하지 말고, 그날의 선택 기준 하나만 남긴다. 예: `비엔나에서 돈보다 시간을 아끼기로 한 날`.
- 피할 것: 일정 나열, 에피소드 번호 의존, 내부자만 아는 생활 기록.

## 공통 상위권 공식

1. `장소 + 비용`
   - 예: 하루 경비, 물가, 숙소, 한달살기 비용, 정착 비용.

2. `장소 + 변화`
   - 예: 더 이상 예전 같지 않은 곳, 관광객이 사라진 곳, 변해버린 섬.

3. `장소 + 위험/불편`
   - 예: 치안, 소매치기, 입국 난이도, 여행 중단, 성희롱, 환율.

4. `장소 + 삶의 선택`
   - 예: 집을 사다, 살아보다, 직장을 그만두다, 파이어족, 정착.

5. `장소 + 관계 사건`
   - 예: 부부의 선택, 혼자 여행, 가장 열받은 날, 한국말이 그리운 순간.

## 공통 하위권 패턴

- 단순 산책: 4K, 무편집, 야간 산책, 안방 구경.
- 일정 나열: 도시명 여러 개, 명소 나열, ep 번호 중심.
- 정보 일반론: 여행 팁, 맛집, 필수영상, 현지 탐방기.
- 내부 일상: 라이브, 집들이, 요리, 짧은 데이트 기록.
- 보상 불명확: 제목을 보고 클릭하면 무엇을 알게 되는지 약함.

## 마스터님 콘텐츠 적용 규칙

### 제목 만들 때

- `어디 갔다`로 시작하지 않는다.
- 먼저 질문한다: 이 장소에서 내가 새로 알게 된 `돈`, `사람`, `생활`, `위험`, `선택`은 무엇인가?
- 제목은 `장소명 + 선택 압력 1개 + 기대와 다른 결론`으로 쓴다.

### 바로 써볼 제목 프레임

- `[도시]에서 오래 머물면 제일 먼저 바뀌는 돈 감각`
- `[도시]는 예쁜데, 살겠냐고 물으면 답이 달라진다`
- `여행자가 아니라 생활자로 보면 [도시]의 단점이 먼저 보인다`
- `[도시]에서 하루를 보내고 나니, 집에 대한 기준이 바뀌었다`
- `[도시]에서 돈보다 먼저 아껴야 했던 것`
- `[도시]가 좋았던 이유보다, 다시 안 갈 이유가 더 선명했다`
- `한 달 살기 후보로 [도시]를 보면 바로 걸리는 조건`
- `[도시]에서 본 사람들의 당연함이 내 기준을 흔들었다`

## 다음 실행 제안

- 여행지별 한 페이지를 만들 때 제목 후보를 먼저 3개 뽑는다.
- 각 제목은 반드시 `비용`, `변화`, `불편`, `삶의 선택`, `관계 사건` 중 하나를 포함한다.
- 하루 기록을 콘텐츠로 바꿀 때는 일정 요약을 버리고, `오늘 바뀐 기준 1개`만 제목으로 올린다.
