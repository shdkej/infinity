## 교차 비교

- RSS 최신 15개 한계는 해소됐고, 공식 API로 플팽부부의 과거 10만+ 영상 4개를 확인했다.
- 하루다씀은 공식 API `order=viewCount` 기준으로도 10만+ 영상이 확인되지 않아 4채널 비교의 완결 조건은 아직 충족하지 못한다.
- 3개 채널에서 확인된 강한 제목은 대체로 장소명만 쓰지 않고, 비용·기간·현실·주의·관계·생활 조건 중 하나를 같이 붙인다.
- 시칠리안은 목적지의 변화/치안/비용을 강하게 전면화하고, 플팽부부는 장기 체류와 실제 사건/생활 조건을 섞는다.
- 신디와쏭은 한달살이/파이어/주거·생활비 조건이 뚜렷하다.
- 조회수는 채널 규모와 업로드 시점 영향을 받으므로 제목 공식으로 단정하지 않고, `제목이 어떤 선택 압력을 만들었는지`만 추출한다.

## 비복제 적용 원칙

- 제목을 베끼지 않는다.
- 적용은 `직접 확인한 장소 + 구체 조건 하나 + 기대와 다른 결과` 구조만 가져온다.
- 현재 여행 장면이 있으면 제목 2안을 만들고 72시간 클릭/댓글 신호로 비교한다.
