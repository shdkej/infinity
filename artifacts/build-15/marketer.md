# build-15 Marketer Output

## 역할 판단

첨부 페이지의 첫인상은 어둡고 정제된 편집 작업실이다. `Frame`이라는 짧은 이름, 형광 라임 포인트, 즉시 보이는 9:16 미리보기는 “사진 한 장을 빠르게 게시용 장면으로 만든다”는 가치를 전달한다. 업로드·템플릿·자막·내보내기의 4단계도 처음 보는 사용자가 기능을 추측하기 쉽다.

현재 공개 표면은 **완성된 Instagram 제작 도구의 MVP**로는 충분하지만, 이름과 약속을 실제 기능 범위에 맞춰 좁히고 공개용 기본 카피를 정리해야 신뢰가 생긴다. 특히 출력이 고정된 `1080 × 1920 · 9:16`이므로 일반적인 Instagram 피드 게시물 제작기라기보다 스토리/릴스 커버용 세로 장면 제작기에 가깝다.

## 이름과 포지셔닝

### 현재 이름

- 브랜드 표시: `Frame`
- 보조 표시: `Instagram maker`
- 문서 `<title>`: `Frame — Instagram Maker`

`Frame`은 사진의 한 장면을 고른다는 의미와 화면 안의 프레임을 함께 연상시켜 유지할 만하다. 다만 `Instagram maker`는 기능 범위가 넓게 들리고, 실제로는 9:16 단일 캔버스와 세 가지 템플릿을 제공한다. 공개 화면의 보조 이름은 다음처럼 구체화하는 편을 권한다.

> `Frame · 인스타 세로 장면 편집기`

또는 현재 영어 톤을 유지해야 한다면:

> `Frame · Story & Reel Cover Maker`

권장 포지셔닝 문장:

> 사진이나 영상을 넣고, 자막과 템플릿을 고른 뒤 9:16 장면으로 내보내세요.

이 문장은 실제 동작과 일치하며, Instagram 게시 성과나 플랫폼 노출을 약속하지 않는다.

## 첫 화면 카피 검토

### 유지할 것

- `사진을 넣고, 텍스트 위치와 폰트만 정하면 됩니다.`: 작업 난이도를 낮게 느끼게 하는 좋은 가치 문장이다.
- `사진 또는 영상 업로드`: 입력 범위를 분명히 한다.
- `JPG, PNG, WebP, MP4 · 로컬에서만 처리`: 프라이버시 신뢰를 만드는 중요한 문구다. 코드상 파일은 브라우저의 object URL로 처리되므로 현재 구현과도 부합한다.
- `모든 처리는 브라우저 안에서만 실행됩니다.`: 공개 표면에서 가장 강한 신뢰 신호 중 하나다.
- `PNG 이미지`, `WebM 영상`: 결과물이 무엇인지 명확하다.

### 수정 권장

현재 헤드라인:

> 한 장을 바로 게시 가능한 장면으로.

`게시 가능한`은 플랫폼 규격·안전 영역·콘텐츠 품질까지 보장하는 것처럼 들린다. 실제 구현은 9:16 캔버스에 이미지/영상과 자막을 합성하는 수준이므로 다음을 권한다.

> 한 장을 바로, 인스타 세로 장면으로.

보조 문장:

> 사진을 넣고, 자막과 위치를 고른 뒤 PNG 또는 WebM으로 내보내세요.

샘플 헤드라인인 `이스탄불에서 오래 남은 건 / 그날의 빛이었습니다`는 감성적인 첫인상을 만들지만, 제품이 여행 기록용인지 범용 제작기인지 혼동시킬 수 있다. 샘플을 유지한다면 `샘플 장면`이라는 상태를 더 분명히 보이고, 범용 제품의 첫 예시를 원하면 다음처럼 목적 중심으로 바꾸는 안을 제안한다.

> 오늘의 장면을 한 문장으로

기존 marketing 산출물의 기준처럼, 정보 나열보다 제작자의 관찰이 남는 문장을 예시로 쓰는 방향은 유지한다. 단, 실제 게시를 유도하는 카피보다 사용자가 자기 문장으로 바꾸게 하는 예시여야 한다.

## 사용자 가치와 공개 표면 리스크

### 가치

1. 별도 계정 연결이나 서버 업로드 없이 로컬 파일로 빠르게 시작한다.
2. Photo Hook, Soft Shade, Editorial 세 가지 선택지만 있어 결정 피로가 낮다.
3. 자막·폰트·위치를 즉시 바꾸고 캔버스에서 결과를 확인한다.
4. 정적 페이지로 제공하기 쉬운 단일 작업 흐름이며, PNG와 짧은 WebM 결과를 바로 저장할 수 있다.

### 공개 전 리스크와 판단

| 항목 | 판단 | 공개 전 제안 |
| --- | --- | --- |

| 샘플 상태 | 샘플 이미지와 여행 문구가 실제 사용자 콘텐츠처럼 보일 수 있다 | `샘플 이미지로 시작` 상태를 유지하고 미리보기 주변에 `샘플` 표식을 두는 것을 권한다 |
| 프라이버시 신뢰 | 로컬 처리 문구는 강점이나 네트워크/저장 여부를 사용자가 직접 확인하기 어렵다 | 공개 안내에 “파일은 서버로 업로드하지 않음”을 짧게 풀어 쓴다. 실제 배포 구조가 이를 훼손하지 않는지 Operator가 확인해야 한다 |
| 접근성 | canvas 중심 미리보기는 시각적으로는 강하지만 결과 텍스트를 비시각 사용자에게 충분히 노출하지 않는다 | 입력 텍스트를 미리보기 설명에 연결하고, 템플릿 선택의 키보드 이동/포커스 상태를 검증한다 |

## 공개용 카피 제안 세트

필수 변경을 최소화한다면 다음 네 줄만 우선 조정한다.

- 브랜드 보조명: `인스타 세로 장면 편집기`
- 헤드라인: `한 장을 바로, 인스타 세로 장면으로.`
- 설명: `사진이나 영상을 넣고, 자막과 위치를 고른 뒤 PNG 또는 WebM으로 내보내세요.`
- 출력 안내: `9:16 세로 캔버스 · 파일은 브라우저 안에서 처리됩니다.`

CTA는 현재처럼 기능 중심으로 둔다. `지금 게시하기`, `바이럴 장면 만들기`, `참여율 높이기` 같은 성과·게시 약속은 이 제품이 증명하지 못하므로 사용하지 않는다.

## 공개 게시 승인 경계

이 검토는 카피·포지셔닝·공개 표면 리스크 기록만 다뤘다. Instagram/Threads 계정 연결, 게시·예약 발행, 광고, 외부 공유는 실행하지 않았다. 공개 URL을 만들기 전에는 다음을 별도 확인해야 한다.

- 배포 후에도 파일이 서버로 전송되지 않는다는 동작·네트워크 확인
- `9:16`, PNG/WebM, 5초 영상이라는 출력 계약의 실제 브라우저 검증
- 모바일 또는 데스크톱 권장 환경의 명시
- 대표 title/description/공유 이미지와 샘플 콘텐츠의 공개 적합성
- 외부 Instagram 게시 호환성에 대한 보장 문구를 넣지 않았는지 확인

## 인계

### Developer

- 포지셔닝을 `9:16 세로 장면`에 맞추고 preview와 export 라벨을 일치시킨다.
- `body min-width: 980px`의 모바일 결과를 확인한다.
- 큰 이미지/영상 입력, 5초 녹화, WebM 미지원 브라우저의 실패 문구를 점검한다.
- 사용자가 입력한 headline/caption이 canvas 밖에서도 접근 가능한지 검증한다.

### Operator

- 정적 사이트 registry나 배포 설정을 변경할 때 공개 URL, 캐시 무효화, 실제 키워드 확인을 기록한다.
- 브라우저 로컬 처리 약속이 배포 헤더·분석 스크립트·추가 네트워크 호출로 깨지지 않는지 확인한다.
- 공개 URL 공유 시 샘플 장면과 메타데이터가 의도한 표면인지 확인한다.

### Red

- 이름이 실제 출력 범위를 과장하지 않는지
- 첫 화면 5초 안에 입력 → 편집 → 내보내기 가치가 보이는지
- “게시 가능”, “Instagram 호환”, “성과 향상” 같은 검증되지 않은 약속이 남아 있지 않은지
- 9:16, PNG, WebM, 로컬 처리 문구가 구현과 일치하는지
