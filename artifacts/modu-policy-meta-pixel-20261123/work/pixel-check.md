- [배포 실행](https://github.com/shdkej/space/actions/runs/45184213050)이 성공했다. 배포 소스는 72223eb19bdeb4c1ad6ae90d4c370a1bed9fea55이며, 운영 홈페이지 HTTP 200 및 광고 동의 모듈 로드를 확인했다.
- 운영 브라우저에서 광고 미동의 시 Meta 요청 0건, 동의 후 홈 PageView 요청에 facebook.com/tr HTTP 200 응답을 확인했다. 해당 요청에는 필드 4개가 있었고 쿠키와 Referer가 없었다. 철회 후와 정책 상세에서 발생한 요청은 각각 0건이었다.
- Lead는 실제 서버 응답 계약과 같은 모의 신규·중복·실패·재시도 응답으로 검증했다. 신규 신청 성공만 1회 집계되며 중복·실패를 제외한다. 실제 고객 연락처로 운영 신청을 만들지 않았으므로 운영 Lead 수신은 미확인이다.
- 확인 당시 Meta 이벤트 관리자의 오늘 보기에는 ‘수신한 활동 없음’으로 표시됐다. 브라우저 HTTP 200과 별도로, 이벤트 관리자 집계·광고 귀속은 확인되지 않았다.
