# design-04 — 미니멀리즘 카드뉴스 배경 샘플

## 산출물

- `minimal-black-architectural-background.png`
- `minimal-black-architectural-background-v2.png` — 수정본, 권장 사용
- 941 × 1672 px, RGB PNG
- 세로 비율 0.5628로 9:16 카드뉴스 캔버스에 사용 가능

## 제작 사양

- 검은색·차콜 중심의 고급 건축물 벽/석재 질감
- 낮은 디테일과 넓은 텍스트 안전영역
- 텍스트·로고·워터마크·인물·장식 요소 없음
- 생성 경로: built-in image generation

## v2 수정 사항

- 왼쪽에 보이던 세로 선/이음매를 완전히 제거했다.
- 검정 일변도의 인상을 줄이고 차콜·흑연·짙은 회색으로 전체 톤을 밝고 차분하게 조정했다.
- 원본 v1은 비교·복구용으로 보존한다.

## 역할 판단

### Planner

요청을 단일 9:16 비트맵 시안으로 제한하고, 카드뉴스 텍스트가 올라갈 공간과 절제된 고급감을 완료 기준으로 확정했다. Knowledge Lab의 “정보를 덜어내고 다음 행동이 보이게 한다”는 정제 원칙과 기존 카드뉴스의 안전영역 운영 기준을 적용했다.

### Developer

프로젝트 아티팩트 경계 안에 원본 PNG를 보존했다. 이미지를 코드나 템플릿에 연결하지 않았으며, 기존 파일을 덮어쓰지 않고 새 `design-04` 디렉터리에 버전 독립적으로 저장했다.

### Marketer

첫인상은 검은색의 무게감보다 텍스트가 읽히는 여백과 표면의 촉감이 먼저 오도록 판단했다. 광고·게시·외부 발송은 범위에서 제외했다.

### Operator

공개 반영, 외부 업로드, 비용 결제, 개인정보·자격증명 변경 없이 로컬 아티팩트와 검증 리포트만 생성했다. 재사용 시 밝은 텍스트를 중앙·상단에 배치하는 것을 권장한다.
