# PC·인터넷 시대 전환사
## 특수 도구에서 일상 인프라로: 50년간의 보급사와 인식 전환

> research-10 | 2026-05-28 | Heartbeat Agent

---

## 개요

1960년대까지 컴퓨터는 대학·정부·대기업만이 운용하는 메인프레임이었다. 오늘날 인류의 74%가 인터넷에 접속하고, 대부분은 주머니 속 스마트폰을 통해 매시간 연결되어 있다. 이 전환은 어떻게 일어났는가?

이 문서는 그 50년 여정을 PC 보급사, 인터넷 보급사, 주요 변곡점, 인식 변화 4개 축으로 정리한다.

---

## 1. PC 보급사: 메인프레임 → 개인용 컴퓨터 → 노트북

### 1950s–1960s: 메인프레임 시대
- 컴퓨터 = 방 한 칸 크기의 기관 소유 자원
- 사용 주체: 연구자, 정부, IBM 고객사
- 개인 접근 불가. 카드 펀치로 배치 처리

### 1970s: 마이크로컴퓨터의 탄생
- **1975**: Altair 8800 — 조립 키트. 사용자는 엔지니어·해커 한정
- **1977 Trinity**: Apple II, Commodore PET, TRS-80
  - Apple II: 스티브 워즈니악 설계. "평범한 사람을 위한 특별한 컴퓨터"로 마케팅
  - 소비자용 PC의 시발점. 취미 영역에서 제품 영역으로 이동
- **1979**: VisiCalc(스프레드시트) 등장 → 첫 킬러 앱. PC의 "비즈니스 도구" 가능성 입증

### 1980s: 대중화의 시작
- **1981**: IBM PC 출시 (1981년 8월 12일)
  - "Big Blue"의 진입으로 기업 PC 시장 공인
  - 3년 만에 200만 대 판매
  - IBM PC 호환 기종(클론) 시장 열림
- **1984**: Apple Macintosh (1984년 1월 24일)
  - 그래픽 유저 인터페이스(GUI) + 마우스 대중화
  - 스티브 잡스: "나머지 우리 모두를 위한 컴퓨터"
  - 전문 기술 없이도 사용 가능 → "컴퓨터 문해력" 개념 확산
  - 출시 당시까지 Apple II는 200만 대 이상 판매
- **1985**: Windows 1.0 출시 (이후 Windows 3.x가 1990년 주류)
- **1984년 보급률**: 미국 가정 약 8.2%

### 1990s: 가정 보급 가속
- **1990**: 미국 성인 42%가 직장·학교·가정에서 컴퓨터 사용
- **1995**: Windows 95 출시
  - 대규모 마케팅 캠페인 (The Rolling Stones "Start Me Up")
  - 플러그앤플레이, 32비트 처리, 인터넷 익스플로러 내장 → 인터넷 대중화의 관문
  - 개인 컴퓨팅 역사상 가장 중요한 제품 중 하나로 평가
- **1997**: 미국 가정 36.6%가 PC 보유
- 1990년대 말: 노트북 가격 하락, 이동성 있는 개인 컴퓨터 등장

### 2000s 이후: 포화와 전환
- **2001**: 전 세계 1억 2,500만 대 PC 출하 (1977년 48,000대 대비 약 2,600배)
- 2000년대 중반: 미국 가정 PC 보급률 70%+ 도달
- PC에서 노트북으로, 이후 스마트폰으로 주 기기 이동

## 2. 인터넷 보급사: 연구망 → 대중 인터넷 → 모바일

### 1969–1990: 연구망 시대 (ARPANET → 인터넷 원형)
- **1969**: ARPANET — 미 국방부 지원, 4개 대학 노드
- **1983**: TCP/IP 표준화. "인터넷"이라는 개념 공식화
- **1991**: Tim Berners-Lee, World Wide Web + HTML 공개 (CERN)
  - 파일 전송이 아닌 "하이퍼텍스트" 링크 개념 도입

### 1993–1995: 일반인 접근 가능해진 순간
- **1993**: **Mosaic 브라우저** — 웹 역사의 전환점
  - NCSA Marc Andreessen 개발
  - 인라인 이미지, 포인트&클릭 내비게이션, 크로스플랫폼
  - "웹의 역사에서 가장 중요한 전환점"으로 역사가들이 인정
- **1994**: Netscape Navigator 출시 → 첫 대중 브라우저; 성공적 IPO가 닷컴 붐 촉발
- **1995**: 인터넷 상업 제한 완전 해제
  - ISP(AOL 등) 다이얼업 서비스 대중화
  - Windows 95 + IE 번들 → 인터넷 진입 장벽 최저
- **1995 기준**: 전 세계 인구의 약 1%만 인터넷 사용

### 1996–2002: 닷컴 붐과 다이얼업 전성기
- **1998-2000**: 닷컴 붐
  - 인터넷 = 새로운 경제 패러다임으로 인식
  - AOL 가입자 2,320만 명(2000년 피크)
  - 미국 성인 인터넷 사용률: 2000년 43%
- **2000**: 전 세계 인터넷 사용률 7% (약 3.6억 명)
- **2000-2003**: 닷컴 버블 붕괴 → 그러나 인터넷 사용자는 계속 증가

### 2003–2007: 브로드밴드 전환
- **2003-2005**: 미국에서 브로드밴드가 다이얼업 추월
  - 2000년: 온라인 성인 중 브로드밴드 3%
  - DSL·케이블 보급 확대로 "상시 연결"(always-on) 개념 등장
- 유튜브(2005), 페이스북(2004), 트위터(2006) 등 소셜 미디어 탄생
- 인터넷 = 항상 켜져 있는 것으로 인식 전환

### 2007–2015: 모바일 인터넷 혁명
- **2007**: **iPhone 출시** — 모바일 웹의 원년
  - 전체 웹 브라우저 탑재 + 터치스크린 + 앱 생태계
  - "iPhone은 웹 성장기의 종착점이자 웹 유비쿼티 시대의 시작" (Computer History Museum)
  - 할머니도 매시간 사용하는 인터넷
- **2010**: 전 세계 인터넷 사용률 29% (20억 명 돌파)
- 2010년대 초: 스마트폰이 개도국에서 1차 인터넷 접근 기기로 부상
  - 유선 인프라 없는 지역도 모바일로 인터넷 첫 경험

### 2015–2025: 인프라화 완성
- **2015**: 전 세계 40% (스마트폰 30억 대 보급)
- **2020**: 전 세계 60% (코로나19가 디지털 전환 가속)
- **2025**: 전 세계 약 74% (~60억 명)
- 밀레니얼·Z세대: 인터넷 없는 세상을 경험한 적 없는 "디지털 네이티브"

## 4. 인식 변화: "특수한 도구 → 당연한 인프라"

### 4-1. 1970s: "해커의 장난감"
- 컴퓨터 = 기술 매니아, 공학도의 취미
- Apple II 구매자: "이걸로 뭘 하냐"는 질문에 답하기 어려운 시대
- 언론: "컴퓨터가 가정에 들어올 것인가?" 호기심 반, 회의론 반

### 4-2. 1980s: "비즈니스 도구"
- IBM PC → 기업이 채택 → "진지한 기계"로 인정
- VisiCalc, Lotus 1-2-3 → 스프레드시트로 생산성 입증
- 학교 컴퓨터 수업 등장: "미래를 위한 기술 교육"
- 여전히 많은 가정에서는 "있으면 좋지만 없어도 되는 것"

### 4-3. 1990s 전반: "소비자 제품"
- Macintosh + Windows GUI → 기술 지식 불필요
- 가정용 PC 마케팅: 아이들 교육 + 가족 사진 + 가계부
- "컴퓨터 문해력(computer literacy)"이 사회 가치로 부상
- 대학생 필수품으로 자리 잡기 시작

### 4-4. 1995–2000: "커뮤니케이션 플랫폼 + 흥분"
- 인터넷 = 새로운 세계. "정보 고속도로"
- 이메일이 편지를 대체하기 시작
- 닷컴 붐: 인터넷 = 돈이 되는 곳. 열광과 과열
- 미디어: "모든 것이 인터넷으로 이동할 것이다"

### 4-5. 2000s: "필수 서비스"
- 닷컴 버블 붕괴 후 현실 정착: 인터넷 = 실제로 쓸모 있는 도구
- 온라인 뱅킹, 온라인 쇼핑, 구글 검색이 일상화
- 이메일 없으면 업무 불가능한 상태
- 인터넷 연결 = 기본 서비스(전화·수도처럼)로 인식 시작
- "인터넷 접속이 없다" = 뭔가 잘못된 상태

### 4-6. 2007–2015: "항상 켜져 있는 것"
- iPhone 이후: 인터넷 = 이동 중에도 끊기면 안 되는 것
- 소셜 미디어: 인터넷 = 친구들이 있는 곳
- 스마트폰 없으면 "현대인으로 살기 어려움"
- 디지털 격차(digital divide) = 교육·경제 기회의 격차로 인식

### 4-7. 2015–2025: "공기처럼 당연한 인프라"
- Z세대: 인터넷 없는 삶 = 상상 불가
- 공공 WiFi = 공공재
- 코로나19(2020-2022): 인터넷 = 직장·학교·의료·사회생활 전부
- 정부·학자들: 인터넷 = "공공 디지털 인프라"로 규제 논의
- Facebook, Google, Amazon = 전기·수도와 같은 필수 유틸리티 개념으로 접근 (Knight Columbia Institute)
