## 접근·근거 한계

YouTube oEmbed와 공식 Starter Story 페이지는 확인했다. `yt-dlp`는 “Sign in to confirm you’re not a bot”에서 중단되어 영상 파일/플랫폼 자막을 별도 저장하지 못했다. 다만 Starter Story가 영상과 함께 공개한 transcript·챕터·디스크립션을 공식 웹 원문으로 확보했다. Kyan의 X 프로필은 검색/열람 결과 HTML 0 lines라 게시물·게시일·반응을 확인하지 못했다. 아래는 확인된 사실만의 복원이며, SNS 날짜와 반응 수는 추정하지 않는다.

## 한 문장 요약

Kyan은 기타를 배우며 겪은 “내 장비로 특정 곡의 기타 톤을 재현하기 어렵고 ChatGPT 답도 부정확하다”는 작은 문제를, AI 코딩으로 일주일 만에 웹 V1로 공개하고, 첫 영상의 바이럴을 하루 3회 다중 플랫폼 게시와 얼굴을 건 신뢰 형성으로 반복해 5개월 안에 웹·모바일 합산 최근 4주 매출 25,000달러 이상을 주장한 사례다.

## 메커니즘 분석

1. 문제의 질: 넓은 “기타 학습”이 아니라 곡의 원래 톤을 내 장비로 옮기는 변환 문제다. 입력(곡·기어)과 출력(설정)이 분명해 데모가 쉽다.
2. 제품의 질: 기능 범위를 좁혀 웹으로 과금 가능한 결과를 먼저 만들었다. AI가 코딩을 가속했지만, 제품 가치는 코드 생성보다 원곡 rig 조사와 사용자 장비 매핑에 있다.
3. 분배의 질: 첫 바이럴을 단발성 운으로 끝내지 않고 게시 빈도·다중 플랫폼·개인 얼굴·전환 포맷 반복으로 루프화했다. 다만 “실제 전환율” 데이터는 없다.
4. 확장의 질: 웹 매출/피드백 이후 iOS를 붙였고, RevenueCat·Superwall로 구독과 실험을 계측했다. 즉 build → attention → paid signal → channel expansion 순서다.

## 실패·차단·미확인 경계

- YouTube 직접 자막/영상 파일: 봇 검증 차단. 공식 transcript로 부분 대체했으나 영상 시각·화면 대시보드는 직접 검증하지 못함.
- X/SNS 원문: `https://x.com/kyanbuilds` HTML 0 lines. 최초 게시물 날짜, 조회/좋아요/댓글, 실제 3회/일 빈도, 플랫폼별 성과는 Waiting.
- 공식 앱스토어/결제: 로그인·스토어 상세/Stripe 원장 접근 없음. 수수료·순매출·환불·잔존율·CAC·LTV는 미확인.
- “100,000 users”, “150,000+ guitarists”, “25K/month”, “guarantee”는 각각 발화/웹 카피의 주장으로만 기록. 독립 검증이나 인과 증명으로 확대하지 않음.
- 영상 디스크립션의 링크는 공식 Starter Story 페이지에서 확인했지만, 디스크립션 원문을 YouTube API로 별도 보존하지 못함.

## 재현 가능한 다음 액션

Kyan X 게시물 export/URL 목록과 YouTube 자막 파일이 제공되면, 게시일 기준으로 `idea → first demo → first viral → first payment → web launch → iOS launch → current` 이벤트를 다시 정렬하고, 각 이벤트에 플랫폼·게시물 ID·조회/반응·CTA·전환 증거를 붙인다. 그 전에는 현재 보고서를 `부분 완료/Waiting`으로 유지한다.
