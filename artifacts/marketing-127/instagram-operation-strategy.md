# @archivenoh Instagram 운영 전략 — 공개 데이터 접근 대기본

## 결론 2축

- 맥락/대상/문제: @archivenoh의 공개 게시물을 확인해, 떠오른 것을 편하게 매일 올리면서 자기검열과 과도한 고민을 줄이는 운영 방식을 만들려 했다.
- 결과/해법/발견: 실제 게시물 데이터가 로드되지 않아 계정의 현재 톤·반복 패턴·강점은 판단하지 않는다. 아래 운영안은 계정 분석이 아니라, 접근이 복구된 뒤 바로 적용할 수 있는 검증 대기용 규칙이다.

## 접근 확인

- 시도: 공식 프로필 URL `https://www.instagram.com/archivenoh/`
- 결과: 웹 fetch `Cache miss`; OpenClaw 브라우저 status는 실행 파일 `/home/ubuntu/.cache/ms-playwright/chromium-1208/chrome-linux/chrome` 부재로 `running: false`.
- 확인한 게시물: 0개. 따라서 게시물별 근거, 캡션 인용, 게시 빈도, 시각 반복 패턴을 기록하지 않는다.

## 역할별 판단

### Planner

완료 기준을 “게시물 3개 이상을 실제로 읽고 근거 링크/게시일/형식을 남기는 것”으로 고정한다. 데이터가 없는 상태에서 계정 진단을 쓰지 않고, 산출물은 Waiting으로 둔다.

### Developer

분석 재개 시 게시물 URL, 날짜, 포맷(사진/릴스/캐러셀), 캡션 핵심 문장, 반복 요소를 한 행씩 기록한다. 브라우저 접근이 복구되기 전에는 스크레이핑이나 로그인 우회 코드를 만들지 않는다.

### Marketer

계정 고유 톤을 확인하기 전에는 “현재 강점”이나 브랜드 문장을 만들지 않는다. 접근 후에는 가장 자주 나타나는 소재와 선택 기준을 기준으로 게시 규칙을 만들되, 일반적인 성장 훅을 먼저 덧씌우지 않는다.

### Operator

공개 게시·프로필 변경 없이 초안과 기록표만 만든다. 1~2주 테스트는 게시 수보다 업로드까지 걸린 시간, 삭제/수정 여부, 다음 소재를 떠올리는 난이도를 관찰한다. 외부 발행은 별도 사용자 승인 없이는 하지 않는다.

### Red

검증 결과: blocker와 근거가 명시되어 있고 계정 특성에 대한 추정은 없다. 다만 실제 게시물 분석 성공 기준은 아직 충족하지 않았으므로 완료/Archive 판정을 하지 않고 Waiting으로 유지한다.

## 접근 복구 후 적용할 최소 운영안

아래는 @archivenoh의 현재 패턴이라고 주장하지 않는 실행 가설이다.

### 업로드 규칙

1. 하루 한 번, 15분 타이머 안에 “오늘 떠오른 한 장면 + 한 문장”만 작성한다.
2. 게시 전 검사는 사실 오류·타인 개인정보·저작권·공개하면 곤란한 정보 4가지만 본다.
3. 문장 다듬기는 1회만 하고, 해시태그·표지·성과 예측은 생략한다.
4. 사진이 없으면 텍스트 중심 이미지 1장도 허용한다. 다음 날 보완할 생각으로 보류하지 않는다.
5. 올린 뒤 24시간 동안 삭제·재작성하지 않는다. 성과 평가는 7일 뒤 한 번만 한다.

### 과잉 기준으로 삼지 않을 것

- 모든 게시물이 계정 주제를 설명해야 한다는 기준
- 매번 새로운 포맷이어야 한다는 기준
- 좋아요/저장 수가 낮으면 실패라는 판정
- 문장이 완결된 통찰이어야 한다는 압박
- 피드 그리드 색·간격을 매일 맞추는 작업

### 1~2주 실험

- 1~3일차: 하루 1개. 15분 제한과 4개 안전검사만 적용.
- 4~7일차: 소재를 `관찰 / 선택 / 작업 중 막힌 것` 세 칸으로만 분류. 가장 쓰기 쉬운 칸을 확인.
- 8~10일차: 반응이 좋았던 글을 복제하지 말고, 같은 소재를 다른 길이로 한 번만 변주.
- 11~14일차: 14개를 다시 읽고 `계속 쓰고 싶은 소재`, `생각보다 부담된 형식`, `다음에도 유지할 규칙` 각 1개만 결정.

재개 조건은 공개 게시물 3개 이상이 실제로 확인되는 것이다. 그때만 위 가설을 계정의 실제 패턴과 대조해 수정한다.
