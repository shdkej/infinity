# `_archivenoh` Instagram 운영 전략 — 공개 근거 기반 통합안

확인 시각: 2026-08-22 UTC
실행 모드: `multi_subagent_roles`
범위: 공개 게시물 분석과 내부 운영 제안. 공개 게시·프로필 변경·로그인·DM·외부 발송은 실행하지 않음.

## 결론 2축

- **근거:** 공개 HTML에서 2026-08-14, 2026-08-20, 2026-08-21 게시물 3건을 확인했다. 14일과 20일은 캡션 없음, 21일은 관찰형 캡션 1건이다. 계정 표기는 `_archivenoh`다.
- **운영안:** 한 캡션에서 확인된 ‘여행 계획에서 AI가 있어도 선택 시간이 줄지 않은 경험’을 확정된 계정 톤이 아니라 실험 가설로 두고, 1~2주 동안 주 2~3회의 작은 기록 실험을 proposal-only로 준비한다.

## 근거와 해석 경계

직접 확인한 사실은 게시일, 게시 간격, 캡션 유무, 2026-08-21 캡션의 문장 구조다. 8일간 3건과 최근 이틀 연속 게시라는 빈도는 확인할 수 있지만 최적 빈도나 지속 습관으로 일반화하지 않는다. 무캡션 게시물의 이미지 내용·스타일·포맷, 좋아요·댓글 값의 의미, 타깃·성장·성과는 판정하지 않는다. 캡션 속 `2026.08.20`은 게시일과 혼동하지 않는다.

## 역할별 판단

### Planner

실제 경험·선택 과정·남은 판단을 핵심 소재 가설로 두고, 일반적인 여행/AI 계정으로 규정하지 않는다. Knowledge Lab의 `original-proof-distribution-loop`, `Content_Strategy`, `Threads`, `TASTE`, `MARKETING_LEARNINGS` 기준에 따라 원본 경험 → 한 문장 판단 → 채널 번역 → 반응 회수 순서를 적용한다.

### Developer

코드 구현은 해당 없음. 분석 산출물은 근거표, 사실/제한/해석 분리, 1~2주 손기록표, 재현 절차로 닫는다. 각 URL은 `curl -L -A 'Mozilla/5.0'`로 재조회하고 메타데이터 변경 시 기존 근거를 덮지 않고 확인 시각과 변경을 별도 기록한다.

### Marketer

현재 가장 강하게 보이는 후보는 장소·상황 → AI가 해결할 것 같은 기대 → 남은 인간의 선택/망설임 → 결론을 닫지 않는 짧은 관찰이다. 이는 캡션 1건에서만 나온 가설이다. 한 게시물에 한 장면·한 관찰을 두고, 설명·교훈·홍보를 억지로 덧붙이지 않는다. 무캡션도 허용하되 성공 포맷으로 확정하지 않는다.

### Operator

운영 지표는 게시 여부, 게시 간격, 캡션 유무·길이, 작성 소요·수정/삭제 여부, URL 접근성, 정성 반응 기록으로 제한한다. 24시간/7일 재확인은 성과 측정이 아니라 공개 상태와 근거 보존용이다. 404·private 전환·rate limit 시 원본 URL·확인 시각·응답을 보존하고 제한적으로 재시도한다.

## 1~2주 내부 실행안

1. 현재 3건을 기준선으로 날짜·캡션 유무·관찰형 여부만 표로 고정한다.
2. 실제 경험에서 다음 소재 3개를 모으고 `무슨 일이 있었나 / 무엇이 어려웠나 / 어떤 기준이 남았나`를 한 줄씩 쓴다.
3. 관찰형·선택형·반성형으로 나누되 같은 첫 문장 골격을 반복하지 않는다.
4. 초안은 `장면 → 이상했던 점 → 남은 질문` 세 줄로 만들고, 게시 전에는 실제 경험·한 문장 관찰·결론을 열어둘 수 있는지만 확인한다.
5. 1주차는 초안·관찰표·승인 대기까지 진행한다. 공개 게시가 별도 승인되면 1~2건만 시험한다.
6. 2주차에는 캡션 있는 기록과 무캡션 게시를 비교 후보로만 손기록하고, 다음 소재 선택에만 반영한다. 좋아요·댓글 0값으로 성공/실패를 판정하지 않는다.
