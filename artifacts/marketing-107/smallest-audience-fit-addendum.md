# Virtue 첫 10명 smallest audience fit 보강안

- intent: marketing-107
- scope: `artifacts/marketing-79/week-one-activation-observation-table.html`와 `artifacts/marketing-104/first-value-retention-gate-addendum.md`에 붙이는 손기록 companion
- boundary: 관찰표 보강안만 작성한다. 신규 이벤트, 속성, 대시보드, 공개 카피, 발송, 배포는 하지 않는다.

## 왜 이 칸이 먼저인가

기존 첫 10명 관찰표는 세션이 잡별 first value에 도달했는지와 첫 주 재방문 이유를 읽는다. 이번 보강은 그 앞단에 `smallest_audience_fit`을 둔다. 목적은 "이 사람이 어느 작은 관객 가설에서 온 사람인가"를 먼저 적어, 저장/판정/재방문 신호를 누구의 반복 가치 신호인지 섞지 않는 것이다.

`smallest_audience_fit`은 retention 예측이나 성공 판정이 아니다. 첫 세션 전후의 자기 말, 대체재, 기대한 결과, 자연스럽게 다시 올 상황을 근거로 J1-J4 중 가장 가까운 관객 가설을 표시하는 선행 분류다.

## 사용자 카드에 추가할 칸

각 사용자 카드의 `잡` 줄 바로 아래, `독립 2판정`보다 앞에 아래 4줄을 붙인다.

| 칸 | 기록값 | 기록 방법 |
|---|---|---|
| `smallest_audience_fit` | `J1 / J2 / J3 / J4 / 혼합 / 불명` | 첫 입력 전후의 자기 말과 기대한 결과로 가장 가까운 작은 관객 가설을 표시한다. |
| `fit 근거 원문` | 원문 1개 | "왜 이 사람을 그 관객으로 봤는가"를 말 그대로 적는다. 이벤트명으로 대신하지 않는다. |
| `다시 돌아올 상황` | 상황 1개 | 같은 job으로 자연스럽게 다시 열 상황을 적는다. "D1 재방문함" 같은 결과값이 아니라 맥락을 쓴다. |
| `fit confidence` | `높음 / 중간 / 낮음` | 근거가 자기 말이면 높음, 행동 추정이면 중간, 이벤트만 있으면 낮음으로 둔다. |

## 기존 칸과의 관계

1. `smallest_audience_fit`을 먼저 적는다.
2. 그 다음 기존 `가치 발견 신호`와 `activation 판정`을 독립으로 적는다.
3. `첫 가치 도달 시점`과 `결과 이해 신호`는 결과를 이해했는지에 대한 칸으로 둔다.
4. `다시 돌아올 상황`은 기존 `첫 주 재방문 이유`나 `retention 예측 신호`를 대체하지 않는다. 재방문이 일어나기 전에 예상 가능한 같은-job 상황을 손기록하는 칸이다.
5. 실제 D1/D7 재방문이 생기면, `다시 돌아올 상황`과 일치했는지 별도로 비교한다.

## J1-J4별 예시

### J1 일상 기록형

- `smallest_audience_fit`: J1
- fit 근거 원문: "오늘 한 작은 일을 그냥 남겨두고 싶어서요."
- 다시 돌아올 상황: 하루 끝에 사소하지만 놓치기 싫은 행동을 하나 적고 싶을 때
- first value 기준: `deed_saved`
- 중복 방지: "내 하루가 남았다"는 `첫 가치 도달 시점/결과 이해 신호`에 적고, 이 칸에는 왜 J1 관객인지와 다시 열 상황만 적는다.

### J2 누적 성장형

- `smallest_audience_fit`: J2
- fit 근거 원문: "쌓이면 숫자나 레벨처럼 보이는 게 궁금해요."
- 다시 돌아올 상황: 어제 저장한 것과 오늘 저장한 것이 누적되는지 확인하고 싶을 때
- first value 기준: `deed_saved`
- 중복 방지: `D1 재방문` 자체를 fit 근거로 쓰지 않는다. 누적 payoff 기대가 있었는지를 먼저 적는다.

### J3 AI 호기심형

- `smallest_audience_fit`: J3
- fit 근거 원문: "AI가 이걸 어떻게 볼지가 궁금했어요."
- 다시 돌아올 상황: 다른 행동도 AI가 어떻게 해석하는지 비교해보고 싶을 때
- first value 기준: `deed_judged`
- 중복 방지: 저장 없는 종료를 fit 낮음이나 retention 약함으로 자동 판정하지 않는다. J3에서는 결과 확인 후 자연 종료가 정상일 수 있다.

### J4 자기 반성형

- `smallest_audience_fit`: J4
- fit 근거 원문: "나중에 내가 왜 그랬는지 다시 보고 싶어요."
- 다시 돌아올 상황: 비슷한 선택을 반복했거나 한 주를 돌아보며 의미를 정리하고 싶을 때
- first value 기준: `deed_saved`
- 중복 방지: 단순 저장 행동만으로 J4로 올리지 않는다. 회고, 의미 정리, 나중에 다시 보기 언어가 있어야 한다.

## 판독 규칙

- 이벤트만으로 `smallest_audience_fit`을 확정하지 않는다. `deed_saved`는 J1/J2/J4 모두의 first value일 수 있다.
- 혼합이면 억지로 하나로 줄이지 말고 `혼합`으로 두고 원문을 남긴다.
- `fit confidence: 낮음` 세션은 activation/retention 판단에서 제외하지 않는다. 단지 job 해석 신뢰도가 낮다고 표시한다.
- 같은 관객 가설의 `다시 돌아올 상황`이 2명 이상 반복되면 후속 관찰 질문 후보가 된다. 공개 카피나 계측 변경으로 바로 옮기지 않는다.
