# 실제 근거 데이터 위험 표시 조사 요구사항

## 목적

사용자가 실제 근거 데이터 기반 위험 표시를 선택했습니다. 구현·표시 전에 단일 행정구역의 공개 원자료를 대상으로 출처, 이용허락, 기준일, 갱신일, 공간·시간 단위와 결측을 검증합니다.

## 현재 범위

- 지역 범위는 아직 정해지지 않았습니다. 국가·도시를 임의로 선택하지 않습니다.
- 조사 결과가 나올 때까지 지도에 위험 구역, 안전 등급, 사건 밀도나 예측을 그리지 않습니다.
- 기존 `sites/safety-map/**`은 수정하지 않습니다.

## 수용 기준

1. 후보 데이터마다 관할 기관 원문 URL과 데이터 제공 주체를 기록합니다.
2. 표시·재배포·파생 이용 가능 여부와 라이선스 원문을 확인합니다.
3. 사건 관측 기간, 발행일, 마지막 갱신일, 갱신 주기, 공간·시간 집계 단위와 결측을 기록합니다.
4. 표시 전 수동 표본 대조와 갱신 실패 상태를 설계합니다.
5. 사용자 화면에는 “공개 관찰 자료이며 개인의 안전을 예측하거나 이동 경로를 권하지 않습니다”와 지연·미신고·관할 차이 한계를 함께 표시하도록 제안합니다.

## 금지

치안 점수, 안전/위험 등급, 개인화, 경로 권고, 실시간 주장, 사용자 위치·제보 수집, 개인 또는 사건 식별 정보는 이번 조사와 후속 표시 범위에 포함하지 않습니다.

## 완료 증거

후보별 출처·라이선스·갱신 메타데이터 표와 수동 대조 기록을 갖춘 조사 보고서, Red 검토 결과, 그리고 사용자 승인된 지역 범위가 있어야 표시 구현을 시작할 수 있습니다.
