## 목적

AI 제품이 빠른 첫 가치를 만들수록 사용자가 수동적으로 감탄만 하고 반복 맥락을 만들지 못하는 위험이 있다.  
이 판독표는 prelaunch 첫 10명 관찰에서 `deed_judged` 이후 저장 없는 종료를 더 선명하게 분리하기 위한 수기 관찰 칸을 제안한다.

**계승 기준 (MARKETING_LEARNINGS.md)**
- `Post-Response Flow Reveals Value, Not The Result Event` (m44): 결과 직후 30초 분리 관찰 프레임
- `Session Value Is Read By Job, Not Event Count` (m42): J3 무저장 종료 = 정상; J1/J2/J4 무저장 = 보류 후보
- `First-User Learning Loop Reads Language, And Help Means Articulation Not Delegation` (m47): 자기 말 기록이 핵심

**재정의하지 않는 매핑**
- J1/J2/J4 = `deed_saved` (first value)
- J3 = `deed_judged` (first value, 저장 선택사항)
- J3 무저장 종료는 정상 완료

## 판독 칸 (5개, 수기 관찰용)

> **사용 조건**: 이 칸들은 계측·이벤트·속성·dashboard를 새로 추가하지 않는다.  
> first-user 관찰 세션에서 관찰자가 직접 손기록하는 칸이다.  
> J3에서는 칸 1-3이 "정상 종료"로 채워지는 것이 정상임을 먼저 확인한다.

### 칸 1: 결과 카드 체류 방식

| 관찰 기준 | 판정 |
|-----------|------|
| 멈추고 읽음 → 자기 말로 반응하거나 저장·재판정 | **자기화 신호** |
| 멈추고 읽음 → "오" / "맞네" 반응 후 맥락 없이 종료 | **수동 감탄 후보** |
| 빠르게 스크롤하거나 읽지 않고 종료 | **마찰/가용성 후보** |
| J3에서 읽고 결정적으로 무저장 종료 | **J3 정상 완료** (판독 종료) |

*손기록 포인트*: 체류 시간(대략 초 단위), 반응 표정/발화 유무

---

### 칸 2: 자기 말 시도 흔적

| 관찰 기준 | 판정 |
|-----------|------|
| 판정 후 자기 언어로 요약·기록 시도, 또는 저장 | **자기화 신호** |
| "이게 맞아" / "잘 나왔다" 단순 동조 발화 후 종료 | **수동 감탄 후보** |
| 아무 언어 반응 없이 종료 | **마찰/가용성 후보, 또는 J3 정상 종료** |
| "이건 좀 아닌 것 같아서 저장 안 해" | **의도적 무저장** (자기화 포함) |

*손기록 포인트*: 발화 원문 그대로 (요약하지 않음), 자기 언어인지 AI 언어 재인용인지 구분

---

### 칸 3: 결과 후 반복 맥락 생성 의도

| 관찰 기준 | 판정 |
|-----------|------|
| 저장, 또는 "다음에 또 이 행동을 기록하고 싶다"는 언급 | **자기화 신호** |
| "재미있다, 한 번 더 해볼게" → 맥락 창출 의도 없음 | **수동 감탄 후보** |
| 바로 앱 이탈, 다음 session 언급 없음 | **보류 (J3 정상 포함, 단독으로 판정 금지)** |

*손기록 포인트*: "한 번 더" 또는 "나중에" 발화 여부 + J3인지 다른 잡인지 먼저 확인

---

### 칸 4: 저장·종료 결정의 주도성

| 관찰 기준 | 판정 |
|-----------|------|
| "이건 내 것이 됐으니 저장한다" — 명시적 의도 저장 | **자기화 저장** |
| 저장 없이 결정적으로 닫음 (J3 흐름) | **J3 정상 완료** |
| 저장하려다 멈춤 / "어디에 저장하는 거야?" | **마찰(B-LOST)** |
| 저장 버튼이 보이지 않거나 오류 | **가용성 차단(B-AVAIL)** |
| "저장 안 해도 됐는데" → 이미 저장된 상황 | **의도 불일치** |

*손기록 포인트*: 버튼 누름의 망설임 여부, 저장 후 표정 변화

---

### 칸 5: 결과 공유 제스처 (선택)

| 관찰 기준 | 판정 |
|-----------|------|
| 화면 보여주기, 스크린샷, "이거 봐봐" 발화 | **공유성 신호** (저장 독립) |
| 웃음·놀람 반응 + 결과 재읽기 | **공유성 신호** |
| 위 없이 조용히 종료 | **단독 신호 없음** |

*손기록 포인트*: Shareworthiness는 저장과 독립이므로 칸 1-4와 별개 열에 기록 (m30 참조)

## marketing-47과의 연결 포인트

`virtue-first-10-design-user-ask-script.md`의 "첫 세션 후 3문항":
1. **first value 위치** → 칸 1과 연결 (어디서 멈췄나)
2. **friction** → 칸 4의 B-LOST / B-AVAIL 연결
3. **결정-위임 인지** → 칸 2의 자기 말 vs AI 언어 재인용 연결

"사용자가 자기 말로 설명한 Virtue" 기록 칸:
- 칸 2 자기 말 시도에서 나온 원문을 그대로 이 칸에 옮긴다
- 수동 감탄 패턴은 AI 언어 재인용("AI가 그렇게 나왔어")이 자기 말을 대체하는 형태로 나타난다

## 수동 감탄 패턴의 조기 신호 (손기록 보조)

> 아래는 관찰에서 "수동 감탄"을 조기 감지하기 위한 비계측 보조 목록이다.

1. AI 언어를 그대로 재인용하며 동조 ("AI가 이렇게 나왔잖아요")
2. 감탄 후 "근데 이거 다음에 어떻게 쓰죠?" → 반복 맥락 미형성
3. 저장 없이 닫은 뒤 "잘 나왔다고 생각하는데 저장은 안 했어요" — J3 외 잡에서
4. 다음 사용 의향 질문에 "언제 써야 할지 모르겠어요" — 반복 use case 미발화
