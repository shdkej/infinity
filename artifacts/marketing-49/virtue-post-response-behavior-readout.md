## 배경

ChartMogul AI activation/retention 노트는 AI가 빠른 첫 가치를 만들수록, 사용자가 수동적으로 감탄만 하고 반복 맥락을 만들지 못할 위험을 지적한다(Passive Admiration Trap). 이 판독표는 그 위험을 Virtue의 J3 결과 카드 직후 30초 관찰 프레임에서 구분하기 위한 수기 판독 도구다.

Virtue first value 매핑 유지:
- J1/J2/J4: `deed_saved` = first value
- J3: `deed_judged` = first value (무저장 정상 종료 포함)

이 판독표는 위 매핑을 바꾸지 않는다. `deed_judged` 이후 행동의 *성격*을 분류하는 보조 판독 칸이다.

## 결과 카드 직후 행동 판독표

| # | 행동 | 분류 | 의미 | 수기 관찰 방법 |
|---|------|------|------|--------------|
| 1 | 저장한다 (`deed_saved` 발화) | 자기화 — 보존 | 판정 결과를 맥락에 편입, 나중에 쓸 것으로 본다 | on-instrument 자동 포착 |
| 2 | 재작성하거나 재시도한다 (`deed_rerolled` 또는 직접 수정 후 저장) | 자기화 — 조정 | 결과를 내 것으로 만들기 위해 수정함; 판정을 원료로 쓴다 | `deed_rerolled` on-instrument; "수정하셨나요?" 선택 기록 |
| 3 | 저장 없이 닫는다 (J3 정상 종료) | 정상 종료 | J3에서 `deed_judged`가 이미 first value; 무저장 닫힘은 실패가 아니다 | on-instrument 자동; 손기록 불필요 |
| 4 | 소리 내어 읽거나 옆 사람에게 보여준다 | 수동 감탄 | 결과를 공유·감상하지만 개인 맥락으로 끌어들이지 않는다 | **손기록**: "보여주거나 읽었나요?" Y/N |
| 5 | 판정 결과를 자기 말로 다시 설명한다 | 자기화 — 언어화 | 결과를 해석해 자기 관점으로 재서술; 가장 깊은 통합 신호 | **손기록**: "본인 말로 다시 말씀해 주셨나요?" Y/N + 한 줄 메모 |
| 6 | 화면에 머물지만 아무것도 안 한다 (3초↑) | 수동 감탄 후보 | 인상을 받았지만 다음 행동 없음; 또는 다음 단계를 모름(B-LOST 후보) | **손기록**: "머뭇거렸나요?" Y/N; 만약 Y → "어디서 막혔나요?" |
| 7 | 저장 상한(`deed_save_capped`) 또는 오류 | 마찰·가용성 | 저장하려 했지만 막힘; value/upgrade demand가 아니라 가용성/마찰 신호 | on-instrument 자동; **approval-needed**: 상한 정책 변경/설명 카피 추가 |

## 수기 판독 칸 (first-user 관찰용)

아래는 first-user baseline 및 design-user ask script와 연결되는 손기록 칸이다.
신규 이벤트/속성은 없다. 모두 관찰자 메모로만 사용한다.

### 칸 A: 결과 직후 첫 행동 (필수)
- [ ] 저장 (on-instrument)
- [ ] 재시도/재작성 (on-instrument)
- [ ] 자기 말 설명 (손기록)
- [ ] 보여주기/소리 내어 읽기 (손기록)
- [ ] 머뭇거림 후 아무것도 안 함 (손기록)
- [ ] 무저장 닫힘 (on-instrument)
- [ ] 상한/오류 (on-instrument)

### 칸 B: 자기화 깊이 (자기화 행동 있을 때만)
- "결과를 본인 말로 한 줄로 설명해 주세요." → 원문 그대로 기록
- [ ] 판정 언어 그대로 반복 | [ ] 자기 경험으로 재해석 | [ ] 이견 표현

### 칸 C: 머뭇거림 원인 분류 (머뭇거림 있을 때만)
- [ ] 다음 버튼/경로를 못 찾음 (B-LOST → 입력 보조 범퍼 후보)
- [ ] 결과 기대와 달라서 멈춤 (B-MISMATCH → 제품 약속 문제, 넛지 아님)
- [ ] J3 정상 감상 후 종료 (정상 → 아무 개입 불필요)

### 칸 D: 재방문 의향 (세션 종료 직후, 1문항)
- "오늘 판정 결과, 나중에 다시 볼 것 같나요?" Y / N / 모르겠다
- 이것은 관찰 재료일 뿐이다. D7 재방문 KPI 합산 금지.

### 칸 E: 판정 주체 인식 (J3 선택)
- "방금 판정을 내린 건 AI인가요, 본인인가요, 둘 다인가요?"
- Decision-Delegation Risk Rides The Verb(m45) 작업용 관찰 재료. 결론 아님.

## 분류 요약

| 분류 | 신호 | 행동 가이드 |
|------|------|------------|
| **자기화** | 저장·재작성·자기 말 설명 | 현재 제품 본체 정상 작동; 반복 패턴 관찰 |
| **정상 종료** (J3) | `deed_judged` 후 무저장 닫힘 | 성공; 저장 넛지 절대 금지 |
| **수동 감탄** | 보여주기·머뭇거림·무행동 | B-LOST면 범퍼 후보; B-MISMATCH면 제품 약속 재검토; 아무것도 금지 |
| **마찰·가용성** | `deed_save_capped`·오류·지연 | 가용성 분리; 승인 없이 정책/카피 변경 금지 |

## 계승한 기준 (from MARKETING_LEARNINGS.md)

- **Post-Response Flow Reveals Value, Not The Result Event** (m44): 결과 직후 30초 수기 관찰 프레임; 도착점(J3) vs 통과점(J1/J2/J4) 구분
- **First Value Mapping** (m06/m07/m09/m10): J3 = `deed_judged`, 무저장 종료 = J3 정상
- **Session Value Is Read By Job** (m42): 행동 수가 아니라 잡별 first value 도달로 읽음; 짧은 J3 세션은 성공
- **Nudges Are Event-Triggered, And Show-Nothing Is The Default** (m40): B-LOST 분류가 범퍼 후보의 전제 조건
- **First-User Learning Loop** (m47): invite→pre→post 3문항+자기 말 기록 루프에 이 판독표 칸 A-E 연결

## 이번에 새로 배운 것

- "수동 감탄"(Passive Admiration Trap)은 기존 on-instrument 신호(`deed_saved`, `deed_rerolled`, `deed_save_capped`, exit)만으로는 포착되지 않는다. 화면에 머물며 아무것도 안 하거나 옆 사람에게 보여주는 행동은 손기록이 유일한 관찰 수단이다.
- J3 결과 직후 머뭇거림은 B-LOST / B-MISMATCH / 감상 후 정상 종료 세 갈래로 반드시 분기해야 한다. "수동 감탄 = 문제"로 단정하면 B-MISMATCH(제품 약속 문제)를 범퍼로 가리는 오류를 범한다.

## 다음 Marketer에게 넘길 규칙

- 수동 감탄 분류는 on-instrument 신호가 없다. 손기록 칸 A~E로만 관찰한다.
- 칸 B(자기 말 설명)는 자기화 깊이의 가장 유의미한 지표다. 원문 그대로 기록한다.
- 수동 감탄이 다수라도 즉시 넛지 후보로 전환하지 않는다. 칸 C(원인 분류)가 선행이다.
- 칸 E(판정 주체 인식)는 m45/m38 후속 작업의 관찰 재료이지 개입 근거가 아니다.
- J3 무저장 종료를 수동 감탄으로 오분류하지 않는다. 칸 A에서 닫힘 = on-instrument 자동, 손기록 불필요.
