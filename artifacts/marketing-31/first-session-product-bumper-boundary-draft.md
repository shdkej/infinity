# Virtue 첫 세션 제품 본체/범퍼 경계표

> prelaunch 내부 문서. 공개 카피·코드·배포 변경 0.

이 문서는 Virtue 첫 세션의 각 표면을 **제품 본체(product core)**와 **범퍼(bumper)**로 분리한다.
PLG(Product-Led Growth) 온보딩 원칙: 제품이 첫 가치를 만들고, 범퍼는 이탈 지점만 보조한다.
투어·가이드·모달 워크플로우는 본체도 범퍼도 아니다 — 사용자가 투어를 완료해도 첫 가치에 닿지 않을 수 있다.

---

## §1 정의

| 용어 | 정의 | Virtue 예시 |
|------|------|------------|
| **제품 본체** | 첫 가치를 만드는 핵심 동작 또는 화면 요소. 제품이 존재하는 이유 자체 | `/add` 결과 카드(AI 판정), 저장된 덕행 카드 |
| **범퍼** | 특정 이탈 위험 지점에서만 작동하는 가이드레일. 본체로 가는 길을 막지 않는 최소 개입 | 홈 빈 상태 CTA, 결과 카드 저장 버튼 강조 |
| **투어/가이드** | 제품과 별개로 사용 방법을 설명하는 요소. prelaunch에서 본체·범퍼 판단 보류 | 온보딩 모달, 툴팁, 스텝 인디케이터 |

핵심 원칙:
- 범퍼가 없어 이탈이 발생했다면 → 범퍼를 추가하면 된다
- 본체로 이어지는 경로 자체가 끊겼다면 → 이것은 범퍼 문제가 아니라 **본체 연결 실패**다
- 투어를 마쳐도 본체(첫 가치)에 닿지 않으면 → 투어는 해결책이 아니다

| **J4 회고형** | `deed_saved`:183 | 범퍼(CTA) + 본체(회고 기반 목록) | 본체(기록 동작) | 통과점 | 본체 완료 + 회고 연결 신호 | S4 도달·`deed_saved` + 회고 경로 인지 | S4 도달했으나 회고 payoff 미인지(홈 복귀 즉시 이탈) |

## §3 표면별 본체/범퍼 상세

### S1 `/` 홈 화면

| 화면 요소 | 역할 분류 | 잡별 메모 |
|----------|----------|-----------|
| 덕행 추가 CTA | 범퍼 (이탈 방지, 첫 행동 유도) | J1~J4 공통 |
| 빈 상태 문구 | 범퍼 | 공백 = 이 범퍼 부재 |
| 최근 덕행 목록 | 본체 (J2 누적 payoff, J4 회고 시작점) | J2/J4에게는 본체, J1/J3에게는 컨텍스트 |
| AI 판정 관련 신호 | **현재 부재** | J3에게 필요한 본체 연결 신호. prelaunch proposal-only |
| level_up 상태 표시 | 본체 (J2 누적 payoff 일부) | 조건부 노출(`level_up_viewed`:199) |

> **J3 핵심 갭**: `/` 화면에서 "AI가 덕행을 판정해준다"는 신호가 없으면, J3 사용자는 `/add` 진입 이유를 모르고 이탈한다.
> 이것은 **범퍼 누락이 아니라 본체(AI 가치)가 앞 화면에 연결되지 않은 본체 연결 실패**다.
> three-screen §3-A 앞단 끊김(J3 앞단 끊김)과 동일한 갭.

## §4 막힘 vs 정상 종료 판독 기준

이 표는 첫 세션에서 관찰한 행동이 "제품이 작동했는가(정상 종료)" vs "이탈이었는가(막힘)"를 본체/범퍼 분리 관점으로 판독한다.

| 관찰 행동 | 판독 | 판독 근거 |
|----------|------|----------|
| `deed_judged` 후 `deed_saved` 없이 종료 + **J3 잡** | **J3 정상 종료** | J3 first value = `deed_judged`. 저장은 선택 |
| `deed_judged` 후 `deed_saved` 없이 종료 + **J1/J2/J4 잡** | **저장 전 이탈 후보** | first value = `deed_saved`. 저장 범퍼 작동 미확인 |
| `/add` 미진입 + **J3 잡** | **본체 연결 실패** | S1에서 AI 신호 부재 → J3 본체(결과 카드)로 이어지지 않음 |
| `deed_save_capped`:167 발화 후 종료 | **가용성 마찰** | 30덕 상한 early-return. `deed_saved` 미발화. value 도달 판단 불가 |
| `deed_rerolled` ×3 후 `deed_saved` 없이 종료 | **판단 유보** | 재시도 상한. J3 탐색 종료일 수도, 불만족 이탈일 수도. 손기록 필요 |
| S4 도달 + `deed_saved` 발화 후 즉시 종료 | **J1/J4 정상 종료** | first value 충족. J2 누적 payoff는 별도 판독 |
| S4 도달 + `level_up_viewed`:199 발화 | **J2 정상 종료 + payoff 확인** | 누적 신호까지 도달 |

### 승격 후보 (MARKETING_LEARNINGS.md)

- **"Bumpers Are Not Tours"**: 투어/가이드는 본체도 범퍼도 아니며, 사용자가 완료해도 첫 가치에 닿지 않을 수 있다. prelaunch에서 범퍼 부재 진단은 "어디서 이탈했나"가 아니라 "본체로 이어지는 경로가 끊겼나"로 읽어야 한다.
- **"J3 Core Disconnection vs. Bumper Gap"**: J3 /add 미진입은 S1 범퍼 부재가 아니라 S1에서 AI 판정이라는 본체가 보이지 않는 것이다. 이 둘을 혼동하면 투어/가이드를 추가해서 해결하려는 오진으로 이어진다.
