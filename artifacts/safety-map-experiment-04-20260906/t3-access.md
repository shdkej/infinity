# T3.1 공개접근·ToS·robots 판정

- 판정 시각: 2026-09-06T10:12:00Z
- 범위: T2.1의 Reddit 후보 C-01~C-03. 게시물 본문·댓글·작성자·이미지는 수집하지 않았습니다.
- 목적: 후보를 표시하거나 집계하지 않고, 자동화된 접근·후속 검토 가능성만 판정합니다.

## 관찰

| 항목 | 관찰 | 판정 |
| --- | --- | --- |
| `https://www.reddit.com/robots.txt` | HTTP 200. `User-agent: *`에 `Disallow: /`를 선언하고 Public Content Policy를 안내합니다. | 자동 수집 금지 |
| Reddit User Agreement | HTTP 200. 이용약관 표면은 공개되지만, robots 및 Public Content Policy 경계를 우선 적용해야 합니다. | 약관만으로 후보 입수 허용 아님 |
| C-01~C-03 원문 URL | 각 HTTP 403. 자동 검토 경로에서 원문 접근이 허용되지 않았습니다. | 후속 자동 입수·본문 보존·집계 금지 |

## 결론

T2.1의 Reddit 후보는 **공개 검색 후보 메타데이터**로만 보존하며, 이 실행 환경에서 자동 접근·본문 수집·신호 표시·핀 생성·지역 집계를 하지 않습니다. robots와 403이 해소되지 않는 한 `no-render`를 유지합니다.

## 다음 Red 검토 대상

- robots `Disallow: /` 및 HTTP 403을 ‘표시 불가’ 근거로 충분히 해석했는지
- 약관 공개 여부를 콘텐츠 자동 수집 허가로 오해하지 않았는지
- 후보 URL·날짜·지역 단위 외 개인정보/본문을 저장하지 않았는지
