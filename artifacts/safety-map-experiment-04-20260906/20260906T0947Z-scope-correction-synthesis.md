# 4차 범위 정정 역할 수렴

## Planner

T2를 공식 T1과 독립시키고, T2~T17의 16개 30분 미니 사이클을 `조사/구현 → Red → 마감확인`으로 고정했습니다.

## Developer

표시 전 데이터 계약은 원문 URL·플랫폼·게시/수집일·지역 단위·자동필터·사람 검토·집계 자격을 요구합니다. 단일 게시물·PII·날짜/공간 단위/검토 누락은 no-render입니다.

## Marketer

화면 언어는 ‘사용자 경험 기반 주의 신호’로 제한하며, 안전 보장·범죄 확정·위험 지역 낙인을 피하고 출처/날짜/신뢰도/근거 없음을 함께 표기합니다.

## Operator

공개 접근·이용약관 내 자료만 사용하고, 작성자·핸들·정확한 주소·원문 본문을 저장하지 않습니다. 자동필터→사람 검토→최근 복수 독립 경험의 지역 단위 집계만 허용합니다.

## 수렴 결정

T2.1은 후보 메타데이터 탐색만 시작합니다. 데이터 표시·개별 핀·집계는 T3~T10의 적격성·계약·Red 단계를 통과하기 전까지 금지합니다.
