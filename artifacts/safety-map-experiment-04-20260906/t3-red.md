# T3.2 Red — 입수성 판정

- 검토 시각: 2026-09-06T10:21:30Z
- 대상: T3.1 접근 판정 및 T2.1 후보 메타데이터 보존 경계
- 판정: **PASS — no-render 결정에 한함**

## 확인

1. `robots.txt`는 `User-agent: *`에 `Disallow: /`를 선언하며, 후보 원문 3건은 이 실행 환경에서 HTTP 403을 반환했습니다. 이는 자동 원문 접근·본문 보존·자동 집계·핀/신호 렌더링을 중단할 운영 근거로 충분합니다.
2. 이용약관 표면이 공개라는 사실을 콘텐츠 자동 수집 허가로 해석하지 않았습니다.
3. 보존 범위는 후보 URL·게시일·지역 단위뿐이며, 본문·댓글·작성자·이미지·정확 주소를 보존하지 않았습니다.

## 경계 보완

- robots는 법적 ToS 허가 여부 자체가 아니라 **자동화 경계의 운영 근거**입니다.
- HTTP 403은 이 실행 환경에서의 접근 불가 관찰이며, 원문이 일반 공개라는 결론이 아닙니다.
- T2.1의 ‘공개 검색 결과로 접근 확인’은 **검색 결과에서 후보 메타데이터를 발견했다는 뜻**으로만 해석합니다. 원문 입수 허용을 뜻하지 않습니다.
- 후보 URL·게시일·지역 단위 자체도 신호 또는 집계 근거가 아닙니다. 공개 접근·약관·사람 검토·복수성·최근성 검증 전까지 계속 `no-render`입니다.
