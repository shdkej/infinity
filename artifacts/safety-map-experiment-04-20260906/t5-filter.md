# T5.1 자동필터 계약 — PII·위험 표현·중복

작성 시각: 2026-09-06T11:12:00Z  
적용 범위: 공개 접근·이용 조건이 별도로 통과한 후보의 **메타데이터 사전검사**. 현재 Reddit 후보는 T3에서 자동 접근 불가로 판정되어 이 필터의 입력 대상이 아니다.

## 입력·출력 경계

- 입력은 T4 계약의 최소 provenance(`source_url`, `published_at_or_unknown`, `collected_at`, `area_unit`)만 허용한다.
- 원문, 댓글, 작성자·핸들·프로필, 이미지, 전화·이메일, 정확 주소·좌표·숙소명, 개인 이동 경로는 입력·로그·산출물에 보존하지 않는다.
- 출력은 `reject` 또는 `hold_for_human_review`뿐이다. `approve_for_render` 출력은 존재하지 않는다.

## 자동 차단 규칙

| 검사 | 조건 | 결과 |
|---|---|---|
| PII | 허용 목록 밖의 식별자·연락처·정확 위치가 포함되거나 필요함 | `reject` |
| 위험 표현 | 안전 보장, 범죄 사실 확정, 위험 점수·예측을 요구하는 표현 | `reject` |
| 메타데이터 | URL·수집일·지역 단위 중 하나가 없음 | `reject` |
| 중복 | 정규화 URL 또는 동일 지역 단위·같은 게시일의 동일 플랫폼 후보 | `hold_for_human_review` |
| 나머지 | 위 차단이 없더라도 | `hold_for_human_review` |

## 중복·표현 원칙

- 정규화 URL은 추적 파라미터를 제거한 동일 원문 식별에만 사용하며, 본문 유사도 분석을 하지 않는다.
- 지역 단위·게시일·플랫폼이 같은 후보는 자동 병합하거나 표본 수로 세지 않는다. 사람 검토에서 독립성·최근성을 확인할 때까지 보류한다.
- 이 필터는 접근 허가·사람 검토·최근 복수 독립 경험·지역 단위 집계·독립 Red를 대체하지 않는다. 따라서 현재 및 통과 후에도 기본값은 **근거 없음/no-render**다.
