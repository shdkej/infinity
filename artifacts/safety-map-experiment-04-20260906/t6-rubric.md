# T6.1 사람 검토 rubric — 위험 회피 보조 근거

작성 시각: 2026-09-06T11:52:00Z  
적용 범위: T3 접근성 판정과 T4 provenance 계약, T5 자동필터를 통과한 **메타데이터 후보**. 이 rubric은 원문 자동 수집·본문 보존·후보 신호 표시를 허용하지 않는다.

## 검토 전제

- 검토자는 공개 접근·이용 조건이 확인된 자료만 다룬다. 자동 접근 불가 또는 이용 조건 미확인 자료는 `hold_no_render`다.
- 보존 가능한 입력은 `source_url`, `platform`, `published_at_or_unknown`, `collected_at`, `area_unit`, 접근/이용 조건 판정뿐이다.
- 작성자·댓글·사진·정확 주소·좌표·개인 이동·원문 인용은 검토 기록에 저장하지 않는다.

## 판정표

| 확인 항목 | 통과 기준 | 미달 시 결과 |
|---|---|---|
| 접근·이용 조건 | 공개 접근이며 자동/수동 검토가 해당 조건 안에 있음 | `hold_no_render` |
| 최소 provenance | URL·게시일(또는 unknown)·수집일·지역 단위가 모두 있음 | `reject` |
| 개인정보·정확 위치 | 개인 식별자, 연락처, 숙소명, 정확 주소·좌표가 불필요하고 보존되지 않음 | `reject` |
| 위험 표현 | 안전 보장·범죄 사실 확정·위험 점수/예측을 요구하거나 암시하지 않음 | `reject` |
| 지역 단위 | 도시 전체가 아닌 검증 가능한 넓은 지역 단위이며 개인 장소를 가리키지 않음 | `hold_no_render` |
| 최근성·독립성 | 이후 T7에서 확인할 최근 복수 독립 경험의 후보가 될 수 있음 | `hold_no_render` |

## 출력과 진입 조건

- 허용 출력은 `reject`와 `hold_no_render`뿐이다. 이 단계에는 `approve_for_render`, 핀, 점수, 안전 경로 출력이 없다.
- `hold_no_render`는 근거가 없거나 후속 확인이 필요한 상태다. 표본 수에 산입하거나 지역 신호로 변환하지 않는다.
- T7의 최근성·독립성, T10의 집계·상충 규칙, 독립 Red 검증을 모두 통과하기 전에는 표시 상태가 계속 **근거 없음/no-render**다.
