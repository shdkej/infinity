# 30–60초 미니멀 큐레이션 숏츠 플레이북

## 목적과 범위

이 플레이북은 후보를 게시·추천하는 권한이 아니라, **한 장면에서 무엇을 남기고 무엇을 뺐는지**를 검토할 수 있는 내부 대본·안전 템플릿입니다. 한 편은 한 대상과 한 판단만 다룹니다. 실제 게시, 외부 연락, 구매·제휴·협찬 실행은 별도 승인 경계를 따릅니다.

## 한 편의 구조

| 구간 | 내용 | 금지 |
|---|---|---|
| 0–3초 | 장면과 선택 압력: 실제 불편·제약을 한 문장으로 제시 | 희소성·FOMO·“필수/최고” 훅 |
| 3–12초 | 대상과 출처·관계 상태·공개 범위를 짧게 고지 | 미확인 관계를 독립 추천처럼 제시 |
| 12–30초 | 관찰 가능한 사실 1–2개와 채택 근거 | 해석을 사실처럼 말하기, 제3자 자산 재게시 |
| 30–42초 | 트레이드오프 1개와 제외한 대안 1개 | 단일 승자 선언, 대규모 테스트 가장 |
| 42–55초 | 시청자 조건: “___라면 ___만 확인” | 저장·구매·할인 중심 CTA |
| 55–60초 (필요 시) | 출처·관계·권리·한계와 다음 검증 행동 | 정보가 넘칠 때 소재·주장을 더 추가 |

30초 안에 관계·출처·안전 고지를 정직하게 넣을 수 없으면 45–60초로 늘립니다. 늘어난 시간은 고지와 한계에만 쓰며, 새 소재나 주장을 추가하지 않습니다.

### 30초 압축 경로

30초판은 아래 순서를 고정합니다. 대안·제외 이유의 상세 비교는 45–60초판으로 넘기며, 이 경로에서도 시청자 적용 조건을 생략하지 않습니다.

| 구간 | 내용 |
|---|---|
| 0–3초 | 선택 압력 한 문장 |
| 3–10초 | 대상과 관계·출처 상태를 화면/음성으로 고지 |
| 10–20초 | 관찰 가능한 사실 1개와 조건부 결정 |
| 20–26초 | 시청자 적용 조건 1개 |
| 26–30초 | 한계와 출처 확인 경로 |

## `ShortReviewCard` 빈 템플릿

```text
id:
subject_type: person | space | object
one_sentence_decision:
scene:
selection_pressure:
observation_fact:
interpretation:
evidence: claim_id / source_url / publisher / opened_at / locator / scope_limit
alternative_or_exclusion:
viewer_condition:
relationship_status: independent | provided | affiliate | collaboration | unknown
rights_status: self_created | licensed | third_party_not_used | unknown
privacy_safety_status:
publish_decision: adopt | hold | exclude
hold_reason_or_review_trigger:
30_60s_beats:
```

`claim_id`가 없는 사실, `unknown`인 관계·권리·동의·안전, 또는 대안/제외 이유가 없는 카드는 `adopt`할 수 없습니다.

## 대상별 통과 체크

| 대상 | `adopt` 필수 조건 | 즉시 `hold/exclude` |
|---|---|---|
| 사람 | 공적 기록 또는 당사자 공개 동의, 식별·관계 공개 범위 확정, 촬영/자산 권리 확인 | 미동의 인물·미성년자·사적 대화·주소 단서·의도 추론 |
| 공간 | 공개 접근 가능, 안전·동선 검토 완료, 위치 노출 수준 확정, 자산 권리 확인 | 사적 주거·소규모 민감 장소·출입 제한 장소·실시간/정확 위치·보안 동선 |
| 물건 | 선택 근거·대안·불일치 조건, 공식 사실의 기준일, 제공/제휴/구매 관계 확인 | ‘최고/필수/가성비’ 단정, 구매 링크 중심 구성, 검증하지 않은 성능 주장 |

## 출처·자산·관계 체크리스트

- [ ] 핵심 사실마다 `URL / 발행 주체 / 열람일 / locator / 사실 또는 해석 / 범위 한계`를 남겼다.
- [ ] 화면 자산은 `self_created` 또는 명시적 `licensed`뿐이다. 제3자 사진·영상·도면·지도·스크린샷·음원은 출처 표기만으로 사용하지 않는다.
- [ ] 제공·협업·제휴·소유·고용·지인 관계를 카드와 공개 표면에 같은 의미로 표시했다.
- [ ] 관계·권리·안전·동의 중 하나라도 `unknown`이면 추천·촬영·공개를 진행하지 않고 `hold`로 둔다.
- [ ] 오류·권리 변경·수정/삭제 요청·관계 변경·안전 정보 변경이 있으면 카드를 `hold`로 되돌리고 변경 이유를 남긴다.

## 사례에서 가져오지 않는 것

- Atlas Obscura: 정확한 주소·제3자 사진 재게시·희소성 훅
- Wirecutter: 대규모 자체 테스트·단일 승자·구매 전환 모델
- 29CM: 상품·혜택·리뷰 이벤트를 결합한 커머스 표면

## 게시 전 판정

```text
모든 핵심 claim_id가 출처와 연결됨?
  아니오 → hold
관계·권리·동의·위치 안전 상태가 모두 확인됨?
  아니오 → hold 또는 exclude
한 장면·한 선택 압력·한 시청자 조건인가?
  아니오 → 원고 분리
공개 실행에 대한 사용자 승인이 있는가?
  아니오 → 내부 초안으로만 보관
```
