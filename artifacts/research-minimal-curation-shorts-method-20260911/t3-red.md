# T3.2 Red — 숏츠 템플릿 가독성·안전·미니멀 적합성 검증

## 초기 판정 — FAIL

1. 30초 구조에서 `viewer_condition`이 42–55초 구간에만 배치돼, 별도 30초 지침 및 선정 프레임과 충돌했다.
2. 활성 상태인 T3.2의 타임라인이 완료/실제를 `미시작 / 0분`으로 표시해 진행 상태를 오해하게 했다.

## 최소 보완

- 30초 압축 경로를 `선택 압력 → 관계·출처 → 관찰+결정 → 시청자 조건 → 한계·출처`로 명시했다. 상세 대안 비교는 45–60초에만 허용한다.
- 활성 태스크의 완료/실제를 `진행 중 / 경과 중(완료 시 확정)`으로 정정했다.

## 재검증 기준

- 한 편은 한 대상·한 판단만 다루며 시청자 조건을 생략하지 않는다.
- 관계·권리·동의·위치 안전 중 하나라도 `unknown`이면 `hold`다.
- 제3자 자산 재게시, FOMO·커머스 전환, 단일 승자·미니멀의 색/브랜드 환원은 허용하지 않는다.

## 최종 재검증 — PASS

- 30초 압축 경로가 `0–3초 압력 → 3–10초 관계·출처 → 10–20초 관찰+결정 → 20–26초 시청자 조건 → 26–30초 한계·출처`로 정합한다.
- 타임라인의 완료·진행·대기 집계와 T3.2 상태가 본문과 일치한다.
- `unknown → hold`, 제3자 자산·FOMO·커머스 전환·스타일식 미니멀 환원 금지가 유지된다.
