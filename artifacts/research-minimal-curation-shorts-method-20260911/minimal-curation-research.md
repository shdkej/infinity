# 미니멀 사람·공간·물건 큐레이션 숏츠 — 최종 리서치 브리프

## 결론

이 포맷의 단위는 “좋아 보이는 대상 소개”가 아니라 **한 선택 압력 아래 무엇을 채택하고 무엇을 뺐는지의 조건부 기록**이다. 사람·공간·물건 모두 `선택 압력 → 확인 가능한 관찰 → 대가/대안 → 시청자 조건 → 출처·관계·권리·안전` 순서를 따른다. 어느 하나라도 확인되지 않으면 공개하지 않고 `hold` 또는 `exclude`로 끝낸다.

이 결론은 플랫폼 성과·구매 전환·추천 정확성을 보장하지 않는다. 실제 후보 선정, 촬영, 외부 연락, 자산 사용, 공개 게시도 이 리서치의 범위가 아니다.

## 확정 방법론

1. **선정:** `time / route / luggage / space / cost / maintenance / relationship` 중 한 선택 압력과 감수한 대가를 한 장면으로 설명한다.
2. **근거:** 핵심 사실은 A급 출처, 또는 독립 B급 두 건으로 확인한다. C급은 발견용, D급은 제외다.
3. **원자성:** 한 편에는 대상 하나·선택 하나·핵심 근거 하나·시청자 조건 하나만 둔다.
4. **표시:** 제공·협업·제휴·소유·고용·지인 관계와 자산 출처를 카드와 공개 표면에 같은 뜻으로 표시한다.
5. **보류:** 관계·권리·동의·위치 안전·근거 중 하나가 `unknown`이면 `hold`다. 사적 위치, 무단 제3자 자산, FOMO·단일 승자·커머스 전환이 핵심이면 `exclude`다.

## 30–60초 템플릿

- **30초:** 선택 압력(0–3) → 관계/출처 고지(3–10) → 관찰+조건부 결정(10–20) → 시청자 조건(20–26) → 한계·출처 경로(26–30).
- **45–60초:** 위 구조에 대안/제외 이유와 제한을 더한다. 시간을 늘려 새 주장·새 소재를 넣지 않는다.
- 미니멀은 무채색·브랜드·소품 수가 아니라, **검증된 선택 압력과 제거한 대가**로만 설명한다.

## 첫 3편 내부 실험 설계

아래는 게시물이 아니라 플레이북이 실제로 `adopt / hold / exclude` 결정을 만드는지 검증하는 내부 카드다. 세 카드 모두 현재 공개 실행은 `hold`다.

| 실험 | 대상군·입력 경계 | 검증 질문 | 필요한 증거 | 통과 기준 | 현재 상태 |
|---|---|---|---|---|---|
| E1 | **물건** — 사용자가 소유하고 직접 촬영할 수 있는 일상 물건 1개 | 반복 사용이 관리·비용·공간 중 하나를 실제로 줄이는가, 그리고 어떤 사람에게는 맞지 않는가? | 사용 장면 기록, 공식 정보 기준일, 대안 1개와 제외 이유, 소유/제공 관계 | 권리=`self_created`, 관계 확인, 핵심 사실 출처, 불일치 조건·대안 완비 | `hold`: 대상·증거 미입력 |
| E2 | **공간** — 공개 접근 가능 여부와 안전·동선 검토가 가능한 공간 1곳 | 머무름을 바꾼 시간·동선·비용·접근성 선택이 있는가? | 공식 접근 정보, 안전/동선 검토, 위치 공개 수준, 직접 제작 자산 | 공개 접근+안전/동선 확인, 정확 위치·실시간 동선 비노출, 권리 확인 | `hold`: 공간·안전 검토 미입력 |
| E3 | **사람** — 공적 기록으로만 다루거나 명시 동의를 받은 인물 1명 | 공적 기록 안에서 반복 선택과 대가를 사실/해석 분리로 말할 수 있는가? | 공적 기록 또는 동의, 관계 공개 범위, 자산 권리, 의도 추론 금지 확인 | `public_record_verified` 또는 `consent_verified`, 식별·관계·권리 통과, 사생활/의도 추론 없음 | `hold`: 대상·동의/공적 기록 미입력 |

### 실험 판정 순서

1. 카드의 핵심 필드를 채운다. 비어 있으면 즉시 `hold`다.
2. 30초 원고를 작성해 시청자 조건과 한계·출처 고지가 실제로 들어가는지 확인한다.
3. 불가하면 45–60초 원고로 확장하되, 새 주장 대신 대안·제외 이유만 추가한다.
4. 권리·관계·사람 동의·공간 안전 중 하나가 불명확하면 원고를 삭제/보류한다. 확인을 위한 외부 연락은 사용자 승인 없이는 하지 않는다.

## 네 역할 수렴

| 역할 | 채택한 판단 |
|---|---|
| Planner | 미감이 아니라 선택 압력·트레이드오프·전이 가능한 조건을 기준으로 삼는다. |
| Developer | 후보 카드의 사실·추론·출처·상태 필드를 분리해 검증 가능한 결정을 남긴다. |
| Marketer | 과시·브랜드 순위·링크 모음 대신 선택 이유와 맞지 않는 조건을 함께 보인다. |
| Operator | 권리·관계·프라이버시·위치 안전 게이트는 출처 표기가 아닌 공개 보류 조건이다. |

## 승인 경계와 다음 행동

- **승인 없이 하지 않음:** 공개 게시, SNS/DM/뉴스레터 발송, 제3자 자산 사용·재배포, 인물·사적 장소 촬영/공개, 외부 연락, 구매·협찬·제휴.
- **다음 내부 행동:** 사용자가 제공하거나 직접 확인 가능한 후보 하나를 E1–E3 중 하나의 카드에만 입력하고 `hold` 게이트를 재판정한다.
