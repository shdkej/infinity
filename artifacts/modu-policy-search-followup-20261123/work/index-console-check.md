# 검색엔진 콘솔 확인 상태

2026-11-23T12:59:17+00:00에 현재 세션에서 확인한 접근 상태를 기록했다.

- Google Search Console에서 현재 로그인 계정은 운영 사이트의 URL 접두어 속성과 상위 도메인 속성 모두에 접근할 수 없었다. 소유권 확인 화면에서 해당 URL용 확인 파일이 발급됐다. 새 소유자 지정은 사용자 판단을 기다린다.
- 네이버 서치어드바이저는 로그인 화면으로 이동했다. 로그인할 수 있도록 ego 브라우저 공간 14를 사용자에게 인계했다.
- 두 엔진 모두 실제 색인 여부와 엔진 측 사이트맵 처리 결과는 미확인이다. 공개 사이트맵이 열리는 것과 엔진이 사이트맵을 처리했다는 것은 서로 다른 상태다.
- 질문형 정책 페이지 3개는 이미 공개되었고 각 운영 URL과 공식 출처를 검증했다. [운영 검증](release-check.md)

## 재개 조건

Google은 기존 속성 접근 권한이 있는 계정으로 전환하거나 현재 계정을 신규 소유자로 등록할지 확인한다. 네이버는 전달한 ego 브라우저 공간 14에서 사용자 로그인을 마친 뒤 재개한다. 권한이 열리는 엔진부터 사이트맵 처리 상태와 페이지별 색인 상태를 조회한다.

## 사용자 인계 후 재개

2026-11-23T13:03:31+00:00 사용자가 네이버 로그인 세션을 인계하고 구글 권한 설정 진행을 위임하여 동일 작업을 재개했다. 계정 정보나 확인용 값은 기록하지 않는다. 엔진별 실제 처리 결과는 조회 후 추가한다.

## 11월 23일 콘솔 조회 결과

Google Search Console에서 HTML 태그로 URL 접두어 속성의 소유권 확인을 마쳤다. 제출한 사이트맵은 성공으로 표시됐고 발견 URL은 14개, 마지막 읽은 날짜는 11월 23일이었다. 실적 데이터는 처리 중이었다.

| URL 검사 대상 | 구글 색인 상태 |
|---|---|
| [홈](https://policy.minimalcollector.com/) | 발견됨 - 현재 색인이 생성되지 않음 |
| [아동수당](https://policy.minimalcollector.com/policies/moon.html) | 발견됨 - 현재 색인이 생성되지 않음 |
| [청년기본소득](https://policy.minimalcollector.com/policies/lee.html) | 발견됨 - 현재 색인이 생성되지 않음 |
| [기후동행카드](https://policy.minimalcollector.com/policies/oh.html) | 발견됨 - 현재 색인이 생성되지 않음 |

네이버 로그인 후 계정에 등록된 사이트가 0개임을 확인하고 대표 주소 등록을 진행했다. 운영 홈페이지에 네이버와 구글 소유확인용 메타 태그가 존재하고 [배포 실행](https://github.com/shdkej/space/actions/runs/45180522054)이 성공했음을 별도로 확인했다. Cloudflare DNS 변경은 없었다. 네이버에서 소유확인을 누른 뒤 별도 보안문자가 표시되어 공간 14를 사용자에게 인계했다. 네이버 소유확인 완료, 사이트맵 제출, 색인 상태는 아직 확인되지 않았다.

사용자가 인계받은 ego 공간 14에서 네이버 소유확인 보안문자(CAPTCHA)를 완료하면 소유확인 결과를 다시 조회하고 사이트맵과 색인 상태를 점검한다.

## 11월 23일 네이버 소유확인 및 제출 결과

사용자 보안문자 입력 후 사이트 등록 목록과 관리 보고서에서 소유확인 완료를 확인했다. 사이트맵 제출 목록에는 sitemap.xml이 2026년 11월 23일 22:14:15 KST에 등록됐다.

홈과 아동수당·청년기본소득·기후동행카드 URL 검사 결과는 각각 HTTP 200 OK였다. 네 URL 모두 robots.txt 수집 가능, 로봇 메타 수집 및 노출 허용이었다. 홈의 첫 검사에서 표시됐던 robots.txt 미존재 메시지는 재조회 시 정상으로 바뀌었다. 신규 사이트의 수집·진단·노출/클릭 보고서에는 아직 데이터가 없다. 위 결과로 실제 검색 색인 등재를 확인할 수 없다.
