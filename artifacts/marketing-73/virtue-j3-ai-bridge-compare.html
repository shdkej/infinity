J3 첫 화면 AI 약속 브리지 비교안

홈 /에서 J3 AI 호기심형 진입 경로가 비어 있는 문제를 해결하기 위한 최소 배치 옵션 3안 비교. production/배포/tracking/public copy 변경 없음.

문제 맥락

현재 홈 약속 강도J1(기록형) 강함. J2(누적형) 중간. J3(AI 호기심형) 거의 없음. J4(회고형) 중간.
J3 진입 경로 공백중립 placeholder(뛰 했어요?)는 J1~J4를 구분 없이 부름. J3이 가장 약하게 불림 (marketing-32 First-Input Defaults 기준).
J3 first value 위치deed_judged — 결과 카드(AI 판정)가 제품 본체. 저장은 범퍼(선택). (marketing-31 Product Body vs Bumper 기준)
현재 empty state gapmarketing-70 감사에서 J3 seeded proof 없음 확인. safest next step = ghost/sample AI 결과 카드 비교안.
동사 프레임 위험버튼 AI 채점은 판결 프레임. 관점 프레임(AI가 본 오늘)으로 정렬 필요. (marketing-45 기준)

비교안 3개

A hero 영역 관점 문구 추가
위치: 홈 hero headline / subheadline 아래
예시: "기록하면 AI가 어떻게 읽었는지 보여드려요" (관점 프레임)
항목평가
J1/J4 훼손 위험중간 — hero가 "기록" 약속과 "AI 읽기" 약속으로 분열. J1/J4 포커스 약화 가능.
J3 기대 강화중간 — AI 약속 명시적이지만 hero 공간이 좋아 다른 메시지와 경쟁.
공개 전제없음 — proposal-only. 실제 카피 변경은 approval-needed.
구현 난이도낙음 (텍스트 한 줄 추가)
안전성중간 — 가장 큰 레버이지만 가장 큰 위험. 관찰 후 검토 권장.
B CTA 보조 힌트 추가 (가장 보수적 차선)
위치: primary CTA 버튼 옆 또는 아래 보조 설명 한 줄
예시 문구: "기록하면 AI가 읽어드려요" / "AI 관점으로 오늘 읽기"
항목평가
J1/J4 훼손 위험낙음 — primary CTA 버튼 자체를 바꾸지 않음. J1/J4 흐름 그대로 유지.
J3 기대 강화낙음~중간 — AI 약속을 전달하지만 보조적. 눈에 잘 안 띄일 가능성.
공개 전제없음 — proposal-only. 보조 문구 변경은 approval-needed.
구현 난이도낙음 (보조 텍스트 추가)
안전성가장 높음 — 가장 작은 footprint. prelaunch 무변경 원칙에 가장 맞음.
C 추천 빈 상태 ghost AI 결과 카드
위치: 홈 `최근 덕행` 빈 상태 영역 내 ghost/preview 표식 카드 1장
예시: "AI 판정 예시" 표식이 붙은 샘플 결과 카드. "기록하면 이런 AI 판정을 받아볼 수 있어요." 형태. (marketing-71 seeded proof 방식 계승)
항목평가
J1/J4 훼손 위험낙음 — 빈 상태 영역 내에만 배치. J1/J2 proof(카드 스택)와 병존 가능. ghost 표식으로 실제 데이터와 혼동 없음.
J3 기대 강화가장 높음 — AI 결과 화면을 직접 미리 보여줌. J3 사용자가 /add 진입 전 AI 결과 기대를 시각적으로 확인 가능.
공개 전제없음 — proposal-only. 구현은 approval-needed (code change).
구현 난이도중간 — ghost 카드 컴포넌트 추가 필요. marketing-71 seeded proof 비교안의 "누적 카드 스택"을 J3 결과 카드로 확장하는 방식.
안전성중간~높음 — J1/J4 훼손 최소 + J3 기대 강화 최대 조합. 구현 시 ghost 표식 명확해야 함.

추천안: Option C — 빈 상태 ghost AI 결과 카드
J1/J4 약속 훼손 위험이 가장 낙으면서 J3 기대 강화가 가장 강한 조합. marketing-70/71 seeded proof 방식을 J3 결과 카드로 확장하는 자연스러운 연결점. ghost/preview 표식을 명확히 하면 실제 데이터 혼동 없음. 구현은 code change이므로 approval-needed.

차선: Option B — CTA 보조 힌트
