## Positioning decision

The next candidate should not be positioned as "another question card." It should be positioned as a **specific room/use-case card kit** inside an already real but crowded conversation-card market.

Recommended next validation frame:

**AI / creator workshop facilitation cards**

Secondary angles to keep as sub-tests:

- product-observation / founder reflection cards
- team retrospective cards
- travel insight-to-content prompt cards

Do **not** route a user-facing listing approval yet. The next useful artifact is a sharper pre-approval packet only after the chosen use-case survives one more evidence pass: top competitor title/image/review-depth check when browser access is available, or a bounded OpenAPI title-language extension if browser access remains blocked.

## Why this frame leads

| candidate angle | keep / drop | reason |
|---|---|---|
| AI / creator workshop facilitation | **lead** | Best fit with the user's AI/workshop/content loop and avoids the generic "relationship card game" center of the category. `워크샵 카드` result language is cleaner even though exact SearchAd demand is thin, so it should borrow broad `질문 카드`/`대화 카드` demand while leading with a workshop-room purchase reason. |
| Product-observation / founder reflection | **sub-test** | Strong fit with Knowledge Lab / Infinity operating rhythm and can feel less generic than icebreaking. Needs clearer Naver language because raw keyword evidence is not yet present. |
| Team retrospective | **sub-test** | Real workshop room use case and commercially plausible, but may drift toward generic team-building/recreation unless the prompt system is specific. |
| Travel insight-to-content | **hold as content-native variant** | Fits the user's travel/content loop, but raw shopping evidence for travel question cards is too thin. Better as a deck module or content lead, not the first category hook. |
| Generic question / conversation / icebreaking cards | **drop as lead** | OpenAPI top-20 is saturated by couple/family/party-game language. This is demand evidence for the object shape, not proof of a differentiated purchase reason. |
| Insight cards | **drop as primary keyword** | Search results are noisy with tarot/oracle products; keep "insight" as internal value language, not the listing lead. |

## Next Marketer rule

When a commerce category is crowded and the object shape is generic, **lead with the purchase situation, not the object name**. Use broad keywords as bridges only after the use-case frame explains why this version exists.
