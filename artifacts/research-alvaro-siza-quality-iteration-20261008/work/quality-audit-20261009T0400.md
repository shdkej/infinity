## 주장 폐쇄 매트릭스

마감 전 과잉 확장을 멈추고 현재 근거의 확정 범위를 정리했다.

| 주장 | 현재 근거 | 판정 |
|---|---|---|
| Siza archive는 분산 보존·공유된다 | CCA·Serralves·Gulbenkian 공식 archive 안내 | 확인 |
| 드로잉·스케치북은 작업 과정 자료다 | CCA fonds와 sketchbook catalog | 확인, 단 개별 인과는 보류 |
| 가구·오브제는 건축과 공간적으로 연결된다 | Serralves Designing Everyday Life | 기관 해석으로 확인, 보편화 보류 |
| 아카이브는 전시·교육·방문 루트로 번역될 수 있다 | Casa da Arquitectura itinerary/교육, Serralves Wing·순회 전시 | 운영 사례로 확인, 효과는 보류 |
| 특정 가구 하나의 스케치가 최종품으로 이어진다 | 현재 검색된 카탈로그 단서 | 직접 대조 전 보류 |
| 미니멀모음은 관계형 카드로 적용할 수 있다 | 위 근거의 실행 번역 | 가설, 내부 검증 필요 |

## 현재 cycle의 실행 결론

- 지금까지의 결과는 ‘Siza 스타일’ 결론이 아니라 출처·공간·동사·불확실성을 함께 보존하는 큐레이션 방법론으로 닫는 것이 정확하다.
- 다음 검증은 넓은 추가 조사보다 단일 가구/램프의 원본 스케치 식별자와 완성품·공간·재료를 직접 대조하는 1개 leaf로 제한한다.
- 직접 대조가 닫히지 않은 상태에서 사용자 취향이나 상품화 가능성을 확정하지 않는다.
- 외부 공개·판매·결제는 실행하지 않는다.

## 품질 판정과 한계

- 확정/보류/가설을 분리한 새 작업 증거: **Active 유지**.
- 현재는 exploratory research이며 Red 검증·rich HTML·Archive 전환 조건이 아니다.
- deadline 전 Archive하지 않는다. 다음 cycle에서 직접 대조가 확보되거나, 남은 시간 예산을 재평가해 탐색을 종료할 수 있다.
