# Toss Sharelink × Threads 실행 가이드 (내부 완료본)

- intent: `marketing-122`
- 작성일: 2026-08-16 UTC

- 범위: 내부 가이드·무발행 파일럿 설계. 공개 발행, 가입, 계정 연결, 광고, DM은 실행하지 않음.

## 결론

쉐어링크를 “쉽게 돈 버는 링크”로 소개하지 않는다. `특정 구매 상황 → 선택 기준 → 공식 링크 → 경제적 이해관계 고지 → 클릭·구매·환불·확정 수익 기록`의 7일 수동 실험으로 검증한다.

공식 공개 문서에서 확인한 범위는 쉐어링크 가입 가능 조건, 링크 클릭 후 24시간 내 구매의 last-click 귀속, 구매확정·취소/환불 반영, 다음 달 25일 정산, 경제적 이해관계 고지 의무와 금지 행위다. 문서상 10%는 기간성 프로모션(기본 5% + 프로모션 5%)이므로 상시 수익률로 쓰지 않는다. 실제 발행 전에는 로그인한 회원 화면에서 계정 가입 상태, 상품별 링크 발급 가능 여부, 현재 캠페인, 세금/사업자 유형, 정산 계좌를 확인해야 한다.

## 내일 가능한 최소 실행

1. Sharelink 로그인 후 공식 화면·약관에서 가입 상태, 상품별 링크 발급 가능 여부, 수익률/캠페인, 정산/환불/세무 조건과 확인 시각을 캡처한다. 확인되지 않으면 발행하지 않는다.
2. 직접 사용했거나 비교 근거가 있는 상품 1개만 고른다. 가격·재고·옵션은 게시 직전에 판매 페이지에서 다시 확인한다.
3. Threads 초안 1개를 작성한다. 공식 링크보다 먼저 `이 포스팅은 토스쇼핑 쉐어링크 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.`를 둔다.
4. 사용자 승인과 Red 통과 전에는 게시하지 않는다.
5. 발행 후 허가된 경우 24/48시간과 7일에 아래 표를 수동 기록한다.

| 시점 | 기록 필드 | 판정 |
|---|---|---|
| 24/48시간 | 노출, 답글, 구체적 사용 사례 답글, 프로필 방문, 클릭 | 선택 기준이 이해됐는지 확인 |
| 7일 | 주문, 취소/환불, 예상·확정 수익, 순수익, 운영 시간, 정책/민원 | 계속·수정·중단 결정 |

### 7일 최소 루틴

- 1일차: 회원 화면에서 자격·캠페인·정산·세무 조건 확인. 하나라도 미확인하면 발행 보류.
- 2일차: 직접 사용 또는 비교 근거가 있는 상품 1개와 가격·재고·옵션 확인 시각을 기록.
- 3일차: 상황 선언형 초안 작성, 고지를 링크보다 앞에 배치하고 Red 검토 대기.
- 4일차: 사용자 승인과 Red pass 전까지 발행하지 않음.
- 5일차: 승인된 경우 첫 게시물 1개만 수동 발행하고 관련 질문에만 답변.
- 6일차: 24/48시간 지표와 링크 오류·고지·정책 이슈를 점검.
- 7일차: 취소/환불 이후 확정 수익과 운영 시간을 확인해 계속·수정·중단을 기록.

## 콘텐츠 기준

- 핫딜 목록보다 “누가 어떤 상황에서 왜 고르는가”를 먼저 쓴다.
- 가격·재고·할인·수익률을 고정값처럼 쓰지 않고 확인 시각을 남긴다.
- 직접 쓰지 않은 상품을 사용 후기처럼 쓰지 않는다.
- `최저가`, `무조건 이득`, `자동 수익`, `월 얼마 보장` 표현은 근거 없이는 금지한다.
- Threads의 질문형 오프닝과 격언형 마무리를 피하고, 상황 선언으로 시작한다.
- 다른 글·이미지·후기를 복사하지 않는다.

```text
출장 가방에 넣을 물건을 줄일 때, 저는 [상품]의 이 조건부터 봅니다.

[직접 사용/비교한 장면]. 좋은 점은 [1개], 아쉬운 점은 [1개]였습니다.
누구에게나 맞는 선택은 아니고, [제외 조건]이면 다른 상품을 보는 편이 낫습니다.

이 포스팅은 토스쇼핑 쉐어링크 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.
[공식 쉐어링크]
가격·옵션·재고·배송·환불 조건은 최종 판매 페이지에서 확인해주세요.
```

## 운영·안전 경계

- 첫 7일은 무예산, 수동 운영, 최대 주 3개 게시로 제한한다.
- 자동 댓글/DM, 링크 도배, 임의 URL 단축·클로킹, 다계정 운영을 하지 않는다.
- 구매자 개인정보·주문 캡처·정산 계좌·OTP·세션 정보를 기록하지 않는다.
- 계정 제한, 링크 오류, 피싱 의심, 고지 누락, 민원, 약관 위반, 수익 데이터 불일치가 발생하면 즉시 링크를 제거하고 중단한다.
