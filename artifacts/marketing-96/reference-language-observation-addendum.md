# Virtue 추천 언어 관찰 보강안

- intent: `marketing-96`
- base observation surface: `artifacts/marketing-79/week-one-activation-observation-table.html`
- purpose: 채널 확장 전, 첫 실사용자가 Virtue를 누구에게 어떤 한 줄로 소개하는지와 왜 추천을 망설이는지를 손기록으로 모은다.

## 추가 필드

기존 사용자 관찰 카드의 `자기 말 (원문 그대로)` 아래에 아래 2개 필드를 추가해 사용한다.

1. `누구에게 뭐라고 소개하겠는가`
   - 첫 가치 직후 사용자가 실제로 떠올린 대상과 소개 한 줄을 원문 그대로 적는다.
   - 예: `친구한테 "오늘 한 행동을 AI가 덕으로 읽어줘서 기분이 덜 찝찝해"라고 말할 듯`
2. `지금 추천을 망설이게 하는 이유`
   - 추천을 바로 하지 못하게 만드는 이유를 사용자의 말로 적는다.
   - 예: `아직 내가 계속 쓸지 모르겠어서 남한테 먼저 말하기는 애매함`

## 기록 규칙

- J1/J2/J4는 `deed_saved`, J3는 `deed_judged`를 first value로 읽는 기존 기준을 바꾸지 않는다.
- 추천 의향을 점수화하지 않는다. 실제 문장과 망설임 이유를 원문으로 남기는 데 집중한다.
- 공유 행동이 실제로 있었는지와, 공유/추천 문장이 무엇이었는지는 분리해 기록한다.
- 빈칸 허용: 사용자가 아직 누구도 떠올리지 못했으면 억지로 채우지 말고 `없음` 또는 침묵 자체를 메모한다.

## 카드 삽입 예시

아래 2줄을 각 카드의 `자기 말 (원문 그대로)` 아래에 붙인다.

```text
추천 언어 · 누구에게 뭐라고 소개하겠는가
추천 마찰 · 지금 추천을 망설이게 하는 이유
```

## 예시 1세트

- 사용자 가정: `J3 AI 호기심형`, `deed_judged`까지 도달 후 저장 없이 종료
- 자기 말 (원문 그대로): `생각보다 평가가 바로 나와서 재밌네`
- 추천 언어 · 누구에게 뭐라고 소개하겠는가: `AI 좋아하는 친구한테 "오늘 한 일을 넣으면 덕인지 바로 읽어주는 장난감 같은 앱"이라고 소개할 수 있음`
- 추천 마찰 · 지금 추천을 망설이게 하는 이유: `아직 한 번 써봐서 매일 쓸 건지 모르겠고, 저장 안 해도 되는지 헷갈림`
- 해석 메모: J3의 무저장 종료는 기존대로 정상 종료이며, 추천 마찰은 실패 판정이 아니라 카피/초대 문장 재료로만 축적한다.

## 사용 위치

- 운영 시에는 기존 표 전체를 다시 만들지 말고 `marketing-79` 관찰표 옆에 이 보강안을 함께 두고 손기록한다.
- 추천 문장이 5명 이상 누적되면 landing/초대 문장 후보는 이 원문에서만 뽑고, 추상 카피는 나중 단계로 미룬다.
