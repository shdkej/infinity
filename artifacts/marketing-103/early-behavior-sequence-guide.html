Virtue Early Behavior Sequence 기록표

첫 10명 세션의 행동 순서를 의도형·막힘형·자연종료로 기록하는 보조 표. marketing-79 관찰표와 함께 사용한다.

early_behavior_sequence 기록 기준
  • 의도형 — 목표를 향해 나아가는 행동. /add 탭, 텍스트 입력 시작, 스크롤하여 결과 확인, 재시도.
  • 막힘형 — 다음 행동이 불명확한 상태. 멈춤 >10초, 즉시 뒤로가기, 같은 화면 반복, 오류 후 이탈.
  • 자연종료 — first value 도달(deed_judged / deed_saved) 후 자발 종료. J3 무저장 종료 포함. 막힘형과 구분.
  • 행동을 최대 5단계까지 순서대로 기록. 이벤트 이름 또는 행동 묘사 중 더 정확한 것으로 쓴다.
J1–J4 시퀀스 예시
  • J1 (일상 기록형): 홈 진입 → /add 탭 → 텍스트 입력 → deed_judged → deed_saved → 종료. 모두 의도형. 입력 후 10초 멈추면 막힘형 1개 삽입.
  • J2 (누적 성장형): 덕력 숫자 확인 → /add 시작 → 입력 → deed_saved. 덕력 확인 후 즉시 뒤로가기 → 막힘형.
  • J3 (AI 호기심형): /add → 입력 → deed_judged → 결과 읽음 → 종료. 저장 없는 종료 = 자연종료. 막힘형 아님.
  • J4 (자기 반성형): 홈 진입 → /add → 반성 텍스트 입력 → deed_saved. 텍스트 지우고 다시 쓰면 의도형+막힘형 혼재 가능.
