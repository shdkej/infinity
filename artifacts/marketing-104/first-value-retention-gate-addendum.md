# Virtue 첫 가치 도달 게이트 companion

- intent: marketing-104
- scope: 첫 10명 관찰표 보조 기록 칸
- use_with: artifacts/marketing-79/week-one-activation-observation-table.html

## 기준

`판정 완료`는 시스템 이벤트가 끝났다는 뜻이고, `첫 가치 도달`은 사용자가 결과를 이해하고 다음 행동을 떠올릴 수 있게 된 순간이다. 둘은 같은 값으로 기록하지 않는다.

- `판정 완료`: `deed_judged` 또는 `deed_saved` 같은 이벤트 완료 여부
- `첫 가치 도달 시점`: 사용자가 "무엇을 얻었는지" 이해한 순간
- `결과 이해 신호`: 결과를 자기 언어로 해석하거나 다시 말한 흔적
- `다음 행동 명료성`: 저장, 홈 복귀, 재방문, 공유, 자연 종료 중 무엇을 하려는지 보이는 정도

## 관찰 카드에 추가할 칸

각 사용자 카드의 `독립 2판정` 아래에 아래 4줄을 보조 칸으로 붙인다.

| 칸 | 기록 방법 | 판정 기준 |
|---|---|---|
| 첫 가치 도달 시점 | `없음 / 결과 확인 직후 / 저장 직후 / 홈 복귀 후 / 종료 직전` 중 하나와 짧은 메모 | 결과를 이해하거나 자기 일에 연결한 첫 순간 |
| 결과 이해 신호 | 원문 발화 또는 행동 1개 | "이게 덕으로 잡히네", "오늘 한 일이 이렇게 보이네"처럼 의미를 해석한 흔적 |
| 다음 행동 명료성 | `명료 / 불명료 / 자연 종료` | 다음에 무엇을 할지 보이면 명료, J3처럼 목적 충족 후 나가면 자연 종료 |
| 자연 종료 여부 | `예 / 아니오 / 불명` | 막혀서 나간 것이 아니라 기대한 확인을 끝내고 나갔는지 |

## J1-J4 예시

### J1 일상 기록형

- 판정 완료: `deed_saved`
- 첫 가치 도달: 저장 직후 홈 또는 최근 덕행에서 "내 하루가 남았다"를 확인한 순간
- 결과 이해 신호: "아, 이런 것도 덕으로 쌓이는구나"
- 다음 행동 명료성: 다음에도 비슷한 일을 저장하겠다는 말이 있으면 `명료`; 저장했지만 홈에서 무엇을 볼지 모르면 `불명료`

### J2 누적 성장형

- 판정 완료: `deed_saved`
- 첫 가치 도달: 점수, 누적, 최근 기록을 보고 "계속하면 쌓인다"를 이해한 순간
- 결과 이해 신호: "숫자가 쌓이는 게 보이네", "며칠 하면 비교가 되겠다"
- 다음 행동 명료성: D1 재방문 이유가 누적 확인이면 `명료`; 단순 호기심만 남으면 `불명료`

### J3 AI 호기심형

- 판정 완료: `deed_judged`
- 첫 가치 도달: AI 판단 결과를 보고 재미, 납득, 반박 중 하나를 표현한 순간
- 결과 이해 신호: "생각보다 바로 평가되네", "왜 이 점수인지 알겠다"
- 다음 행동 명료성: 저장 없이 나가도 결과 확인 목적을 달성했으면 `자연 종료`; 저장을 못 찾아 헤매면 `불명료`

### J4 자기 반성형

- 판정 완료: `deed_saved`
- 첫 가치 도달: 입력한 행동이 자기 반성 문맥으로 정리됐다고 느낀 순간
- 결과 이해 신호: "기록해두니까 정리된다", "오늘 한 선택을 다시 보게 된다"
- 다음 행동 명료성: 다음 반성 기록 또는 홈 복귀 확인이 보이면 `명료`; 저장 후 결과 의미를 못 읽으면 `불명료`

## 읽는 순서

1. 먼저 기존 `activation 판정`을 잡별 이벤트 기준으로 기록한다.
2. 별도로 `첫 가치 도달 시점`을 기록한다.
3. `판정 완료`만 있고 결과 이해 신호가 없으면 activation을 과대 해석하지 않는다.
4. 결과 이해 신호가 있어도 잡별 activation 이벤트가 끝나지 않았으면 activation 도달로 올리지 않는다.
5. J3는 `deed_judged` 후 저장 없는 종료가 자연 종료일 수 있으므로 실패로 자동 분류하지 않는다.
