# T3.2 — Red: 측정·Stop 조건 검증

**판정: PASS**

검토 대상: `validation-design.md`

- 분석 단위는 참여자 1명당 과거 장면 1건과 독립 발생한 실제 다음 선택 1건의 비교쌍으로 고정됐으며 중복 집계를 금지한다.
- `actual`만 Continue 근거로 사용한다. 가상 시나리오·단순 재독은 보조 로그이며 행동 효용·반복성 근거가 아니다.
- 카드 스키마는 `장면 → 유지/피함 → 다음 기준` 3필드로 고정됐고, 시간순 수동 열람만 허용한다.
- 기존 자료와 같은 장면·같은 선택의 동일 과업 비교에서 시간, 기준 인용, 반사실, 채택/거절, 추가 근거를 기록한다.
- 저장된 기준의 명시 인용이 없거나 기존 자료와 동등하면 Continue로 계산하지 않는다. Stop/Discard는 호감·재독·가상 긍정 신호보다 우선한다.
- 비식별 최소 수집, 금지 필드, 로컬 fixture의 export/delete 검증, 별도 동의·승인 전 실제 수집 금지를 명시한다.
- 직접 WTP·가격 수용성·반복 유료 행동·외부 실행을 주장하거나 수행하지 않는다.

## 한계

이 문서는 사전등록된 내부 측정 계약이다. 실제 사용자 행동, 독립 효용, 반복 사용 또는 직접 WTP를 입증하지 않는다.
