# C1 — 다음 반증 질문 고정

## 고정 결론

여행 회수 카드는 **가설 유지** 상태다. 현 자료는 시장성, 직접 지불 의사, 반복 사용 또는 기존 노트·사진 대비 증분 효용을 입증하지 않는다.

## 다음 반증 질문 (우선순위)

1. **카드 단위:** 3필드(`장면 → 유지/피함 → 다음 기준`)와 6필드 중 하나를 사전 고정했을 때, 추가 설명 없이 완결·재열람·선택 근거 인용이 가능한가?
2. **동일 과업 비교:** 같은 과거 장면·다음 선택에서 기존 노트/사진만 쓴 결과보다 카드가 추가 선택 근거를 제공하는가? 동등하면 `Stop/Discard`다.
3. **선택 기여:** 카드 열람 뒤에만 저장된 기준을 인용해 이유·선택·확신 중 사전 정의한 하나가 바뀌거나 확정되는가? 단순 재독은 Continue 근거가 아니다.
4. **반복성:** 실제 또는 사전 고정된 유사 상황의 서로 다른 날짜에 동일 카드가 다시 열리고 선택 이유로 인용되는가? 없으면 반복 가설은 보류한다.
5. **대체재·포지셔닝:** 사용자가 장소 탐색·추천·체크리스트·일기 보관을 핵심으로 요구하거나 기존 도구로 충분하다고 하면, 차별화 근거로 세지 않고 `Stop/Discard`로 기록한다.

## 역할 판단

- **Planner:** 사람/기록의 분석 단위와 카드 스키마를 하나로 고정하지 않으면 통과·중단 기준을 계산할 수 없다.
- **Developer:** 검색·추천·AI 없이도 수동 재열람 경로와 동등 과업 비교가 정의되기 전에는 데이터 모델·구현 범위를 정하지 않는다.
- **Marketer:** 인접 서비스 가격은 직접 WTP가 아니다. 기록 만족과 선택 재사용을 구분하지 못하면 가설은 유지되지 않는다.
- **Operator:** 승인 전에는 모집·결제·배포·외부 발송을 하지 않으며, 향후 실험도 비식별 최소 수집·삭제 절차를 먼저 고정해야 한다.

## 판정 영향

- 질문 1–4가 관찰되지 않으면 각각 Continue 증거에서 제외하고 가설을 보류한다.
- 질문 2 또는 5에서 기존 대안 동등/충분성이 확인되면 `Stop/Discard`가 Continue보다 우선한다.
- 가격 선호는 별도 승인된 후속 연구가 없으면 직접 WTP 증거로 기록하지 않는다.

## 인계

T2.1은 위 2·5번의 대체 설명부터 조사한다. 외부 행동 없이 공개 기능·계획 근거와 기존 artifact의 주장 경계만 대조한다.
