# T1.1 — 기존 결론의 증거 공백

## 판정

이 문서는 여행 회수 카드의 시장성·직접 WTP·반복 사용을 증명하지 않는다. 기존 결론을 다음 검증에서 **기각할 수 있게 만드는 공백 목록**이다.

## 근거 공백과 반증 질문

| 공백 | 사전 고정할 반증 질문 | Stop/보류 신호 |
| --- | --- | --- |
| 카드 단위가 3필드(`장면·유지/피함·다음 기준`)와 6필드(`누구·언제·예산·기분·좋음/피함`)로 충돌 | 하나의 필드셋을 고정했을 때 추가 설명 없이 완결·재열람·기준 인용이 가능한가 | 두 스키마를 병행해야 하거나 필드가 늘어나면 UX·개인정보 경계 판단을 보류 |
| `3분 이내`와 `30초 목표`가 공존 | 한 임계값으로 각 입력 시간·중앙값·완결률을 기록할 수 있는가 | 임계값을 사후 변경하거나 보정 설명이 필요하면 통과로 세지 않음 |
| 재열람과 실제 선택 기여가 분리되지 않음 | 카드 없이 내린 최초 선택과 카드 열람 뒤 선택을 분리했을 때 저장된 기준이 이유로 인용되는가 | 단순 재독·회고 만족은 선택 기여로 계산하지 않음 |
| 기존 노트·사진·장소 저장 대비 증분가치가 없음 | 같은 장면·상황에서 기존 자료만 쓴 결과보다 카드가 더 빠르거나 새 기준을 회수하는가 | 동등하면 차별 가설을 기각 |
| 여행 사이 반복성과 실제/가상 상황이 혼재 | 재열람이 실제 다음 선택에서 자연 발생했는지, 가상 프롬프트인지 구분할 수 있는가 | 가상 사례만 있으면 반복 행동 근거로 쓰지 않음 |
| 대상 사용자의 행동 조건이 없음 | 과거 기록·다가오는 실제 선택·기존 기록 도구 사용 여부를 최소 비식별 범주로 확인할 수 있는가 | 특정 기록 습관 보유자에게만 성립하면 일반화하지 않음 |
| 기록 만족과 판단 재사용이 혼재 | 보관 이유가 추억/사진 보관이 아니라 다음 선택의 구체 기준인지 구분되는가 | 회고·저장 이유만이면 Stop/Discard |
| 직접 WTP·가격 단위 근거가 없음 | 가격 응답을 비구속 선호로만 기록하고 재사용 행동과 분리할 수 있는가 | 인접 가격 또는 가상 의향만으로 가격·결제 판단을 하지 않음 |
| L0 데이터 수명 계약이 미정 | 로컬 저장 위치·필드·삭제·내보내기·자유텍스트 식별자 처리를 명시할 수 있는가 | 계약 없이 프로토타입·참여자 검증으로 진행하지 않음 |

## 역할별 수렴

- **Planner (`role_depth_planner`)**: 분석 단위와 반사실 비교, 실제/가상 상황 구분이 먼저 고정돼야 합니다.
- **Developer (`role_depth_developer`)**: 단일 카드 스키마·수동 재열람 방식·동일 과업 대체재 비교가 없으면 데이터 모델과 구현 범위를 정할 수 없습니다.
- **Marketer (`role_depth_marketer`)**: ‘다음 선택의 기준 카드’가 기록/사진/장소 저장으로 환원되는지와 가격 단위·타깃의 행동 조건이 미검증입니다.
- **Operator (Genie)**: 동의 전에는 실제 참여자·기록을 수집하지 않습니다. 최소수집·삭제·내보내기 계약과 Stop 우선 규칙이 먼저 문서화돼야 합니다.

## 공개 근거의 사용 한계

TripIt Pro의 연간 가격과 실시간 기능, Polarsteps Plus의 유료 시각화·통계 구분은 공식 페이지로 재확인했습니다. 이는 **인접 제품이 무엇에 과금하는지**의 최신 맥락일 뿐, 여행 회수 카드의 직접 WTP·가격·반복 수요 증거가 아닙니다.
