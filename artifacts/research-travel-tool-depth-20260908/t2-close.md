# C2 — 가설 우선순위 재판정

**판정: 저우선·미검증 가설 유지 (구현 보류)**

여행 회수 카드의 포지셔닝은 “다음 유사 선택에서 다시 꺼내 쓸 개인 기준 카드”로만 남긴다. 이는 출시·MVP·가격·수익화 결론이 아니다.

## 역할 수렴

- **Planner:** 동일 장면·동일 선택 과업에서 기존 노트·사진·장소 저장만으로 기준을 회수할 수 있거나 카드가 추가 근거를 만들지 못하면 `Stop/Discard`다.
- **Developer:** 3필드와 6필드 스키마를 합치지 않는다. 단일 스키마, 수동 시간순 재열람, 동일 과업 비교, 입력 시간과 기준 인용을 사전 고정하기 전에는 데이터 모델·검색 방식·구현 범위를 정하지 않는다.
- **Marketer:** Day One·Mapstr·TripIt·Polarsteps 가격은 인접 범주 맥락일 뿐 직접 WTP나 가격 단위의 근거가 아니다. 저널/사진 보관, 장소 리스트, 플래너로 환원되면 `Stop/Discard`다.
- **Operator:** 외부 모집·발송·결제·사전결제·배포·권한 변경은 하지 않았다. 향후 별도 승인 범위에서도 최소 비식별 수집·삭제 절차·로컬 데이터 계약이 먼저다.

## 재판정 규칙

다음 동일 과업 비교 전에는 가설 상태를 높이지 않는다.

1. **한 카드 스키마만** 사전 고정한다(3필드 또는 6필드; 혼합 금지).
2. 같은 과거 장면과 독립적으로 발생한 같은 다음 선택에서, 기존 노트/사진/장소 저장과 카드를 비교한다.
3. 카드의 Continue 근거는 저장된 기준을 실제 선택 이유로 **명시적으로 인용한 경우**만 인정한다. 호감·재독·가상 시나리오는 제외한다.
4. 기존 도구가 동등한 기준을 회수하거나 카드가 추가 근거를 만들지 못하면 `Stop/Discard`가 우선한다.
5. 저널/추억 보관, 장소 탐색·추천·리스트, 일정·체크리스트 수요로 환원되거나 기준 인용이 없으면 `Stop/Discard`다.

## 미검증 한계

독립 효용, 실제 사용자 행동, 반복 사용, 직접 WTP, 가격 단위·수용성은 모두 미검증이다. 공개 제품 기능/가격은 직접 증거가 아니다.

## 다음 안전한 행동

별도 승인이 있을 때만 단일 카드 스키마와 동일 과업 비교의 측정·동의·삭제 계약을 설계한다. 이 기록만으로 프로토타입, 모집, 결제, 배포를 시작하지 않는다.
