# T3.3 — C3: 동의·L0 경계 마감

## 마감 판단

T3 측정 설계는 **별도 동의·승인 전 실행하지 않는 내부 사전등록 계약**으로 마감한다. 실제 참여자 모집·연락·데이터 수집·결제·배포·외부 발송은 수행하지 않았다.

## 역할별 확인

- **Planner:** 실제 독립 선택만 분석 단위로 쓰며, 가상 시나리오·단순 재독은 Continue 근거에서 제외한다.
- **Developer:** 3필드 카드와 시간순 수동 열람만 허용한다. fixture에서 생성·목록·비식별 export·삭제·재조회 불가를 먼저 확인한다.
- **Marketer:** 카드 기준의 명시 인용과 기존 자료 대비 추가 선택 근거가 없으면 가설을 승격하지 않는다.
- **Operator:** 허용 필드는 비식별 ID·비교쌍 ID·3필드·시간·분류·인용 여부·채택/거절 코드뿐이다. 금지 필드와 식별 자유 텍스트는 즉시 삭제·분석 제외한다.

## 보호 경계

1. 실제 데이터 수집은 별도 동의와 승인 전 금지한다.
2. 정확 위치, EXIF, 원본 사진, 예약·확인번호, 동행인, 검색·이동 이력, 계정·외부 API는 수집하지 않는다.
3. 원문은 측정 종료 시 삭제하며, 명시적 수동 내보내기가 있을 때만 비식별 집계 JSON/CSV를 남긴다.
4. Stop/Discard 신호 하나라도 있으면 호감·재독·가상 긍정 반응보다 우선한다.
5. 이 계약은 실제 사용자 행동, 독립 효용, 반복 사용, 직접 WTP 또는 출시 가능성을 입증하지 않는다.

## 재개 조건

별도 승인된 범위에서만 로컬 fixture 검증을 시작할 수 있다. 참여자 모집·연락·실제 데이터 수집·결제·외부 전송은 그 승인에도 별도 경계로 남는다.
