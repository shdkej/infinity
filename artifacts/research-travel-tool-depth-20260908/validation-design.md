# T3.1 — 7일 검증 측정 설계 (사전등록 초안)

## 판정 범위

이 문서는 **외부 실험 실행 계획이 아니라**, 향후 별도 동의·승인 범위에서만 사용할 수 있는 내부 측정 계약이다. 직접 WTP, 가격 수용성, 반복 유료 행동, 출시 가능성은 측정하거나 주장하지 않는다.

## 고정 단위와 카드

- **분석 단위:** 참여자 1명당 `과거 장면 1건 + 독립적으로 발생한 실제 다음 선택 1건`의 비교쌍 1건. 사람별 중복 집계는 금지한다.
- **카드:** `장면 → 유지/피함 → 다음 기준`의 3필드만 사용한다. 6필드, 추천 출력, 점수, 지도, 검색, 태그 필터, AI, 알림은 제외한다.
- **입력 기준:** 카드 완성은 3분 이내·진행자 보정 설명 없음이 원칙이다. 시간, 완결 여부, 보정 여부는 원자료로 남기며 보정 사례는 Continue 근거로 세지 않는다.
- **재열람:** 시간순 수동 목록 열람만 허용한다. 검색·위치·지도·추천·AI·자동 재노출은 금지한다.

## 동일 과업 비교 절차

각 적격 비교쌍은 같은 과거 장면과 실제 다음 선택에서 아래 순서를 따른다.

1. 기존 노트·사진·장소 저장만으로 다음 선택 기준을 회수한다.
2. 같은 장면의 3필드 카드만으로 다음 선택 기준을 회수한다.
3. 두 조건에서 회수 시간, 인용 기준, `카드가 없었다면 무엇을 골랐나` 반사실, 채택/거절 이유, 카드가 추가한 선택 근거를 기록한다.
4. 선택 사례를 `actual` / `hypothetical` / `단순 재독`으로 분류한다. **actual만** 증분 효용·반복성의 Continue 근거가 될 수 있다.

## 질문과 판정 규칙

| 측정 질문 | Continue 후보로 인정되는 최소 증거 | Stop/Discard 우선 신호 |
| --- | --- | --- |
| 카드가 기존 자료보다 추가 기준을 주는가 | 실제 선택에서 저장 기준을 명시 인용하고 기존 자료에 없던 선택 근거가 있음 | 기존 자료와 동등·우세하거나 새 근거가 없음 |
| 재열람이 실제 선택에 기여하는가 | actual 선택에서 카드의 기준을 채택·확정 이유로 인용 | 호감, 회고 만족, 일반 지식, 기준 인용 없는 변화 |
| 포지셔닝이 이해되는가 | 사용자가 자발적으로 ‘다음 선택의 개인 기준’으로 설명 | 일기·사진 보관, 장소 리스트·추천, 일정·체크리스트·예약 관리로 환원 |
| 재사용이 실제인가 | 독립 발생한 actual 선택에서 재열람 촉발과 선택 마감을 기록 | 가상 시나리오·진행자 프롬프트·단순 재독만 존재 |

`Stop/Discard` 신호 하나라도 성립하면 빠른 입력, 호감, 재독, 가상 시나리오의 긍정 반응보다 우선한다. 실제 사례가 부족하거나 중단 신호가 없더라도, 결과는 **가설 유지**일 뿐 출시·구현·가격·결제 결정이 아니다.

## 최소 데이터 계약 (향후 승인 전 실행 금지)

- 허용 필드: 익명 참여자 ID, 비교쌍 ID, 3필드 카드, 시간, actual/hypothetical 분류, 기준 인용 여부, 채택/거절 코드.
- 금지 필드: 이름·연락처·정확 위치·EXIF·원본 사진·예약/확인번호·동행인·검색/이동 이력. 자유 텍스트의 식별자·상호·주소·인물명은 발견 즉시 삭제·분석 제외한다.
- 저장/삭제: 브라우저 로컬 임시 저장 또는 로컬 JSON fixture만 허용한다. 측정 종료 후 원문은 삭제하고, 명시적 수동 내보내기가 있을 때만 비식별 집계 JSON/CSV를 남긴다.
- 사전 fixture 검증: 가짜 데이터로 `생성 → 시간순 목록 → 비식별 export → delete → 재조회 불가`를 확인한다. 실제 참여자 데이터는 별도 동의·승인 전 수집하지 않는다.

## 역할 수렴과 한계

- Planner `depth_t31_planner`: 분석 단위·실제/가상 분리·Stop 우선 사전고정.
- Developer `depth_t31_developer`: 3필드 스키마·수동 열람·동일 과업 비교·삭제 fixture 계약.
- Marketer `depth_t31_marketer`: 자발적 범주화와 대체재 환원을 통한 포지셔닝 반증; 가격 질문·WTP 제외.
- Operator (Genie): 최소수집·삭제·외부 실행 금지와 사용 전 동의/승인 경계.

이 설계는 실제 사용자 행동, 독립 효용, 반복 사용, 직접 WTP를 증명하지 않는다. 해당 증거는 이 문서만으로 생성되지 않는다.
