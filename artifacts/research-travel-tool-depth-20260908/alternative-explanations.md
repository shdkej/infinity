# T2.1 — 상위 가설의 대체 설명 조사

## 결론

여행 회수 카드는 **가설 유지**다. 공개 기능 근거만으로는 독립 효용, 반복 사용, 직접 WTP를 입증할 수 없다. 특히 기존 도구가 같은 기록을 찾아 다음 선택 근거로 회수할 수 있다면, 별도 카드의 가치는 기각된다.

## 공개 기능 근거 (확인일: 2026-09-08)

| 대체재 | 확인된 기능 | 카드 가설에 대한 영향 |
|---|---|---|
| Day One | 태그·즐겨찾기·검색 필터로 사진과 엔트리를 찾고, `On This Day`로 과거 기록을 재열람할 수 있다. [공식 기능](https://dayoneapp.com/features/), [공식 필터 가이드](https://dayoneapp.com/guides/tips-and-tutorials/filters/) | 동일 장면에서 기존 엔트리가 다음 선택 기준을 충분히 회수하면 카드의 차별화는 없다. |
| Mapstr | 장소마다 태그·노트·댓글·사진·상태를 붙이고, 키워드·태그·댓글로 검색/필터/정렬할 수 있다. [공식 FAQ](https://en.mapstr.com/faq) | 장소 맥락이 핵심이면 장소 저장 도구와 입력·재열람이 중복될 수 있다. 정확 위치·지도 중심 흐름은 본 가설의 L0 범위 밖이다. |
| Beli | 방문/희망 식당 목록과 지도, 친구 기반 공유·추천을 제공한다. [공식 소개](https://beliapp.com/) | 식당/장소 목록·발견·공유가 우선 수요라면 회수 카드는 독립 범주가 아니라 목록 기능의 변형일 수 있다. |

이 문서는 위 기능이 ‘다음 선택 기준’을 동등하게 회수한다고 주장하지 않는다. 그 여부는 동일 과업 비교가 없는 현재 상태에서 미검증이다.

## 우선 대체 설명과 기각 기준

1. **기존 노트·사진으로 충분함** — 같은 과거 장면과 같은 선택 상황에서 기존 자료만으로 기준을 찾거나, 카드가 새 선택 근거를 추가하지 못하면 `Stop/Discard`.
2. **기록·회고 만족의 오인** — 카드가 좋게 느껴지거나 단순 재독되는 것만으로는 선택 효용이 아니다. 저장된 기준을 인용한 이유·선택·확신 변화가 없으면 Continue 근거에서 제외.
3. **장소 목록·추천 수요** — 태그·후기·지도·추천·공유가 핵심 요구라면 Mapstr/Beli류와 중복이므로 `Stop/Discard`.
4. **플래너·체크리스트 수요** — 일정·예약·경로·알림·할 일 관리가 핵심이면 L0 범위를 넘고, 회수 카드의 차별 근거가 아니다. `Stop/Discard`.
5. **사전 선호·시나리오 유도** — 카드 없이 내린 최초 선택과 열람 후 선택을 분리하지 못하거나, 저장된 기준 인용이 없으면 선택 기여로 계산하지 않는다.
6. **여행과 무관한 7일 재독** — 재열람 촉발 상황이 실제/사전 정의된 유사 선택이 아니면 반복 증거가 아니다.

## 최소 동일 과업 비교 계약 (미실행)

- **단위:** 사람 1명당 동일한 과거 장면 1개와 독립적으로 발생한 다음 선택 1개.
- **입력:** 3필드 카드(`장면 → 유지/피함 → 다음 기준`) 하나만 사용한다. 6필드 안은 비교 전에 폐기하거나 별도 가설로 분리한다.
- **비교:** 기존 노트/사진/장소 저장만 사용한 회수와 카드 사용 회수의 시간·인용된 기준·추가 근거를 기록한다.
- **판정:** 카드가 추가 기준을 제공하지 못하거나 기존 자료와 동등하면 `Stop/Discard`; 단순 호감, 가상 사례, 단순 재독은 Continue 근거에서 제외한다.

## 경계

공개 제품 페이지는 기능 근거이며 직접 WTP·가격 수용성·실제 사용자 행동의 증거가 아니다. 모집, 결제, 사전결제, 배포, 외부 발송, 계정·위치·원본 사진·예약 정보 수집은 수행하지 않았다.

## 역할 수렴

- **Planner:** 카드 없는 최초 선택과 열람 후 선택을 분리하고, 기준 인용이 있을 때만 선택 기여로 계산한다.
- **Developer:** 3필드 카드와 수동 시간순 재열람만을 비교 단위로 고정한다. 검색·지도·추천·AI는 비교를 오염시키므로 제외한다.
- **Marketer:** 저널·사진 보관·장소 리스트·플래너로 환원되는 해석은 모두 `Stop/Discard`다.
- **Operator:** 비교가 승인되기 전에는 외부 행동이 없으며, 비식별 최소 수집과 삭제 계약 없이 프로토타입을 시작하지 않는다.
