# marketing-124 — Instagram intro / closed-loop cards

## Planner

- 목표: 계정이 무엇을 관찰하고 어떻게 일하는지 3장의 이미지로 한 번에 읽히게 한다.
- 완료 기준: 카드 3장, 인스타 소개글 후보, 편집 가능한 SVG와 PNG 렌더, 역할별 판단 및 Red 검증.
- 범위: 계정 소개·방법론·팔로워 기대치. 공개 게시, 프로필 변경, 외부 업로드는 제외.
- Knowledge Lab 근거: `agent-wiki/content/docs/syntheses/original-proof-distribution-loop.mdx`의 원본 증거·반복 발행·회수 루프 원칙과 `DESIGN.md`의 warm clarity/100→10 원칙.

## Developer

- 인스타 세로 4:5(1080×1350) SVG 3개를 원본으로 제작했다.
- 흰 바탕, 검정 3분할 순환 원, 굵은 선, 텍스트 안전영역을 사용했다.
- SVG는 코드네이티브 다이어그램이므로 raster image generation은 사용하지 않았다.
- PNG는 SVG에서 로컬 렌더링했으며, 외부 폰트·외부 리소스·네트워크 의존성이 없다.

## Marketer

- 카피는 계정의 활동 영역(여행·AI·제품·개인 운영 시스템)과 방법(가설→실험→증거→다음 조정)을 구체적으로 남겼다.
- 동기부여 포스터·스타트업식 과장·긴 자기소개는 제거했다.
- 소개글은 확정안 1개와 대안 2개를 제공하되, 게시 전 사용자가 선택한다.

## Operator

- 산출물은 Infinity artifact 폴더에만 저장했다.
- Instagram 게시, 프로필 수정, 외부 업로드, 공유 링크 생성은 실행하지 않았다.
- 재현 명령과 검사 결과는 `verification.txt`에 기록했다.

## Card plan

주문구: `여행 · AI · 제품 · 운영 시스템`

### Card 2 — Method

주문구: `가설 → 실험 → 증거`

보조문구: `작게 만들고, 빠르게 다시 돕니다.`

시각: 3분할 원의 각 구간에 세 단계를 배치.

### Card 3 — Promise

주문구: `한 번의 답보다, 다음 실험`

보조문구: `과정과 배운 것을 남깁니다.`

시각: 루프를 가장 크게 두고, 약속 문구만 남긴다.
