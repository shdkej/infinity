marketing-75 Virtue 변경 등급표와 안내 표면 맵

Virtue prelaunch 단계에서 모든 변경을 같은 강도로 알리지 않기 위한 내부 기준 문서다. 외부 공지나 배포 계획이 아니라, 무엇을 크게 설명하고 무엇을 제품 안에서 조용히 처리할지 구분하는 docs-only 가드레일이다.

Tier 1-4 정의
Tier 정의 권장 안내 표면 설명 강도 금지선
Tier 1 시각 polish, 문장 다듬기, 내부 품질 개선처럼 기대 경로를 바꾸지 않는 변경 기본적으로 무안내. 필요해도 화면 안 미세 힌트 1회 거의 침묵 외부 공지, 런칭 톤, 성과 약속 금지
Tier 2 기존 흐름은 유지하지만 이해를 돕는 보강. 다음 행동의 맥락이 더 선명해지는 변경 해당 화면의 contextual hint, sample label, empty-state helper 짧은 제품 내 안내 이메일/블로그 우선 공지 금지, 새 가치 제안처럼 과장 금지
Tier 3 first value 기대나 권한 해석을 실질적으로 바꾸는 변경 해당 화면 + 후속 교육 표면(결과 카드, 다음 화면) 연동 화면 안 설명 필요 출시 선언처럼 포장 금지, tracking/deploy 변경 자동 동반 금지
Tier 4 사용자 약속, 권한 경계, 제품 포지셔닝을 재정의하는 변경 제품 내 설명 + 별도 승인 후 외부/운영 표면 검토 명시적 설명 필요 현재 L1 범위에서는 실행 금지. approval-needed
