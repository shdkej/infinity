# 카타니아 하루 6장 비공개 캐러셀

여섯 장의 사용자 제공 사진을 각각 1080×1350 RGB 카드로 렌더했습니다. 카드 1–2는 복잡함, 3–4는 정리, 5–6은 여백의 리듬입니다. 제공 기록 밖의 가격·식당명·타인 감정·장소 평가는 추가하지 않았습니다.

`public_posted=false`, `external_uploaded=false`, `profile_changed=false`이며, 원본 사진의 인물·표식·저작물은 공개 검토되지 않았습니다.

```bash
python3 generate_assets.py
python3 validate_assets.py
```
