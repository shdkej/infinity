# T2.1a — The 100 Day Project 원문 메모

- 확인일: 2026-09-10
- 1차 출처: [The 100 Day Project — About](https://www.the100dayproject.org/about)
- 조사 범위: 반복 창작·공유·커뮤니티의 **작동 조건**만 확인한다. 이 사례를 유입·커뮤니티·제품 적합의 증거로 일반화하지 않는다.

## 원문에서 확인한 조건

| 확인 사실 | 해당 시리즈에 옮길 수 있는 제한적 판단 | 옮기면 안 되는 것 |
| --- | --- | --- |
| 프로젝트는 하나의 창작 활동을 100일 동안 하고, 과정을 온라인에 기록·공유하는 구조다. | 반복 형식은 항목 단위를 작게 하고, 무엇을 남길지 먼저 고정할 때 설명 가능해진다. | ‘1/100’이 곧 매일 발행·100일 완주여야 한다는 결론 |
| 공식 안내는 하루 5–10분 안에 할 수 있는 프로젝트, 접근 가능·휴대 가능한 도구, 생성적인 규칙을 권한다. | 첫 14일에는 실제 기록 하나를 다시 보는 작은 단위만 설계한다. | 저비용/짧은 단위가 자동으로 독자 반응이나 사업성을 만든다는 주장 |
| 해시태그·Instagram·Facebook 그룹·뉴스레터는 참여자 발견과 응원용 경로로 안내된다. | 참여자 간 상호작용은 별도의 운영 설계와 표면이 있어야 생긴다. | 콘텐츠 저장/댓글 하나를 커뮤니티 수요 또는 가입 의향으로 읽는 것 |
| 공식 FAQ는 시작일·프로젝트 변경·결석에 유연하며, ‘규칙은 만들어진 것’이라고 설명한다. | 스트릭 실패나 연속 발행을 핵심 품질 지표로 두지 않는다. | 완주 압박·레벨·보상으로 반응을 유도하는 방식 |

## 미니멀 수집 1/100에 대한 결정

이 사례는 `항목을 작게 만들고 반복 형식을 명료하게 할 수 있다`는 운영 힌트로만 쓴다. 미니멀 수집은 100일 챌린지를 복제하지 않는다. `1/100`은 내부 목록의 항목 표기이며, 일일 발행·공개 공유·해시태그·커뮤니티 참여를 요구하지 않는다. 공개 게시·DM·커뮤니티 개설과 개인정보 수집은 여전히 별도 사용자 승인 없이는 금지한다.
