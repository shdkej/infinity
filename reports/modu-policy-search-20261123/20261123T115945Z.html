모두의정책 검색·AI 검색 설정

모두의정책 공개 페이지 14개에 검색용 대표 주소와 구조화 데이터를 적용했습니다. 정책 10개의 기록 42건은 자바스크립트를 꺼도 출처와 함께 읽을 수 있습니다.

01 변경 전
검색기가 크롤링 규칙과 사이트맵을 요청하면 HTTP 403을 받았고, 홈페이지에 구조화 데이터가 없었습니다.
02 현재
크롤링 규칙과 사이트맵이 HTTP 200으로 열리며, 정책별 고유 주소에서 기록과 근거 링크를 제공합니다.
검색 설정 변경
공개 페이지 검증
  1. 사이트맵에 등록한 14개 주소가 모두 HTTP 200을 반환하고 각 문서의 대표 주소와 구조화 데이터가 일치합니다.
  2. 정책 상세 10개에 기록 42건과 출처 링크 42개가 초기 HTML에 포함됩니다. 휴대폰에서 자바스크립트를 꺼도 내용을 읽을 수 있습니다.
  3. 홈페이지의 정책 창에서 해당 정책의 고유 페이지로 이동할 수 있습니다. 아동수당 상세 링크를 운영 사이트에서 확인했습니다.
실제 검색 결과에 표시되는 시점과 AI 답변에 인용되는 빈도는 이번 운영 검증으로 측정할 수 없습니다.
