레퍼런스 분석 Gemini 전환

기본 분석은 Flash-Lite, 정밀 분석은 Flash로 실행하고 사진 분석을 재사용합니다.

01 작업 목적
같은 사진을 다시 분석할 때 발생하는 모델 호출과 비용을 줄이고 어려운 사진에 정밀 분석을 선택할 수 있게 합니다.
02 구현 결과
기본 3.1 Flash-Lite와 정밀 3.8 Flash, 콘텐츠 해시·모델·분석 버전별 영구 캐시를 운영 배포했습니다.
핵심 내용 · 리서치 본문
핵심 발견
  1. 운영 서버 키를 연결했습니다. 브라우저에서 입력한 Gemini 키는 해당 탭에서만 사용합니다.
  2. 실제 아카이브 사진의 기본 분석이 4.4초 만에 제목, 설명 3개, 하단 가격 문구를 검출했습니다. 캐시 재사용도 확인했습니다.
  3. 정밀 분석 첫 호출이 75초 제한을 초과했습니다. 대기 시간과 추론 설정을 수정했으며 수정 후 실호출은 별도 승인 대기입니다.
새 사진은 기본 분석을 먼저 사용하고 세밀한 비교가 필요할 때 정밀 분석을 실행합니다.
근거 · 소스

기본·정밀 선택 및 편집·저장 모바일 브라우저 확인, 전체 테스트 218개 통과. 최초 정밀 호출은 약 75초 뒤 연결 오류로 끝나 정밀 대기 시간을 240초로 조정했습니다.

다음 판단

사진 1장으로 확인한 관찰이며 전체 아카이브의 정확도 측정은 별도입니다.

저장과 출력
1단계 아카이브 디자인 템플릿에서 선택하고 편집합니다. 4단계에서 장면당 JPG 또는 MP4를 출력합니다. 유료 API 호출은 없습니다.
