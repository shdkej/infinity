영역별 글꼴과 레퍼런스 배경

한 카드에서 네 가지 글꼴을 조합하고 배경 유형과 설명을 저장합니다.

01 편집
제목, 본문, 안내 문구 등 각 영역이 템플릿 글꼴을 따르거나 별도의 분위기를 선택합니다.
02 배경
사진·일러스트는 장면 소재 또는 저장한 설명으로 준비한 생성 이미지를 사용하고, 단색은 소재 없이 바탕색을 그립니다.
핵심 내용 · 리서치 본문
핵심 발견
  1. 390px 브라우저에서 세 가지 배경과 영역별 글꼴을 선택한 뒤 템플릿 저장을 확인했습니다.
  2. 실제 운영 컨테이너가 네 글꼴 파일을 제공하며 단색 배경의 JPG와 MP4를 각각 800×1000으로 생성했습니다.
  3. 무료 수동 편집을 지원합니다. Gemini 분석은 영역별 분위기와 배경 유형, 색, 설명을 요청합니다. 이번 검증에서 새 유료 분석을 호출하지 않았습니다.
아카이브에서 레퍼런스를 선택한 뒤 글자 영역 직접 편집과 배경 디자인을 사용합니다.
근거 · 소스

테스트 221개 통과. UI 빌드·린트, 모바일 브라우저 저장과 JPG·MP4 렌더를 확인했습니다.
