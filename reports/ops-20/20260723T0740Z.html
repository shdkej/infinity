ops-20 media inbound staged 사진 경계 정리

무엇을 막았나

OpenClaw가 임시 수신한 media/inbound/openclaw-staged-* 폴더가 git status에 untracked로 누적되어 카드뉴스 정본 변경과 섞이는 문제를 막았다.

어떻게 고쳤나

.gitignore에 media/inbound/openclaw-staged-*/를 추가해 inbound staged 폴더를 runtime cache로 분리했다.

검증

git status --short --ignored -- media/inbound에서 기존 staged 폴더 3개가 !! ignored 상태로 표시된다. 원본 파일은 삭제하지 않았다.
