weekly_review 같은 주 블록 replacement gate

같은 ISO week의 canonical 회고가 반복 append되는 문제를 문서 계약과 dry-run helper로 막았다.

01 무엇을 점검했나
system/data/weekly_review.md에 2026-W27을 포함한 같은 주 canonical 블록이 중복 누적되는 문제.
02 이상 여부·조치
YYYY-Www를 키로 canonical heading만 replace/dedupe하고 수동 메모는 보존하는 계약과 helper를 추가했다. 2026-W27 dry-run은 canonical count 1로 통과했다.
핵심 내용
  • artifacts/ops-06/weekly-review-replacement-contract.md에 generator/workflow 계약을 기록했다.
  • scripts/weekly_review_block_gate.py는 기존 파일과 생성 블록을 받아 첫 canonical 블록을 교체하고 추가 canonical 중복을 제거한다.
  • 수동 생활/소비 메모처럼 canonical date-range heading이 아닌 같은 주 블록은 보존한다.
검증

python3 scripts/weekly_review_block_gate.py /home/ubuntu/.openclaw/workspace/system/data/weekly_review.md 2026-W27 /tmp/ops-06-weekly-block.md

결과: PASS canonical block count for 2026-W27: 1
