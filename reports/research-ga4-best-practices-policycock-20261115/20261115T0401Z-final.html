모두의정책 GA4 측정 설계 탐색

Google 공식 자료와 현재 brief를 대조한 읽기 전용 조사. 연결·수집 상태와 성과 수치는 검증하지 않았습니다.

01 무엇을 확인했나
프로젝트 문서는 GA4를 유입·검색·재방문, PostHog를 제품 행동·전환·오류 분석 후보로 나눕니다. 두 도구는 미연결이며 이벤트 계약은 계획입니다.
02 핵심 결과와 경계
측정 질문을 먼저 정의하되 외부 신청 링크 클릭을 실제 완료로 세지 않습니다. 현재 기준선·전환 수치는 없음; 계정·코드·고객 데이터·법률 판단은 범위 밖입니다.
핵심 내용 · 리서치 본문
핵심 발견
  1. User acquisition(최초 사용자 유입), Traffic acquisition(세션 유입), Search Console 질의, 사이트 내부 검색은 서로 다른 측정 질문입니다.
  2. policy_viewed / policy_saved / next_action_started / next_action_completed는 예정 이벤트로, 실측 데이터가 아닙니다. 외부 클릭은 완료 증거가 아닙니다.
  3. URL·검색어·자유입력·정책 주제는 개인정보 또는 민감한 맥락을 노출할 수 있습니다. Google 기술 가이드는 법률 판단을 대신하지 않습니다.
후속 구현 논의 전 (1) 정적 랜딩의 최소 측정 질문, (2) next_action_completed의 관찰 가능한 완료 증거, (3) 수집하지 않을 속성 allowlist를 먼저 문서화하세요. 이 브리프는 설정 승인이 아닙니다.
근거 · 소스

프로젝트 문서와 Google Analytics Help 공식 문서 10건 대조. 세부 링크와 한계는 본문 Markdown에 기록했습니다.

GA4/Search Console 연결, 실제 신청 흐름, 내부 트래픽·UTM·보존·동의 담당은 미확정입니다. 별도 승인 전 접근·설정·수집하지 않습니다.

측정 질문 · 품질 · 개인정보 경계
현재와 예정의 구분

현재 초기 범위는 창업·사업자 지원정책 탐색과 신청 준비. 향후 정책 범위 확대는 별도 가설입니다. 문의/마케팅 원천 PC-001은 blocked이며 GA4/PostHog 미연결입니다.

유입User acquisition은 사용자 최초 유입, Traffic acquisition은 세션 유입. 같은 축으로 직접 비교하지 않습니다.
검색Google 질의는 Search Console 연계 데이터와 구분. 연계 상태 미확인, 보고에 최대 48시간 지연 가능. 내부 검색 이벤트는 query parameter에서 search_term을 보낼 수 있어 raw term 수집 전 검토 필요.
행동상세보기·저장·외부 이동·실제 신청 완료는 서로 다른 단계. 실제 완료를 확인하는 연동/증거는 확인되지 않았습니다.
품질과 해석
  • 추천 이벤트는 동작 의미가 일치할 때 쓰며 자동 전송된다고 가정하지 않습니다.
  • Realtime/DebugView는 향후 승인된 수집의 진단용. 표준 보고는 보통 24–48시간 지연될 수 있습니다.
  • 활성 데이터 제외 필터는 새 데이터의 영구 제외를 일으킬 수 있어 적용하지 않습니다.
  • 방문·재방문은 수요·만족이 아니며 유입·전환율·유지율은 모두 미측정입니다.
개인정보와 미확정 결정

Google은 PII 전송을 금지하고 URL, 제목, query/search 및 캠페인 파라미터를 누출 경로로 안내합니다. policy_id/category/source/action_type도 허용목록과 민감도 판단 전 미확정입니다. 문의 원문·연락처·프로필·raw search는 보내지 않는 최소화 방향입니다.

Consent Mode는 동의 상태를 태그에 전달하는 기술이지 법률 적합성 판정이 아닙니다. 속성/스트림, Search Console, 실제 기능, PostHog 정본, 내부 트래픽·UTM·보존·동의 담당은 미확정입니다.
