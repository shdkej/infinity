Control Center를 shadcn/ui 운영툴로 재구성하고 Status 구성을 웹에서 관리

단순 CRUD 폼이던 CMS를 surface→section→card→link 계층을 직접 편집하는 운영 도구로 끌어올렸다. 실제 production publish는 다음 경계로 분리했다.

01 무엇이 문제였나
기존 CMS는 record 한 줄을 넣고 빼는 평면 CRUD 폼이라, Status 페이지가 실제로 어떤 surface·card·link로 구성되는지 웹에서 만들거나 고칠 수 없었다. 운영툴이라기보다 입력칸에 가까웠다.
02 어떻게 해결했나
shadcn/ui 기반으로 재구성하고, self-referential 트리 테이블 하나로 surface/section/card/link·status·copy·order·visibility를 모두 웹에서 편집하게 했다. 구성 트리·라이브 Preview·Edit drawer·감사(activity) 로그를 한 화면에 묶었다.
  1. Status 구성 트리: 계층 편집 + 순서/노출 토글 + drawer 편집
  2. 라이브 Preview: visible 항목만 Status 페이지 형태로 즉시 반영
  3. Surface Registry(기존 record) + Activity 감사 로그를 동일 피드로 통합
