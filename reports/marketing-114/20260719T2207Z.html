Virtue 세션 2-3 재참여 관찰 companion

첫 세션 activation과 다음 방문의 second value 신호를 분리해 읽는 내부 companion을 추가했다.

01 무엇이 문제였나
기존 첫 10명 관찰표는 첫 가치 도달과 채택 증거는 잡지만, 세션 2-3에서 무엇을 이어 하려고 돌아왔는지를 별도 칸으로 분리하지 못했다.
02 어떻게 해결하나
session_2_return_trigger, last_stop_point, resume_prompt_fit, second_value_signal 네 칸과 J1-J4 샘플 판독을 companion 문서로 추가했다.
핵심 내용 · 리서치 본문
핵심 발견
  1. 세션 2는 "돌아왔는가"보다 "무엇을 이어 하려고 돌아왔는가"를 먼저 기록해야 acquisition 문제와 activation 이후 문제를 분리할 수 있다.
  2. J1/J2/J4는 저장 후 이어가기 언어가 중요하고, J3는 저장 없이 첫 결과를 보고 나간 뒤 다른 입력으로 돌아오는 것이 자연 반복일 수 있다.
  3. 미방문, cap, 503, 지연, 저장 없는 종료는 retention 실패로 환산하지 않고 `last_stop_point`와 종료 성격으로 남겨야 한다.
기존 `marketing-79` 관찰표는 유지하고 새 문서는 세션 2-3 addendum으로 병행 사용한다. 제품 코드, PostHog 설정, 공개 카피, 발송, 비용 변경은 하지 않았다.
근거 · 소스

`MARKETING_LEARNINGS.md`의 First Value Mapping, First-Week Non-Return, Session Value By Job, marketing-113 채택 증거 묶음을 계승했다.

다음 판단

실제 첫 사용자 2명 이상에서 같은 `last_stop_point`나 `resume_prompt_fit` 문제가 반복될 때만 별도 UX/copy proposal intent로 분리한다.

상세 · 추가 칸
ColumnUse
session_2_return_trigger다시 연 직접 계기. 첫 세션의 다시 열 이유가 실제 행동으로 이어졌는지 본다.
last_stop_point직전 세션의 마지막 의미 지점. 결과 카드, 저장 후 홈, cap/503, 저장 전 혼란, 자연 종료를 분리한다.
resume_prompt_fit이어가기 힌트가 job과 맞는지 fits / absent / wrong / not-needed로 적는다.
second_value_signal같은 job 재사용, 누적 의미 이해, 다른 입력 재시도, 저장 기록 확인 같은 두 번째 가치 단서를 적는다.
