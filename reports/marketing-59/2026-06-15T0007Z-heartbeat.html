Virtue Launch-Ready PLG Signal Gate

PLG 신호 위계를 Virtue prelaunch 3층 게이트로 번역 — 첫 10명 관찰에서 acquisition/activation/measurement 신호 혼재를 방지한다.

01 무엇이 문제였나
Virtue prelaunch 첫 10명 관찰에서 acquisition / activation / measurement-too-early 신호가 혼재되어, 관찰 결과를 오독할 위험이 있었다.
02 어떻게 해결하나
PLG 신호를 지금 볼 신호(9개 수기) / 보류할 신호(7개) / launch 이후 볼 신호(7개)로 3층 분리하고, first-10 수기 review gate 6개 질문 + 판정 출력 3단계를 작성했다.
수행한 작업
항목내용
지금 볼 신호9개 수기 관찰 신호 정의 (first successful output, outcome 품질, accepted output, next action visible, confusion note, retry reason, job label, value unit, limit trust)
보류할 신호7개 (D1/D7 재방문율, activation rate, 공유율, task completion, 시간 지표, 리텐션 코호트 등) — 데이터 부족 또는 계측 미구성으로 보류
Launch 이후 볼 신호7개 (funnel conversion, PQL, 유료 전환율, CAC/LTV, NPS, 채널 효율, PostHog) — scale 필요 신호
First-10 review gate6개 질문 + launch-ready / 개선 필요 / 데이터 부족 판정 출력 정의
