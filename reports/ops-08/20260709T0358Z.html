자동 리뷰 산출물 추적 경계 고정

OpenClaw 자동 리뷰 초안과 월간 소스 스냅샷을 정본 변경 검토면에서 분리했다.

01 무엇을 점검했나
`daily-reviews/`와 `monthly-review-sources/`가 실행마다 생기는 리뷰 중간 산출물인데 정본 문서 변경과 같은 git status 표면에 섞일 수 있었다.
02 이상 여부·조치
OpenClaw workspace의 `.gitignore`에 두 경로를 명시해 새 실행 산출물은 기본적으로 local runtime/cache로 남고, 큐레이션된 정본만 별도 승격하도록 경계를 만들었다.
핵심 내용 · 실행 본문
핵심 조치
  1. /home/ubuntu/.openclaw/workspace/.gitignore에 daily-reviews/ ignore 규칙을 추가했다.
  2. monthly-review-sources/도 같은 블록에 추가해 월간 소스 스냅샷 누적을 정본 검토면에서 분리했다.
  3. 주석에 "curated canonical summaries만 승격" 원칙을 남겨 추후 추적 여부 판단 기준을 보존했다.
검증: scoped git status에서 두 산출물 경로와 `.gitignore`만 확인했고, 실제 변경은 `.gitignore` 한 파일로 제한했다.
상세

이번 사이클은 구현 범위를 ignore boundary 보강으로 제한했다. 생성 스크립트 이동이나 산출물 포맷 변경은 하지 않았다.
