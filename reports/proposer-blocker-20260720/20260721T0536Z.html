Signal-to-intent proposer blocker 해소

사용자 승인 후 openclaw cron runs 호출 형식 오류를 실제 CLI와 cron payload 양쪽에서 정리했다.

axis ax1 · 원인

Proposer가 cron 실행 이력을 확인하면서 job id 없이 openclaw cron runs를 호출해 Missing required option "--id <id>" 오류가 발생했다.

axis ax2 · 조치

Signal-to-intent proposer job id를 확인하고, 정본 문서와 실제 cron payload 모두에 openclaw cron runs --id <job-id> --limit <n> 규칙을 반영했다.

검증 메타
  • job id: 1a881731-a2f7-4faa-965f-dfbba9bac0e1
  • 검증 명령: openclaw cron runs --id 1a881731-a2f7-4faa-965f-dfbba9bac0e1 --limit 5
  • payload 확인: openclaw cron get 1a881731-a2f7-4faa-965f-dfbba9bac0e1
