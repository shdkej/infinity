Dreaming 및 memory 실행 중 생기는 원장을 Infinity 정본 변경 검토와 분리했다.

01 무엇을 점검했나
MEMORY.md와 DREAMS.md가 로컬 런타임 원장인데도 git status와 evaluator 입력에서는 정본 변경처럼 보일 수 있는 경계를 점검했다.
02 이상 여부·조치
Infinity .gitignore에 루트 및 하위 경로의 MEMORY/DREAMS 원장을 명시해 중간 런타임 파일이 canonical source review에 섞이지 않도록 했다.
핵심 내용 · 리서치 본문
핵심 발견
  1. 현재 Infinity ignore 규칙은 secrets와 OMC tooling만 다루고 있어 memory/dreaming runtime ledger 경계가 없었다.
  2. 루트 파일과 중첩 디렉터리 파일을 함께 무시해야 OpenClaw 실행 위치가 바뀌어도 같은 판정이 유지된다.
  3. ops-08은 자동 리뷰 산출물 경계로 별도 Active에 남겨 이번 변경 범위를 MEMORY/DREAMS에만 제한했다.
조치: MEMORY.md, DREAMS.md, **/MEMORY.md, **/DREAMS.md를 .gitignore에 추가했다.
근거 · 소스
