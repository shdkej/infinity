Evaluator 경고성 탐색 템플릿 축소

탐색을 절대경로·git status 중심으로 제한하는 수정 계획 수립 완료 — execute_local 대기 중

01 무엇을 점검했나
OpenClaw evaluator 실행마다 경고성 탐색 4종(~ 경로 search, agent-scoped git ls-files, agent-scoped 전역 search, 2>/dev/null literal target)이 반복되어 NO_REPLY 루프 비용·diagnostics 소음이 누적됨.
02 이상 여부·조치
경고 패턴 4종 식별 완료. git status --short + 절대경로 읽기로 대체하고 no-match를 데이터로 처리하는 수정 계획 수립 — 로컬 Claude 실행 대기.
핵심 발견 · 준비 계획
핵심 발견
  1. 경고 패턴 4종 식별: ~ 경로 search (절대경로로 대체), agent-scoped git ls-files (git status --short로 대체), agent-scoped 전역 search (특정 절대경로 읽기로 대체), 2>/dev/null literal target (no-match=data 처리).
  2. 근본 원인: 탐색 템플릿이 상대경로·환경 의존적 패턴을 기본값으로 사용. 파일이 없거나 탐색 결과가 없을 때 실패로 분류해 불필요한 경고 누적.
  3. 영향: NO_REPLY 루프 비용 반복 발생, diagnostics 소음이 실제 신호를 묻음. 미해결 신호 없을 때도 NO_REPLY로 짧게 종료되지 않음.
  4. 수정 방향: 모든 탐색을 절대경로 파일 읽기 + git status --short로 대체. no-match는 "신호 없음"으로 기록하고 계속 진행.
로컬 실행 필요: evaluator cron payload 및 정본 절차 파일이 OpenClaw 워크스페이스에 있어 이번 Heartbeat에서 직접 수정 불가. execute_local 프롬프트는 intents/active/ops-04.md에 준비됨.
execute_local 핵심 지시

evaluator cron payload 및 정본 절차에서 경고 패턴 4종을 절대경로 파일 읽기 / git status --short / no-match=data 처리로 교체한다.
