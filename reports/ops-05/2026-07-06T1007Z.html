카드뉴스 중간 산출물 경계 고정

OpenClaw 카드뉴스 실행 후 preview/sample/variant 파일이 검토 대상 정본과 섞이지 않도록 ignore 경계를 보강했다.

01 무엇을 점검했나
카드뉴스 산출물 경계를 점검했다. 원문 평가 노트는 캐시를 system/cache/ 또는 ignored run 경로로 보내고, 정본 템플릿과 라이브러리만 추적하라고 정리하고 있었다.
02 이상 여부·조치
.gitignore에 카드뉴스 preview/sample/variant와 초안 config 패턴을 추가했다. 정본 library, published URL, 명시적으로 추적된 기존 assets는 건드리지 않았다.
핵심 내용 · 실행 본문
핵심 발견
  1. system/docs/EVALUATION_NOTES.md는 카드뉴스 렌더 JPG/WebP/run report가 정본 문서와 같은 status에 섞이는 것을 운영 비용으로 기록하고 있었다.
  2. 실제 후보 디렉터리는 system/reports/card-news/samples/, *-previews/, *-variants/ 계열이었다.
  3. 정본 경로인 system/data/card-news/templates/ 전체를 무시하지 않고, *-draft*, *-sample*, *-preview* JSON만 ignore 대상으로 제한했다.

검증은 scoped status와 git check-ignore -v로 수행했다. 새 초안 config 예시인 example-draft.json, example-preview.json가 새 규칙에 걸리는 것을 확인했고, 기존 사용자 변경인 평가 노트와 static page는 건드리지 않았다.

  • 추가 ignore: system/data/card-news/templates/*-draft*.json, *-sample*.json, *-preview*.json.
