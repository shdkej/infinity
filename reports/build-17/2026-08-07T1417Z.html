Instagram Maker CSS 및 모바일 Preview 레이아웃 수정

무엇이 문제였나

CSS 링크는 존재했지만 모바일을 `min-width:980px`가 강제해 preview가 우측으로 밀릴 수 있었고, 두 정적 배포 복사본을 함께 검증해야 했다.

어떻게 해결하나

두 CSS에 모바일 단일 열 분기와 viewport 폭 상한을 적용한 상태를 확인하고, 390px에서 가로 overflow 없음과 1440px 데스크톱 회귀를 통과시켰다.

핵심 내용
  • CSS stylesheet, JS, 폰트 응답이 모두 HTTP 200이었다.
  • Chromium CDP 모바일: innerWidth 390, scrollWidth 375, canvas x 35.4 / width 304.2.
  • Chromium CDP 데스크톱: innerWidth 1440, scrollWidth 1425, canvas x 688.1 / width 438.9.
  • 두 app.js에 node --check를 실행했고 통과했다.
역할 합의·충돌·최종 순서

Planner는 범위를 두 dist와 로컬 검증으로 제한했다. Developer는 원인을 body min-width와 반응형 분기로 고정했다. Marketer는 preview 선배치와 canvas 텍스트 안전 폭을 분리했다. Operator는 공개 배포/인프라 변경을 하지 않고 원격 게이트를 남겼다. 합의된 순서는 CSS 동기화 확인 → HTTP/구문 검사 → 모바일/데스크톱 CDP → Red → 원격 반영이다. 기각안은 overflow만 숨기는 임시 처방과 승인 없는 공개 배포다.
