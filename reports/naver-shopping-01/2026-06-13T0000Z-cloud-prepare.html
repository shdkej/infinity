소싱-우선 후보 스크린

러기지택 하향 이후 미탐색 카테고리 10종 적합도 분석 — 로컬 Naver API 검증 우선순위 제안

01 무엇을 조사했나
소싱 우선 전환 후 아직 검증하지 않은 카테고리 10종을 사용자 핏·소싱 마찰·옵션 복잡도 기준으로 1차 평가했다. 이전 스크린에서 제외된 여권케이스·케이블 파우치·접이식 슬리퍼가 가장 깨끗한 후보로 부상했다.
02 핵심 결과
여권케이스·케이블 파우치·접이식 슬리퍼를 1순위 로컬 검증 대상으로 제안한다. 세 카테고리 모두 사용자 핏 높음, 소싱 마찰 낮음, 키워드 노이즈 적음. 다음 로컬 Naver API 실행 시 이 세 키워드부터 OpenAPI + SearchAd 체크를 시작한다.

1순위 후보 근거
  • 여권케이스/홀더 — 여행 필수품, 명확한 구매 객체, 사이즈·색상 외 옵션 없음, RFID 차단 기능 추가만 해도 차별화 가능. 키워드가 선반(shelf)에서 깨끗하게 분리됨. 사용자 여행 핏 직결.
  • 케이블 정리 파우치 — AI/창작자 워크플로우 핏. 원격근무자·디지털 노마드 포지션과 자연스럽게 연결. 옵션 복잡도 낮음(색상·크기만). 경량 콘텐츠 앵글: "여행 짐 쌀 때 케이블 정리" 자연 연결.
  • 접이식 슬리퍼 — 기내·호텔 실사용 여행 아이템. 기성품 소싱 경로 다양함(OEM 미니 슬리퍼). 색상 외 옵션 없음. 러기지택과 달리 사용자 선호 하향 이유 없음.
제외·보류 이유
  • 러기지택/캐리어네임택 — 사용자 선호 하향 (2026-06-11). 이번 스크린에서 재검토 안 함.
  • 해외여행 체크리스트 insert / 여행준비카드 — 이전 스크린 결과 HOLD (commodity·저구매의도·키워드 노이즈).
  • 핸드폰 도난방지 스트랩 — WATCH 상태 유지. 수요 신호는 있으나 호환성·품질 리스크. 1순위 검증 후 재평가.
  • AI/창작자 워크샵 카드 — copy-led 상태. 시각적 순위/리뷰 깊이 데이터 없이 상품 방향 결정 불가.
