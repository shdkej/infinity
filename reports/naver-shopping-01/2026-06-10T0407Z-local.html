질문/워크샵 카드 — 제목 언어 확장 스캔

marketing-50이 고른 AI/크리에이터 워크샵 리드 프레임이 자기 키워드로 제목을 끌 수 있는지, 아니면 copy-led sub-test로 남아야 하는지 한 번의 bounded OpenAPI 패스로 판정.

01 무엇이 문제였나
브라우저 visual-rank(418)·review-depth(429)가 막힌 상태에서, AI/creator 워크샵 프레임이 자기 키워드로 listing 제목을 끌 만한 언어 증거가 있는지 미확인이었다. broad 질문/대화 카드가 generic game으로 포화라는 건 알았지만, 좁힌 use-case(AI·크리에이터·회고·기획)에 실제 쇼핑 언어가 있는지는 안 봤다.
02 어떻게 해결하나
한 번의 bounded OpenAPI 패스(top-10, sort=sim, 6개 term) 결과 프레임은 native keyword 언어가 없다. AI 워크샵 카드(38,619)·크리에이터 워크샵 카드(10,172)는 generic 야유회/타로 game pool로 희석. 실수요 있는 다리는 워크샵 질문 카드(23,997) 하나뿐. → 프레임은 DRAFT·copy-led로 확정, 차별화는 키워드가 아니라 copy에 둔다.
  1. AI/크리에이터 접두어는 차별화 listing을 0건 노출 → 제목 리드 키워드 불가.
  2. 실수요 workshop-language 다리는 워크샵 질문 카드 하나뿐, 그마저 company-recreation 성향.
  3. 회고 카드(37, 애니 굿즈)·기획 워크샵 카드(11,907→명찰/현수막)는 dead/off-target.
  4. 인사이트 카드는 타로/오라클 noise이나 코칭·워크숍 질문카드 1건(33,000원) = use-case-led 프리미엄 선례.

Verdict: 프레임은 DRAFT·copy-led(keyword는 sub-test grade). 검색 다리 워크샵 질문 카드 > broad 질문 카드/대화 카드; 차별화(AI/creator workshop room, "아이디어 확산 아닌 다음 실험으로 좁히기")는 copy·detail에. OpenAPI title-language 증거 소진 → 승격엔 visual-rank(418)+review-depth(429)만 남았고 logged-in browser 필요.

마케팅 학습 루프 · 가정/계승/승격
  • 계승한 기준: broad keyword ≠ differentiation proof; purchase situation before object shape(Purchase Situation Before Object Shape, marketing-50); Knowledge Lab/user fit은 demand 증거 아님; OpenAPI/SearchAd는 directional only; 큰 total·object keyword를 title lead로 두기 전 정보성/제네릭/노이즈 분리(marketing-48).
  • 이번에 새로 배운 것: positioning 프레임이 use-case(AI/크리에이터/회고/기획)일 때, title-language 확장은 그 use-case 명사들이 쇼핑 언어가 아예 없음을 드러낼 수 있다 — 그러면 프레임은 copy-led로 확정되고, 검색 다리는 room을 여전히 담는 가장 깨끗한 object 키워드(워크샵 질문 카드)여야 한다.
  • 다음 Marketer에게 넘길 규칙: use-case 리드 프레임을 키워드로 검증할 때 먼저 그 use-case 명사에 native 쇼핑 언어가 있는지 본다. 없으면 키워드 리드를 포기하고 copy-led로 고정, broad object 키워드를 다리로만 쓴다. 프리미엄 use-case 선례(여기 코칭 인사이트 질문카드 33,000원) 1건은 가능성 신호이지 수요 확정이 아니다.
  • MARKETING_LEARNINGS.md 승격 후보: "Use-case 리드 프레임의 명사가 쇼핑 언어가 없으면 그 프레임은 copy-led다 — 키워드 다리는 room을 담는 가장 깨끗한 object 키워드로 분리한다." (다른 후보에서 한 번 더 반복되면 승격; 현재는 단일 사례라 report에 보류.)
