소싱 우선 후보 스크리닝

러기지택·카드 인서트·워크샵 카드 검토 이후 더 넓은 소싱 우선 화면 실행 — Tier 1 후보 3개 도출

01 무엇을 조사했나
소싱 우선 조건(낮은 샘플 마찰·옵션 복잡도·QA 리스크) + 사용자 핏(여행·기록·AI워크플로·일상시스템)으로 14개 후보 카테고리 스크리닝
02 핵심 결과
Tier 1 후보 3개 도출: 여행 테마 다꾸 스티커 세트 / 미니 폴라로이드 포토앨범 / 포켓 리필 노트 — 모두 도매 소싱 쉽고, 옵션 단순, QA 리스크 낮음, 구매 상황 포지셔닝 가능
  1. 여행 테마 다꾸 스티커 세트 — "해외여행 기록하는 사람을 위한 다꾸 세트" (구매 상황 명확)
  2. 미니 폴라로이드 포토앨범 — "여행 끝나고 바로 사진 정리하는 앨범" (기억 남기기 핏 최강)
  3. 포켓 리필 노트 — "AI 정리와 함께 쓰는 아날로그 포켓 노트" (AI/creator workflow 연결)
스크리닝 상세 — 후보별 평가

소싱 우선 기준: 완제품 도매 소싱 또는 경량 번들 가능. 커스텀 제작 없음.

Tier 1 — 즉시 진행 가능

후보샘플 마찰옵션 복잡도QA 위험사용자 핏차별화판정
여행 다꾸 스티커 세트 매우 낮음낮음매우 낮음높음높음 Tier 1
미니 폴라로이드 포토앨범 낮음낮음낮음매우 높음높음 Tier 1
포켓 리필 노트 낮음낮음~중간낮음매우 높음높음 Tier 1

Tier 2 — 조건부 진행 (추가 확인 필요)

후보조건판정
멀티포켓 트래블 파우치 경쟁 강도 확인 필요 (색상/크기 옵션 중간) Tier 2
마스킹테이프/와시테이프 단독 SKU는 약함 — 다꾸 스티커 번들 후보 Tier 2
케이블/이어폰 오거나이저 경쟁 극심 — 독자 포지셔닝 어려움 Tier 2

Tier 3 — 이번 사이클 보류

  • 스마트폰/태블릿 거치대 — 경쟁 극심, 차별화 어려움
  • 포토카드 바인더 — 아이돌 굿즈 노이즈, 사용자 핏 중간
  • 드라이플라워/조화 소품 — 사용자 핏 낮음

이미 제외된 후보 (이전 스크리닝)

  • 러기지택/캐리어네임택 — 사용자 선호 낮음 (다운그레이드)
  • 여행 체크리스트 카드 인서트 — mobile CTR 약함, 제네릭 (HOLD)
  • 워크샵 질문 카드 — 소싱 마찰 높음, draft 단계

권장 다음 액션

  • Tier 1 최우선: 여행 다꾸 스티커 세트 도매꾹/알리바바 샘플 가격·MOQ 확인 (로컬 필요)
  • 번들 가능성: 포토앨범 + 스티커 + 노트 = "여행 기록 스타터 세트" 초안
  • 구매 상황 포지셔닝: 최소 1개 후보 스토리 제목 초안 (cloud 가능)
  • 네이버 키워드 수요: 상위 3개 후보 SearchAd 조회 (로컬 세션 필요)

적용된 기준

  • Purchase Situation Before Object Shape (marketing-50): 구매 상황 먼저, 오브젝트명 나중
  • 소싱 우선 = 완제품/경량 번들, 커스텀 제작 없음
  • 사용자 선호: 여행·기록·AI워크플로·일상시스템 (2026-06-11 확인)
