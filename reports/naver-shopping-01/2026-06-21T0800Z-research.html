크로스바디/넥 폰 스트랩 2차 SKU 소싱 스크린

2026-06-21 마스터 결정(크로스바디 2차 SKU 확보)에 따른 cloud research. alibaba.com 대체 공급처 접근법과 손목+크로스바디 병행 샘플 경로 포함.

01 무엇을 조사했나
크로스바디/넥 폰 스트랩 소싱 환경 + alibaba.com 대체 공급처 접근 가능성 (1688 세션 없이 Huanhuan/Zhanhong 계열 접근 경로 탐색)
02 핵심 결과
범용 훅/D링형 크로스바디 숄더 스트랩 GREEN 조건부 전환. alibaba.com 계정 없이 기존 공급사 계열 접근 확인. 손목+크로스바디 단일 샘플 주문 라운드로 2 SKU 동시 검증 가능.
핵심 내용 · 리서치 본문
핵심 발견
  1. 소싱 환경 — Alibaba 국제몰 크로스바디/넥 폰 스트랩 598개+. MOQ 10–100개, 단가 USD 0.75–1.50 (약 1,000–2,000 KRW). 손목 스트랩보다 높으나 판매가 9,900–15,000 KRW 기준 마진 허용.
  2. 옵션 복잡도 제어 — 케이스 일체형은 모델 호환 분기로 HIGH. 범용 훅/D링형(손목 스트랩과 동일 연결 구조) 선택 시 LOW-MEDIUM으로 제어 가능 → 1순위 타입.
  3. 대체 공급처 — alibaba.com 브라우징은 계정 불필요. Huanhuan(Shenzhen)·Zhanhong(Dongguan) 계열 국제몰 등록 확인. 1688 직접 세션 없이 공급사 확인·리뷰 접근 가능. 가격 20–30% 높게 표시될 수 있으나 컨택 전 단계는 무료.
  4. 클레임 리스크 — 넥(목걸이) 타입은 주관적 불편함 클레임 위험. 크로스바디(숄더) 타입 우선 선택 권장. 포지셔닝: "소매치기 방지" X → "핸즈프리 여행 필수템 / 분실 방지" ✓.
  5. 네이버 키워드 — "핸드폰 목걸이 스트랩", "크로스바디 폰스트랩" 판매자 다수 활성. 실제 SearchAd 검색량·CTR은 로컬 접근 필요 — 이번 heartbeat 미확인.
  6. 병행 효율 — 손목+크로스바디를 동일 Alibaba 공급사에서 단일 주문 라운드로 동시 샘플 주문 가능. 공급사 컨택 1회로 2 SKU 검증.
  7. 다음 경계 — (L0 즉시) alibaba.com 브라우징·공급사 확인. (로컬 필요) SearchAd 크로스바디 실측. (L2 sample-order-gated) 공급사 컨택 + 샘플 주문 결제.
추천: 크로스바디 스트랩은 범용 훅/D링형 숄더 타입으로 확정. alibaba.com에서 손목 스트랩 공급사(Huanhuan/Zhanhong 계열) 확인 시 크로스바디도 함께 조회 → 단일 샘플 주문 승인 요청. 1688 계정 없이 시작 가능.
