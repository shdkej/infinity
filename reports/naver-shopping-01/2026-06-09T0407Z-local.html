DataLab 접근 복구 → 첫 시드 부분 검증

읽기 전용 패스에서 DataLab 카테고리 키워드 랭크 API가 다시 열렸다. 구조화된 여행 체크리스트 수요는 상위 키워드로 보이지 않고, 유일하게 견고한 여행 앵커는 트래블러스노트(인서트 생태계)였다.

01 무엇을 조사했나
승인된 첫 시드(Travel-Prep System / Travel Scenario Card / Checklist Insert Set)에 대해, 소수의 바운드된 읽기 전용 프로브로 접근성을 재확인하고 keyword-competitor-validation-plan의 DataLab 부분만 실행했다. 네이버쇼핑 검색·경쟁 스캔은 여전히 차단(HTTP 418)이라 미실행.
02 핵심 결과
DataLab 카테고리 키워드 랭크 API가 다시 접근 가능(이전 IP 차단에서 변화)해 실데이터를 반환했다. 다이어리/플래너 상위 20위에 여행 키워드는 전무했고(구조화 수요는 스터디·위클리 플래너가 흡수), 노트/수첩에서는 트래블러스노트가 4위로 유일한 견고한 여행 앵커였다. 방향성: PIVOT 쪽(인서트 포맷에 탑승)으로 기운다 — 단정 아님.
  1. DataLab 카테고리 키워드 랭크 API 접근 복구 (실데이터 확인) — 가용성 상태 변화
  2. 네이버쇼핑 공개검색은 여전히 HTTP 418 차단 → 경쟁/화이트스페이스 스캔 미실행
  3. 다이어리/플래너(50001039) 상위20: 여행 키워드 0건, 구조화는 스터디·위클리 플래너
  4. 노트/수첩(50001040) 상위20: 트래블러스노트 4위 = 인서트 생태계(메모리·유연 저널 성향)

주의: 이는 카테고리 내 상대 랭크이며 절대 검색량·12개월 트렌드 방향이 아니다(클릭 트렌드 엔드포인트 파싱 미해결). 랭크 API는 count 파라미터와 무관하게 상위 20위로 캡된다.

플랜 루브릭 대비 방향성 (단정 아님)

  • Core "구조화 여행 체크리스트/시나리오" 수요는 다이어리/플래너 상위 키워드로 가시화되지 않음 — 구조화 의도는 스터디·위클리 플래너가 흡수.
  • 유일한 견고한 여행 앵커 = 트래블러스노트(표준 인서트·리필 생태계) → 플랜의 "Checklist Insert Set" 폼이 트래블러스노트 인서트 규격에 탑승할 때 실수요 앵커가 생김.
  • 결론: 독립 "여행 체크리스트" SKU보다 인서트 포맷 탑재(PIVOT 방향)가 유리해 보임. 경쟁 화이트스페이스(상위20 리스팅·가격대·리뷰깊이)는 418 차단으로 미검증 → 정식 verdict 보류.

가정 원장 (상속 / 변경 / 충돌 / 재사용 후보)

  • 상속(유지): fit 증거 ≠ 시장 증거; 작은 방향 신호는 PMF/전환/매출 판정이 아님(Prelaunch Decision Boundary); 접근 차단은 가용성 조건이지 수요 신호 아님(Availability And Friction Are Not Value).
  • 변경(이번 런): DataLab 상태가 "IP 차단"에서 "카테고리 랭크 API 접근 가능"으로 바뀜 — 부분 실증 채널 확보. 첫 시드 수요를 "전부 미검증"에서 "방향성 부분 검증"으로 갱신.
  • 충돌: 플랜의 Core 가설(구조화 체크리스트가 핵심 수요)과 실측(상위 키워드에 부재, 견고 앵커는 트래블러스노트)이 어긋남 → Core 단독 강도 약화, Contrast/Overlap 인접 포맷이 실수요 보유. PIVOT 경고 강화(반전 아님, 데이터 추가 필요).
  • 재사용 후보(단일 런·보류): "여행 인서트 수요는 트래블러스노트 표준 인서트 생태계에 집중된다 — 독립 체크리스트보다 규격 인서트가 진입점일 수 있다." 실제 경쟁 스캔(418 해제 시)으로 확인 후에만 승격.

다음 실행(접근 복귀·해제 시)

  • 클릭 트렌드 엔드포인트의 정확한 keyword 파라미터 포맷 해결 → Core/Niche 12개월 방향·인구통계 확보.
  • 418 해제 또는 로그인 브라우저 경로 확보 시 네이버쇼핑 상위20 경쟁 스캔(포맷 버킷·가격대·리뷰깊이·화이트스페이스) 실행 → PROMOTE/PIVOT/HOLD 정식 판정.

경계: 읽기 전용 리서치·계획만 수행. 상품등록·리스팅·가격/배송/재고/옵션·광고/예산·고객/주문·계정/스토어 설정·공개 게시는 건별 명시 승인 전까지 미실행.
