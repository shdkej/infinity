naver-shopping-01 Research Note PIVOT · 방향성 (광고축 추가)

광고 축을 열었더니 — 피벗의 구매자는 거래형, 체크리스트는 정보형

07:07Z 방향성 PIVOT 이후, 리뷰깊이·시각랭크·광고 트라이어드 중 기존 경로로 닿는 광고 축 1개를 바운드 읽기전용으로 확보했다. 리뷰깊이는 새로운 차단(429)을 만났다.

01 무엇을 조사했나
07:07Z PIVOT은 OpenAPI가 결과폭+가격만 줘서 방향성에 그쳤다. PROMOTE급으로 올리려면 리뷰깊이·시각랭크·광고 세 축이 필요하다. 이번 런은 기존 경로로 실제 닿는 광고 축을 SearchAd /keywordstool의 광고depth·클릭·CTR 필드(이전 미수집)로 1회 확보하고, 상품페이지 GET 1회로 리뷰깊이 가용성도 테스트했다.
02 핵심 결과
광고 데이터가 의도를 갈랐다 — 피벗 키워드(트래블러스노트리필)는 거래형(소량 250/mo에도 광고 CTR 1.59%·depth 6 → 구매자가 광고를 클릭), 여행체크리스트는 정보형(검색 1,740이나 CTR 0.03% 사실상 죽음). 판정은 방향성 PIVOT 유지, 광고-의도 레이어만 추가. 리뷰깊이는 상품페이지 HTTP 429로 재차단.
  1. 피벗은 거래형: 트래블러스노트리필 광고 CTR PC 1.11% / 모바일 1.59% + depth 6 (소량 250/mo) → 구매자가 광고를 클릭 = 피벗의 첫 거래의도 신호.
  2. 체크리스트는 정보형: 여행체크리스트 모바일 검색 1,740이나 CTR 0.03% → 읽는 수요지 사는 수요 아님 → "독립 체크리스트로 리드하지 말 것" 의도 측면 재확인.
  3. 앵커가 트래픽 엔진: 트래블러스노트 6,420/mo · 광고 depth 8 · CTR 2.44%.
  4. 새 주의: 피벗 키워드 시장은 얇고(리필 250+속지 180 ≈ 430/mo) 광고 경합(depth 6) → 리필 키워드만으로 부족, 앵커의 유료노출 경쟁을 타야 함.
  5. 리뷰깊이 재차단: 스마트스토어 상품페이지 GET = HTTP 429(검색 418과 별개) → 리뷰수는 두 경로 모두 불가. 시각랭크 여전히 418(재시도 안 함).

PROMOTE급 트라이어드 상태:

  • 광고 = 확보 (이번 런)
  • 리뷰깊이 = 차단 (HTTP 429) — 상품페이지도 막힘, 검색 418과 별개
  • 시각랭크 = 차단 (HTTP 418) — 웹검색, 재시도 안 함

→ 판정 변동 없음: PIVOT (방향성). 첫 SKU = 트래블러스노트 표준사이즈(패스포트/미디움) 여행준비 구조화 인서트. 광고 증거는 (a) 피벗 구매자가 거래형이고 (b) 독립 체크리스트 키워드가 정보형임을 더해 방향을 강화하지만, 리뷰깊이·시각랭크가 미확인이라 PROMOTE급은 아니다. 얇은 피벗 키워드 볼륨 + 광고 depth 6은 앵커 의존이라는 트래픽-소스 주의를 새로 남긴다.

승인 경계(유지): 소싱·상품등록·가격/배송/재고/옵션·광고/예산·고객/주문·계정/스토어설정·공개발행은 건별 명시 승인 전까지 미접촉.
