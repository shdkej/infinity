Naver 접근 가능 시 (IP 해제 또는 Electron 세션 재개) 다음 순서로 키워드 검증 수행:

  1. 여권케이스 / 여권지갑 / 여권 파우치
  2. 마스킹테이프 세트 / 와시테이프 / 여행 다꾸
  3. 수면마스크 여행 / 여행 안대 / 귀마개 여행
  4. 스티커 팩 / 다이어리 스티커 / 플래너 스티커
  5. 소분용기 여행 / 여행 용기 세트
  6. 포켓앨범 / 미니앨범 / 인스탁스 앨범
  7. 케이블 정리 / 선정리 클립 / 멀티 케이블 홀더

각 키워드: OpenAPI 상품 수 + SearchAd 예상 월 검색량(PC+mobile) + 상위 10개 스캔 → PROMOTE/PIVOT/HOLD 판정.

  • PROMOTE 기준: 1,000–50,000개 상품, ≥500/mo 모바일 검색, 상위 판매자 리뷰 평균 <1,000
  • PIVOT: 수요 ✅ but shelf 포화 → 차별화 필요
  • HOLD: 수요 약하거나 노이즈 과다
