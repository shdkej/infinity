클라우드 prepare 패스 — 로컬 크론 실행을 위한 5개 가설 + API 호출 계획 수립

01 🔍 무엇을 조사했나
캐리어네임택(7,310/mo)·러기지택(3,780/mo) — 도착일 실패방지 스토리의 가장 낮은 마찰 WATCH 표면. 클라우드 환경에서 로컬 Naver API 없이 차별화 가설 프레임워크를 선제 수립. 이전 패스(2026-06-10T19:07Z)에서 이 두 키워드가 '다음 안전 액션'으로 지정됐으나 아직 top-20 스캔 미실행.
02 📊 핵심 결과
차별화 가설 5개 + PROMOTE/PIVOT/HOLD 루브릭 정의 완료. 실제 top-20 스캔은 로컬 크론(08:30 KST)에서 OpenAPI + SearchAd 호출로 실행. 소싱/등록/가격/광고/공개발행 액션 0.
차별화 가설 5개 요약
번호가설검증 키워드신호
H1긴급연락처 표시 차별화 (도착일 실패방지)긴급연락처 이름표, 비상연락 캐리어택top-10에 긴급연락처 언어 없으면 white space
H2국제여행 한영 이중언어 포맷해외여행 이름표, 영문 이름표, 공항 이름표한영 병기 포맷이 없으면 해외여행객 세그먼트 가능
H3커스터마이징 수준·가격대 분포캐리어네임택, 러기지택 top-20 가격대5,000원 이상 세그먼트 존재 → 프리미엄 진입 가능
H4여행 키트 번들 구성캐리어 셋트, 여행 준비 키트번들 부재 → first-listing 기회
H5콘텐츠 차별화 스토리 (도착 체크리스트 내장)캐리어네임택 + 체크리스트 조합스토리 상품 부재 → unique positioning

API 호출 계획 (로컬 실행용):

  • 1차: OpenAPI top-20 (캐리어네임택, 러기지택, 여행 이름표, 캐리어 이름표)
  • 2차: SearchAd exact (캐리어네임택, 러기지택, 여행 이름표, 캐리어 이름표, 긴급연락처 이름표, 해외여행 이름표)
  • 기록 스키마: 가격대, 포맷(generic/custom/leather), 스토리 유무, 원산지, 제목 패턴, ad depth, CTR

루브릭 요약: PROMOTE = white space + 5,000원 이상 세그먼트 + CTR >2% / PIVOT = thin white space + copy-led 가능 / HOLD = 완전 포화 + 스토리 선점됨

주의: 소싱 승인은 PROMOTE 판정 + visual-rank·review-depth 재확인 후에만 가능.
