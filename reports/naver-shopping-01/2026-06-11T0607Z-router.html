짐표 / 캐리어 네임택 키워드 분화 테스트

클라우드 가용 소스 기반 시장 용어 현황 점검 — 로컬 SearchAd 검증 준비 완료

01 🟡 무엇을 점검했나
짐표 vs 캐리어 네임택 — 클라우드 접근 가능 소스(공개 상품 목록·검색 결과)에서 실제 판매자 용어 분포와 경쟁 구조를 점검했다. Naver Shopping(HTTP 418)·DataLab·ItemScout은 이 호스트에서 차단됨.
02 ✅ 이상 여부 · 조치
캐리어 네임택이 지배 용어; 짐표는 비공식·틈새; 차별화는 가죽·자수·커스텀·B2B 방향. 볼륨 수치는 로컬 SearchAd에서 검증 필요 → 사용자 브라우저 세션으로 키워드 플래너 실행 요청.
키워드 용어 분류 · 경쟁 신호
용어 시장 빈도 신호
캐리어 네임택 지배적 다수 스마트스토어 상품명에 사용; 입증된 수요
러기지택 중간 영어 음역어, 병렬 사용; 캐리어 네임택과 혼용
이름표 중간(범용) 어린이집·학교·캐리어 등 복합 사용; 여행 특화 아님
짐표 비공식·낮음 일상 구어체; 상품명 채택률 낮음 → 경쟁 낮을 수 있으나 검색량도 낮을 가능성
수하물 태그 공식·낮음 항공·공항 맥락; 소비자 검색 의도 약함

차별화 각도 (공개 소스 관찰)

  • 프리미엄 가죽 소재 (가죽 캐리어 네임택) — 단가 상승, 소량 판매 가능
  • 커스텀 자수·각인 (자수 캐리어네임택, 커스텀 네임택) — 개인화 수요
  • B2B 여행사 단체선물 (여행사 단체선물 이름표 러기지택) — CJ온스타일 등 노출 확인
  • 크로스오버 어린이집 이름표 + 캐리어택 — 2in1 구매 상황 세팅

접근 제한 현황

  • Naver Shopping 검색: HTTP 418 (이 호스트 IP 차단)
  • Naver DataLab: 이 호스트에서 차단
  • ItemScout: 인증 필요 (403)
  • 공개 상품 페이지 일부: 403
다음 액션 · 로컬 검증 과제

로컬 SearchAd 키워드 플래너 실행 요청 (사용자 브라우저 세션)

  • 검색 키워드: 짐표, 캐리어 네임택, 러기지택, 여행 이름표, 캐리어 이름표
  • 확인 항목: PC+모바일 월간 검색수, 상품수(경쟁강도), 클릭율
  • 판단 기준: 검색수 > 500/mo + 경쟁강도 낮음 → PROCEED; 검색수 낮음 → PIVOT to 캐리어 네임택 메인

현재 권장 방향 (볼륨 확인 전 가설)

  • 리드 키워드: 캐리어 네임택 (입증된 수요, 적정 경쟁)
  • 틈새 후보: 가죽 캐리어 네임택 + 자수/각인 옵션 (프리미엄 포지셔닝)
  • 짐표는 부가 태그로 활용 가능하나 리드 키워드 적합성 낮음
