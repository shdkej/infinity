Control Center Draft Editor MVP

기존 Status Control Center에 draft-only Editable CMS / Draft Editor 섹션을 추가했다. 첫 대상은 Family Wedding 안내장의 NOTICE 필드이며, 입력값은 정본 파일을 쓰지 않고 브라우저 메모리에서 unified diff preview로만 표시된다.

axis ax1 · 사용자 가치

사용자는 이제 Control Center 공개 URL에서 수정 가능한 표면과 필드를 보고, NOTICE 새 문구를 입력해 어떤 변경이 일어날지 diff로 먼저 확인할 수 있다.

axis ax2 · 운영 경계

write API, auth/permission, GitHub/AWS token server function, production deploy button, automatic commit-push from UI, Terraform/AWS resource, cost, destructive, secret editing은 구현하지 않았다. UI는 preview.write=none 경계를 명시한다.
