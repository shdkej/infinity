# 세부 작업 시간 기록 기준선

시간 계약을 3차 작업 중간에 도입했습니다. 이 문서는 커밋 시각을 완료 시각으로 쓰지 않으며, `task-plan.json`의 실제 실행 근거만 사용합니다.

- T3.1: 2분 / 예상 20분 / 편차 -18분. 격리 경로 생성과 경계 검사가 예상보다 짧았습니다.
- T3.2: 2분 / 예상 35분 / 편차 -33분. 기존 격리 경로의 화면 골격으로 렌더 구조 검사가 짧았습니다.
- T3.3: 100분 / 예상 30분 / 편차 +70분. 초기 실행 설정 차단, 사용자 승인 뒤 설정 생성, 배포, 라이브 상호작용 검증이 포함됐습니다.
- T3.4, T3.5, T4.1, T4.2: 완료 시각만 남아 시작 시각·실제 시간은 추정하지 않았습니다.
- T1·T2 완료 leaf: 시간 계약 전 완료되어 시작·완료·실제 시간이 기록되지 않았습니다.
- T4.3 이후: 시작·완료·실제 시간과 편차를 leaf 상태 전환 때 즉시 기록합니다.

최종 보고서는 완료 leaf별 `estimated_minutes`, `actual_minutes`, `variance_minutes`, `variance_reason`을 집계하고, 기록 없음은 누락이 아닌 근거 부재로 분리 표기합니다.
