# T3.3 라이브 지도 배포 및 상호작용 검증

## 실행 범위

- 기존 정식 Space 경로의 독립 형제 사이트 `sites/safety-map-experiment-03/**`만 사용했습니다.
- `sites/safety-map/**`는 수정하지 않았습니다.
- runtime 설정은 `write-safety-map-experiment-03-runtime-config.sh`로 생성했습니다. 설정 값과 토큰 값은 읽거나 기록하거나 커밋하지 않았습니다.

## Space 원격 증거

- 커밋: `d6879e7bf5d81d023ec45954c27d4aa0c603a85c`
- 원격 일치: 로컬 `HEAD`와 `origin/main`이 같은 커밋임을 확인했습니다.
- 배포: `static-site-aws-template.yml` 실행 `33962073902`가 `main`의 위 커밋에서 성공했습니다.
- 라이브 URL: `https://safety-map-experiment-03.aws.shdkej.com/`는 HTTP 200을 반환했습니다.
- runtime 설정 파일도 HTTP 200을 확인했으나 본문은 열람하지 않았습니다.

## 라이브 동작 증거

- 데스크톱 1440px: Mapbox 캔버스가 렌더되었고, Rome 검색 뒤 상태가 `GLOBAL FIELD / Rome`으로 바뀌었습니다. 레이어 제어가 동작하고 페이지 가로 넘침과 브라우저 오류는 없었습니다.
- 모바일 390px: 캔버스와 검색 상태가 유지되었고 페이지 가로 넘침이 없었습니다.
- 검색, 기본/위성 레이어 전환, Mapbox 기본 확대·축소·이동 제어를 확인했습니다.
- `navigator.geolocation` 호출은 코드에 없으며, 검사 중 위치 권한 대화상자는 나타나지 않았습니다.
- 화면은 안전 점수, 안전 경로, 추적을 제공하지 않고 데이터 부재와 현지 공공기관 확인 경계를 표시합니다.

## 보류 관문

Red 1차 검증은 Mapbox 성능 측정 전송을 발견해 수정 필요로 판정했습니다. `performanceMetricsCollection:false` 보완 배포와 별도 재검증을 진행합니다. Red 통과 전에는 완료나 Archive를 선언하지 않습니다.
