자동 데일리 리뷰 렌더 게이트 고정

반복적으로 본문 첫머리에 노출되던 내부 점검 문구를 저장/발송 직전 차단하는 정본 규칙을 OpenClaw 로컬 자동화 문서에 추가했다.

01 무엇이 문제였나
자동 회고 초안의 첫 3줄에 중복 게이트·확인 소스·소스 한계 같은 내부 점검 블록이 사용자 본문보다 먼저 남는 회귀가 반복됐다.
02 어떻게 해결하나
`LOCAL_REVIEW_AUTOMATION.md`의 자동 저녁 회고 원칙에 저장/발송 직전 렌더 게이트를 추가했고, 첫 줄이 헤드라인 또는 한 줄 요약인지 재확인하도록 고정했다.
핵심 내용 · 실행 결과
변경 사항
  • 첫 3줄의 내부 점검 패턴: `중복 게이트`, `확인 소스`, `소스 한계`, `## 중복`, `## 소스`.
  • 해당 블록은 사용자 본문 시작부에서 제거하고, 필요할 때만 하단 `운영 메모`로 이동하도록 명시했다.
  • 게이트 통과 후 첫 줄이 헤드라인/한 줄 요약이 아니면 저장·발송하지 않도록 했다.
L2 자체 승인 근거: 단일 로컬 문서 수정이고, 비용·시크릿·운영 데이터 변경이 없으며, git revert로 되돌릴 수 있다.
검증
  • 수정 위치: /home/ubuntu/.openclaw/workspace/system/docs/LOCAL_REVIEW_AUTOMATION.md 7번 자동 저녁 회고 원칙.
  • 검증: 문서 발췌에서 렌더 게이트와 첫 줄 검증 규칙이 저장/발송 전 단계에 들어간 것을 확인했다.
  • 커밋/푸시: OpenClaw 백업 repo 3f77abc를 main에 push 완료.
