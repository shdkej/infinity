카드뉴스 published 재현성 게이트 고정

published 라이브러리가 untracked 로컬 입력을 참조한 채 완료되지 않도록 빌더 단계에 재현성 검사를 추가했다.

01 무엇을 점검했나
카드뉴스 library의 status: published 항목이 참조하는 local_config와 같은 slug의 source-assets가 tracked, ignored, external 중 어느 경계에도 들어가지 않은 채 남는 문제를 점검했다.
02 이상 여부·조치
system/scripts/build_card_news_library.py에 published boundary gate를 추가해 untracked 로컬 입력이면 빌드를 실패시키도록 했다. 현재 known-bad 항목으로 dry-run 실패를 확인했다.
핵심 내용
  1. local_config는 최상위 repo 기준 git tracked 또는 ignored 상태만 통과한다.
  2. system/data/card-news/source-assets/{config-stem} 폴더가 존재하면 같은 경계 검사를 받는다.
  3. 검증 실패 메시지는 어떤 published item의 어떤 입력이 untracked인지 직접 출력한다.
검증: python3 -m py_compile system/scripts/build_card_news_library.py 통과. python3 system/scripts/build_card_news_library.py --data system/data/card-news/library/items.json --out /tmp/card-news-library-test.html는 czech-walk, golden-eagle, feedback-loop, cologne의 untracked 입력을 잡고 실패했다.
변경 범위
  • 수정: /home/ubuntu/.openclaw/workspace/system/scripts/build_card_news_library.py
  • 완료 판단: publish 완료 조건에 local_config/source-assets 경계 검사가 들어갔고, 현재 반복 사례에서 완료 처리되지 않는 것을 확인했다.
  • 금지/제외: 기존 카드뉴스 항목, 원본 사진, 템플릿 파일, 공개 배포 파일은 수정하지 않았다.
