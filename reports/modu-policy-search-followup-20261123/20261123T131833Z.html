모두의정책 검색엔진 점검과 질문형 정책 페이지

질문형 정책 페이지 3개를 공개하고 구글과 네이버에 사이트맵을 제출했습니다. 구글이 검사한 URL 4개는 발견됐지만 아직 색인되지 않았고, 네이버는 4개 모두 수집이 가능한 상태였습니다.

01 정책 페이지
아동수당 연령, 경기도 청년기본소득 신청 조건, 후불 기후동행카드 이용에 대해 기존 정책 주소에서 바로 답을 읽고 공식 출처로 이동할 수 있습니다.
02 검색엔진 확인
두 엔진에서 소유권 확인과 사이트맵 제출을 마쳤습니다.
검색엔진별 조회 결과
11월 23일 확인 결과
  1. 구글 Search Console에서 소유권을 확인했습니다. 사이트맵 처리는 성공, 발견 URL은 14개, 마지막 읽은 날은 11월 23일이었습니다. 홈과 정책 상세 세 곳은 모두 ‘발견됨 - 현재 색인이 생성되지 않음’이었고 실적은 처리 중이었습니다.
  2. 네이버 서치어드바이저에서 소유확인을 마치고 사이트맵을 제출했습니다. 11월 23일 22:14:15 KST에 제출 목록에 등록됐습니다. 네 URL 모두 HTTP 200, robots.txt 수집 가능, 로봇 메타 수집·노출 허용으로 확인됐습니다.
  3. 네이버의 별도 ‘색인 상태 확인’ 메뉴에서는 네 URL 각각 ‘URL 검사 결과가 없습니다’로 표시됐습니다. 신규 네이버 속성의 수집·진단·노출/클릭 보고서에는 아직 데이터가 없습니다. 홈의 첫 robots.txt 미존재 메시지는 재조회에서 정상으로 확인됐습니다.
네이버에서 확인된 수집 가능 상태만으로 실제 색인 등재 여부는 판단할 수 없습니다.
