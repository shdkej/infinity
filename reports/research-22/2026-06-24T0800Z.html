AI 자료수집·정리·관리 운영법 조사

수집→정리→확인→보관→재사용→갱신 6단계 운영 구조, 도구 비교, 개인 현실 루프

01 무엇을 조사했나
AI가 자료를 수집·정리·관리하는 6단계 운영 구조 — 소스 신뢰 기준, 정보 최소 단위, 도구 역할 분리, 루프 설계
02 핵심 결과
소스 코퍼스 사전 정의 + 최소 정보 단위(URL·날짜·판단메모) 유지가 "AI가 정리했지만 나중에 못 믿는 자료" 문제를 막는 구조적 해법. 도구는 역할별 분리, 루프는 일 5분·주 30분·월 2시간이 현실 최소치.
  1. 소스 코퍼스를 먼저 정의하지 않으면 AI는 임의 출처를 혼합한다 — 허용 소스 목록이 신뢰의 시작점
  2. 도구마다 한 단계만 담당해야 중복·충돌이 줄어든다 (수집→하이라이트→연결→문답→인용→공유)
  3. 정보 최소 단위 = 원문URL + 날짜 + 요약 + 신뢰도 + 판단메모 — 하나라도 빠지면 재사용 불가
  4. 중복·갱신 루프는 추가 시점이 아니라 주간 리뷰에 내장해야 정보 부패를 막는다
  5. 일 5분 캡처 + 주 30분 리뷰 + 월 2시간 합성이 개인이 지속 가능한 최소 구조다
  6. "못 믿는 자료" 5대 경고 신호: URL 없음·단일 소스·날짜 없음·AI 단독 요약·판단 맥락 없음
6단계 운영표 (수집 → 갱신)
  • 01 수집허용 소스 목록을 먼저 정의. RSS·북마크·Readwise로 캡처. 소셜 미디어 단독 발원은 2차 소스 확인 필수.
  • 02 정리최소 단위로 분해: 원문URL + 날짜 + 요약(3줄 이하) + 태그 + 신뢰도(1~3) + 판단메모. AI 요약은 보조, 원문 링크 필수 보존.
  • 03 확인핵심 주장은 2개 이상 소스 교차 검증. AI 단독 요약에는 ⚠ 미검증 표시. 날짜·저자 누락 항목은 보류 처리.
  • 04 보관도구별 역할 분리 저장 (아래 도구 비교 참고). 같은 자료를 여러 곳에 전문 복사 금지 — 링크 참조 원칙.
  • 05 재사용태그·그래프 링크 기반 검색. 주간 리뷰에서 연결 관계 강화. NotebookLM으로 문답 추출.
  • 06 갱신월간 오래된 자료 스캔 (6개월 이상 미확인 항목). 소스 URL 유효성 점검. 새 정보로 교체 또는 아카이브 표시.
도구 비교 — 역할별 분리 원칙
각 도구는 파이프라인의 한 단계만 담당. 모든 도구에 같은 자료를 넣는 건 관리 부담만 늘린다.
Perplexity
역할: 웹 탐색·발견 단계
강점: 실시간 웹, 출처 인용, 범위 넓음, Spaces로 코퍼스 제한 가능
약점: 출처 신뢰도 혼합, 개인 지식베이스 없음, 결과가 일회성
Readwise
역할: 하이라이트 수집·복습 단계
강점: Kindle·웹·PDF 통합, 자동 복습 큐, Obsidian 동기화
약점: 요약이 원문 의존적, 구조화 불가, 별도 연결 없음
Obsidian
역할: 장기 개인 지식베이스·연결 단계
강점: 오프라인, 그래프 링크, 무제한 확장, 2026년부터 공식 CLI 제공
약점: 구조 직접 설계 필요, 초기 러닝커브
NotebookLM
역할: 업로드한 코퍼스 문답·합성 단계
강점: 출처 인용 명확, 자신의 소스만 사용, 신뢰도 제어 가능
약점: 소스 수 제한, 실시간 웹 없음, 외부 업로드 필요
Zotero
역할: 학술 논문·공식 문서 인용 관리
강점: 메타데이터 완벽, 인용 형식화 자동, 브라우저 플러그인
약점: 웹 일반 콘텐츠 약함, UI 구식
agent-wiki 류
역할: 에이전트가 쿼리할 수 있는 공유 지식 공개 단계
강점: SAM/Infinity 에이전트 접근 가능, 구조화된 지식 노출
약점: 수동 관리 필요, 개인 원본과 별도 동기화
"못 믿는 자료" 체크리스트

아래 신호 중 하나라도 있으면 해당 자료를 ⚠ 미검증으로 표시하고 재사용 전 확인:

  • 출처 URL 없음 — AI가 학습 기억에서 생성한 내용일 가능성. 원문 링크 없이는 사실 확인 불가.
  • 단일 소스만 인용 — 교차 검증 없음. 핵심 주장은 2개 이상 독립 소스 필요.
  • 날짜 없음 — 최신성 불명. 기술·통계 자료는 6개월 이상 경과 시 갱신 필요.
  • AI 단독 요약만 있고 원문 없음 — AI 요약은 오류·생략·편향 가능. 원문 링크 필수 보존.
  • 판단 맥락 없음 — 누가, 언제, 왜 수집했는지 모르면 재사용 시 맥락 오해 발생.

소스 신뢰도 3단계

  • T1 (신뢰): 공식 문서, 동료 검토 논문, 직접 실험 결과 — 교차 검증 없이 사용 가능
  • T2 (보통): 전문 미디어, 커뮤니티 정리본, AI 요약+원문 링크 있음 — 핵심 주장만 교차 확인
  • T3 (주의): 소셜 미디어, AI 단독 생성, 단일 익명 출처 — 사용 전 T1/T2로 검증 필수
