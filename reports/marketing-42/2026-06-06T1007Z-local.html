Virtue 세션당 가치 판독표

출시 후 한 세션을 "이벤트 수"가 아니라 잡별 first value 도달과 종료 성격으로 읽도록, 세션 모양을 성공·정상·보류·마찰 네 칸으로 미리 고정한 docs-only 내부 판독표. 짧은 세션·저장 없는 종료·반복 reroll·클릭 많은 세션의 단순판정을 막는다.

01 무엇이 문제였나
Virtue는 prelaunch라 세션 품질을 activation rate·전환율로 산출할 단계가 아닌데, 출시 후 작은 숫자가 들어오면 `deed_judged`·`deed_rerolled`·`deed_saved` 같은 이벤트 수를 곧장 세션 가치로 읽는 오독이 가장 흔하다 — 특히 "짧은 세션=이탈", "reroll 많음=불신", "클릭 많음=engagement 좋음", "저장 없음=실패"처럼. AI 제품에선 fewer actions가 더 빠른 가치일 수도, 많은 행동이 마찰일 수도 있다.
02 어떻게 해결하나
한 세션의 모양(event shape)을 잡별 first value 기준으로 성공 / 정상 / 보류 / 마찰 네 칸으로 읽는 내부 판독표 1장(docs-only)을 확정했다. 세션 점수·임계값·activation rate는 산출하지 않고 "첫 10명 또는 첫 7일 분류 후보"로만 남겼다. 같은 "짧고 저장 없는 세션"이 J3엔 성공·J1엔 보류임을 못박았다.
  1. 이벤트 수≠가치 — 가치는 잡별 first value(J1/J2/J4=deed_saved, J3=deed_judged) 도달로만 읽음(재정의 0)
  2. 짧은 무저장 세션=J3 성공/J1·J2·J4 보류 — drop ≠ end, 막힘 4분류(m31)로 라우팅 후 성격 결정
  3. 반복 reroll=보류(다의적), deed_save_capped=마찰(availability), 다이벤트 무가치=보류/마찰
  4. 코드 diff 0 · 신규 이벤트/속성/tracking/대시보드/카피/임계값/전환율/PQL/가격 0 · 충돌 마커 0
