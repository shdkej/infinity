핵심 발견
  1. YouTube 레퍼런스 파이프라인: Figma stylescape → AI image generation(Magnific/Freepik) → Spline cursor-reactive 3D object → Unicorn Studio atmospheric texture/grain. 도구보다 파이프라인이 핵심.
  2. Sam Samuel 번역: DESIGN.md로 시각 방향 먼저 → 생성형 캐릭터 asset → Spline/R3F interaction → Unicorn Studio 배경 grain. CharacterStage가 공간의 주인, HUD가 그 위에 떠 있음.
  3. Option D(pre-rendered + CSS parallax)가 Status 즉시 적용에 최적: WebM 1-3MB, GPU 없음, LCP poster 보호, 모바일 최고 성능, 반일 구현.
  4. Option B(Spline) + Option C(Unicorn Studio) 조합이 레퍼런스에 가장 근접하지만 외부 런타임 2개 종속 + Spline Pro 셀프호스팅 비용($12-18/월) 발생. prototype 환경 전용 권장.
  5. Option A(R3F)는 장기 제어권 최고(shader, bone, custom material)이나 3-5일 소요. Option B 시각 검증 완료 후 전환 여부 결정 권장.
  6. Reusable skill add-3d-character-stage: mode 입력(spline|r3f|video|auto) → component + CSS tokens + fallback chain + DESIGN.md SpatialPresence 패턴 자동 생성.
