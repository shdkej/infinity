PC·인터넷 시대 전환사

특수 도구에서 일상 인프라로 — 메인프레임 시대에서 스마트폰 세대까지 50년간의 보급사와 사회 인식 전환

01 🔍 무엇을 조사했나
PC가 없던 메인프레임 시대에서 스마트폰 인터넷 시대까지 — 50년간 기술이 어떻게 대중에게 침투하고 사회 인프라가 됐는지 주요 변곡점과 인식 전환 과정
02 📊 핵심 결과
4대 변곡점 제품(Apple II · Macintosh · Mosaic · iPhone)과 각 시대의 킬러 앱(VisiCalc · IE · SNS)이 보급을 이끌었고, 인식은 「해커 장난감 → 비즈니스 도구 → 소비자 제품 → 필수 인프라」로 단계적 전환됐다. 전 세계 인터넷 보급률 1%(1995) → 74%(2025).
주요 변곡점 타임라인
연도사건·제품전환의 의미
1977Apple II취미→소비자 제품. "평범한 사람을 위한 컴퓨터"
1979VisiCalc첫 킬러 앱. PC의 비즈니스 가치 입증
1981IBM PC기업 시장 공인. PC = 정상적인 업무 도구
1984Apple MacintoshGUI + 마우스. 전문 지식 없이도 사용 가능
1991World Wide Web 공개하이퍼텍스트 링크. 정보 공유 시스템 탄생
1993Mosaic 브라우저그래픽 웹 탐색. 인터넷 대중 접근의 진정한 시작
1995Windows 95 + 상업 인터넷 개방PC + 인터넷 대중화 결합. IE 번들로 진입 장벽 제거
1998–2000닷컴 붐인터넷 = 새로운 경제. 미디어·쇼핑 온라인 이동
2003–2005브로드밴드 전환"상시 연결" 시대. 인터넷 = 항상 켜져 있는 것
2007iPhone모바일 인터넷. 인터넷 = 주머니 속 항상 있는 것
2020–2022코로나19 팬데믹원격근무·교육 → 인터넷 = 필수 공공 인프라

시기인식주요 신호
1970s해커의 장난감Apple II 구매자: "이걸로 뭘 하냐?"
1980s비즈니스 도구IBM PC + VisiCalc → 기업 채택
1990s 전반소비자 제품Mac GUI + Windows → 기술 지식 불필요
1995–2000커뮤니케이션 플랫폼이메일·웹·닷컴 붐. "정보 고속도로"
2000s필수 서비스온라인 뱅킹·구글 검색 일상화
2007–2015항상 켜져 있는 것iPhone → 이동 중에도 끊기면 안 되는 것
2015–2025공기처럼 당연한 인프라코로나19 → 인터넷 = 직장·학교·의료 전부
