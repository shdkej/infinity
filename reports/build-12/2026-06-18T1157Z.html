핵심 발견 (MECE — 레이어 / 모션 / 반응형 / 접근성 / 단계 / 검증)
  1. 레이어 분리 — stage z-index:0 / HUD z-index:10. 기존 카드 스타일은 0 수정, 래퍼에 .hud-layer 클래스만 추가해 카드의 backdrop-blur 너머로 프레즌스가 비치게 함.

  3. 반응형 차등 — desktop 78vh+perspective / tablet 54vh / mobile 30vh 중앙 고정·parallax off. "모바일 작고 안정적, 데스크탑 크고 미래지향" 규칙을 코드로 분리.
