Control Center Next.js Supabase CMS

Control Center CMS를 실제 웹에서 데이터를 만들고 고칠 수 있는 Next.js + Supabase CRUD MVP로 배포했다. 공개 주소는 https://cms.oracle.shdkej.com이다.

axis ax1 · 사용자 가치

사용자는 이제 CMS 화면에서 Family Wedding NOTICE 같은 운영 값을 직접 생성, 수정, 삭제할 수 있다. 이번 데이터는 Supabase scratch table에 머물며 실제 공개 페이지 반영은 별도 승인 단계로 남겨 두었다.

axis ax2 · 운영 경계

서비스 키는 Kubernetes Secret에서 server-side route만 사용한다. 브라우저에는 service role key를 노출하지 않는다. production page write, commit/push from UI, deploy button, auth/permission, rollback은 build-08에서 다룬다.
