steel background provenance 정리

재사용 배경 에셋의 필수 provenance를 ignored run 파일이 아니라 tracked asset 경계로 고정했다.

axis ax1 · 문제

asset.json의 source_reference가 ignored system/reports/card-news/runs/ 산출물을 가리켜 깨끗한 checkout에서 재사용 근거가 약해졌다.

axis ax2 · 조치

source_reference를 tracked PNG로 바꾸고, ignored run은 generation_log_reference로 낮췄다. 스킬 문서에도 tracked provenance 규칙을 추가했다.

검증
  • python3 -m json.tool 통과
  • asset.json과 PNG는 git tracked
  • ignored run 파일은 필수 source reference에서 제거
