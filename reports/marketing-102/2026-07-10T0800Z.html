Virtue D7 재가치 관찰 게이트 정렬

기존 activation 관찰표(marketing-79/98)와 후보 레지스트리(marketing-101)를 대조해 D7 재가치 판단 게이트를 1장으로 고정한 결과.

01 무엇이 문제였나
prelaunch 소표본에서 activation 신호와 D7 재가치 신호가 같은 관찰 표면에 섞이면, 첫 세션의 “첫 가치처럼 보인 행동”을 D7 리텐션 예측으로 과대해석할 위험이 있다. 기존 관찰표에 D7 체크포인트, same-job 유지 질문, add_flow_started 금지선이 없었다.
02 어떻게 해결하나
J1-J4별 D7 재가치 질문, same-job 유지 판정 기준, second value evidence, add_flow_started 금지선을 1장 게이트로 고정했다. 기존 관찰표 구조는 그대로 두고, 이 표를 D7 관찰 시점에 붙여 쓴다.
핵심 발견 · 판정 내용
핵심 발견
  1. 기존 관찰표는 activation gate(D1까지)에는 충분하지만 D7 레이어가 없다 — D7 체크포인트, same-job 질문, second value 칸, add_flow_started 금지선 모두 미존재.
  2. J3(AI 호기심형)는 D7에도 저장 없이 재방문할 수 있다 — deed_judged가 다시 일어나면 same-job 유지. “저장 없으면 실패” 독해 금지.
  3. add_flow_started는 activation에서도, D7 재가치에서도 성공 신호가 아니다 — /add 진입만으로는 잡별 재가치를 판단할 수 없다.
  4. 잡이 D1→D7 사이에 전환되면 same-job 유지 불가 — 잡 전환 자체는 별도 메모 항목.
  5. marketing-101 A1-A4 후보 레지스트리와 충돌 없음 — D7 게이트는 activation 정의를 바꾸지 않고 그 이후 레이어를 추가한다.
이 게이트를 쓰면 PostHog 수치 해석 시 “첫 세션에 가치처럼 보인 행동”과 “D7에도 같은 잡으로 돌아온 행동”을 분리할 수 있고, 사후선택 위험이 줄어든다.
marketing-101 충돌 검증
  • D7 재가치 질문은 marketing-101의 activation 정의(J1/J2/J4=deed_saved, J3=deed_judged)를 변경하지 않는다.
  • same-job 유지 기준은 first verification gate와 독립 작동 — 첫 세션 판정에 소급 없음.
  • second value evidence는 marketing-101 bundle · window 항목을 D7 시점으로 좁힌 것 — 중복 확장 없음.
수행 작업 · 산출물
  • 기존 관찰표(marketing-79/98)와 activation registry(marketing-101)를 대조해 D7 레이어 공백 확인
  • J1-J4별 D7 재가치 질문, same-job 유지 판정, second value evidence를 잡별로 정리
  • add_flow_started 금지선 명시 (activation 및 D7 모두 적용)
  • marketing-101 A1-A4 충돌 없음 검증
