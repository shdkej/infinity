Virtue D7 재가치 관찰 게이트

첫 가치처럼 보인 행동과 다시 올 이유가 남은 행동을 분리하기 위해, 기존 관찰표와 activation 후보 등록부를 대조했다.

01 무엇이 문제였나
`marketing-79`와 `marketing-101`은 first value 기준은 맞지만, D7에서 same-job 유지 여부와 second value evidence를 한 행에 남기는 칸이 아직 명시적이지 않았다.
02 어떻게 해결하나
신규 계측 없이 D7 손기록 4칸을 붙인다. J1/J2/J4는 `deed_saved`, J3는 `deed_judged` 기준을 유지하고, `add_flow_started`는 성공 지표로 보지 않는다.
  1. D7 return reason, same job, second value evidence, no-read를 분리한다.
  2. J3의 저장 없는 종료와 재방문은 저장 전환이 아니라 AI 관점 재가치로 읽는다.
  3. D7 미방문, cap, 503, latency는 retention 실패나 upgrade demand로 환산하지 않는다.
핵심 내용 · 리서치 본문
핵심 발견
  1. `marketing-79`는 D1 재방문과 세션 성격 분류까지는 충분하지만 D7 second value 칸이 없다.
  2. `marketing-101`의 A1-A4 후보는 D7 언어를 암시하나, 관찰자가 그대로 복사해 쓸 질문 형태는 아니다.
  3. D7은 retention%가 아니라 "같은 잡으로 다시 가치가 생겼는가"를 묻는 정성 게이트가 맞다.
  4. `add_flow_started`는 의도/탐색 신호다. activation 성공이나 재가치 증거로 승격하면 첫 행동과 첫 가치를 섞게 된다.
결론: activation 후보를 새로 늘리지 않고, 기존 첫 10-20명 손기록에 D7 return reason, same job, second value evidence, no-read 칸만 덧붙인다.
근거 · 소스

`marketing-79` 관찰표, `marketing-101` activation 후보 등록부, 2026-05-27 retention-predictive activation 외부 노트를 대조했다.

다음 판단

실제 첫 10-20명 기록 후 D7 칸이 비어 있거나 중복된다면 관찰표 artifact를 직접 개정하는 후속 intent를 열 수 있다.
