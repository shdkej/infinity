## 핵심 개념

### Userpilot — Agentic PLG

Agentic PLG: AI 에이전트가 제품을 발견·평가·활성화하는 PLG 진화형. 에이전트가 API 문서, MCP 표면, 구조화된 콘텐츠를 읽어 task completion 첫 가치를 만든다.

**Context moat**: PLG에서 경쟁 장벽은 기능 우위가 아니라 에이전트가 제품 의미를 정확히 읽는 문맥 정의에서 나온다. 문맥 미정의 제품은 에이전트가 잘못 추천하거나 wrong use-case로 활성화한다.

**Virtue 적용 한계**: Virtue는 task-completion 제품이 아닌 사람 경험·선택 본체 제품이다. agent-for-you 유통은 no-fit (marketing-46). 단, agent-readable 문맥 정의는 launch-ready 자산 — 에이전트가 Virtue를 "AI 채점 도구"·"productivity tracker"로 오독하지 않도록 J1-J4 문맥 경계를 내부에서 먼저 고정한다.

### Mixpanel — PLG 2026

핵심: "Intent signal clarity" — first session 의도가 명확할수록 D7 retention이 높다. PLG 2026은 이벤트 수가 아닌 "사용자가 원하던 것을 얻었는가"가 핵심.

프레임: first session을 "context window"로 읽기 — context before (사용자가 가져온 것) → first output (AI/제품 산출) → context after (직후 반응)가 세트다.

**Virtue 적용**: J1-J4별로 이 세 맥락이 다르다. 단일 프레임으로 묶으면 J3 정상 종료가 J1 이탈처럼 보인다. Context Map은 에이전트와 관찰자가 동일한 의도 언어를 쓰도록 기준을 고정한다.
