## Concepts Referenced

**PLG Foundation → Activation → Conversion sequence**
- Foundation ends when "can we measure activation?" is YES, not when activation is good
- Measurement readiness is a separate gate from measurement value

**First Win (Activation)**
- First meaningful value delivered to user
- Virtue: J1/J2/J4 = deed_saved; J3 = deed_judged
- Not a conversion signal by itself

**PQL (Product Qualified Lead)**
- A bundle behavior: repeated first-value events + D7 revisit
- NOT a single event (deed_save_capped, deed_rerolled, single deed_judged)
- Post-launch gate, not prelaunch signal

**Prelaunch Signal Discipline**
- Signal = directional learning material, not confirmation
- Small sample (n<10): read language, not rates
- Separate: human real use / self-test / synthetic / mock before reading anything
