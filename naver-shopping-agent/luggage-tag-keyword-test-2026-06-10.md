## Privacy Risk Assessment

Traditional name+address tag: REAL RISK
- Confirms house is empty while traveling
- Name/address visible to baggage handlers, strangers

Mitigation options (no user approval needed):
1. **Nickname-only** — zero address exposure, most user-friendly
2. **Email/phone only** — standard, acceptable
3. **QR code (dynamic)** — tech-forward but complex for first SKU
4. **Visual-only identity** — pattern/emoji, no personal data

**RECOMMENDATION:** Nickname + visual marker design.
