# marketing-47: Virtue 첫 10명 design-user ask script

- Source note: `/home/ubuntu/workspace/knowledge-lab/source/external-links/marketing/2026-06-08-founder-led-first-users.md`
- Rationale: Virtue는 아직 prelaunch라 확장 채널보다 첫 사용자 학습 루프가 먼저다. 첫 10명에게 공개 발송하기 전에 잡별 초대 문장, 사용 전 질문, 첫 세션 후 질문, 승인 경계를 문서화하면 작은 표본을 성패 수치가 아니라 문제 언어와 첫 가치 신호로 읽을 수 있다.
- Expected impact: 첫 사용자 대화에서 반복되는 고객 언어, 첫 가치 순간, 결정-위임 오해, 부담 신호를 더 일관되게 수집한다. 공개 모집이나 광고 없이 출시 전 포지셔닝/온보딩 후보의 근거를 늘린다.
- Permission level: L2 docs-only. 실제 초대 발송, 공개 포스팅, 외부 DM, 광고, 프로덕션 카피/계측/배포 변경은 approval-needed.
- Owner route: Infinity router -> Claude Code 또는 local docs executor.
- Success criteria: Virtue repo 또는 Infinity artifact에 내부용 ask script 1개를 남긴다. 문서는 J1 기록형, J2 누적형, J3 AI 호기심형, J4 회고형별 초대 문장 후보와 사용 전 2문항, 첫 세션 후 3문항, "사용자가 자기 말로 설명한 Virtue" 기록 칸, 승인 필요선을 포함한다.
- First verification gate: 외부 발송/공개 카피/신규 이벤트/속성/tracking/privacy/dashboard/session replay/배포/비용 변경 없이 docs-only diff인지 확인한다. 기존 `first-real-user-baseline-template`, `first-60-second-value-observation-script`, `ai-promise-decision-control-audit-table`과 충돌하지 않아야 한다.
