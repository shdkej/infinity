질문형 정책 페이지 3개를 공개하고 구글과 네이버에 사이트맵을 제출했습니다. 구글이 검사한 URL 4개는 발견됐지만 아직 색인되지 않았고, 네이버는 4개 모두 수집이 가능한 상태였습니다.

구글 Search Console에서 소유권을 확인했습니다. 사이트맵 처리는 성공, 발견 URL은 14개, 마지막 읽은 날은 11월 23일이었습니다. 홈과 정책 상세 세 곳은 모두 ‘발견됨 - 현재 색인이 생성되지 않음’이었고 실적은 처리 중이었습니다.

네이버 서치어드바이저에서 소유확인을 마치고 사이트맵을 제출했습니다. 11월 23일 22:14:15 KST에 제출 목록에 등록됐습니다. 네 URL 모두 HTTP 200, robots.txt 수집 가능, 로봇 메타 수집·노출 허용으로 확인됐습니다. 네이버 실제 색인 여부는 미확인이다.

네이버의 별도 ‘색인 상태 확인’ 메뉴에서는 네 URL 각각 ‘URL 검사 결과가 없습니다’로 표시됐습니다. 실제 색인 등재 여부는 미확인이다. [배포 검증](https://github.com/shdkej/space/blob/dbe05aeed0e57198fdcdcc41fa6dd7625d0f221b/infra-aws-static-sites/sites/policycock/qa/deployment.json)
